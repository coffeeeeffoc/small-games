# H5 与 Cocos 局部对齐 · 2026-10-19

本轮沿用已有横竖屏和美术，不改变关卡规则。围捕与街区局部对齐现有页面；象棋增加与 H5 对应的玩法准备与重开确认页。Cocos 继续使用离屏 Canvas 与现有桥接层。

## 设计映射

- 围捕小队沿用 [2026-10-18 保安造型确认稿](../../../local/cops-robbers/docs/design/security-guards-2026-10-18/README.md)、[首页实测](../../../local/cops-robbers/docs/design/home-polish-2026-10-18/README.md)及[接力选中反馈](../../../local/cops-robbers/docs/design/selection-2026-10-07/verification.md)。保持花园、奶油按钮、青绿选中环；统一菜单名称、同关续局、三星标准、拖动和当前局面提示。
- 街区追捕沿用 [手机页面设计](../../../local/cops-robbers-realtime/docs/design/mobile-2026-10-05/README.md)与[首页局部调整](../../../local/cops-robbers-realtime/docs/design/home-polish-2026-10-18/README.md)。保留现有横屏原生布局；头像页在现有两列三行位置展示 H5 的六个角色预设，场内头像读取同一裁剪数据。拖队员到道路发令，拖回原点、多指、取消和切页不发令。辅助成绩与普通成绩分别呈现。
- 原生宿主不显示浏览器全屏入口。支援关闭广告时直接补领，开启时仍由现有广告接口确认完成；补领后需要玩家再次点击才消耗。
- 街区第二轮局部对齐以已批准的 [玩具小镇效果图](../../../local/cops-robbers-realtime/docs/design/cartoon-refresh-2026-10-05/concept.png)及 [首页确认稿](../../../local/cops-robbers-realtime/docs/design/home-polish-2026-10-18/concept.png)为依据：保持原生左右首页、选关和底部操作位置，改用 H5 奶油底、蓝色主操作、橙色支援及圆角 HUD；首页展示当前预设角色。地图直接复用 H5 的纯 Canvas 树木、房屋、花坛、长椅与道路绘制，不复制布局或引入 DOM。仅在独立离屏画布可用时缓存背景，不能将桥接后的 `sdk.createCanvas()` 当作缓存画布。

## 资源与验证约定

运行头像是既有 `src/assets/characters.png` 的部署编码，保留尺寸、透明通道与角色造型；具体命令、源与输出摘要见验证记录。只有 Cocos 的 `visualAssets.portraits` 配置请求新资源；旧原生入口保留既有回退。

## 图集部署编码

源：`games/local/cops-robbers-realtime/src/assets/characters.png`；输出：同目录 `characters-native.webp`。两张均为 1280×1280，保持透明与原裁剪坐标，查看原图及输出后未发现造型或裁剪变化。输出 402,518 字节，构建复制为 `street-characters.webp`；源码身份同时包含原 PNG 和输出 WebP。

```sh
magick games/local/cops-robbers-realtime/src/assets/characters.png -quality 92 -define webp:alpha-quality=100 games/local/cops-robbers-realtime/src/assets/characters-native.webp
```

SHA-256：原 PNG `8b3acea185d3275257964a4844ae8f80252029ba4eece18fab42f3af2ed9d200`；WebP `965783dd3aff4bdd86077d5cf316b2bbd80f789e38032fce9ab0ad8b859cc6a0`。原图更新时须重新编码、复核并更新摘要；不把旧编码自动当作新美术。最终原生主包大小仍须检查实际 Creator 产物。
