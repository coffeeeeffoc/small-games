# 窄门与机关 · 2026-10-23

本轮保留竖屏拖板救援、六人全救目标、30 个稳定关卡 ID、旧存档和既有入口。问题是第 7 关起重复前六关模板；本轮将后 24 关改为有明确路线目标的机关关，保留前六关入门。

## 设计

- 装甲砖需要 4–8 次撞击，显示剩余次数、分层刻度和裂纹。既可耐心凿穿，也可寻找绕路或爆破开关。
- 钢墙构成口袋房、双塔、错层通道和中央井，开口净宽 30–42 逻辑像素；球直径 14，要求控制角度但可反复尝试。不可破坏钢墙与橙色装甲材质分离。
- 分球器：命中一次放出两颗额外球，场上最多三球；全部掉落才扣一次机会。装置耗尽会熄灭，不可刷无限球。多球破笼仍按落地时间错开释放，保留接人决策。
- 开闸器：撞击后永久打开同标记闸门，改变路线；爆破器：冲击附近装甲两层，不直接开笼。两者均显示图形符号、触发状态和局部反馈。
- 关卡顺序先单机制，再组合装甲、狭缝和支援角色。选关预览显示真实钢墙、门和机关，发球前一句话说明当前路线。
- 月牙用实际月牙轮廓绘制，月亮内侧保留原天空，去掉深色圆遮罩。

## 实现边界

本次沿用现有 Canvas 渲染和纯 JS 确定性模拟。整体引擎迁移会扩大本次关卡/机制改造的范围，并牵动后端回放与现有平台入口；本轮复用现有入口、公共 Host、音频/无障碍/减弱动态设置。未进行 Cocos 迁移。新增机制为独立配置，不在模拟中按关卡 ID 分支。排行榜规则版本同步升级，旧规则成绩不混入新规则。

`concept.svg` 是实现前的手机比例局部设计稿，沿用现有首页与菜单风格；新增布局重点是装甲、窄门机关室和开启闸门的可见变化。实际截图和测试记录将在验收后补充。桌面触屏模拟不代表手机真机或原生小游戏验收。
