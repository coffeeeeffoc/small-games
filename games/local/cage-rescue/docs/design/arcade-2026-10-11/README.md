# 全员救援与街机画面调整

## 方案

保持现有 390 × 700 竖屏场地、六关阵形与一指拖动挡板的操作。每关必须击破所有笼子并接住全部队友才通关；目标人数由关卡笼子数量决定。漏接仍由安全网承接并离场，因此一人漏接即无法完成本关。三次球机会、错峰释放和救援缓降沿用现有规则；只在全员仍可救回时允许广告补球。

计数、选关、帮助、发球提示、开发试玩和结算全部使用全员目标。保留原存档已获得的关卡与装扮解锁，新通关记录必须满足全员救援。

## 视觉

先生成手机比例三联效果图 `concept.png`，覆盖主页、游玩、选关，再调整渲染。保留夜间工地、橙黄救援队员与青绿笼架的主题，将其强化为卡通街机：深色厚描边、明亮倒角、实体金属笼架、圆润大头角色、工业斜纹挡板、星形命中特效和救援印章。弱化坐标网格，用月亮、远处城市、吊索和工地轮廓建立场景。

主页突出立体标题和救援插画；选关以任务牌与阵形缩略图表达进度；游玩只保留关卡、全员救援计数、球机会和暂停。顶部用六枚队员标记提示全员目标。主要按钮至少保留 44 CSS px 热区；暂停继续使用两根等高等宽的实心竖条。所有变更适配现有三个装扮配色，减少动态效果时停用运动特效。

## 验收

- 四人、五人救回均继续游玩，最后一人接住才结算、解锁下一关。
- 漏接一人失败，且不允许补球挽回；仍可通过免费重试继续。
- 六关通过正常挡板输入可完成全员救援；无修改状态或续命。
- 旧存档解锁保留，未达到全员目标的新结果不能保存为通关。
- Chromium 手机视口与触屏检查主页、选关、发球、拖动与取消、暂停恢复、胜负结算及返回；截图与效果图对照。
- 构建及仓库增量候选验证通过后，正常推送到 `dev`，记录准确 base/head 与线上检查状态。

## 连续游玩性能修复

用户反馈 Chrome 电脑、手机连续游玩几关后整页卡住。源码检查显示 Shell 同时只挂载当前游戏，目录登记不会启动全部游戏。规则固定步长、粒子寿命、轨迹数量和音频节点均有边界，未发现可复现的死循环。

可测得的问题是每一帧都重建全场景，暂停、结算、选关及其他菜单也持续绘制。渲染现在为当前场景复用一张离屏位图，只有关卡、皮肤、尺寸或对象受损时更新；球、挡板、下落队友和短命中特效仍动态绘制。静止页面停止 RAF，后台取消已挂起帧；返回保持暂停，显式继续后重新运行。相同尺寸不重建画布，退出释放位图及提示定时器。

`performance-samples.json` 记录 Linux Chromium 151、390 × 844、DPR 2、4 倍 CPU 降速下的各 3 秒采样。基线是本轮新画面在性能修复前的版本，不能当作线上卡死现场：暂停时创建 1,080 个渐变，优化后为 0；对应任务耗时从约 3.07 秒降至 0.007 秒。优化后的准备、暂停、选关采样均未出现超过 50 ms 的长任务。

新增回归检查暂停/菜单/结算停画、尺寸变化重绘、后台恢复、dispose 释放，以及电脑鼠标和手机触屏视口各连续两遍六关的正常输入和垃圾回收后资源数量。实际 Shell 专项使用真实时间、4 倍 CPU 降速检查连续两关及反复进入/退出，确认单 iframe、旧文档卸载、资源数量及不加载其他游戏。最终结果补充于下方验收记录。未在用户设备上复现整页停止响应，因此不能保证覆盖所有可能根因；没有声称已做真机测试。

## 验收记录

- Node 24.21.0、pnpm 12.6.0、Linux Chromium 151.0.7922.173。
- `pnpm --filter @coffeeeeffoc/cage-rescue test`：37 项通过；包含六关全员可达、四/五人不结算、漏接失败、旧存档解锁和新记录校验。
- `PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/chromium pnpm --filter @coffeeeeffoc/cage-rescue test:browser`：12 组通过、页面/资源错误 0；包含缓存后每帧仅 3 个动态渐变、静止页面 0 次持续重绘、缩放、后台恢复和退出释放。广告奖励与 Pixel 7 触屏事件专项通过。见 `browser-report.json`。
- `CAGE_RESCUE_TEST_MATCH=continuous node games/local/cage-rescue/tests/browser.mjs`：电脑鼠标和手机触屏视口各连续两遍六关、共 24 局全部通过，无状态编辑或补球。使用浏览器加速 RAF，分别约 486.6 和 488.5 秒模拟游玩；不是等时真机游玩。第二遍后垃圾回收 JS heap 相比第一遍增加约 0.12 MB，活动离屏缓存与选关预览合计不超过 7 张。见 `continuous-report.json`。
- `PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/chromium node games/local/cage-rescue/tests/shell-performance.mjs`：实际生产 Shell、DPR 2、4 倍 CPU 降速，电脑鼠标与手机触屏各连续两关正常全员通关；使用真实时间 RAF。两端各 8 次进入/退出，全部卸载 iframe，旧文档数量和垃圾回收后的 JS heap 在检查范围内；未请求其他独立游戏或内置游戏动态模块，页面错误 0。见 `shell-performance.json`。Shell 源码与此次合并的远端版本一致；专项构建只复制本游戏与开发模式所需乌龙城制品，没有准备完整目录的游戏包。
