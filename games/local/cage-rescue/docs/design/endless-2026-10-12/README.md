# 30 关、无尽模式与排行榜

沿用夜间救援的竖屏、安全区与原色板。`concept.svg` 是本次实现前的四页矢量设计稿，覆盖主页、滚动选关、无尽 HUD、独立排行榜页面；不是实际运行截图。按钮保持至少 44 CSS px。

战役保留旧关 ID 与布局，扩展至 30 关，逐步提高路线/布局与操作要求。无尽玩法不改变战役进度，难度封顶而挑战长度不限。首页直接进入无尽；排行榜支持闯关、无尽两个类型并展示身份/连接状态，离线不阻断本地玩法。

验收：旧档恢复、正常解锁、30 关可达、无尽跨波/跨段、暂停及返回、触屏与取消、排行榜切换与离线重试。生产截图和实际验证由运行校验阶段补充。

## 章节机制追加设计
