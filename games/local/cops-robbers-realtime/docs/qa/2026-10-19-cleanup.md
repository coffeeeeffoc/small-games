# 2026-10-19 目录整理与生命周期验证

基于 `dev 96315a0a` 的工作区修改；本文不是最终提交 SHA 的发布证明。环境：Linux、Node 24.21.0、pnpm 12.6.0、Playwright Chromium，手机尺寸及触屏模拟，非实体设备。

## 变更

- 练习保留正式局的角色位置、路线、计时 tick、命令日志、开局票据、支援及战术试炼提示；退出后显示原局暂停页，明确继续后回到游戏画面。
- 导航离开使排队中的开局失效，Web Locks 释放后不会在准备页后台计时或消耗新手次数。
- 删除 11 个依赖已移除 UI 的旧浏览器脚本及重复 npm 锁。保留服务端规则引用、关卡见证、原生入口、公共同步副本、历史设计和营销证据。
- 浏览器报告改写入忽略目录 `outputs/browser/`，`OUTPUT_DIR` 可指定输出根目录；截图等待有限动画结束。
- 生产广告配置检查不再写死广告位：关闭广告验证免费补领且不调用 SDK；广告开启时核对配置广告位。独立 host 夹具仍检查完整观看、取消、失败、后台、次数边界和无配置不可用行为。
- 安全区首页断言采用已认可的左侧 cutout 避让，并检查与右侧胶囊不相交。修复 568×320 横屏失败页按钮越过底部安全区：分享移到插画下方，与重试/回溯同排；短屏压缩统计留白、标题和插画，保留 44px 热区。
