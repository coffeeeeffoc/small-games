# 玩具小镇视觉改版

先生成 [三屏效果图](concept.png)，再实施首页、准备页、游戏页。效果图为视觉方向参考；实现沿用现有角色与街区资产、四种玩法及真实道路图，不采用效果图中虚构的玩法名。

- 蓝天、奶油色与糖果蓝构成主色，橙色对应小偷，薄荷绿对应地图与榜单。
- 首页增加角色对话气泡、立体操作卡片。设置齿轮置于右上角，声音、全屏移入独立设置页。
- 准备页采用彩色双列玩法卡片、选中勾和立体边框，保留可滚动内容及固定开始按钮。
- 桌面首页采用场景与操作双列布局；竖屏与桌面为底部队员栏预留高度，矮屏横屏使用右侧队员栏，地图在可用区域居中，修复横屏错误扣除队员栏宽度的问题。
- 不改变核心规则、服务端协议和关卡数据；装饰避开实时操作道路。

验证使用 Chromium 触屏模拟，覆盖 320×740、390×844、844×390、1680×893；未进行物理手机验证。

## 验证

- 游戏单元测试：35/35 通过；构建通过。
- 开发者模式同步检查：49 个游戏、0 问题；开发者模式单元测试：5/5 通过。由于工作区缺失 `tidebreak` 包，`pnpm` 自动安装失败，改为直接执行同一 npm script 对应的 Node 命令。
- 构建产物触屏回归：四种尺寸的设置页、浏览器返回、声音持久化、全屏进入/退出、地图居中与队员栏避让、44px 控件、道路下令、手势取消、暂停/继续/返回首页通过。
- 独立及 iframe 手机尺寸下：URL、存储、默认关闭、显式关闭四种开发者开关通过；iframe 触屏下令与手势取消通过。
