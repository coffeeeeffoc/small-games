# 街区追捕：回溯、冲刺与 TapTap H5 接入

日期：2026-10-13。保留现有卡通街区、警察/小偷身份、全部单机模式和触屏指挥。

## 规则

- 实际开始一局才消耗新手赠送资格；重试计新局，选关、刷新准备页、暂停恢复和独立合作练习不计新局。本机累计跨刷新保存，旧存档从第 1 局开始。
- 第 1–5 局各赠回溯和冲刺 1 次。每局每种能力还可在赠送次数用完后通过激励广告补 1 次；第 6 局起不赠送，每种能力可通过广告获得 1 次。
- 冲刺对当前选中的可行动角色生效，移动速度提升 20%，持续 4 秒。玩家仍自己选人、下令和封路；不改变抓捕/逃脱判定、身体阻挡和指挥轮换。暂停时持续时间也暂停；生效期间不叠加。
- 冲刺入口常驻游玩画面的控件区。无次数时点击即申请广告，先冻结角色、局内时间和能力时间；完整观看后领取 1 次，玩家明确点击使用并继续。提前关闭、失败或缺 provider 不消耗补领资格、不发奖励，正常玩法可继续。
- 回溯入口位于失败页，恢复约 5 秒前（不足 5 秒回到开局）的完整规则状态：双方位置/路线、抓捕与逃脱进度、AI 状态、轮换命令、随机种子和局内时间。失败页重试始终免费。回溯不恢复能力次数，旧时间线上的快照在恢复后丢弃。
- 使用任一能力即属于辅助通关，辅助最佳独立保存，不覆盖普通最佳；完成标记和下一关保持可用。练习不领取能力和不计纪录。

## 页面与视觉

- 沿用当前手机布局与方向投影；原生宿主仍横屏，H5 保持全屏及触控映射。
- 首页暂隐藏好友 PK、全站榜及需域名的相关入口；保留开始、装扮、手册。准备/结算去掉服务器纪录和上传操作，同时停止后台网络请求及邀请自动进入。
- 游玩控件区增加橙色冲刺按钮，明确次数、广告补领或剩余秒数；与选人、守住和暂停控件保持至少约 44 CSS px 热区。
- 失败页添加次级回溯按钮，保留免费重试主操作；支援页显示获得/取消/不可用状态，明确继续动作。
- 先生成首页、游玩、失败和支援状态的手机比例效果图；实现后保存实际截图对照。

## 接入与影响范围

- 复用 H5 publishing 与原生 host 的奖励结果 completed/dismissed/unavailable/failed；TapTap H5 按官方 SDK 适配，无真实宿主时明确不可用，模拟广告仅显式测试启用。
- 游戏自有支援模块负责次数、快照和奖励消费；engine 仅扩展单角色移动倍率；Web/native 两个入口共用规则。保留现有成绩服务与 PK 代码，当前入口不启用。
- 影响入口 main.js/native.js、engine.js、HTML/CSS、两个渲染器、生产构建/开发服务器、规则/触屏测试、Shell 专属语义断言、TapTap 包与说明；不改其他游戏业务和共享广告实现。

## 验收

- 规则验证第 1/5/6 局、重试/恢复/练习计数、完整回溯、消费不回滚、单角色实际提速、倍率结束/暂停、角色身份与真实胜负、取消/失败/迟到奖励及存档兼容。
- 生产浏览器以 320×740、390×844、844×390（含触屏）走通首页、选关、游玩、冲刺、广告冻结/取消/完成、失败回溯、暂停恢复、辅助结算和刷新计数；断言无成绩/PK网络请求，保留开发模式和全屏行为。
- TapTap H5 上传目录含 index.html，附带 ZIP 遵循官方实现的 dist/index.html 目录形态；验证相对资源、ZIP/dist 完全一致及 SHA-256，记录真实 SDK、实体设备、上传审核未完成的边界。
- 完成相关检查后提交，按准确 base/head 验证并正常推送 dev，分别核实远端提交和云端发布。
