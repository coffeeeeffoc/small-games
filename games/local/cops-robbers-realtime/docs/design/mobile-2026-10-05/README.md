- [补充页面效果图](secondary-pages.png)：街区地图、好友房间、暂停、成功结算、失败结算、昵称与邀请。
- [六位角色素材](../../../src/assets/characters.png)：阳光巡警、机灵警花、暖心警长、街头小机灵、橘子少女、眼镜智多星。

视觉使用奶油色底、深蓝文字、蓝色警察与橙色小偷、圆润卡片及有厚度的按钮。角色采用接近真实制服和衣物的可爱卡通人像。设计图中的金币、等级、示例成绩和锁定关卡仅为视觉示意；代码只显示真实进度、真实服务端成绩，继续开放所有关卡。

## 页面与交互

首页的开始游戏进入准备页。准备页直接选择阵营、玩法、先手和指挥方式；点关卡卡片进入街区地图，选好后回到准备页。四种玩法和现有关卡引擎保持一致。

好友 PK 分为大厅、创建、加入、房间、实战、结果、昵称、邀请、规则和全站积分榜页面。单人通关榜单独按当前配置查看，支持左右切换关卡和进入好友积分榜。房间创建、加入、角色交换、准备、轮询、指令、重连与成绩仍由原有服务端确认。

选关、暂停、结算、操作手册、分享和装扮均采用整页切换，使用滑入动效；入口有轻微呼吸、角色摆动和按压反馈。系统“减少动态效果”开启时关闭装饰动效。设置使用卡片与分段按钮，头像上传通过相机卡片打开系统文件选择器。

头像预设与自定义图片仅保存在本机；SVG、单人 Canvas 和好友赛 Canvas 读取同一套素材与设置。头像上传支持 PNG、JPG、WebP、GIF，最大 8 MB，解码后缩为 128 像素。原生小游戏保留无 DOM / Path2D 的矢量回退。

H5 首页与页面在手机竖屏保持自然方向。实战将街区世界坐标投影为纵向布局，角色、编号与出口提示保持直立；横屏保留横向地图。引擎仍使用原世界坐标，显示与触点互逆。底部编号头像便于点选重叠队员，“守住”按钮适合拇指操作；地图、点选、拖动与取消仍是直接操作。

## 验证

`pnpm test:browser`（亦可 `pnpm test:mobile-pages`）使用 Chromium 触屏模拟，覆盖 320×740、390×844、844×390。`GAME_URL` 指向带 competition.js 的构建和实际测试 API；本次实际路由、store、规则与持久化 PGlite 组成的本地测试服务为 `http://127.0.0.1:43705`。脚本输出截图及 `artifacts/mobile-pages/report.json`。

真实触摸检查包括角色选中、道路下令、短场胜利、服务端重放保存、纪录读取、头像预设/上传/重开、暂停/恢复、手势取消；两个独立浏览器身份检查昵称、房间、角色交换、准备、双方指令和积分榜。独立页面与 iframe 验证开发者模式开关。

具体执行结果和实际页面截图见 [验证记录](verification.md)。浏览器触屏模拟及本地数据库不等同于物理手机、线上数据库或小游戏平台登录/分享验收。
