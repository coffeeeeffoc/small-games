# 街区追捕：横屏与页面分工

先生成 [首页效果图](home-mockup.png)，再实现。效果图与首页街区插画使用内置 imagegen 生成。

设计提示词：16:9 中文游戏首页；奶油纸色、深绿文字、蓝色警察与橙色小偷；左侧大标题和开始按钮，右侧卡通街区追捕插画；底部仅好友 PK、全站榜、角色头像、玩法说明；右上角声音与 Web 全屏。插画单独生成，不把图片里的文字当真实按钮。

页面分工：

- 首页：进入游戏、好友 PK、通关榜及好友积分榜、全局警察/小偷头像、说明与提示。
- 选关：街区分页、关卡预览、模式/角色/先手/指挥规则、本人最佳、同配置服务器最快、开始。
- 游戏：场景内点角色、点道路；点击已选角色原地停下。只留回首页、计时、抓获数、暂停及 Web 全屏；退出/重试/选关在暂停和结算面板。
- 说明：操作规则、本关提示、练习入口，集中在首页查看。

横屏：H5 竖屏视口旋转整个页面和模态框，Canvas 按布局尺寸绘制并对触点做逆变换；原生包配置 landscape。Web 不承诺突破操作系统旋转锁，而是让内容始终横向显示。

成绩：继续读取旧的个人纪录；新纪录按模式、角色、关卡、指挥规则及先手分开。上传固定 60 Hz 的操作序列，服务端使用相同引擎重放、确认胜利并计算时间，复用 PostgreSQL competition_best/results。服务器故障时保留个人纪录并提供重试，不能用本地成绩填充全站最快。

验证：引擎回归、服务端重放与输入拒绝、真实 HTTP/数据库持久化、390×844 和 844×390 触屏、320×740、小窗口桌面、手势取消、头像保存、模态框横屏、Web 全屏、原生构建。浏览器模拟与原生包构建不等同于手机真机验收。
