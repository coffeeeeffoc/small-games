# 别跑！街区围捕

48 关实时协作围捕小游戏，每关有 2～6 个连通环路和 2～4 个出口。点选警察，再点击道路位置；小偷主动寻找未封锁的出口。先截断逃生路线，再靠近收网；全部抓获才能过关，逃掉一个就失败。

## 启动

需要 Node.js 20 或更新版本。游戏运行不依赖第三方库。

```sh
npm install
npm run dev
```

打开 <http://127.0.0.1:43690>。开发服务器只监听本机回环地址，避免与其他项目的监听地址发生混淆；可用 `PORT` 环境变量换端口。

## 操作

- 点角色或编号头像选警察，再点道路；也可从警察拖向目标，松手下令。
- 鼠标在空地是箭头，道路上为指示手；悬停警察显示抓取手形与蓝色高亮，拖动时握紧；悬停小偷显示目标指针与橙色高亮，点击命令警察前往其当前位置。
- 途中点击新目标会立即改道；到达后原地留守，不自动追人。
- 点击“原地守住”取消当前行进命令。点建筑不会覆盖原命令。
- 警察和小偷都不能穿墙，小偷不能穿过警察；友军可以通过彼此。
- 每关有橙色逃脱口。小偷到达后翻越 1.2 秒便会逃走，出口旁会显示倒数和危险提示；及时封口或围住小偷可以打断翻越。暂停不累计逃脱时间。
- 开局先安排出口守卫，再派机动警察包抄。堵住一个出口后，小偷会寻找其他出口或绕行路线，不会只在地图内无目的兜圈。
- 先分头封住逃生岔路，再派人推进；7 个换防关还留有内圈回路，必须看准时机移动守卫。守卫撤离也会给小偷留下逃跑机会。单警只能拦路，堵进死巷也不能独自抓获。
- 至少两名警察在沿路 136 单位内协作，并将小偷能到达的全部退路压入沿路 68 单位抓捕范围，持续 0.8 秒才算抓获。远处守卫不能代替近身夹击。
- 选人、查看路线、下令时游戏继续。打开暂停、选关、帮助时暂停，暂停期间不能布置命令。
- 数字 `1`–`5` 选警察，方向键选择相邻路口，`Enter` 下令，`H` 留守，`Esc` / `P` 暂停。

横屏手机优先；竖屏仍可操作。支持静音、浏览器提供的全屏、降低装饰动画、页面离开暂停和浏览器返回缓存恢复。

## 已实现

48 张独立固定路网，分为 8 个街区章节；警察 3～5 名、小偷 1～6 名，每张地图有 2～6 个环路。路口、回环、连接巷和出口位置逐关变化，取消镜像模板和编号警察站位答案。第 18、22、27、28、34、45、46 关需要中途换防；始终守在最初出口处的对照策略无法通关。选关页显示各关真实路网缩略图；达成每关挑战用时可获得挑战星。所有可见交叉路口均实际连通。

包含沿路自动寻路、实时改令、小偷绕路与避警、连续身体拦截、沿道路计算的围捕范围、抓捕进度、角色行走/转向/敬礼/冒汗/举手、合成音效、选关、暂停、重试、下一关与本地最佳用时。

没有整局硬性倒计时，压力来自小偷的实际逃脱。进度保存在当前浏览器的 `localStorage`，无账号或服务器；清除浏览器数据会删除进度。旧版已解锁关卡保留，新协作规则的最佳成绩以 `streetBest` 单独记录，避免与旧版用时混榜。所有图形和声音均在本地生成，加载后不请求外部资源。

## 验证

```sh
npm test
npm run test:levels
npm run build
```

浏览器回归需先保持开发服务器运行。默认使用本机 Chrome；未安装 Chrome 时，执行 `npx playwright install chromium`，并设置环境变量 `BROWSER_CHANNEL=bundled` 后运行检查（PowerShell：`$env:BROWSER_CHANNEL = 'bundled'`）。

```sh
npm run test:browser
npm run test:lifecycle
```

- 地图测试压缩二度弯路节点后比较路口连接图，镜像、旋转和单纯拉长道路不算不同关卡。
- 核心测试覆盖沿路距离、连续改道、迎面不穿人、沿道路收网，以及奔向出口、绕行、出口改选、翻越暂停/中断、失败冻结和同帧抓捕/逃脱优先级。
- `test:levels` 同时检查全员协作可赢、无人指挥会逃脱失败、单警尾追失败，逐一让任意警察留在出生点的缺员对照，以及换防关的固守失败对照，使用真实 `commandCop` / `stepGame`，不改变坐标、速度、时间或胜负。验证脚本输出当前规则的实际结果，旧版封闭地图的验证数据不适用于本次难度调整。
- 浏览器检查包含真实逃脱失败、不误解锁、翻越提示、暂停、失败回看/重试、截住出口后通关、点选/拖动/改道、键盘、进度与横竖屏布局。截图与 JSON 报告写入 `artifacts/`。
- 最终关浏览器检查使用前 47 关已完成的存档夹具进入关卡，再用真实触摸命令完成 4 名守卫加 1 名机动警察围捕 6 小偷；不注入胜利或移动状态。

浏览器验证是 Windows Chrome 和手机尺寸/触摸模拟；尚未在实体 Android/iPhone 上验证。后台测试显式触发窗口失焦事件以验证应用暂停边界；浏览器返回缓存另行通过真实页面导航验证。

## 静态交付

`npm run build` 输出 `dist/`，可部署到静态主机根目录或子路径。无需后端，也无需打包运行时。

```sh
node scripts/serve.mjs --dist
```

服务器端口与开发服务相同，使用前应停止开发服务，或设置不同的 `PORT`。本次交付未发布公网网站或打包 APK。

## 代码

- `src/engine.js`：纯模拟、寻路、碰撞与沿道路的围捕判定。
- `src/levels.js`：48 张独立路网、关卡提示及验证用封锁策略。
- `src/renderer.js`：缓存街区背景、路线和角色动画。
- `src/main.js`：输入、页面流程、进度和生命周期。
- `src/audio.js`：浏览器合成音效。
- `src/style.css`：桌面、横屏和竖屏布局。
