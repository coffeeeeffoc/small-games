# 别跑！街区围捕

大厅提供“先来一次短场收网”：三张独立编排的小地图为桥口夹击、三岔收口、双街协作，分别在 20/22/25 秒内合围全部对手。准备画面直接显示场景、编号队员和开始按钮；局中提示下一个队员以及包抄位置，失败后说明漏口并可立即重试。三张地图都用真实引擎验证了带 1.2 秒反应延迟的普通指令胜利见证，耗时约 4.3/4.2/5.0 秒。完成第三场可直接尝试轮换指挥。

短场固定追逐队、同时起步和普通调动，成绩单独记录，保留普通玩法与轮换成绩。`?mode=quick&level=1&rule=standard` 打开相同准备题；`level` 仅接受 1–3，不从链接接收成绩。三张图都有不同道路和队伍配置，未复制原有 100 关。

本地单机提供街区挑战、自由追逐、出口竞速三种玩法，每种 100 关。开局可选择追逐队或突围队；另一方由同一套道路、拦截和合围规则下的电脑控制。所有关卡可以直接选择。挑战末 20 关为 40–45 个路口、7–8 条独立环路、7 名追逐队员对 8 名突围队员，并加入两座实际有人行动的外院；自由模式从 12 个路口、1 条环路逐步增加到 40 个路口、9 条环路。

- **街区挑战**：固定同时起步，有可复演的追逐队获胜解法；验证的是针对固定电脑策略的具体操作，并非声称对任何人类策略必胜。
- **自由追逐**：无出口，追逐队在 120 秒内合围全部对手；突围队坚持到计时结束获胜。
- **出口竞速**：任意一名突围队员在出口停留 1.2 秒即可获胜；追逐队需要全部合围。120 秒仍有人未被合围时突围队获胜。

两种自由模式都支持我方先动、对方先动、系统分配。先动方先行动 2 秒，之后双方同时行动；待命阶段既不能下令也不能提前移动。重试保留该题已分配的实际先动方；更换玩法、角色或先手偏好重新分配。自由模式未做全策略数学求解，不宣称理论平衡或任何一方必胜。

新增“轮换指挥”：每次有效调动之后，下一道移动命令必须换队员；守住、原地命令和重复既有目的地不会交棒。被拒绝的命令保留原路线，并解释换人的原因。仅剩一名突围队员时允许连续指挥。该规则是额外自由挑战，没有证明所有地图都能在它的约束下获胜；原有 100 关参考解保证的是“自由调动”。轮换成绩按玩法、角色、地图独立保存，不授予标准挑战成绩。

工具栏“分享”固定地图、角色、规则与本题实际先动方，好友从准备状态重玩同题。分享链接不包含比赛凭证和成绩；打开分享面板会暂停本地局，关闭后继续。浏览器分享取消不会显示已复制。

## 操作与装扮

点编号角色选中，再点道路下令；也可拖动我方角色。角色到达目标会停下，需要继续下令。数字 1–9 选角色，方向键选择路口，Enter 下令，H 原地守住，Esc/P 暂停。至少两名追逐队员在沿路 136 单位内，并把对手的全部退路压入 68 单位合围范围，持续 0.8 秒才算合围；单人拦路不会单独抓获。

拖出后放回按下位置可取消本次指令，队员继续执行原路线；触摸中断或丢失指针捕获会清除预览目标，避免之后误下令。

准备区提供两队装扮、主题和本地头像。头像在设备浏览器内解码、缩小、存储，不发送到游戏服务器；也用于好友赛 Canvas 角色。追逐队保持蓝色方形轮廓，突围队保持橙色圆形轮廓及角色标识，换头像后仍可区分。清除浏览器数据会删除头像和本地成绩。

失败后“看看哪里漏了”进入明确标识的静态复盘：地图保留最后局面，显示“返回准备”和“重新挑战”，不会再显示行动中。切后台或窗口失焦暂停单机，返回后明确点击继续；好友实时赛继续按服务端时间推进。

## 好友赛

宿主 Shell 的好友赛支持双方分别控制追逐队、突围队及先行动方，可在准备阶段交换。自由追逐和出口竞速各 100 张地图，服务端抽图、计时、验证命令、判定胜负和保存成绩。比赛中的头像只读取本机装扮，不上传和广播图片。接口规则与反刷限制以 `services/runtime-api/rules/realtime.mjs` 为准。

## 开发与验证

```sh
pnpm dev
pnpm test
pnpm test:levels
pnpm test:browser
pnpm test:lifecycle
pnpm test:guided
pnpm test:competition
pnpm test:review
pnpm test:mobile-roster
pnpm test:input
pnpm test:relay-browser
pnpm test:quick-browser
pnpm build
```

默认源码服务为 `http://127.0.0.1:43690`，`node scripts/serve.mjs --dist` 服务构建产物。浏览器脚本默认使用本机 Chrome；可用 `GAME_URL` 指定实际源站。

- `tests/modes.test.mjs` 检查每模式 100 个拓扑、连通性、角色控制、先动约束和超时结算。
- `tests/pursuit-ai.test.mjs` 在 200 张自由地图上用真实引擎验证：完全不操作的突围队会被追逐电脑合围，同时合法移动仍有获胜样例。出生点禁止形成无法绕过的互相掩护封闭区域。
- `scripts/verify-levels.mjs` 用真实命令复演 100 个挑战胜利见证，并记录不操作的结果。前 48 关额外保留单人尾追、缺员和换防对照；新增挑战不继承未经执行的旧难度结论。
- `scripts/mobile-roster-playtest.mjs` 验证 320 像素窄屏空路口不会被邻近角色截获点击，7/8 人布局在竖屏和横屏的角色入口保持至少 44 像素，最后一名可真实选中；角色和先动偏好在刷新后保留。
- `scripts/input-playtest.mjs` 用竖屏和横屏的真实鼠标与触摸输入检查拖回起点取消、保留已有路线、后续拖动恢复，以及指针捕获中断后回车不会提交旧预览。支持 `BROWSER_EXECUTABLE` 指定 Chromium 路径。
- `tests/relay.test.mjs` 检验接力有效命令、非法命令保留路线、原地和守住不交棒、最后一人和 AI 的控制边界、默认规则、分享参数校验；`scripts/relay-playtest.mjs` 用真实触摸完成第 1 街区轮换合围，并检验同题先手、重试、分享暂停与独立成绩。
- `tests/quick.test.mjs` 验证三张短场图的真实延迟指令胜利、无操作超时和独立分享边界；`scripts/quick-playtest.mjs` 真实触摸通关三图，检验限时失败学习、重试、320 像素竖屏和横屏准备入口、同题分享与独立成绩。
- `scripts/review-repro.mjs` 用手机触摸驱动自然失败、复盘、返回、重新挑战，以及突围角色移动、追逐电脑运动、失焦暂停与恢复。
- `scripts/playtest.mjs` 覆盖桌面及触摸实操、失败复盘与重试、第 1/2/18 关真实通关、成绩保存和 100 关地图入口。
- `scripts/lifecycle-playtest.mjs` 覆盖损坏存档、静音、触摸取消、失焦与浏览器前进后退缓存恢复，并用旧存档入口实操第 48 关离线通关；不宣称浏览器通关全部 100 关。
- `scripts/guided-playtest.mjs` 覆盖练习提示、误操作恢复、保留原局、窄屏和实际 HTML 全屏进出。
- `scripts/competition-playtest.mjs` 将双方 Canvas 触控命令交给当前服务端规则，检查角色、2 秒先动与物理结算，并覆盖对战浮层和单机关卡衔接；HTTP、双身份房间与 PostgreSQL 另由共享集成测试验证。

这些检查覆盖本地 Node、桌面 Chrome 的触摸模拟和宿主 H5。微信/微博等真实内置浏览器、物理手机与原生小游戏环境需分别验收，不能由模拟结果代替。
