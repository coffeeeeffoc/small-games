# 回声实验室 · Echo Lab

一个可本地运行的小型声音沙盒：移动声源、收音点和板材，根据实际几何路径生成回声。原生 JavaScript、SVG 与 Web Audio 实现，无第三方依赖，无安装或构建步骤。

## 在 Windows 启动

1. 安装 Node.js 24.21.0 或以上版本，与 small-games 工具链保持一致。
2. 将完整 `echo-lab` 文件夹解压到：

   ```text
   F:\playground\playground-ai\small-games\games\local\echo-lab
   ```

3. 双击 `start-windows.cmd`，会启动本地服务并打开浏览器。也可在终端运行：

   ```bat
   cd /d F:\playground\playground-ai\small-games\games\local\echo-lab
   npm run dev
   ```

4. 打开 <http://localhost:4173>。保持终端窗口开启；按 `Ctrl+C` 停止服务。

独立启动无需安装运行时依赖。请通过本地服务访问，不要直接双击 `index.html`。已接入 small-games 的游戏目录、`#/games/echo-lab` 路由、workspace 构建和 Pages 发布流程；构建产物使用相对路径，也可单独部署 `dist/`。手机可直接拖动和旋转板材。

## 第一次体验

1. 在「一声回应」场景点击「试听空间效果」，再点击「原声」比较。
2. 拖动右侧绿色反射板，再次试听。默认反射约比直达声晚 **193 ms**。
3. 选中板材，拖动圆形旋转手柄，或调整角度、长度和反射强度；也可拖动红色声源、蓝色收音点。
4. 添加橙色消音板（吸音屏），把它放到可见路径上，再听变化。反射板和消音板都支持移动、旋转和长度调节。
5. 尝试「空旷大厅」「安静房间」，或把板材移得更远，完成界面中 220–280 ms 回应的小目标。
6. 导入自己的音频，或允许麦克风后录制；在「导出音频」中选择原声、调制声 WAV，或「原声 + 调制声（ZIP）」一次导出两份 WAV 和对应房间 JSON。

默认墙面反射率统一作用于四面墙。展开「分别调节四面墙」，勾选某面墙的单独调节即可覆盖默认值；也可点击画布中的墙壁，在属性区取消「使用默认反射率」后调整。修改默认值不会覆盖独立设置；取消单独调节或点击「四面墙恢复统一调节」即可恢复跟随默认值。0% 表示不产生镜面反射。

支持拍手、鼓点、琴音三个内置测试音。导入文件最大 **20 MB**；导入音频取前 **15 秒**，录音到 15 秒自动结束。音频格式能否解码取决于浏览器。导出包含全部有效传播路径的尾音，音量滑块同时影响试听和导出。

布局会在当前浏览器自动记住，也可用「保存布局」导出 JSON，再通过「导入布局」恢复。v2 文件包含独立墙面反射率、内置测试音与音量，兼容原来的 v1 布局。原声导出对应当前试听的输入：导入或录音经单声源处理，使用当前音量与固定输出余量，不添加房间传播延时或反射；调制声包含全部有效传播路径的尾音。联合导出固定同一音频、布局和音量快照。

点击「分享房间配置链接」，复制 URL 或下载链接文本文件。链接将配置编码在 `#room=` 中，无需后端或账号，部署到 HTTPS 静态站即可分享。其他用户打开后可查看房间概要，点击「一键复用配置」应用并保存；应用前保留自己的当前布局。链接固定导出时的配置，后续编辑不会改变已分享的房间。small-games 内生成的链接直接指向同一站点的独立实验室页面。

录音和导入音频只保存在当前页面内存中，**不会写入 localStorage，也不会包含在配置文件或分享链接中**；分享自定义声音时，接收方使用内置拍手测试。需另外发送已导出的音频。刷新或关闭页面前，请先导出需要保留的声音。本机 localhost 链接仅用于本机测试，跨设备请使用已部署站点的 URL。

## 声音模型与边界

- 房间范围为 8–120 m × 8–100 m，最多 8 个装置；缩小房间会自动约束对象和板材端点的位置。
- 使用二维镜像声源法，计算直达声、一次及二次镜面反射。有限板材必须真的被路径击中；任一段穿过其他不透声板材，整条路径即被遮挡。
- 反射板与吸音屏都是双面、不透声的薄板。吸音屏反射较弱，也会挡住直达声；此处不是仅贴在墙面的吸音泡棉模型。
- 两端完全重合的板材共用一个声学表面，采用最小反射系数（吸音层优先），不会因重复堆叠放大同一回声；画面中仍可分别选中和移动。
- 传播时间 = 路径长度 ÷ 343 m/s。「延迟 ×4」明确将全部传播时间放大四倍，不改变几何或路径增益。
- 时间线显示绝对到达时间；「最强回声延迟」显示相对于无遮挡几何直达声的延时。即使直达声被挡住，比较基准仍保持一致。
- 图中最多显示 8 条最强反射路径，音频使用所有有效路径。左右声像根据路径到达收音点的方向生成。
- 路径增益固定为 `sqrt(12 / (12 + 路径长度)) × 0.68^反射次数 × 各表面反射系数乘积`。反射系数是振幅系数；不会按布局自动归一化，避免吸音后其他反射反而被放大。输出有固定余量和软限幅。
- 未模拟地板、天花板、绕射、低频驻波、材料频率特性、空气频率吸收或高阶弥散混响。因此这是创意声学原型，不能用于建筑声学测量或设计验收。

当前重点是「摆放改变声音」的实验循环，仅提供一个轻量目标；支持无后端的房间配置链接分享，未提供账号或实时多人协作。

## 本地与隐私

服务仅监听本机 `127.0.0.1`。页面资源、测试音生成、录音、音频解码、卷积与 WAV 导出均在本机完成；不上传声音或布局，不依赖 CDN，无统计上报。麦克风仅在点击录制并授权后启用。启动后可断网使用。

## 检查代码

在项目目录运行：

```bat
npm run check
npm test
npm run build
```

在 small-games workspace 中，还可运行 `pnpm --filter @coffeeeeffoc/echo-lab test:browser`，使用已有 `@playwright/test` 与 Chromium 验证实际音频、导出、链接跨浏览器复用和手机触屏拖动/旋转/取消。独立复制目录时需另行提供 Playwright 开发依赖或设置 `PLAYWRIGHT_MODULE`；应用本身不依赖它。

浏览器测试会自动启动并关闭临时本地服务；设置 `ECHO_LAB_URL` 可检查已运行或已部署的站点。Windows 本次验收通过 21 项单元测试和 14 个交互场景，使用 Chromium、360/390 px 手机视口和原生触屏事件；麦克风使用浏览器的模拟设备。另验证了构建后 Shell 内的录音、配置分享和退出释放麦克风。尚未完成实体手机及真实麦克风验收。

声学测试覆盖镜面反射位置与延时、有限板材、二次反射、遮挡、吸音屏位置和材料变化、倍率、确定性、布局校验及边界。若某些受限执行环境不能创建测试子进程，可用 `node tests/acoustics.test.js` 单独运行声学测试；普通本地运行无需此替代方式。

主要文件：`src/acoustics.js` 声学几何；`src/audio.js` 音频；`src/app.js` 交互与绘图；`server.js` 本地静态服务。
