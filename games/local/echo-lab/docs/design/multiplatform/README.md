# 三端适配方案

2026-10-22。沿用现有深绿底、荧光绿反射板、珊瑚色声源和蓝色收音点。Web 维持现有工作台；H5 沿用已支持触屏的响应式工作台，独立入口提供安全区和全屏。微信小程序使用原生 WXML 与 2D Canvas，不嵌套网站。

声音实验适合竖屏：上部房间画布，下部试听和所选对象编辑；配置、声音与帮助通过页内导航切换。核心循环为选择场景 → 直接拖动声源/收音点/板材 → 试听空间效果与原声对比 → 保存或分享配置。无关卡、胜负或成长体系，不新增游戏化入口。

小程序主界面参见 concept.svg（布局效果图，非运行截图）。保留原生导航安全区，按钮高度至少 44 px，画布触点按 CSS 尺寸映射并处理 touchcancel。支持板材增删、自由/沿板/垂直移动、角度/长度/反射率/扩散调整、房间和各墙参数、音量、预设与延迟倍率。声音页支持三种测试音、录音、音频导入和 WAV 导出；配置页支持自动存档、跨端 JSON 导入导出。

共享核心负责声学几何、预设、布局白名单、编辑几何、测试音生成、声路增益与延时、单声道裁切和 WAV 编码。Web/H5 共用 DOM/SVG 控制器；微信单独适配录音、播放、文件、存储和 Canvas。小程序不依赖 DOM、Blob 或浏览器 URL 编码能力。

默认 build 仍为 Web → dist/，保留 GitHub/Shell 发布契约。build:h5 → dist-h5/，build:wechat → dist-wechat/，三个构建互不清理其他目标。微信使用 esbuild 生成 CommonJS 工程，不依赖开发者工具处理源码 ESM。正式预览和发布需自己的 AppID、微信后台隐私配置及真机音频验收。

验收覆盖已有 Web 音频/触屏回归、H5 生产包、默认构建隔离、共享 PCM 波形、微信宿主模拟中的触摸/取消/存档/录音/文件与生命周期。模拟器和浏览器截图不作为微信真机证据。
