# 三端改造验证

2026-10-22，Linux 云环境，Node 24.21.0、pnpm 12.6.0、Playwright 1.55.1 / Chromium 140.0.7339.186。

- 既有声学、几何、布局与 ZIP 测试通过；新增共享 PCM、原生适配、布局互通、构建隔离和兼容入口测试。
- Web Audio 实际录制（合成麦克风）、解码、立体声 WAV、相对/绝对延时、遮挡静音、扩散声路及尾音通过。共享 PCM 与真实 OfflineAudioContext 比较最大误差为 `5.96e-8`，覆盖小数采样延时、左右声像、零声路和限幅。
- 24 个 Web 交互场景通过，包括桌面、360/390 px 触屏及 844 × 390 横屏、短板手柄、沿板/垂直移动、取消、设备方向变化、房间配置复用、音频导入/录音/导出。
- Web 与 H5 生产包在 320、390、1280 px 下通过页面入口、触屏添加装置、存档恢复、无横向溢出、全屏进出及显式开发开关。截图为 actual/ 中的真实 Chromium 页面（非微信截图）。H5 沿用原有响应式工作台；小程序布局参照 concept.svg 的颜色、房间画布、试听主操作与原生页内导航。
- 小程序 CommonJS bundle 在无 DOM、Blob、URL、TextEncoder 的 VM 中启动；宿主模拟覆盖 DPR=3 坐标、拖动/取消、装置编辑、存储失败、JSON 互通、文件选择 hide/show、卸载后的迟到结果、真实文件分享调用及临时文件清理。
- 录音宿主模拟覆盖权限拒绝、等待权限时进入后台、start/stop 同步异常、全局 RecorderManager 旧 stop 排空、重复停止、导入解码被新输入取消以及后台取消。
- 默认 build 明确输出 Web dist/；单独 H5、微信构建不清理或混入其他目标。旧 src/ 与 styles.css 作为兼容转发保留；微信 bundle 不携带浏览器模块。
- 发布范围针对 echo-lab 和相关验证脚本；esbuild 只新增本游戏的已锁定 0.28.2 开发依赖，没有新增或修改外部 resolution。对应范围测试拒绝版本漂移、重复 importer、额外依赖、manifest 不符、缺失基线和其他锁文件字节变化。

限制：未在微信开发者工具或实体 iOS/Android 微信中运行；不将 VM、Chromium 或概念效果图视作真机证据。需填写真实 AppID、配置微信后台隐私指引，再验收麦克风、原生音频解码、文件选择/分享、性能与安全区。Web/H5 在本次验证中使用合成麦克风，没有采集真实声音。
