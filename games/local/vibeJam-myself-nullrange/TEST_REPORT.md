# 验证记录

日期：2026-09-12。环境：Windows、Node 20.9 / 24.12、pnpm 8.14、Chromium 内置浏览器。

## 已通过

- `pnpm test`：确定性地形、转向升降、加速能量、弹道连续碰撞、锁定范围、导弹与扫描冷却、残骸吸取、碰撞保护、三波通关、失败、重开和对象数量上限。标准模式的完整模拟只使用公开操纵输入，不改血量或敌机。
- `tests/input.test.js`：独立多指移动、射击、加速；松开单指不影响其他指针；cancel、lostcapture、失焦、页面隐藏、重开、销毁清理；触摸与键盘混用。
- `pnpm build`：生产构建成功，运行资源约 142 KB gzip（HTML、CSS、JS 合计）。Vite 提示单个 JS 包略高于 500 KB 的建议性警告，未做额外分包。
- 浏览器流程脚本 `tests/browser.js`：26 项检查通过，包括开局、组合操纵与连射、导弹、扫描冷却、加速、暂停冻结、帮助页、声音按钮焦点、双视角、重开、控件可见与不重叠、12 击杀胜利结算、胜利后再次出击。
- 浏览器通关由 DOM 按钮与合成键盘驱动真实帧循环，新手护航模式约 11 秒，12 击杀、赏金 2200；没有修改游戏状态来注入命中或跳关。该控制器反应明显快于手动操作，时间不代表普通玩家体验。
- 桌面浏览器手机尺寸回归约 60 FPS；战斗采样约 33–68 draw calls、4.1 万三角面。该数值不代表真实手机性能。
- 实际浏览器拖动摇杆，偏航从 0 变为 -0.1043、俯仰从 0 变为 0.0298，释放后输入四项全部归零。
- 1280×720、844×390、390×844、320×568 视觉与控件布局检查。窄屏额外错开扫描按钮；竖屏使用较远追尾镜头保证机翼完整可见。
- 生产地址 `http://localhost:43171` 可加载和出击，中文 HUD、暂停流程正常，没有页面控制台错误；生产页面不存在 `window.__flight` 调试对象。

## 验证边界

内置浏览器不支持 CDP 原生 `Input.dispatchTouchEvent`；另一个 Chrome 连接的请求策略加载失败。因此多指事件已通过可运行输入测试验证，但本轮没有完成真实手机双拇指测试、手机 GPU 性能或 iOS Safari 全屏测试。手机同局域网访问依赖本机网络/防火墙，尚未由物理手机确认。

本轮未发布公网、打包 APK 或接入原站联机服务。开发和生产预览服务仅在本机启动；最佳成绩仅保存在浏览器本机。
