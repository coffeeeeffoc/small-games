# 零域 · NULL RANGE 中文手机版

以 Null Range 的低空飞行、线框地形、空战与残骸回收为参考，独立编写的单人手机网页游戏。三波任务共 12 架敌机，支持通关、失败结算和重开。

## 启动

```sh
pnpm install
pnpm dev
```

电脑打开 <http://localhost:43170>。手机和电脑连接同一个局域网，打开启动输出中的局域网地址；本次环境为 <http://192.168.1.25:43170>。浏览器不支持全屏时可直接旋转手机游玩。

```sh
pnpm test
pnpm build
pnpm preview
```

生产输出在 `dist/`，可部署到任意静态网站，包括带目录前缀的网站；所有运行资源均随构建打包。首次访问仍需从服务器加载，不包含 Service Worker 离线缓存。Vite 6 支持本机 pnpm 使用的 Node 20.9，也支持 Node 24。

## 操作

| 操作 | 手机 | 电脑 |
| --- | --- | --- |
| 转向 / 升降 | 左摇杆左右 / 上下 | A、D / W、S 或方向键 |
| 脉冲激光 | 按住右侧开火 | 空格 |
| 加速 | 按住加速 | Shift |
| 追踪导弹 | 点导弹，需前方有目标 | E |
| 扫描、磁吸残骸 | 点扫描 | Q |
| 切换追尾 / 座舱 | 点视角按钮 | V |
| 暂停 | 右上暂停按钮 | Esc / P |

飞船自动巡航，松开摇杆逐渐回平。激光有准星附近的瞄准辅助和过热冷却；导弹 6 枚、冷却 3 秒；扫描持续 6 秒、冷却 10 秒。击杀获得赏金，回收残骸补充护盾、能量和赏金。护盾在脱战后恢复，机体损伤保留；地形碰撞有短暂无敌并弹起机头。切到后台或窗口失焦自动暂停。

## 实现与验证

- `src/sim.js`：固定种子世界、飞行、战斗、三波任务与得分。
- `src/view.js`：Three.js 程序化地形、飞船、弹道、扫描波和爆炸。
- `src/input.js`：Pointer Events 多指捕获、键盘、取消与失焦清理。
- `src/main.js`：中文流程、雷达、音效与本机最高分。
- `tests/`：模拟、输入及浏览器流程检查，见 [TEST_REPORT.md](TEST_REPORT.md)。

在开发页面浏览器控制台运行：

```js
await (await import('/tests/browser.js')).runBrowserChecks()
```

浏览器检查通过 DOM 按钮与合成键盘事件驾驶游戏，不修改血量、敌机或模拟时间。生产构建不暴露开发调试对象。三维场景需要 WebGL 2；没有加载外部模型、字体、统计或在线服务。
