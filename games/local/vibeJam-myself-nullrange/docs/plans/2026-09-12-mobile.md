# 零域：中文手机飞行游戏实施清单

**目标：** 参考 Null Range 在线体验及本地客户端调研，独立实现能完成一局的中文触屏飞行战斗。
**架构：** Three.js 渲染程序化线框地形和飞船；纯 JS 模拟与 DOM 触屏控件分开；无后端和外部素材请求。
**技术：** JavaScript、Three.js、Vite、Pointer Events、Web Audio、Node assert。

1. `src/sim.js`：自动巡航、转向升降、坡面碰撞、敌机还击、辅助瞄准、导弹、扫描回收、三波任务和结算；`tests/sim.test.js` 验证状态流。
2. `src/input.js`：独立 pointer 捕获的摇杆、连射与加速，多点触控；失焦/隐藏/取消清理。
3. `src/view.js`：程序地形、机体、弹道、爆炸、追尾/座舱视角、雷达与锁定坐标。
4. `index.html`、`src/style.css`、`src/main.js`：中文机库、紧凑 HUD、手柄、暂停与结算；手机安全区、竖横屏、音效与本地最佳成绩。
5. `pnpm test`、`pnpm build`；实际浏览器验证开局、移动射击、技能、暂停重开、双指、横竖屏与资源错误。

本版将原作开放赏金玩法改编为三波单人任务。联机、交易升级和音乐模式不属于本轮。所有视觉与音效自行生成；原目录只读。
