# 视觉与交互实现说明

[02-concept.png](02-concept.png) 是实现前生成的效果图，包含主页、游玩和星图。真实 Creator 3.8.8 Web Mobile 运行截图保存在 [actual/](actual/)，2026-10-22 已完成桌面 Chromium 触屏模拟及逐页视觉核对。

## 表现语言

午夜蓝 `#061522` 为底，香槟金 `#efd39b` 表达金属和主操作，青瓷绿 `#8ff5df` 表达可释放与星光，珊瑚色区分部分环。主页采用天文工坊背景和悬浮星仪；棋盘保留大面积空间，底部仅放撤回、提示，详细规则移至帮助页。竖屏逻辑宽度390，横屏改为左侧操作、右侧棋盘。

背景 `assets/resources/atelier.jpg` 和透明星仪 `armillary.png` 由本轮图像生成产出，按移动端尺寸缩放压缩，合计约768KB。两张素材都完成加载才报告就绪，失败出现重试入口；手动创建的纹理与帧在退出时释放。图像原稿保留于工作区 `/workspace/generated_images`，生产资源已包含于工程。

棋盘由原生 Cocos Graphics 绘制：多层金属环带、内外高光、刻纹、端帽、投影及交叉处交替上穿/下穿的桥接段。四件修复物用不同的几何造型表达，每件六个进度槽，对应章节六关。按钮和暂停双竖条也由原生图形绘制。

## 动作与状态

按下时环缘、按钮抬亮；环带拖动超过6逻辑像素后连续跟手。磁吸仅在用户移动时向合法出口辅助最多6°，累计原始拖动角度，避免慢拖时粘在吸附点。交叉处标记显示真实几何是否让开；锁环提示所需的指定钥环。

普通环松手释放后约380ms滑离并散出星尘；目标环约650ms升起星核，之后展示结算。权威规则状态在释放时更新，其他环可继续操作，不用动画锁住整盘。成绩同步保存，切后台不丢奖励；取消手势、失焦、页面切换会恢复未提交的拖动。

结算页按顺序点亮星级，展示对应章节修复物；分享后区分已打开系统分享、已复制、取消与失败。无提示最优解三星、无提示其他解二星、使用提示一星。减少动态设置取消飞行动画和悬浮，仍保留可辨识的静态状态。

## 实际画面对照

- 390×844 主页、星图、游玩、暂停、帮助、设置、结算保持午夜蓝、金色和青绿的视觉体系；背景与星仪素材完整，未见文字或控件遮挡。
- 320×640 底部操作完整可见；844×390 首页采用左右布局，实际点击、进入和退出游玩均可用。
- 环体采用实时矢量高光与刻纹，材质细节仍少于概念图中的金属雕纹；首关仅两环，视觉密度也低于概念图。没有将这项差异记为逐像素一致。
- 实际手势覆盖24关最优解、经典第74关、取消恢复、慢拖离开吸附、飞离期间再次拖动、提示与撤回、暂停和失焦、重载存档、开发试玩和分享挑战隔离。
- 独立入口与 sandbox iframe 通过原生CDP touch输入完成；触屏模拟不代表物理手机、听感或触感验收。

`tests/cocos.browser.mjs` 使用只读快照定位原生 Canvas 控件，通过 Chromium CDP touch操作；不会用测试接口直接修改局面。[verification.json](actual/verification.json) 与 [publishing-verification.json](actual/publishing-verification.json) 记录最终构建的实际结果。视图底部增加渐暗以提高背景上文字的可读性，并修复 Creator 默认样式使隐藏的全屏提示出现残影的问题。
