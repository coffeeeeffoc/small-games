# 星核主线：24 张手工星盘

关卡依据 [玩法方案](01-gameplay.md) 和本轮概念图设计。四章各六关，每关一枚星核、最多八环。`assets/scripts/core/catalog.ts` 是唯一配置源；已有 `orbit-01` 至 `orbit-74` 的几何、关卡顺序与 ID 原样保存在 `classic.ts`，新主线使用 `nova-01` 至 `nova-24`。

新关目标只要求释放带星核的指定环。表中最少释放数由纯规则 BFS 得出，包含最后释放目标环的一步。所有 24 关均可留下至少一只普通环；玩家选择路线会影响星级。提示提供当前状态下最短路线的下一环及合法角度，不会代替操作。无提示完成得二星，释放数量不超过该关最短路线再得第三星；尝试旋转不处罚星级。

## 纯规则和存档验收

`rules.ts` 与引擎、DOM、平台 SDK 无依赖。BFS 的状态只包含已释放集合，锁与几何随释放单调放宽；同一集合不重复搜索。24 关最多 256 种集合。经典星盘沿用全环释放目标与计数锁。依赖锁校验禁止缺失 ID、自引用、重复钥环与循环；所有目标必须引用实际环。

`storage.ts` 使用新键 `orbit-atelier.v2`，只读导入 `orbit-atelier.v1`。经典和新主线各自顺序解锁，互不截断奖牌。存档恢复从配置重建几何、目标、依赖和计数，仅采纳有限角度与已释放标记，并验证释放集合可达；版本不符或非法当前局被丢弃，奖牌和设置保留。旧 v1 当前局只允许映射经典关。撤回的提示数取前后最大值，不能洗掉提示记录。

实际运行 `node --test games/local/orbit-atelier/tests/nova-core.test.ts`：8 项通过，0 失败，包含 98 关逐步求解、最短路线、磁吸边界、锁依赖、独立解锁、星级、v1 迁移、存档伪造/损坏与撤回。此记录仅为纯规则验证，不代表 Cocos 画面、触屏或真机验收。
