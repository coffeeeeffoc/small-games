# 星扣工坊 · 星仪修复计划

2026-10-21，按玩法 → 效果图 → 关卡 → Cocos 实现的顺序重构。

## 核心体验

玩家修复一座失去星光的天文工坊。每一关是一组互相穿扣的珐琅金属环，其中带四芒星的目标环封存星核。观察连接、沿环拖动、让开口同时越过两处连接，再松手抽离。释放目标环即可完成；无需清空所有装饰支路。这使“先拆哪条路、哪些环可以留下”成为实际决策，而非把所有环逐个点完。

新主线采用独立 `nova-*` ID 与版本化存档，旧 `orbit-*` 74 关保持为经典星盘；不覆盖、重新解释或清空旧进度。新主线包含四章、24关，每章修复一件星仪。纯规则层管理穿扣、依赖星栓、目标和最短释放路径，关卡配置层管理图形和解锁关系，Cocos 层负责表现、触摸和平台生命周期。

## 操作与反馈

- 竖屏、单手直接拖环，按手机 390×844 设计；画面中央大比例星仪，至少44逻辑像素热区。横屏改为左侧操作、右侧棋盘，保证完整显示。
- 按住：环缘抬亮、刻度显现；重叠处优先选已选可动环。移动6px后开始旋转，连续贴手，不用外置方向按钮。
- 缺口接近真实可释放角度时最多吸附6°；只在用户转动时发生，仍以同一几何净空规则检查。被多方向阻挡时不吸附答案。
- 接触点以断口/闭合标记区分，合法出口有光弧和箭头。失败只在接触处短促震动，不震动整个屏幕，不处罚等待。
- 松手成功：金属清音、环沿出口滑离、星尘汇入星核；动画约300ms，其他圆环立即可继续操作。星栓解锁时有独立闪光。
- 目标释放：星核升起、对应星座连线、三星依次点亮。三星条件为独立完成且释放步数达到关卡最优解；一星完成、二星无提示。无倒计时、无体力、失败可随时重来。
- 撤回保留已用提示次数；手势取消、失焦、切后台恢复拖动前状态。暂停保留盘面，设置控制声音、触感、减少动态。

## 页面及视觉要求

主页：深蓝星空、中央立体天文仪、短标题、醒目的“继续修复”和星图入口。选关：四章星座地图，节点清楚表达已完成/当前/未解锁。游玩：顶端仅返回/暂停、关号与星核目标；底部撤回与提示。结算：修复物与成绩，下一关、重试、返回。帮助和设置独立页面。

美术采用午夜蓝、青瓷绿、香槟金和少量珊瑚色。圆环必须有厚度、受光面、暗面、接触阴影和端帽；背景星云与细线天文刻度只陪衬可交互物。UI 不使用仪表盘卡片、广告文案和大段规则。实现图与概念图分开存档。

## 技术与验收

真正的 Cocos Creator 3.8.8 工程、序列化启动场景、Component、Graphics/Sprite/Label、触屏 Input、逐帧动画和资源导入；不以 SVG/DOM 棋盘冒充 Cocos。新规则与存档不依赖引擎，可用 Node 验证所有关可解、最短路径、星栓依赖、进度迁移和取消语义。

生产构建需 Creator 或严格匹配源摘要的真实制品。实际验证覆盖390×844、320×640、844×390，触屏主页→选关→旋转→暂停→结算→下一关、提示/撤回、存档、取消与后台。未取得引擎构建和真实运行截图前，不宣称运行验收通过；桌面触屏模拟不宣称物理真机验收。
