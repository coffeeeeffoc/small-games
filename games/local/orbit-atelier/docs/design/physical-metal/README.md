# 实体金属解扣：从圆环到异形机关

用户否定宽缺口平面 C 弧与假扣件，确认前期普通金属圆环、后期九连环类异形件都需要。本轮替换默认主线的结构与交互，不继续以增加旧式圆环数量代替真实难度。

## 产品与结构

前六关为相互穿扣的普通圆环，后六关加入椭圆、U 形长叉、焊杆环与组合结构。中心线位于真实三维空间，金属杆统一半径 3.5；开口圆环仅缺 24°，也包含完整闭环和闭合焊杆件。前后遮挡来自空间深度，不添加黑色假扣、平面接点叉号或凭空穿过实体的动画。

金色底环固定，带星标的青银色件是目标；其余活动件可先取下。环上拖动旋转，倾斜模式上下拖动，抽离按钮沿关卡结构的出口移动；受阻会真实停在接触处并返回。空处拖动查看背面。提示只标姿态，抽离仍由玩家决定。暂停、取消和退出不提交半段抽离。

原有 24 关星核主线、74 关经典与六关旧机关保留为旧版目录；新增 metal-01～12 稳定 ID，默认开始和选关进入实体主线。存档仍只读迁移旧键，按目录保存进行中的局面，避免切换新旧玩法覆盖旧局。

## 实施与验收

1. 纯三维轮廓、保守连续碰撞、旋转/倾斜扫过与抽离规划；验证初始不相交、反向缺口受阻、对口能过、异形杆不穿透。
2. 原生 Cocos Graphics 投影、圆杆高光和按深度绘制；触摸坐标使用实际引擎视口，选择命中轮廓，支持观察视角。
3. 目录、提示、奖励辅助、撤回、多目录存档和旧版入口接线，保持旧奖牌和未完成局。
4. 真实 Creator 构建，实际鼠标/触摸通关前后段、取消/暂停/存档与小屏/横屏采样，更新上架资料及当前有效媒体。

物理模型为有限姿态、指定出口轴下的金属杆几何检查，提示搜索为空不等于任意自由三维姿态都无解。保守碰撞会略提前止动；不宣称完整刚体动力学或物理真机验收。效果图与实际画面分别登记。

## 效果与实现

[结构概念图](concept.png)由内置 imagegen 基于用户截图生成，用于确认普通圆环→长环/长叉→带杆组合的进阶方向；它不是实际运行截图。已选图归档在本目录，原始生成记录为 exec-97aa0681-f93e-4527-9371-98783bcfaac7。

实际绘制使用连续圆杆高光和交叉处的深度覆盖，消除了逐段描边的珠串接缝。点击命中沿真实投影轮廓计算；空白拖动仅改变观察角度。方向键旋转，Q/E 倾斜，空格抽离，Esc 暂停。抽离期间锁定姿态，取消不留下半段位移；原生观察手势取消后可接受下一指针。

运行验证发现 Creator 的宽松编译会把集合展开转换成 concat(Set)，造成提示与结算找不到解法，已改为 Array.from。单测之外另以 Creator 真实构建逐关操作和结算覆盖该问题。固定底件的角度和倾斜也由存档重建校验，不能通过读取存档改变固定结构。
