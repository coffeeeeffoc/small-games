# 水位联动站：规则与 50 关验算

这是离散水量的街机逻辑谜题，数值不用于真实水利或压力工程教学。

## 规则

- 每个槽等宽，容量与液位上限均为 10 格。每次只开或关一个阀门，消耗一次操作。所有内置阀门初始关闭。
- 每次操作后，所有连通分量按总水量平均液位。内部使用整数千分量，余数按槽顺序保留，同组高度最大相差 0.001 格，总水量严格守恒。
- 箱子槽液位不高于 `switchAt` 时点亮机关；机关锁存，后续涨水不熄灭。`requires` 为数组时，数组中的机关必须全部点亮后才能操作阀门。
- 平衡后依配置顺序处理溢流，每个口每回合至多执行一次。上游整个连通分量高于 `at` 的水进入下游，再各自均分；转移量不超过下游剩余容量。已连通的上下游不溢流。
- 50 关包含单溢流、双级串联和分支双溢流；同一次水量经过两级水轮时，每一级的实际转移都计入全站累计动力。水轮目标为各出口 `powerNeeded` 之和，并非各水轮独立计数。
- 所有箱子机关、水轮动力与所有小船出口同时达标即通关。双船关两艘船都必须保持在各自出口高度；最后一次操作成功优先判胜。
- 预测与执行共用纯函数。提示以广度优先搜索返回剩余预算内的最短解，无解返回 `null`。
- 预算为最短解加 1～2 次容错，奖励额外操作再增加一次。撤销与奖励历史由界面维护。

## 章节与兼容性

每章 10 关：港口启航、分舱实验站、支流调度港、溢流动力站、联动总控站。前 8 关保留原来的 ID、排列、槽水量、阈值、闸门、目标和预算；只重新归并章节名称，旧存档仍按 ID 匹配。

后续谜题包括三/四/五槽长链、星形、T 形分支与四槽闭环；目标角色和操作顺序也不同。新增双船、双机关锁、临时寄存、先升船后落箱、分批补水、多次隔离、串联溢流及双港平衡。

## 验证

从游戏目录运行 `node --test tests/engine.test.mjs`。覆盖 50 关最短解、每一步剩余最短提示、全部目标初始未完成、5×10 章节结构、双机关锁、两级溢流、操作预算与奖励步数、预览纯净，以及仅开不关无法通过的隔离关。

全状态遍历包含一次奖励操作，验证每个可达状态的容量与千分量守恒。按求解器相同的状态等价规则（液位、阀状态、已锁存机关、饱和累计动力）去重，不把剩余预算更多的相同状态重复保存。

本次 50 关共检查 31159 个状态，单关最多 3349 个。初始求解最高 7.24 ms，解路径上的剩余求解最高 7.94 ms；另抽查 697 个包含错误操作和额外步数的分支提示，最高 11.11 ms。这些时间来自当前 Node 执行环境，仅作规模记录，测试使用状态数量上限而非机器相关耗时作为约束。
