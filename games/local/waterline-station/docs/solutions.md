# 水位联动站：规则与关卡验算

这是离散水量的街机逻辑谜题，数值不用于真实水利或压力工程教学。

## 规则

- 每个槽等宽，容量与液位上限均为 10 格。每次只开或关一个阀门，消耗一次操作。
- 每次操作后，所有连通分量按总水量平均液位。规则内部使用整数千分量，除不尽的余数按槽顺序保留；同组高度最大相差 0.001 格，总水量严格守恒。
- 箱子所在槽液位不高于 switchAt 时压下机关；机关灯锁存，后续水位升高仍保持点亮。带 requires 的阀门需对应机关灯点亮后才可操作。
- 平衡后进入溢流阶段。每个溢流口按配置顺序只执行一次：将上游整个连通分量超过 at 的水转移到下游连通分量，再分别均分。转移不超过下游剩余容量，装不下的水保留上游。
- 上下游已属同一连通分量时不溢流。每个溢流口每步至多执行一次，因此自定义循环出口也确定终止。八个内置关卡都至多一个溢流口。
- 每一格实际溢流水量贡献一格累计水轮能量。所有机关灯、水轮目标与小船出口目标同时满足即成功。最后一次操作达成目标优先判胜。
- 预览使用与真实操作相同的纯函数，不修改原状态。提示用广度优先搜索，返回剩余操作预算内的最短路径；无解返回 null。
- 一次额外操作通过 state.bonusMoves = 1 扩展本关预算；撤销与奖励领取历史由界面维护。

## 最短解

所有闸门初始关闭；同一个阀门第二次出现表示关闭。下表由求解器产生并由测试逐步重放，液位按 A/B/C/D/E 顺序。

| 关卡              | 最少操作 | 阀门序列               | 最终液位              |
| ----------------- | -------: | ---------------------- | --------------------- |
| 1. 初次联动       |        1 | AB                     | 4 / 4 / 4             |
| 2. 一阀，三室     |        2 | AB → BC                | 4 / 4 / 4             |
| 3. 溢流发电       |        1 | AB                     | 4 / 4 / 3             |
| 4. 留住那格水     |        3 | AB → AB → BC           | 4 / 7 / 7             |
| 5. 先降，再升     |        4 | AB → BC → BC → CD      | 3 / 3 / 6.5 / 6.5     |
| 6. 双箱接力       |        4 | AB → CD → CD → DE      | 4 / 4 / 3 / 6.5 / 6.5 |
| 7. 关阀，才有落差 |        4 | AB → BC → BC → BD      | 3 / 3 / 9 / 3         |
| 8. 全站协奏       |        5 | AB → BD → BD → BC → CE | 4 / 4 / 4 / 10 / 4    |

第 4～8 关还遍历了所有只开不关的合法序列，确认都无法获胜；必须通过关阀隔离保留液位。第 2 关第二次开阀将三个槽从 5 / 5 / 2 同时变为 4 / 4 / 4。第 3 关一次开阀同时完成箱子开关、溢流发电和小船起航。

## 1. 初次联动

1. 打开 A—B：液位 4 / 4 / 4，水轮累计 0，已点亮 A。

## 2. 一阀，三室

1. 打开 A—B：液位 5 / 5 / 2，水轮累计 0，已点亮 A。
2. 打开 B—C：液位 4 / 4 / 4，水轮累计 0，已点亮 A。

## 3. 溢流发电

1. 打开 A—B：液位 4 / 4 / 3，水轮累计 2，已点亮 A。

## 4. 留住那格水

1. 打开 A—B：液位 4 / 4 / 10，水轮累计 0，已点亮 A。
2. 关闭 A—B：液位 4 / 4 / 10，水轮累计 0，已点亮 A。
3. 打开 B—C：液位 4 / 7 / 7，水轮累计 0，已点亮 A。

## 5. 先降，再升

1. 打开 A—B：液位 4 / 4 / 1 / 10，水轮累计 0，已点亮 无。
2. 打开 B—C：液位 3 / 3 / 3 / 10，水轮累计 0，已点亮 A。
3. 关闭 B—C：液位 3 / 3 / 3 / 10，水轮累计 0，已点亮 A。
4. 打开 C—D：液位 3 / 3 / 6.5 / 6.5，水轮累计 0，已点亮 A。

## 6. 双箱接力

1. 打开 A—B：液位 4 / 4 / 6 / 0 / 10，水轮累计 0，已点亮 A。
2. 打开 C—D：液位 4 / 4 / 3 / 3 / 10，水轮累计 0，已点亮 A、C。
3. 关闭 C—D：液位 4 / 4 / 3 / 3 / 10，水轮累计 0，已点亮 A、C。
4. 打开 D—E：液位 4 / 4 / 3 / 6.5 / 6.5，水轮累计 0，已点亮 A、C。

## 7. 关阀，才有落差

1. 打开 A—B：液位 3 / 3 / 2 / 10，水轮累计 2，已点亮 无。
2. 打开 B—C：液位 2.667 / 2.667 / 2.666 / 10，水轮累计 2，已点亮 A。
3. 关闭 B—C：液位 2.667 / 2.667 / 2.666 / 10，水轮累计 2，已点亮 A。
4. 打开 B—D：液位 3 / 3 / 9 / 3，水轮累计 8.334，已点亮 A。

## 8. 全站协奏

1. 打开 A—B：液位 3 / 3 / 8 / 2 / 10，水轮累计 2，已点亮 无。
2. 打开 B—D：液位 2.667 / 2.667 / 8 / 2.666 / 10，水轮累计 2，已点亮 A。
3. 关闭 B—D：液位 2.667 / 2.667 / 8 / 2.666 / 10，水轮累计 2，已点亮 A。
