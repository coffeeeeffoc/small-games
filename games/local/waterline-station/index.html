    值班员手册 / QUICK START

    你调闸门，水找平衡。

    1. 直接点击场景里的阀门

      点圆形阀门打开，再点一次关闭。点水管只将这条连接和相关阀门置顶，不消耗操作；锁住的阀门也可以点选查看。打开后水量自动均分，每次开关消耗一次操作。

    2. 让机关依次启动

      箱子降到黄色平台，会压下并锁存开关；船升到出口线且任务完成即可出航。实验站还会出现溢流水轮。

    3. 计划，再试一次

      预测模式先显示虚线液位，再次点击同一闸门确认。撤销和提示免费，卡住时每关可加一次操作。

    溢流每次调度结算一次；水轮累计收到的水量。所有数值为街机规则，不用于水利或压力工程教学。
