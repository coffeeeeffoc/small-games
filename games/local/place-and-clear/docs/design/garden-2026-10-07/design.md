# 积木花园：双无尽与美术改版

2026-10-08：按用户提供的“效果图／实现图”差距进行第二轮对齐。继续使用本目录原效果图，当前实现及验收见 [第二版记录](refinement.md) 和 [四页对照](comparison-v2.png)。

## 产品决定

- 保持竖屏 8×8 棋盘、固定朝向、直接拖放和点击放置。关卡仍为三选二。
- 无尽页直接提供「三选二」「立即补位」两个入口。三选二保留本地练习及现有在线排位；立即补位先提供完整本地对局，不接入旧规则排行榜。
- 立即补位：合法落子 → 同步清行列及计分 → 原槽补入一块 → 检查三块是否仍有合法落点。其他两块保留，不自动丢弃，无撤销或续局。难度按每两步折算原有组数阶段，纪录独立，暂停／返回／重启可恢复。
- 设置显示「消除闪光」，开启表示允许闪光，关闭表示柔和反馈；沿用 reducedFlash 存储字段并反向展示，保留旧设置意图。

## 美术与布局

柔和积木花园：浅薄荷天空、奶油云朵、远处起伏草坡，珊瑚／薄荷／金黄积木，奶油色立体托盘。深绿色标题，珊瑚色主按钮及实体底边，圆润游戏徽章。背景装饰位于屏幕边缘，不覆盖棋盘、候选与按钮。

首页：设置与星星小徽章 → 大标题 → 立体积木场景插画 → 当前关卡与开始／继续 → 选关与无尽入口 → 排行榜／帮助。避免长介绍和统计卡片堆叠。

无尽：上下两张带积木小插画的游戏入口，每张只显示规则一句话、本地最高分和开始按钮；三选二在线入口作为次操作。

游玩：保留现有棋盘格比例和坐标映射，调整外围背景、托盘、得分和状态排版；即时补位用「已放积木」替代组数。选关沿用正常解锁与章节，用路线和游戏印章强调旅程。

效果图：先通过内置 image_gen 生成首页、无尽、游玩和选关的四联手机效果图，保存 concept.png。按该图实现 CSS/SVG 与原生 Canvas，共享玩法层。实现截图保存 actual/。

## 验收

- 两种无尽补块、失败、结束、重开、存档恢复与独立纪录正确；旧三选二序列和排位规则不变。
- 消除闪光开关可读、实际反馈一致，旧存档与存储不可用可继续。
- 390×844 与 320×568 手机触屏覆盖首页、无尽、选关、游玩、暂停、结算、返回；手势取消及失焦不误落子。
- 原生 Canvas 同步入口与视觉方向，运行现有原生检查。桌面模拟不作为手机真机或平台验收。
