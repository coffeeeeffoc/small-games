# 2026-10-11 移动复审与120关扩展

本记录描述 2026-10-11 的局部扩展；当时基于花园版主页和游玩画面，levels.svg 表达选关分页：每页三个章节，共30个按钮；页码明确范围，翻页按钮至少44px。默认定位真实进度；开发试玩与正常解锁仍分离。竖屏积木直接拖拽无需切换方向，横屏保持原逻辑适配。历史画面与布局草图不限制后续样式；新要求按认可效果图及[完整视觉验收](../../../../../../docs/game-development.md#新样式要求与完整视觉验收)实现。

从新玩家看，需要在30关之后继续可达而不丢原战绩；从关卡策划看，需要独立空格布局和固定库存，不能仅改颜色、镜像旧题；从触控与性能看，一次不应追加120个按钮；从稳定性看，失去pointer capture要取消拖拽，坏存档的配置不能进入模拟。

新增31–120是离线生成后保存的固定棋盘/库存/解法，九章分别练习长边、拐角、纵横、多线、交叉、预算、大块和跨组取舍。脚本不是运行时随机调难度；验收用真实引擎逐步回放每一条路线、验证三星与完整解锁/旧30关存档。

## 验证

Node 24.21.0 / pnpm 12.6.0 / Linux，Chromium 151.0.7922.173（系统浏览器，版本来自实际报告）。44项单元通过，全部120关按真实引擎逐步获得三星并正常顺序解锁；旧30关记录保存后继续解锁31。四种只看当前库存的贪心策略均无法自动通关新增关卡。最后预算章参考路径只留3格余量。

生产构建和 tests/browser.mjs 通过，报告 verification.json，零页面异常。320×568、360×640、390×844及旋转覆盖直接拖拽、手势取消、多点、暂停、刷新续局、结算、全屏及拒绝能力降级；真实触屏翻到第120关并逐步赢得三星。开发试玩不写正式战绩。正式顺序解锁由规则测试完整验证；另以真实引擎生成119关已完成存档，在dev=0中默认定位最后一页，经23次触屏拖拽通关120、写入三星记录、返回选关并刷新恢复，报告 final-verification.json。
