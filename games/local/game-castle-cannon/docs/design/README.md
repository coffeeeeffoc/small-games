# 一炮拆城 · 画面与验收

目标图先于 UI 实现生成，见 `target.png`。原创攻城场景使用浅蓝天空、草丘、奶油色固定城墙模块、珊瑚箭塔、蓝方圆头盔小兵和木质炮车；正式画面采用轻量 Canvas 几何绘制，保留目标图的通路缺口、友军推进、箭塔威胁与下方弹药区，细节密度比目标插画低。没有借用鸟类角色、弹弓、堆叠谜题、关卡或现成音效。

所有页面横屏，逻辑画布 960×480。首页主操作为继续/开始，地图正常按首胜解锁三城，设置与帮助独立页面。战斗只有兵力、占领、剩余时间、暂停、两种弹药与装填提示；结算不自动打开装备或奖励弹窗。旗帜工坊只改变旗帜和头盔，首胜材料支持两种可正常获得外观。预留的增援门、掩体和路线数组不参与首版规则。

竖屏 H5 旋转整个界面并反向映射触点，不需要自动旋转或全屏才能游玩；旋转、尺寸改变与全屏改变取消当前手势并保留对局。H5 复用公共 fullscreen.js，入口仅在首页、设置和暂停显示。微信由现有 Native Game Shell 承载，game.json 配置 landscape，核心画面没有浏览器全屏入口。

实际截图由 `scripts/browser-check.mjs` 生成：`desktop-home.png`、`desktop-levels.png`、`desktop-aim.png`（破门后瞄准上方箭塔）、`desktop-breach.png`、`desktop-battle.png`、胜败与第三城结算；`touch-portrait-*` 为 Chromium 390×844 模拟触屏和关闭自动旋转时的整界面旋转兜底，不是真机。`iframe-*` 为嵌入触屏入口。暂停图标为两根分离的实心等高竖条。

`browser-evidence.json` 记录真实鼠标 / CDP 触屏操作的三城通关、正常存档重载、外观购买、无操作失败、重试与两种射击顺序的损失差异。规则测试另验证门阻路与破门、局部爆破和单目标穿透、塔伤害及拆除减损、占领、失败与奖励幂等。`lifecycle-evidence.json` 另以桌面、竖屏模拟触屏和 iframe 实际输入验证旋转取消拖动、暂停保留战局及重复重试。`native-evidence.json` 是 Node VM 模拟 wx SDK 装载正式微信预览 JS 的结果，覆盖取消、隐藏恢复、暂停、胜利、存档、资源与清理；没有运行微信开发者工具或真机。

音效是本次用固定种子合成的短 WAV：炮击、碎裂、箭矢、胜利与撤退，不含第三方录音。默认音量 0.35，设置可关闭。

广告只有平台已配置广告位且 Host 授权时才显示可选按钮；取消、失败或不可用不发奖励。失败增援重试每次正常战局最多一次，首胜额外材料每城一次并存档。当前 H5 与微信 touristappid 预览均未配置广告位，仅显示预留说明；未申请账号、收费服务、上架审核或真实广告凭证。
