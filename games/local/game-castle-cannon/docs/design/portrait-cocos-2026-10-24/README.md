# Cocos 竖屏界面改版

用户确认本次同时迁移到 Cocos，保留已有环境和美术。核心玩法仍为实时双城炮战：拖动瞄准、蓄力发射、拆城与保护炮手；生命归零失败，战役胜利可继续下一关，结算可重试或回首页。

以上为生成的设计效果图，实际运行证据单独保存在 `actual/`。九宫格皮肤位于 `assets/resources/ui-kit.png`，采用钢蓝面板、黄铜边框与金色主操作；选中、禁用、按住均有独立反馈。

竖屏让顶部状态、中央弹道和底部拇指操作形成稳定分区。首页留出城堡展示空间，开始对战为主操作，战役与练习为第二层，外观、帮助、设置为辅助入口。所有页面保留统一返回路径，不设置全屏和单独暂停入口。

## 实现边界

- Creator 3.8.8 负责场景、真实网格、PBR 材质、UI、输入、音频、生命周期及 Web 发行构建。原有 Three.js 场景只在构建阶段导出几何和材质，不进入新的 Web 核心运行包。
- 复用 120 关配置、权威模拟、机器人、存档及 `duel-v2` 对战协议。继续使用 `small-games:castle-cannon:progress` 的 Host 封装；正常解锁与开发试玩隔离。
- 预览与实际炮弹共用积分和首个碰撞计算，覆盖城墙、炮位、炮手、地堡与地形。空闲显示 65% 参考蓄力；按住时显示当前蓄力。预测不改变战斗状态，移动目标和联机延迟仍可能改变实际命中。
- 返回按钮直接打开继续／退出确认，本地冻结模拟，联机明确显示对局仍继续。取消手势、失焦、关闭音效和销毁会释放输入与停止音频。
- 不增加广告奖励：本次保留既有公平炮战与材料成长，正常玩法不依赖广告或联网。公网匹配服务未部署。
- 原生 Canvas 消费者保留兼容入口；本次验收目标为 Web/H5，不能把桌面触屏模拟当作手机真机或原生平台验收。

实际验证、版本与素材入口见 [verification.md](verification.md) 和 [上架资料状态](../../../publishing/STATUS.md)。
