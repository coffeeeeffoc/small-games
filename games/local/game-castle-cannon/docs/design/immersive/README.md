# 一炮拆城：原创目标与实际运行证据

`target-battle.png`、`target-impact.png` 在实现前生成并保留。目标图不用于运行背景；原创纹理源图保存在 materials，炮车、炮兵、门楼、拱石与砌石由 `scripts/art/` 的 Blender 4.3 脚本生成，运行模型为量化真实几何。其余建筑、人物、地形、植被、天空、碎片与音效也由本项目代码构建。

## 最新整幅对照

最新固定游戏机位、默认画质截图为 `valley-actual-composition.png`（破门、蓝兵与上塔瞄准）和 `valley-actual-battle.png`（实际炮击上塔）。没有编辑截图像素。两名炮兵分别持弹与操作推弹杆；炮车有中空炮口、铁箍、铆钉、辐条与木纹，车轮接触真实支撑平台。门区扩大为约十米缺口，残门叶随尺寸调整；士兵逐排穿过缺口，再沿可见弯道进入庭院。后塔移开通路，障碍位于门内可见路段；实体射线测试覆盖三关永久墙体、门楼与目标视线。河流分成上下水位并沿峡谷转弯，石桥、瀑布与远村进入同一机位；内城后退至右侧，门内保留庭院。

整幅自评：破门与射塔的关系、炮兵操作姿势、缺口和河谷空间更清楚；仍未达到原目标图的整体美术品质。角色表情、自然植被、山岩细节、天空空气层次、内城建筑变化与材质精细度存在明显差距。不能把技术路线通过、局部细节改善或截图完成等同于原图品质验收通过。

`portal-*`、`final-*`、`hero-*`、`cache-*` 和未带阶段前缀的破坏细节图为较早阶段记录，不能当作最新构图。旧 Blender 样板及其 Library 备份保留。

## 真实三维与渲染优化

固定 PerspectiveCamera，960×540 逻辑画面；默认 768×432 WebGL2、4x MSAA 与 1024² PCF 阴影，公开省电设置为 384×216、简化材质/几何且关闭阴影。默认画质保留完整原始模型。炮车俯仰与车架转向跟随真正的瞄准点，固定模块缺失、断墙与残门、瓦砾、士兵伤亡/倒地/推进和炮弹均来自实际规则及三维对象。

静态缓存仅用于当前真实三维地形、永久建筑和炮兵平台，保存 HDR 颜色及实际深度；相机尺寸、画质、外观、关卡、目标损伤和阴影变化会刷新。动态图像不写入环境缓存，深度恢复用于正确遮挡，未使用目标图或照片替代场景。炮车、士兵、可破坏模块、残门/瓦砾、瞄准、箭矢和炮弹继续动态渲染。士兵沿用原模型的 13 个材质部件并实例化，死亡倒地保留，结束后移除其绘制实例。

输入事件立即更新状态与 HUD，GPU 绘制由定时循环提交，并限制为一帧在途。重试先刷新 CPU 拾取映射，GPU 忙时保留绘制请求。CPU 提交耗时及提交序号都不能代替实际帧率。

`performance-evidence.json` 是同一构建、相机、模型、材质、阴影、视口与分辨率，仅切换真实静态缓存的墙钟 A/B。浏览器运行真实对局，采样期间兵力按规则减少，初末状态和提交帧数完整记录；不使用 Playwright Clock。驱动已确认是 Linux Chromium 的 ANGLE SwiftShader，GPU timer query 扩展不可用。页面调用 p95 是协议响应时间，CPU renderMs 不包括驱动/合成等待，不能直接当作触控延迟或 GPU 时间。`performance-history.json` 与两份历史 A/B 保留前后数据并标注不同源码、MSAA 或并发构建等差异；不能混为严格同质量对照。开发者模式下 `renderProbe=uncached` 仅用于重现 A/B，普通玩家不启用。

## 规则与输入验证

35 项单测覆盖实心单目标伤害、爆破范围、门阻挡和破门通路、箭塔损耗与拆塔减损、自动推进/占领/失败、存档与重试、快速重试的 CPU 拾取、GPU 排队、材质/几何恢复、独立士兵实例、静态缓存共享材质恢复和实体视线。门先拆推进更快，塔先拆损耗更少，不操作会失败；障碍在完整城门后方时会先命中城门，破门后可以直接命中障碍。

`normal-browser-evidence.json` 记录默认画质原生 CDP 鼠标三关；`browser-evidence.json` 记录省电画质桌面与竖屏模拟触屏三关及 iframe 首关；`input-evidence.json` 记录鼠标/触屏取消、释放到画布外、多点触控、暂停/旋转/恢复和连续重试。测试使用浏览器原生输入，没有用 DOM dispatchEvent、战局状态修改或受控时钟替代通关。截图脚本单独使用 Playwright Clock 复现取帧时刻，运行规则仍正常推进；该截图记录不作为性能或整局输入证据。

## 平台与广告范围

H5 保留首页、三关选择、成长、设置、帮助、战斗、暂停、胜败和重试；手机竖屏用完整容器旋转兜底，包含控件和触点映射。Web/iframe 全屏共用仓库能力，原生小游戏不调用浏览器全屏 API。

微信 preview 使用现有 Shell 的离屏 WebGL2 表面、图片加载、存档、音频和生命周期抽象，游戏不直接访问 wx。没有 WebGL2 时降级为 Canvas。`native-webgl-evidence.json` 验证的是编译微信入口在 DOM-backed SDK 桥接和 Chromium WebGL2 中的真实触屏首关、材质和清理；`../native-evidence.json` 是模拟 SDK 降级、存档与生命周期检查。这些都不能称为微信开发者工具、微信真机或上线验证。

微信开发者工具、真机、实际移动 GPU/电池性能与真实广告凭证/上线审核尚未验证。广告仅接已有 Host 抽象，未配置时不提供可用广告奖励；基础瞄准、两种弹药和正常重试免费。未创建广告账号或收费服务。
