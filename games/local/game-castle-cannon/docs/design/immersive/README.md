## 真实三维与渲染优化

固定 PerspectiveCamera，960×540 逻辑画面；默认 768×432 WebGL2、4x MSAA 与 1024² PCF 阴影，公开省电设置为 384×216、简化材质/几何且关闭阴影。默认画质保留完整原始模型。炮车俯仰与车架转向跟随真正的瞄准点，固定模块缺失、断墙与残门、瓦砾、士兵伤亡/倒地/推进和炮弹均来自实际规则及三维对象。

静态缓存仅用于当前真实三维地形、永久建筑和炮兵平台，保存 HDR 颜色及实际深度；相机尺寸、画质、外观、关卡、目标损伤和阴影变化会刷新。动态图像不写入环境缓存，深度恢复用于正确遮挡，未使用目标图或照片替代场景。炮车、士兵、可破坏模块、残门/瓦砾、瞄准、箭矢和炮弹继续动态渲染。士兵沿用原模型的 13 个材质部件并实例化，死亡倒地保留，结束后移除其绘制实例。

输入事件立即更新状态与 HUD，GPU 绘制由定时循环提交，并限制为一帧在途。重试先刷新 CPU 拾取映射，GPU 忙时保留绘制请求。CPU 提交耗时及提交序号都不能代替实际帧率。

`performance-evidence.json` 是 b5 阶段的数据，不代表本轮新几何的实测性能；它在同一构建、相机、模型、材质、阴影、视口与分辨率，仅切换真实静态缓存的墙钟 A/B。浏览器运行真实对局，采样期间兵力按规则减少，初末状态和提交帧数完整记录；不使用 Playwright Clock。驱动已确认是 Linux Chromium 的 ANGLE SwiftShader，GPU timer query 扩展不可用。页面调用 p95 是协议响应时间，CPU renderMs 不包括驱动/合成等待，不能直接当作触控延迟或 GPU 时间。`performance-history.json` 与两份历史 A/B 保留前后数据并标注不同源码、MSAA 或并发构建等差异；不能混为严格同质量对照。开发者模式下 `renderProbe=uncached` 仅用于重现 A/B，普通玩家不启用。

## 规则与输入验证

41 项单测覆盖实心单目标伤害、爆破范围、门阻挡和破门通路、箭塔损耗与拆塔减损、自动推进/占领/失败、存档与重试、快速重试的 CPU 拾取、GPU 排队、材质/几何恢复、独立士兵实例、静态缓存共享材质恢复和实体视线，并检查树林实例合批、可见林带与城堡基础高度。门先拆推进更快，塔先拆损耗更少，不操作会失败；障碍在完整城门后方时会先命中城门，破门后可以直接命中障碍。

`normal-browser-evidence.json` 记录默认画质原生 CDP 鼠标三关；`browser-evidence.json` 记录本轮省电画质竖屏模拟触屏三关及 iframe 首关；前一阶段省电桌面等记录保留在 `browser-b5-evidence.json`；`input-evidence.json` 记录鼠标/触屏取消、释放到画布外、多点触控、暂停/旋转/恢复和连续重试。测试使用浏览器原生输入，没有用 DOM dispatchEvent、战局状态修改或受控时钟替代通关。截图脚本单独使用 Playwright Clock 复现取帧时刻，运行规则仍正常推进；该截图记录不作为性能或整局输入证据。

## 平台与广告范围

H5 保留首页、三关选择、成长、设置、帮助、战斗、暂停、胜败和重试；手机竖屏用完整容器旋转兜底，包含控件和触点映射。Web/iframe 全屏共用仓库能力，原生小游戏不调用浏览器全屏 API。

微信 preview 使用现有 Shell 的离屏 WebGL2 表面、图片加载、存档、音频和生命周期抽象，游戏不直接访问 wx。没有 WebGL2 时降级为 Canvas。`native-webgl-evidence.json` 验证的是编译微信入口在 DOM-backed SDK 桥接和 Chromium WebGL2 中的真实触屏首关、材质和清理；`../native-evidence.json` 是模拟 SDK 降级、存档与生命周期检查。这些都不能称为微信开发者工具、微信真机或上线验证。

微信开发者工具、真机、实际移动 GPU/电池性能与真实广告凭证/上线审核尚未验证。广告仅接已有 Host 抽象，未配置时不提供可用广告奖励；基础瞄准、两种弹药和正常重试免费。未创建广告账号或收费服务。
