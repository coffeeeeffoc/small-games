# 炮战移动端复审与 120 关战役

沿用 2026-10-09 双城炮战的横屏场景、棕金按钮、旋转兜底和触屏调炮；主页仅增加「战役选关」入口。练习、联机与战役分别结算。战役选关沿用地图页，按每章 10 关分页，显示已通过、当前解锁及锁定；结算提供下一关/重试/选关。布局实施依据为 [选关效果图](campaign.svg)，原主页/游玩风格继续依据已有 concept.png。

120 关分 12 章，10 个战术模板：门前初战、高台炮位、城墙缺口、薄墙、坚固城楼、敌方地堡、我方高台、地堡反击、敌方换位、弹种变化。每章逐步收紧敌方反应与估算误差，调整敌方生命、有限医疗和城防结构值；玩家基础伤害与装填保持原规则。原三城稳定 ID 继续保留，旧已通关记录打开对应后续关，不清空材料、外观和设置。

审查角色与待优化点：

| 角色      | 发现                                           | 改造                                                                  |
| --------- | ---------------------------------------------- | --------------------------------------------------------------------- |
| 玩家      | 旧三关不再可进入；新练习只有一图，缺少推进目标 | 将现有炮战接入 120 关战役、正常解锁与首胜奖励                         |
| 关卡设计  | 相同机器人重复对战缺少战术差异                 | 起始炮位、缺口/城防、地堡残局、换位、弹种与有限补给组合，章节逐步递进 |
| 移动操作  | 蓄力取消需覆盖暂停/后台/旋转                   | 沿用触点取消，补充战役流程与暂停恢复测试                              |
| 生命周期  | 手动暂停后失焦/回前台会自动进入战场            | 区分宿主自动暂停与玩家手动菜单，手动暂停保持                          |
| 成长/存档 | 解锁上限写死为第 3 关；外观材料无新获取路径    | 上限读取战役目录，连续通关推导解锁，首胜幂等并保留旧存档              |

验收：120 个稳定唯一 ID、战术配置校验；正常玩家不能越级、重玩/开发试玩不重复奖励；后期真实弹道可获胜；手机旋转页面触屏选关、调炮/蓄力、暂停/帮助返回、结算与下一关；保存少量实际截图。浏览器模拟不称为真机验证。
