# 围捕小队：统一街区风格与小屏完整布局

2026-10-10。先制作四屏效果图，再改造运行界面，最后保存实际运行截图与验证记录。

## 设计目标

首页外围、插画、按钮和各类弹层统一为街区卡通风格：天空蓝、薄荷绿、奶油纸面、海蓝文字与金黄色主操作。复用现有追逃插画和角色素材，减少内外画框的割裂感。

首页以实际可用视口高度布局，标题、插画与入口按高度分配。320×568 手机及短横屏也直接看见开始/继续、换装、好友、玩法、指南、地图、试炼、分享和全屏。装饰区域随剩余空间收缩，操作热区保持至少44px。横屏首页改为插画与入口并排。

弹层使用标题、内容、操作三段结构。标题和关闭/继续/确认操作始终在可见区域，整个弹层不滚动；玩法长说明、关卡列表、换装选项、好友赛详细内容各自在内容区滚动。简短提示与设置尽量不出现滚动。好友赛入口沿用真实公共控制器，不添加假入口或修改对战规则。

本游戏现有棋盘支持竖屏和短横屏；保持方向策略和玩法、存档、最短提示不变。将弹层适配覆盖到实际构建与Shell iframe中注入的好友赛样式，使用游戏内局部覆盖，避免影响其他游戏。

## 验收标准

- 首页和简短弹层无页面级竖向或横向滚动，所有主要入口真实可点击。
- 320×568、360×640、390×844、667×375、844×390及桌面1440×900覆盖首页、主要弹层、挑战与对抗。
- 实际触屏检查进入地图、选关、提示、撤销、胜负结算、返回继续；长内容滚动不影响标题与底部操作。
- 覆盖独立H5、注入公共好友对战的生产页面及iframe；检查全屏进退与开发者模式保持。
- 保存浏览器实图与检查记录。浏览器触屏模拟不等同于实体手机/小游戏宿主验收。
