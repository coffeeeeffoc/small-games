# 路口选择与接力留守反馈修复

用户截图可由第一关解法前四步复现：路口为 2、10、1 的三名警察，小偷位于 7；3 号警察刚移动到 1，接力棒仍在他手中。换防接力不允许同一人连续移动，因此 5、6 此时并非合法落点。旧界面仍显示普通选中态，重新选择还会覆盖具体限制说明，直到点击落点才报错。

沿用现有游戏效果图和布局，补齐状态反馈：只能留守的队员头像显示“留守”，地图选中环使用虚线，选择、回合结束、撤销与恢复时立即解释限制；无相邻空位的队员使用同一合法目标判断。脚下路口的无障碍名称明确为“点击留守一步”。规则、解法与存档格式不变。

## 验证

环境：Windows、Node 24.21.0、pnpm 12.6.0、Playwright Chromium 触屏模拟。开发服务 `http://127.0.0.1:43452`，生产构建预览 `http://127.0.0.1:43453`。

- 修复前 `BASE_URL=http://127.0.0.1:43452 node scripts/check-game-shell.mjs` 在第一关第四步断言失败：实际提示“换一位警察，接力包抄！”，缺少“3 号本步只能留守”。修复后通过。
- `pnpm test`：100 关解法、1672 次行动、可达性、失败条件、100 关最短解、1163 个提示、6 关接力、3 关试炼及对抗规则通过。
- `pnpm build` 通过；同一 `check-game-shell.mjs` 对生产构建执行 9 项场景检查：主页/选关/返回继续、触摸与拖拽取消、提示取消、模式切换、占用反馈、第一关复现、标准模式 1→6、6 个接力关卡逐步核对所有警察的合法目标与留守状态并通关。
- 第一关在 390×844、844×390 下检查受限点击不消耗回合，点 1 可留守且不会交棒；撤销后调动另一名警察，3 号从 1→6 可通过点击道路中心移动。普通模式的相同局面中 5、6 均高亮，1→6 可直接移动。
- `BASE_URL=http://127.0.0.1:43452 node scripts/check-art-layout.mjs`：13 项场景通过，覆盖 320×568、390×844、844×390、1440×900、1920×1080 和第 1/40/60/84/90/100 关；独立/iframe 的默认、URL、存储及显式关闭开发开关，素材、路口命中、触屏与撤销通过。
