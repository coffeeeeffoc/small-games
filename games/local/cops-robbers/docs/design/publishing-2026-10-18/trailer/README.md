# 围捕小队首页／详情页宣传片

交付文件：`cops-robbers-promo-1080p.mp4`。横屏 16:9，1920×1080，30 fps，21 秒，H.264 High / yuv420p，AAC 立体声，MP4 faststart。

## 创意与分镜

采用原有角色美术的 2.5D 动画宣传片：角色独立位移、弹跳与转身倾斜、尘土、守路提示、收网光环、镜头推进和短转场。未拼接游戏录屏，未放入假的交互面板，也未展示尚未开放的好友联机功能。

## 素材来源

- 角色：游戏 `assets/patrol-characters.svg` 内嵌透明 WebP 的原始美术；`character-atlas.png` 为无修改解包副本。
- 片尾：同一发布目录现有 `promo-1920x1080.jpg`。
- 场景：使用内置 **imagegen** 根据 `patrol-garden.webp` 和 `home-chase.webp` 风格参考生成空花园场景，保存在 `garden-stage.png`；完整提示词见 `generation-prompt.txt`。
- 音乐与提示音：`render.py` 使用合成波形与确定性噪声生成，无外部曲库或采样。未添加人声旁白，静音时字幕可完整表达主题。
- 字幕：Windows 微软雅黑粗体，直接栅格化，视频不依赖字幕文件或客户端字体。

## 重建与检查

在本目录执行 `python render.py`；依赖现有 Python、Pillow、numpy、FFmpeg 和 ffprobe。渲染串行执行，编码限制两线程。

`video-checks.json` 是对最终 MP4 执行 ffprobe 的结果；脚本对编码、尺寸、比例、时长、文件大小和音轨设有断言。`storyboard.jpg` 为源渲染关键帧，`decoded-contact-sheet.jpg` 为最终成片解码后的联系表。
