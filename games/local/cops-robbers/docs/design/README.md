# 围捕小队界面设计

2026-10-05 先制作 `cartoon-ui-concept.png`，再实现首页、选关、游玩三层界面。薄荷草地、奶油道路、海蓝警队、橙色小偷和黄色操作高亮贯穿各层。效果图中的锁仅为视觉示意；实际保持全部关卡可玩。

- 首页：使用原创生成的追逃插画，主入口开始巡逻，提供继续、全局换装、好友、玩法、指南与 Web 全屏。生成插画转为 191 KB WebP，随构建打包，无远程图片依赖。
- 选关：按街区展示蛇形道路和关卡路口，已完成星级与当前关卡保持可见；完整关卡名、三星目标保留在无障碍名称中。
- 游玩：返回、步数、待捕目标、棋盘、短提示、角色头像、撤销、重来、提示；高亮可达路口、选中角色与提示落点。完整动态说明仍提供给辅助技术。
- 装扮：默认警察与小偷，可分别选择猫狐、星际造型或本地头像；沿用本地存储，首页头像、SVG 棋盘与 Canvas 角色同步。插画是默认角色的封面美术，当前装扮通过首页可点击头像与实时棋盘展示。
- 全屏：仅 Web/H5 首页显示；关卡中和原生小游戏平台均无全屏入口，不自动请求全屏。
- 进度：沿用存档与玩法规则；回到首页、选回未完成关卡、继续人机对抗均保留局面。分享入口根据当前局面生成正确的同题链接。

素材：效果图和首页插画由本次任务使用图像生成工具原创生成；`assets/home-chase.webp` 是首页插画的压缩版本。棋盘角色、房屋、植物和路径仍使用本地 SVG/Canvas 绘制，所有交互由实际游戏逻辑提供。

浏览器验证环境：Linux Chromium，触屏模拟，320×568、390×844、667×375、844×390、1440×900。检查触屏点选、拖拽、拖拽取消、撤销、提示、保存、返回继续与平台入口。尚未进行微信/B站客户端真机验证。
