# 围捕小队原生移动端

竖屏 Canvas：路网为近方形，拇指点击队员后点击相邻路口；所有页面在宿主安全区以内，同页只有一个暂停入口。原生宿主全屏，不展示浏览器全屏按钮。

主页 → 开始/继续、选关、三种单机模式、帮助设置；选关按100关标准、6关接力、3关快练各自进度解锁，分页每页9关。游玩 → 暂停 → 继续、帮助、重试、主页；结算 → 下一关/重试/主页。

复用 engine.js、levels.js、relay.js、quick-trials.js 原有规则，矢量渲染不依赖DOM。保留v3存档未知字段与所有模式记录；标准、接力、快练分别保存中途棋盘与撤销历史。帮助不触发对局状态改变。

触屏只在同一单指按下和释放目标一致时触发；滑出、取消、多指、后台、窗口变化清空手势。后台自动暂停，恢复保持暂停。resize仅重排，不重建棋盘。缺可选声音/震动/存储时提供如实反馈。好友入口仅配置真实服务才开放，切换先清理本地监听。

效果图为确定尺寸的SVG布局稿，覆盖主页/选关/对局，原生开发者工具与设备验收另外记录。
