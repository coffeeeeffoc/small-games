# 首页与分享调整 · 2026-10-18

当轮参考[卡通界面效果图](../cartoon-ui-concept.png)，后续以最新认可图更新场景和界面；局部布局按用户截图调整，并与街区围捕的[左上控件效果图](../../../../cops-robbers-realtime/docs/design/home-polish-2026-10-18/concept.png)保持一致。

首页标识仅避让刘海/状态栏加 4px，音效、设置在下方竖排；中央标题避让右侧胶囊。移除全屏按钮，无服务包隐藏好友 PK。隐藏入口后菜单自动填满可用列；横屏取消重复的顶栏留白。

首页分享游戏入口；游玩与结算分享当前关卡。公开链接移除开发参数、服务地址和身份凭证。回合动画期间暂时禁用分享，避免结算覆盖分享面板。游玩顶栏不拦截关卡分享热区，小屏为分享按钮预留实际高度。

浏览器模拟验证：6 关接力触屏通关、3 关快速试炼通关、失败撤销、对抗角色/先手分享、首页干净链接、5 种视口返回与存档恢复、72 项弹窗/返回/结果检查。共享安全区及离线构建验证记录见[三款汇总](../../../../cops-robbers-realtime/docs/design/home-polish-2026-10-18/README.md)。
