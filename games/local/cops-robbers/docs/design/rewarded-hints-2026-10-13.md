# 广告提示与 TapTap H5 准备

沿用现有竖屏街区棋盘与已认可效果图，本次仅调整提示按钮、禁用好友入口并复用公共广告弹层，不新增页面或改版布局。

- 点“看广告”后锁定本局输入，观看完成才调用原有最短路线求解器；一次广告对应一次当前位置提示，不消耗步数。关闭、失败、不可用、超时不发提示，可继续手动游玩。按钮使用三个字避免 320 像素屏幕出现不均衡换行，无障碍名称为“看广告获取提示”。
- 普通 Web 默认显示公共适配器的四秒“模拟广告”；真实 H5 宿主通过 `SmallGamesRewardAds.offer` 或 `SmallGamesPublishingConfig` 注入提供方。模拟广告不代表广告变现接入完成。
- 广告和求解都绑定当前局面与请求。返回、重开、切模式、后台与离开页面取消请求；迟到回调不能覆盖新局。广告期间锁定触屏及键盘输入，结束恢复此前输入状态。
- 首页好友入口显示禁用状态；使用现有 `data-competition-launch` 防重复挂载契约占据入口，公共联机控制器提前返回，旧 room 链接不启动房间或全站榜。原生单机入口也关闭好友入口。
- TapTap H5 使用静态相对资源与单一 `dist/` 顶层目录，入口 `dist/index.html`；竖屏方向参数为 1。上传包排除以前构建留下的联机脚本、API 配置及测试资料，保留本地存档、开发模式、全屏和人机对抗。
- 验收：真实生产包中的手机触屏走通模拟广告完成/取消、宿主失败/缺失/异常、重复请求和旧回调隔离；验证单机通关、返回恢复、无联机请求、独立及 iframe 入口，并保存实际截图。后台上传、真实广告 SDK 和 TapTap 真机验收单独记录。
