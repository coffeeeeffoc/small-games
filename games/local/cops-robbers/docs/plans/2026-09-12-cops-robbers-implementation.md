# 围捕小队实施计划

> 历史实施记录。下方原版结果不代表新版验证；当前单警点击即走、真实逃生出口与 60 关重制见 [逃生出口改版](2026-09-12-escape-challenge.md) 和 README。

用户已授权按设计实施回合制围堵游戏，目标为完整的 60 关。

1. **规则与关卡**：`src/engine.js` 集中处理移动、预测、围捕和确定性逃跑；`src/levels.js` 与通关记录提供 60 张地图。用 `scripts/check-levels.mjs` 检查边界并回放每张地图的通关解。
2. **画面与输入**：`index.html`、`src/main.js`、`src/style.css` 使用原生 SVG 与 DOM，提供点选及拖动、路口高亮、规划冲突、下一步预览、分阶段动画。`src/art.js` 提供角色表情和五种街区装饰。
3. **完整流程**：关卡选择、章节进度、胜利与下一关、撤销与重试、本地存档、当前局面求解提示、音效开关与减少动态效果。提示放在 Worker 中计算，保持页面可操作。
4. **验证与交付**：Node 规则检查，静态构建后真实浏览器覆盖交互、动画、胜利、存档恢复、触控与不同尺寸；浏览器重放全部 60 关。记录实际结果，启动本地试玩并打开页面。

实现不引入运行时框架。Node 原生 HTTP 服务用于开发与本地预览，静态文件直接部署即可；浏览器验证依赖只用于开发。

## 已完成

- 原生 SVG 游戏、五种街区、60 关，以及 1–5 名警察与 1–5 名小偷的不同组合。
- 确定性的回合规则、逐步预览、交换与留守、成组和分批抓捕。
- 点选与拖动、角色表情和动作、Web Audio 音效、逐回合撤销、重开、两层提示、关卡地图、本地进度。
- 全部 60 关通过真实规则回放（283 回合）；每关随机行动四回合后的当前局面提示也可求解。
- 构建产物在 Edge 中通过全部 60 关的真实点击通关；390×844 和 320×740 触屏模拟完成操作、首屏和溢出检查；没有浏览器脚本或资源错误。
- 浏览器试玩发现并修复 SVG 角色命中空隙、快速连续点击被忽略、顶部状态遮挡、预览覆盖数字、直达链接刷新回退、留守角色原地跑及动画设置恢复问题。

关卡的参考回合数来自已验证解法，不声称是数学最优解。首版使用固定手绘路网与经过搜索的初始布置；第 2、9 关复用直巷，但人数、起点与抓捕任务不同，其余关卡道路布局各异。

补充 Chrome 浏览器边界检查共 9 项全部通过：真实拖动与取消、动画中重开和切关、警察交换冲突、损坏或不可用存储、真实音频播放与静音、纯键盘操作、直达关卡后刷新恢复、偏离参考解后的提示与留守姿态、显式动画设置优先。真实 Web Audio 抓捕与胜利产生 9 个新音符，静音后新增 0 个；无页面或控制台错误。
