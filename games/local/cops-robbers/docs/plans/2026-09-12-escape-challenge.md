# 逃生出口与即点即走改版

用户反馈：上一版警察没有失守压力，路网无真正逃生出口，而且每步都要点击“行动”过于繁琐。用户已授权直接修正，以下规则取代原来的全队规划规则。

- 地图加入明确标识的逃生出口。小偷到达未被警察占据的出口立即逃出，任何一名逃走本关失败；可撤销失败那一步或重试。
- 选中一名警察，点击相邻空路口立即执行这一名警察的一步，之后全部小偷移动；其他警察留守。去掉独立行动确认按钮。默认选中第一名警察，连续点击即可继续走。
- 小偷会寻找绕开警察、通往出口的最短路线；只有逃生路线被切断才转为避险。警察需要优先卡位，不能只跟在后面追。
- 重新筛选全部 60 关的出口、警力、起点和通关解。保留清楚的教学，逐渐增加多出口、绕行路线和调度次序的要求。每关可解，并验证真实失守分支与粗糙策略的失败情况。
- 地图直接表现逃生方向与威胁，失败动画、撤销、提示、存档和浏览器检查同步更新。旧版存档保留原键，新版使用 v2，旧通关记录不冒充新版成绩。

验证：共享规则检查 + 新版 60 关真实浏览器逐步点击通关 + 逃脱失败与撤销重试 + 手机点击/拖动与无确认按钮 + 最新静态构建复验。

已完成：60 关参考解共 511 次单警行动，全部通过真实浏览器回放；每关均验证可逃脱失败，58 种路网，50 个多小偷关卡中 49 关的参考解分次抓获小偷。参考解步数不代表最短解。规则记录见 `outputs/level-audit.json`，浏览器通关记录见 `outputs/escape-report.json`。

交互修复包括：提示与预览图层不拦截路口点击；手动选警或开始拖动时取消旧提示，避免异步计算完成后误选另一名警察。当前版本保存键为 `cops-robbers-v2`，保留旧版原始存档。
