# H5 混合命令回归

使用已有开发服务或生产预览服务，在该游戏目录执行：

```sh
pnpm test:commands
node scripts/check-command-model.mjs --replay outputs/command-model/level-1-seed-91842.json
```

`BASE_URL` 默认为 `http://127.0.0.1:43420`。浏览器选择沿用 `BROWSER_EXECUTABLE` / `BROWSER_CHANNEL`，否则使用锁定 Playwright 的浏览器。脚本不启动服务、不安装浏览器，不改变普通 build 或全仓测试。只运行无依赖测试可用 `node --test scripts/command-model.test.mjs`。

默认只测 1、28、120 三个代表关卡，每关 seed 91842 和 20261020，各 24 条命令；手机视口 390×844，真实 `tap()`，关闭教学和音效、使用减少动态设置。`LEVEL_IDS`、`COMMAND_SEEDS`（逗号分隔）、`COMMAND_STEPS`（6–100）可限制规模。固定前缀覆盖移动、提示、撤销、移动、重开、提示；随后用固定种子组合，终局通过真实结算按钮撤销或重开。提示广告使用已有浏览器测试的 completed fixture，不代表真实广告平台验收。

模型保存首次实际棋局和每次走棋前的独立快照，不复制业务追逃或撤销实现。`legalTargets` 仅生成/检查可执行输入，不充当提示、撤销、重开的预期结果。三个独立性质分别要求：

- 提示前后双方位置、回合、阶段及剩余/逃脱人数不变；允许选择和提示高亮改变。
- 撤销后恢复最近一次移动前观察到的完整棋局。
- 重开后恢复首次进入的初始棋局，并清空模型历史。

保留原有解法回放及其胜利验证；混合操作测试没有替代全关解法测试。`playtest.mjs` 与新测试共享加载、DOM 快照及提示 fixture 助手。

每个用例都会在 `outputs/command-model/` 保存完整具体命令、seed、算法版本、逐步前后棋局、命令计数、错误和手机截图。`COMMAND_OUTPUT` 可指定其他输出位置；`CANDIDATE_SHA` 记录主线程已验证的候选提交，未提供时明确为 null。报告同时记录源码 SHA-256；运行方须确保 `BASE_URL` 服务的制品对应同一候选，不能仅凭本地摘要声称远端一致。

失败先持久化原始 JSON，再开始删除式缩减。最多尝试 16 次、30 秒预算，每个候选在全新浏览器 context 中从初始状态重放，等待超时受剩余预算限制。只接受同一 `assertion:*` 签名失败；移除前序操作导致命令前置条件不成立时标为 `invalid`，超时/浏览器错误标为 `error`，均不接受。每次接受更小序列立即保存 `*-minimal.json`；缩减中异常记入原始记录的 `shrinkError`，不丢原始失败。预算耗尽所得序列不保证全局最短。

使用输出的原始或 minimal 文件传给 `--replay` 可只执行具体命令，不依赖再次随机生成。重放失败保持非零退出码；前置失效同样不算通过。重放结果另存 `replay-report.json`。无依赖自测覆盖性质检测、快照隔离、固定种子、同签名缩减、无效前置拒绝、预算及后续异常前已保存证据。

本说明定义测试契约；实际运行是否通过，以对应候选的 JSON 报告和主线程验证记录为准，桌面手机模拟不等于真机验收。
