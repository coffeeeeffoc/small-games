# 围捕小队

手机友好的回合制围堵解谜游戏：点选警察，再点相邻路口，警察立即走一步，所有小偷随即行动。每步只能移动一名警察，其余警察留守。堵住小偷所在路口的全部退路即可抓获，抓完全部小偷通关。

60 关分为连环小巷、街角市场、环形公园、码头街区和城市总动员；警察人数、小偷人数、道路、起点和真正的逃生出口随关卡变化。小偷会寻找没有被警察堵住的逃生路线，**任意一名小偷抵达红色出口即失败**。需要先截断出城路线，再留人守口、轮流调动警察完成围堵。前 48 关为三人小队，最后 12 关为四人小队；所有地图都有多条环路、跨街通道和 2–3 个逃生口，没有可供单人轻易收尾的死胡同。

## 本地运行

需要 Node.js 22 或更新版本。游戏运行没有第三方依赖；Playwright 仅用于浏览器检查。

```sh
npm install
npm run dev
```

打开[本地游戏](http://127.0.0.1:43420)。Windows PowerShell 可用 `$env:PORT=43421` 更换端口。服务仅监听本机，端口占用时会明确报错。

```sh
npm run build
npm run preview
```

构建只复制 `index.html`、`src` 和可选静态素材至项目内 `dist`，不删除其中已有的其他文件。预览服务只提供游戏静态资源，不暴露文档、脚本、依赖和工作区其他内容。页面使用相对资源路径，可放到静态站点子路径。

## 操作

- 点警察，再点高亮路口立即移动，无需“行动”确认。选中的警察会保留，方便接着点击相邻路口。
- 点警察脚下的路口数字可等待一步，让小偷行动；其他警察始终留守。警察不能进入被警察或小偷占用的路口，不能同时交换位置。
- 拖动警察到相邻路口也可立即移动；拖到空白处或取消拖动不会消耗一步。
- “撤销”恢复上一步之前双方的位置；“重开”恢复当前关卡。失败窗口可直接撤销导致逃脱的那一步，或重新挑战。
- “提示”只显示建议与高亮，不代替玩家走棋；“关卡”可选择全部 60 关。
- 键盘用 Tab 选择角色和路口，Enter 或空格激活当前控件，Ctrl / ⌘ + Z 撤销。
- 右上角可关闭音效；支持系统减少动态效果偏好。
- 开局自动进入专注界面；“返回大厅”查看完整说明，“继续围捕”保留当前回合。横屏时棋盘和必要操作并排显示；专注布局不要求浏览器支持真正全屏。
- 胜利记录保存在当前浏览器本地。新版使用 `cops-robbers-v3` 保存进度，旧版已通关记录不会当作新版通关。清理浏览器数据后记录会消失。

可用 `?level=12` 直接进入某关，`?level=12&motion=reduce` 减少动画。

## 检查

```sh
npm test
npm run build
npm run preview
# 保持预览运行，在另一个终端执行：
npm run test:browser
npm run test:interactions
npm run test:focus
npm run test:ranking
npm run test:competition-renderer
```

规则检查验证地图、道路无虚假交叉、单警移动、捕获与逃脱边界，并按记录的解法回放全部关卡。每关逐一移除任意警察，穷举全部可达局面，确认少一人无法通关（没有搜索步数或状态数截断）；同时确认完整小队可通关，全部队员都参与移动。不封出口则会真实逃脱。浏览器检查使用已安装的 Edge 或 Chrome，实际点击完成全部 60 关，逐步核对双方位置，同时检查撤销、重开、选关、音效开关、本地记录和手机布局。可设置 `BASE_URL` 指向其他本地预览端口，或设置 `BROWSER_CHANNEL=chrome`。定点试玩可设置 `LEVEL_IDS=1,2,8,12`，报告会如实记录覆盖关卡数量。

`test:interactions` 通过真实输入复现漏守出口导致的失败、失败撤销和重试、抓捕尚未结束、提示不自动走棋、延迟提示不能抢走玩家选中的警察、连续快点、拖动取消、动画中重开与选关、存档升级、实际音频静音以及键盘操作。

新版浏览器检查生成 `outputs/escape-desktop.png`、`outputs/escape-mobile.png`、`outputs/escape-report.json` 和 `outputs/escape-interactions.json`；失败时以非零状态退出。指定 `LEVEL_IDS` 的定点检查保存为 `outputs/escape-smoke.json`，不会覆盖全量报告。失败场景截图另存为 `outputs/escape-defeat.png`。浏览器检查应针对最新构建重新执行。

## 关卡维护

`node scripts/generate-levels.mjs` 使用固定随机种子生成全部关卡与参考路线，只有全部通过全员协作筛选后才写入 `src/levels.js` / `src/solutions.js`。`scripts/teamwork.mjs` 的缺员检查遍历有限位置状态图，不会将搜索超时误判为无解。参考步数不承诺为最短解。

本次重新设计了所有路线，使用 `cops-robbers-v3` 保存进度；旧地图的通关记录和进行中的棋局不会套用到新地图，音效和动画偏好继续沿用。

历史版本的浏览器报告不能代表当前地图；修改关卡后应重新运行上述规则、构建和浏览器检查。手机尺寸浏览器检查不等于实体手机验证。
