# 围捕小队：首轮优化与验收

日期：2026-09-21。基线体验评分 7.5/10；本轮为实现记录，最终评分由另一位 agent 独立复评。

## 发现与实现

- 首关只有规则段落，新玩家难以从“守口、换防”转为实际操作。现在复用已验证的首关参考解，按当前真实局面标出警察与目标路口，并解释七步中的守口、接防、留守、合围。可在设置关闭；首次通关自动关闭，重玩不再自动泄题；偏离路线不会限制自由操作或提示错误落点。
- 原来的橙线没有说明推演条件。现在明确显示“若原地留守”或“走到 X 号后”，危险时直接报出下一步会失守的出口。
- 失败文案原来笼统提示“提前守口”。现在重放最后一步的真实引擎结果，显示小偷从哪个路口逃到哪个出口；确实因为守口警察离岗而失守时指出接防问题。仍可一键撤销或重试。
- 复用现有星级与最少步数存档，在局内、结算和选关显示个人最佳、三星步数和差距，以及街区三星进度。手机教学和威胁文字加大，未增加新的遮挡面板。

本轮只改本游戏的 `index.html`、`src/main.js`、`src/style.css`、`scripts/check-interactions.mjs`。未修改引擎、关卡、协作必要性或计分门槛。
