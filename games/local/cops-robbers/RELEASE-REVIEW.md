## 本轮修复：先复现失败，再改最小代码

1. **横屏胜利框无法继续（已确认）**：首关在 390×844 正常完成，转 844×390；胜利框高度被限制为 350px，但 `overflow:visible` 让“下一关”位于 y=414，浏览器无法滚入且点击超时。把胜利框恢复为 `overflow:auto`；通过条件是旋转后可真实点击下一关，并在横屏重新通关后点击重玩。保留截图 `outputs/escape-landscape-victory.png` 和交互回归。
2. **拖回原位误耗回合（已确认）**：首步守住 2 号出口后，把该警察拖向别处再拖回原位松手，原实现当作留守，步数从 1 变 2，小偷由另一出口逃脱。仅在拖动松手路径排除起始路口；仍可点脚下编号或键盘空格主动留守。通过条件是实际 Chrome 触摸输入拖回/松手后双方位置与步数原样保留、拖向合法新路口仍走一步。显示变化/旋转调用既有 cancelDrag，避免旧屏幕坐标继续提交。
3. **窄屏隐藏存档失败（已确认）**：320px 且浏览器拒绝存储时，提示节点有“无法保存”文字却被 CSS 隐藏。错误态保留可见提示“退出后进度会丢失”，允许底部自动换行；正常保存恢复正常样式。通过条件是拒绝存储时仍可通关、失败和重试，320px 错误提示实际可见。

额外完成用户明确要求的公共能力接入：页面加载共用全屏脚本，顶部显示至少 44px 的全屏按钮，手机工具栏保持可访问；305px 缩去装饰徽标。真实请求范围为完整 document（画面、HUD、操作），共用脚本在原生 dialog 内镜像退出入口、处理拒绝/不支持和系统退出。没有把 CSS 铺满声称为浏览器全屏。

# 围捕小队：首轮优化与验收

日期：2026-09-21。基线体验评分 7.5/10；本轮为实现记录，最终评分由另一位 agent 独立复评。

## 发现与实现

- 首关只有规则段落，新玩家难以从“守口、换防”转为实际操作。现在复用已验证的首关参考解，按当前真实局面标出警察与目标路口，并解释七步中的守口、接防、留守、合围。可在设置关闭；首次通关自动关闭，重玩不再自动泄题；偏离路线不会限制自由操作或提示错误落点。
- 原来的橙线没有说明推演条件。现在明确显示“若原地留守”或“走到 X 号后”，危险时直接报出下一步会失守的出口。
- 失败文案原来笼统提示“提前守口”。现在重放最后一步的真实引擎结果，显示小偷从哪个路口逃到哪个出口；确实因为守口警察离岗而失守时指出接防问题。仍可一键撤销或重试。
- 复用现有星级与最少步数存档，在局内、结算和选关显示个人最佳、三星步数和差距，以及街区三星进度。手机教学和威胁文字加大，未增加新的遮挡面板。

本轮只改本游戏的 `index.html`、`src/main.js`、`src/style.css`、`scripts/check-interactions.mjs`。未修改引擎、关卡、协作必要性或计分门槛。
