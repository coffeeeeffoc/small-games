# Ink Is Everything · 一滴墨，决定一切

一个可独立运行、零运行依赖的网页回合制探索游戏。本次实现第一章「遗忘之庭」：找回两枚钥印，在终页门廊开启墨之门，击败守门者完成旅程。桌面和触屏均可游玩。

## 启动、构建与测试

在仓库根目录运行：

```sh
node games/local/ink-is-everything/server.mjs
node games/local/ink-is-everything/build.mjs
node --test games/local/ink-is-everything/engine.test.mjs
```

独立服务默认地址为 `http://127.0.0.1:4412/`，也支持 `/ink-is-everything/` 前缀，可传入 `--host 0.0.0.0 --port 4412`。构建输出在当前游戏目录的 `dist/`，可以部署到任意静态站点及子路径。

使用仓库配置的 pnpm 版本也可运行：

```sh
pnpm --filter @coffeeeeffoc/ink-is-everything dev
pnpm --filter @coffeeeeffoc/ink-is-everything build
pnpm --filter @coffeeeeffoc/ink-is-everything test
```

游戏已登记到 Shell 大厅、Pages 打包清单与桌面/移动端交互烟测。

## 操作与取舍

- 点击「开始落笔」，从当前旅人拖到相邻房间即可绘路；也可以先点击相邻房间，再点击绘路按钮。新区域通常消耗 6 墨；已绘路线可免费回访。
- 探索、墨弹、治疗和契约共用唯一的墨水池，初始为 72 / 100 墨、5 生命。没有金币，也没有擦除地图回收墨水的功能。
- 每次战斗行动都会让敌人执行已显示的意图。墨弹消耗 5 墨造成 4 伤害；干笔免费造成 1 伤害；防守完全挡下当前攻击，成功挡伤获得专注，使下一次干笔造成 3 伤害。
- 治疗消耗 8 墨恢复 2 生命。战斗中治疗也会触发敌人行动；洗笔泉提供一次免费恢复。
- 支路奖励、敌人掉落和泉水需要手动领取；已领取的补给不会刷新。签订契约可提升攻击、减少绘路消耗或提升治疗，在本次旅程中持续生效。
- 墨水耗尽仍可用干笔、防守和免费摸索继续游玩。摸索耗 2 回合并擦伤 1 生命（最低保留 1），遇敌时还会增加敌人生命。
- 快捷键：`1` 绘路、`2` 墨弹、`3` 治疗、`4` 契约、`A` 干笔、`D` 防守、`Esc` 暂停或关闭弹窗。触屏直接点击对应按钮。

游戏没有行动倒计时。结果页显示探索量、余墨和四种用途的实际支出，可对比不同路线与资源分配。

## 本地保存

每次有效行动后，将章节编号和行动序列自动保存到当前浏览器的 `localStorage`。重新打开时可选择「继续上次旅程」或从空白页开始；恢复时会由规则引擎重新验证并回放行动。重新开始会替换当前记录，胜负结算后移除未完成旅程。

记录仅保存在当前浏览器与站点来源下，不上传服务器，也不跨设备同步。隐私模式或禁用存储时仍可游玩，但可能无法保留进度。声音偏好同样在本地保存。

## 文件与扩展

| 文件 | 职责 |
| --- | --- |
| `levels.mjs` | 章节、房间图、奖励、敌人意图、契约与消耗参数 |
| `engine.mjs` | 纯状态规则：创建章节、列出合法操作、执行回合与生成结算 |
| `game.mjs` | 界面交互、键盘、弹窗、声音、行动保存和恢复 |
| `art.mjs` | 原创纸墨场景、角色、插画与图标 SVG |
| `style.css` / `index.html` | 页面结构、纸墨样式与响应式布局 |
| `engine.test.mjs` | 多种资源分配通关、零墨续行、非法操作和状态隔离验证 |

新增章节时，在 `LEVELS` 中增加独立章节 ID，配置 `start`、`gate`、`requiredSeals`、`initial`、`rules`、`contracts`、`rooms` 和 `links`。每个房间使用稳定 ID，声明类型、地图坐标、相邻出口、提示及可选敌人或奖励；敌人的 `intents` 数组决定循环预告行为。引擎通过 `createGame(levelId)` 加载相应章节，无需复制战斗规则。

当前界面只提供第一章入口。扩展更多章节时，增加章节选择，并将第一章的标题、目标、起点选择及教程数字改为读取章节数据；同时增加对应通关与存档兼容测试。若改变旧章节规则，应更新保存版本或设计迁移，避免旧行动序列被误解释。新增外部资源时也应加入 `build.mjs` 的复制清单。

## 浏览器验收

启动上述独立服务后，运行可重复的端到端验收脚本：

```sh
node games/local/ink-is-everything/docs/playtest.mjs
```

默认使用仓库的 `@playwright/test`。可通过 `PLAYWRIGHT_MODULE` 指定兼容 Playwright 模块路径，通过 `CHROMIUM_PATH` 指定浏览器执行文件，通过 `GAME_URL` 指定测试站点。

脚本使用真实鼠标、触摸和键盘操作，并独立运行规则引擎逐步核对生命、墨水、位置、回合与敌人意图。覆盖鼠标/触摸拖动绘路与已绘路线免费回访、桌面直达路线通关及重开、390×844 手机全图探索与两种契约、战斗疗伤、战斗中刷新续玩、取消重开保护存档、领取奖励及终门预览返回、暂停与帮助弹窗阻止快捷键、失败重开、禁用本地存储及移动端横向溢出检查。结果写入 `docs/playtest-report.json`，四张代表画面保存在 `docs/screenshots/`；浏览器控制台异常及失败请求也会使验收失败。

本次交互验证环境为 Chromium 桌面与 390×844 手机视口，使用原生鼠标/键盘事件及浏览器原生触摸事件；已检查拖动取消、触控通关与暂停图标。尚未进行实体手机或 Safari 真机验证。
