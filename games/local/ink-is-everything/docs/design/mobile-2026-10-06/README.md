# 移动端改造 · 2026-10-06

效果图：`concept.png`。保留现有纸墨场景资产，以横屏手机为设计基准；效果图定义页面关系、必要信息与拇指操作布局，实际场景沿用游戏当前的俯视纸墨画风。

- 首页：开始/继续、选关为主操作；帮助与全屏收在底部。
- 选关：章节入口与六房间探索路线；显示所在、已清、已访与未访，不提供绕过探索规则的普通跳关。
- 游玩：场景占满逻辑视口，顶部墨汁生命条、等级与钥印、房间短名、暂停；左移动，右固定用途的近战干笔与远程墨弹、闪避及溅墨。
- 装备：地上金色刻印不自动吸附，靠近后主动拾取。升级/拾取得到的待选装备只提醒数量，玩家主动打开，允许稍后；仅主动选择时暂停。
- 页面：暂停、帮助、成长与结算使用同一纸墨游戏内页面，无浏览器原生 top-layer 弹窗。返回主页保留当前进度。
- 方向：主页、选关、战斗及覆盖页统一横屏。可用时请求方向锁；竖屏视口直接旋转完整根容器，并逆变换场景点击、摇杆、瞄准与多指坐标。全屏失败也能继续。

## 实际验收记录

源码预回归覆盖三种手机视口、多指战斗、延迟装备与绘桥；最终汇总复验使用已构建的独立游戏与真实 Shell 生产入口。Chromium 桌面移动视口与原生 CDP 触控模拟共 **16/16 项通过，0 运行错误**。覆盖 844×390、390×844 旋转兜底、568×320 小屏；装备不自动暂停与主动拾取/稍后选择、三次存档恢复、墨尽结算重试与返回、手势取消/blur、尺寸变化、全屏成功/拒绝、存储不可用及 sandbox iframe。绘桥起终点均位于 HUD 和拇指控件之间且无遮挡，取消不扣墨，完成扣 8 墨。

真实第一章通过触屏完整通关：6 个房间、两枚钥印、墨桥支路、20 个敌人、双阶段守门者，10 次主动装备选择，游戏内 66 秒。Shell 游玩时隐藏外围导航并占满手机视口，主页保留单个返回目录入口。

证据：[浏览器汇总](./browser-report.md)、[机器可读结果](./browser-report.json)。代表截图：[首页](./actual-home-landscape.png)、[选关](./actual-chapters-landscape.png)、[战斗](./actual-chapter-boss.png)、[竖屏桥支路](./actual-bridge-portrait.png)、[墨尽结算](./actual-ink-exhausted-result-portrait.png)、[沉浸 Shell](./actual-shell-portrait-playing.png)、[通关](./actual-chapter-victory.png)。

以已构建的 Shell dist 在 4413 端口提供静态服务后，可在游戏目录复跑：

```sh
GAME_URL=http://127.0.0.1:4413/games/ink-is-everything/ \
SHELL_URL=http://127.0.0.1:4413/ \
CHROMIUM_PATH=/usr/bin/chromium \
node docs/mobile-redesign.playtest.mjs
```

不设置 GAME_URL 时默认使用 4412 源站；设置 QA_CASE 正则可单独复验相关流程。实体 iOS/Android 手机、Safari 真机和原生小游戏宿主尚未验证，浏览器触控模拟不能代替这些设备。
