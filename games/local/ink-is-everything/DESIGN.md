# Ink Is Everything · v3 规则与扩展设计

## 核心循环

生命与技能资源合并成同一个墨池。玩家以走位和免费闪避避开预警，消耗墨汁远攻或溅墨，再通过命中吸取、击杀恢复、主动捡回技能墨滴补充。装备与经验让同一套动作逐步改变，形成伤害、吸取、回收与机动等选择。

初始 90/100 墨汁。敌人命中直接扣墨，归零失败；主动施法、绘桥和交易至少保留 1 点。没有独立玩家 HP、金币、花墨治疗或删地图回墨。免费干笔在低墨时仍能吸取，但必须靠近敌人并观察攻击方向。

| 动作        | 基础效果                                        |
| ----------- | ----------------------------------------------- |
| 墨弹        | 消耗 6，伤害 8，冷却 0.4 秒                     |
| 溅墨        | 消耗 14，半径 135，伤害 14，冷却 4 秒           |
| 干笔        | 免费，伤害 5，范围 65，冷却 0.45 秒             |
| 闪避        | 免费，冷却 1.1 秒，位移 0.18 秒、无敌 0.22 秒   |
| 命中 / 击杀 | 按实际伤害吸取 25%；击杀直接恢复 6              |
| 技能回收    | 返还消耗的 50%，墨滴需移动到附近拾取，12 秒干涸 |

回收滴落在施法点约 80–110 像素外，0.5 秒后生效，基础拾取半径 26。满墨不会自动销毁可用回收滴；空放技能再捡回仍有净消耗。装备返还比例最高 80%，因此回收不能成为无敌原地循环。命中收益按实际伤害计算，不能利用对低血量敌人的过量伤害刷取恢复。

## 成长与路线

击杀经验为 6/8/16/50（洇墨灵、吐墨者、守卫、首领）。第一次升级需 12 经验，后续门槛每级增加 8；每级墨汁上限与当前墨汁各增加 8，并提供装备选择。场景中的金色装备刻印需玩家主动点击或通过附近互动拾取，不会吸附。升级与拾取只入队待选装备，顶部金色提醒表示数量；移动、战斗、过门继续进行，玩家主动打开选择页才暂停，并可关闭后稍后选择。每类装备最多三阶。

| 装备   | 每阶效果                             | 商店价格 |
| ------ | ------------------------------------ | -------: |
| 锋笔   | 墨弹伤害 +2，干笔伤害 +1             |       18 |
| 回流珀 | 吸取比例 +8 个百分点                 |       18 |
| 墨囊   | 墨汁上限 +16，立即恢复 16            |       24 |
| 溅墨印 | 溅墨伤害 +4、半径 +18、冷却 −0.35 秒 |       20 |
| 疾书靴 | 速度 +12，闪避冷却 −0.1 秒           |       16 |
| 聚墨环 | 拾取半径 +8，返还比例 +8 个百分点    |       18 |

墨囊购买净消耗 8 墨汁，容量收益需与当前生存资源权衡；从升级或场景奖励获得时不花墨汁。

第一章保留六个场景：庭院清场掉首件装备；北侧花 8 墨绘桥进入书库，取得 24 墨汁和装备；守印长廊、断笔兵营分别提供钥印与装备；洗笔驿站提供一次 24 墨汁泉水和商店；双钥印开启最终战。守门者 180 墨量，半量后增强弹幕与蓄力速度。清理过的房间与奖励不刷新。

## 数据与代码边界

`content` 定义内容，`core` 只运行收到的定义，`ui` 收集输入与展示，`render` 只读模拟状态。根 `engine.mjs` 把章节 ID 解析为定义对象，核心不导入章节注册表，也不写死第一章房间 ID、钥印总数或中文标题。公共敌人、技能、装备、规则和成长参数分别维护，章节只编排空间与遭遇。

房间通过 `objective/clearedObjective/clearMessage` 提供阶段文案，通过 `rewardPosition/clearReward` 指定可见战利品，通过 `waves` 编排后续遭遇，通过 `isFinal` 声明胜利房间。门、桥和交互物也是数据；新章节新增文件并在 `content/chapters/index.mjs` 注册即可自动进入 UI，构建递归复制内容目录。

存档 v3 不保存可信规则定义，恢复时重建几何并校验角色、装备、成长、波次、奖励与墨滴生命周期。公开 API 与新增章节步骤见 README；核心、模块边界和额外章节浏览器测试共同验证可扩展性。

## 验收边界

桌面与触屏真实输入覆盖整章、吸取与回收、升级和装备、绘桥、双钥印、最终战及刷新续玩。另有多指取消、低正墨恢复、商店购买、30 秒站桩观察和额外章节注入测试。结果以 `docs/*report.json` 为准；不沿用 v2 的独立生命、零墨可生存或旧通关统计。自动脚本能验证机制闭环，不能替代普通玩家的难度、趣味性、留存与单局时长测试。

## 移动端页面与显示

首页以开始/继续和选关为主操作；选关展示章节及已访、已清、未访的探索路线，不提供普通跳房间。游玩只显示墨汁生命条、等级/钥印、房间名、暂停与当前需要的操作。帮助、声音、全屏和已装备技能收纳于暂停页。近战干笔与远程墨弹有固定独立按钮，无需模式切换；墨不足不将墨弹静默变成近战，干笔挥笔弧与墨弹长尾明确呈现攻击方式。

完整游戏根容器在竖屏视口旋转，所有菜单与安全区随游戏方向映射；场景点击、瞄准和摇杆将物理坐标转换为逻辑横屏坐标。全屏与方向锁失败不阻断游玩，尺寸与方向变化只调整视口和取消输入，不重置对局。主动菜单使用根容器内覆盖页，避免原生弹窗与旋转脱离以及奖励队列强制重开。触点取消、失焦、结束、重试和返回主页均清理捕获与持续按键。

效果图与浏览器验证记录见 `docs/design/mobile-2026-10-06/`。
