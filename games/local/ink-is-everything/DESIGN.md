# Ink Is Everything · 第一章动作版设计

## 本次解决的问题

旧版实际操作是“选择房间 → 按攻击按钮 → 读事件”，概念图里的移动、墨弹、场景和危险没有成为可操纵的玩法。本版改为持续运行的俯视动作地牢：玩家在 960 × 600 的房间内移动、瞄准、射击、挥笔和闪避；敌人具有位置、蓄力方向、攻击过程和破绽。画面内的碰撞、弹道、命中、掉落与门的状态共同表达规则。

墨水仍是唯一可消耗的货币，不加入金币，不做删地图回墨。主路完全免费，支路绘桥才消耗墨水。触屏完成所有核心动作；键鼠是补充输入。暂停、说明、交易和结算由界面管理，界面暂停时不调用 `step`。

## 每几秒就能做出的决定

- **移动和瞄准**：靠走位避开红色攻击预警，利用石柱挡住双方墨弹。
- **墨弹**：每发消耗 2 墨、伤害 3、冷却 0.25 秒。安全距离换资源消耗，投射物真实飞行并命中。
- **干笔**：消耗 0、伤害 2、冷却 0.4 秒，65 像素的前方近战范围加目标自身半径。可以同时命中相邻墨灵，但需要进入近身危险区域；它不会格挡伤害。
- **闪避**：消耗 0，冷却 1.1 秒，冲刺 0.18 秒、无敌 0.22 秒。遵循墙和深渊碰撞，不能穿墙抄路。
- **治疗**：消耗 10 墨，恢复 3 血。初始 6/6 生命、64/100 墨；满血不扣墨。
- **探索**：花 8 墨，在庭院上方两个锚点之间画出实体墨桥。通过支路战斗后可获得 34 墨、2 生命，另有敌人掉落。
- **契约**：靠近驿站商人，以同一池墨换取永久强化。18 墨锋笔让墨弹伤害 4、干笔伤害 3；12 墨护页使生命上限 +2 并恢复 2；14 墨流云使移速 +10%、闪避冷却降至 0.72 秒。每种限购一次。

探索有看得见的回报，强攻节约时间，干笔承担站位风险。墨为零时仍可移动、闪避、近战、拾取战利品并完成最终战。敌人击败后有限掉墨；每击败五只普通敌人另掉一颗心。回访清理过的房间不会刷新敌人或补给。

## 一章六个房间

| 房间             | 空间与敌人组合                                   | 目的                                                 |
| ---------------- | ------------------------------------------------ | ---------------------------------------------------- |
| 落笔庭院         | 两个近战墨灵、一个吐墨者；两个矮墙；上方真实深渊 | 十秒内能够开火命中；学习移动与红色蓄力；选择是否绘桥 |
| 遗墨书库（支路） | 双书架夹出中央通道；两个近战墨灵和吐墨者         | 用一场短战换明确补给，北侧墨匣清场后靠近自动开启     |
| 守印长廊         | 错位石柱；两波敌人，第二波加入冲锋守卫           | 将躲弹与躲冲锋结合；清场掉落第一枚钥印               |
| 洗笔驿站         | 安全枢纽、一次免费泉水、契约师                   | 可见的资源再分配；北门通向第二钥印，东门是最终战     |
| 断笔兵营         | 左右纵向石柱；两波近战、远程、冲锋混合           | 学会离开冲锋线，再靠近输出；获得第二枚钥印           |
| 墨之门           | 四座石柱形成中央和环形通道；110 血守门者         | 运用整局资源、掩体与走位完成二阶段 Boss              |

两枚钥印靠近自动拾取；清场后钥印会主动飞向玩家，不需要额外“领取奖励”菜单。墨滴和心在 118 像素内向玩家聚拢。主路需要 17 次击杀，全探索需要 20 次。

常规向前门在清场后开启，Boss 门还要求两枚钥印。清场后走近门中心即可换房，也支持主动互动。战斗中回撤旧房间必须主动互动，避免一次闪避意外结束所在房间的战斗。再次进入时保存该房间剩余敌人、血量、波次与掉落。

## 敌人为什么能被躲开

敌人没有被动触碰伤害，所有伤害来自可识别的攻击过程。蓄力开始时锁定方向，之后不跟踪玩家改向。

- **洇墨灵**：8 血。进入近距离后蓄力 0.7 秒，沿锁定方向扑出约 114 像素，恢复 1.05 秒。伤害 1。
- **吐墨者**：9 血。保持一定距离，蓄力 0.95 秒后发射三个较慢的扇形墨弹，恢复 1.5 秒。每弹伤害 1。
- **断笔守卫**：22 血。蓄力 0.95 秒后直线冲锋约 306 像素，撞墙停止位移，恢复 1.5 秒。伤害 1。
- **终页守门者**：110 血。交替使用锁定方向冲锋与五发扇形墨弹。冲锋伤害 2，墨弹伤害 1。半血后蓄力从 0.95 缩至 0.72 秒，墨弹变为九发并加快；冲锋后仍有 1.65 秒破绽。

玩家受伤后有 1 秒保护，防止同一扇形弹幕连续瞬间扣光生命。闪避保护只有 0.22 秒，不能靠一直按按钮获得永久无敌。

## 模块约定与扩展

`levels.mjs` 保存章节、几何、敌人组合、波次、一次奖励、契约、连接门与出生点。`engine.mjs` 不访问 DOM、Canvas 或音频。`art.mjs` 只读取状态并绘图。界面收集触点/按键，在每帧调用模拟并负责菜单、音效和暂停。

公开模拟 API：

```js
const game = createGame('chapter-1'); // status = 'ready'
command(game, { type: 'start' });
step(
  game,
  {
    moveX: 0,
    moveY: 0, // -1..1，斜向归一化
    aimX: 640,
    aimY: 300, // 世界坐标瞄准目标
    shoot: false,
    melee: false,
    dash: false,
  },
  1 / 60,
);
command(game, { type: 'heal' });
command(game, { type: 'interact', objectId: 'market-east' });
command(game, { type: 'draw', bridgeId: 'archive-bridge' });
command(game, { type: 'buy', contractId: 'fine-nib' });
const json = serializeGame(game);
const restored = restoreGame(json); // 无效/旧版本存档返回 null
```

`command` 返回 `{ ok, message }`；商人互动额外返回 `shop: true`，换房额外返回 `roomChanged: true`。`state.message/messageTimer` 提供即时反馈，`getObjective` 返回当前目标，`getNearbyInteractable` 返回附近对象与距离。引擎验证绘桥的目标、距离与墨水，连续描线的完成度由界面验证。

当前房间通过 `getRoom(game)` 或 `game.rooms[game.roomId]` 读取；`game.enemies` 和 `game.pickups` 引用当前房间的对应数组。状态中的瞄准方向为归一化向量，输入中的瞄准点则是世界坐标。`step` 的秒数上限是 0.05，切换浏览器标签后不会突然跳过数秒。

添加新章节时配置独立 `LEVELS[id]`、`start/gate/spawn/initial/rules/contracts/rooms`。房间可增加几何、连接与波次；目前四种敌人只需在数据中组合。引入新敌人行为时扩展 `config` 和 `advanceEnemy`，为其预警形状补充渲染。新增章节的钥印数量同时更新 `requiredSeals` 和门配置；当前第一章的文本、存档生命/钥印上限检查按首章约束，扩展数值规则时也需同步这些验证。

存档 v2 重建可信章节几何并验证数值，恢复当前房间数组引用、敌人行动与飞行中的弹丸。旧回合版存档不会被错误解释成动作版状态。暂停是外部停止模拟，恢复游戏不重置攻击冷却，也不凭空增加无敌时间。

## 验证和时长边界

`node --test engine.test.mjs` 包含 18 项检查，覆盖真实移动碰撞、穿墙限制、墨弹命中与扣墨、干笔方向/范围、闪避冷却、敌人锁定预警、受伤、治疗、绘桥、门锁、奖励一次性、契约、存档，以及三组持续模拟：

1. 直接主路、不绘桥不买契约，完成双钥印与最终 Boss。
2. 绘桥进入书库、自动领取墨匣、购买锋笔契约，完成全部六房。
3. 与正式关卡一致的 110 血二阶段 Boss，玩家初始 0 墨且无升级，靠近战与闪避取胜。

三组持续模拟只提交实际移动/瞄准/动作输入与合法互动，不直接修改战斗中的生命、墨水、敌人血量或关卡进度。确定性熟练脚本能够在约 1–2 分钟内完成主线；它每帧获取坐标并同时操作移动、近战、瞄准，不能当作真人首玩时长。首玩目标是数分钟内获得完整操作与取舍体验，尚未通过真人计时验证原提案的 8–15 分钟，不用增加强制等待或堆血来假造时长。
