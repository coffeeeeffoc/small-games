# Ink Is Everything · 一滴墨，决定一切

第一章「遗忘之庭」是一个 13 房间、完全回合制的纸墨地牢。初始 72/100 墨、5/5 生命。墨水同时支付探索、攻击、恢复和契约；没有金币，也没有删除或擦除地图回收资源的操作。目标是领取两枚钥印，在终页门廊开启墨之门并击败守门者。

## 取舍与操作

| 操作     |  墨水 | 效果与取舍                                                                                                      |
| -------- | ----: | --------------------------------------------------------------------------------------------------------------- |
| 绘路     |     6 | 用 1 回合揭示并进入相邻房间，不受擦伤，敌人保持基础生命。                                                       |
| 摸索     |     0 | 用 2 回合揭示并进入相邻房间，擦伤 1 生命但最低保留 1；该房敌人额外获得 2 生命。所有代价事先告知，擦伤不会致死。 |
| 已知路径 |     0 | 在相邻、已揭示房间之间移动，不重复生成奖励或敌人。                                                              |
| 墨弹     |     5 | 造成 4 伤害；利锋契约提高到 6。                                                                                 |
| 干笔轻击 |     0 | 造成 1 伤害；有专注时造成 3，并消耗专注。                                                                       |
| 收笔防守 |     0 | 完全挡下本回合敌人的攻击。挡到攻击后获得 2 专注；空挡无收益，专注不叠加。                                       |
| 蘸墨疗伤 |     8 | 恢复 2 生命；护页契约提高到 3。战斗中治疗后敌人照常行动。                                                       |
| 收下馈赠 |     0 | 领取当前房间的一次性资源或钥印。                                                                                |
| 签订契约 | 10–12 | 三种永久强化各限一次，所有房间共享效果。                                                                        |

移动进入战斗不会立即受击。敌人意图清楚显示本回合名称、伤害和说明；玩家每次攻击、防守或治疗后执行该意图，再切换下一个意图。击杀会打断即将发生的攻击。战斗中不能移动；战胜之后可以自由回访已知道路。专注只在当前战斗有效，换房时清空。

先读意图、在蓄墨/散墨时出手，在扑击/横扫/刺页时防守，是零墨也能完成关卡的基础。它需要更多回合；墨弹可提前击杀、避免一个完整敌人循环。绘路可节省每场战斗的 2 点输出需求，并避免摸索擦伤、节省 1 回合。缺血时即使进入安全房间，以墨绘路也能保住容错；选择摸索，则可能需要把省下的墨投入治疗。墨水购买的是进度、容错与战斗效率，而不是继续游戏的唯一资格。

摸索的 2 回合会一次性计入行动统计，不添加现实等待，也不会令敌人提前行动。擦伤每次最多扣 1 生命，最低保留 1；只有首次揭示房间才发生，回走已知道路不再擦伤。因此初始 0 墨、1 生命也能通过观察意图完成整章，既有资源分配压力，也没有资源耗尽软锁。

## 关卡与奖励

从落笔处进入断句长廊后，三条方向均有可见收益提示：北侧遗墨书库安全提供 20 墨，并连接一次性免费恢复 3 生命的洗笔泉；东侧折页守卫持第一枚钥印与 8 墨；南侧无名契约师出售契约。商人旁的封墨匣有 4 生命墨怪，奖励 24 墨，既可用墨弹速取，也可通过意图与干笔获取。

折页守卫之后可选择洇墨庭院（安全获得 16 墨）或留白石桥。断笔骑士有 10 生命，持第二枚钥印与 10 墨。余白观台提供 12 墨和 1 生命，适合作为最终战前的补给支路。终页门廊可回访补给，开门不消耗钥印或墨。终页守门者基础 16 生命，使用「蓄墨 → 横扫 2 → 散墨 → 刺页 1」循环。

奖励由玩家主动领取。纯治疗点在满生命时无法消耗；满墨的纯墨箱也可留待之后。资源上限截断后的实际回收量用于统计。每份奖励、钥印和契约都有独立的一次性状态，来回走动不能刷取。

## 多种可行分配

- **直接破局：** 绘路找两名守卫，以墨弹结合防守快速拿钥印，然后进入终门。无需商人或所有支路即可无伤通关。
- **探索与契约：** 先签利锋/引路，取封墨匣与书库，以探索收益覆盖前期支出；利锋减少后续敌人循环，引路降低更多探索的成本。
- **干笔行者：** 初始墨设为 0 仍可全程免费摸索，擦伤最低保留 1 生命，再以防守专注配合干笔避免战斗伤害通关；回合、容错和操作成本更高，但不会因为资源耗尽软锁。
- **恢复容错：** 允许失误后用治疗、泉水和护页契约恢复，不要求玩家只选无伤路径。治疗时机也是一次战斗决定。

没有强制倒计时、刷怪或等待回墨。结算展示总行动回合、探索比例、四类墨水支出、余墨与玩法称号。28 回合以内为「行云流水」、45 回合以内为「从容有度」，其后为「细读每一页」；这些是可见的可选效率目标，不影响通关。同一最短路线以墨速攻约 21 回合，免费摸索与干笔约 44 回合，墨水投入有明确效率回报。首玩目标 8–15 分钟包含阅读纸面提示、路线规划与交互；熟练速通可能显著更短，不以强制等待拉长时长。

## 扩展与状态协议

`levels.mjs` 导出按章节 ID 索引的 `LEVELS`（`levels` 为别名），关卡包含规则、初始资源、契约、房间与链接。房间使用稳定字符串 ID、0–100 坐标、类型、说明、奖励提示及可选敌人与奖励；邻接表从 `links` 推导。增加章节时复制配置并调用 `createGame(newId)`，无需改动核心动作流程。当前引擎支持关卡自己的起点、终门、所需钥印数量、成本、战斗数值和契约列表；全新效果类型需要扩展 reducer。

`engine.mjs` 导出 `createGame(levelId = 'chapter-1')`、`act(state, { type, target? })`、`getRoom(state, id?)`、`getIntent(state)`、`getOptions(state)`。状态含 `roomId`、墨/生命/钥印、`status`、行动回合、专注、契约、房间字典、统计和日志。每个房间独立持有 `revealed`、`visited`、`cleared`、`claimed`、`traced`，敌人持有当前生命和意图序号。

`getOptions` 是界面可用动作的唯一来源，返回 `{ type, target?, label, cost, enabled, reason?, description, kind }[]`。`act` 返回 `{ state, ok, message, events }`，成功动作深拷贝状态；拒绝动作不修改状态、不消耗回合。胜负之后只允许 `restart`。核心引擎不依赖 DOM、音频、计时器或随机数，方便存档、重放与自动验证。

运行 `node --test engine.test.mjs`。测试覆盖两条不同资源策略、零墨开局及零墨残血最终战、失败重开、不可变性、资源不足、不可重复奖励/购买、钥印门槛、胜负终局锁定、战斗治疗/防守节奏和关卡可达性。
