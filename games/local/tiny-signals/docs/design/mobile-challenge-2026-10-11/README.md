# 同频归航：少步挑战与竖屏可玩性

2026-10-11。陶瓷、黄铜与四座岛的视觉按本次认可效果图实现，保留六关自由选关规则；四盘同时可见，采用竖屏。核心循环不变：同一方向控制四位信使，利用障碍错开步调，到站即留下，争取最少步数。

## 页面与操作

- 保留现有打开即玩的入口。顶部用 44px 暂停与返回按钮提供明确退出路径；返回后显示专属主页，继续保留局面，选关从六个真实关卡选择。主页显示当前任务、已完成数量和开始/继续。
- 游玩保留四盘、步数、简明目标和底部拇指工具区。竖屏上压缩外围说明，帮助按需展开；方向输入沿用任意位置单指滑动，双指允许滚动。菜单和主页不响应手势，触点取消、失焦、暂停清除手势与待执行输入。
- 每位信使首次到站时亮边/弹跳，播报名字及已归航数量；撤销后重走仍可感知，不靠颜色单独表达。关闭动画偏好下保留文字。
- 胜利沿用棋盘下方的结算横幅（示意图右屏展开显示结算信息层级），显示使用步数、最优星/提示标记、同关挑战目标差距，提供再挑战/下一站、分享和返回。开发试玩与使用提示的记录不产生公开挑战。
- 合法分享参数只允许版本、稳定关卡 ID 和 1–100000 整数步数且不少于已证明最优解。不合法或重复关键参数回退正常游玩，不显示用户提供文本。邀请成绩明确为好友自报，不声称服务端排行榜。
- 挑战重开、撤销、分享与正常局相同，但不写正常关卡最佳或最后选关；离开挑战回主页后可继续正常关卡。开发模式全部视为试玩，不写正常进度、不分享。
- 复用公共 H5 publishing 的分享和诚实取消/失败状态；不加入奖励或强迫广告来打断思考。

## 预期验收

手机 390×844 与 320×568 实际浏览器输入；单指滑动、取消、多指、暂停/恢复、预览、到站提示、正常胜利/存档、受邀挑战/存档隔离、分享取消/拒绝复制降级、开发试玩禁分享；生产 dist 资源、桌面按键及 Node 规则测试。浏览器模拟不当真机。
