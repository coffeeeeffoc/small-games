| 主按钮 | 两侧 30 px 边距，330 × 58，18 px 圆角 |

| 候选 | y=623；每个 104 × 119；三个位置固定，取走后不重排 |
| 底部辅助 | y=767；高度 43 px，实际实现补足至少 44 px 热区；再加底部安全区 |

积木用圆润方格、顶部短高光与底部阴影形成软立体触感；形状整体轮廓必须清楚。棋盘格间留白让对象容易分辨。主按钮墨绿，避免和棋盘上的三种块色竞争注意力。SVG 以直接可还原的 CSS/SVG 几何形状制作，无远程图片依赖。

## 屏幕与状态约束

积木拖放需要棋盘及候选同时可见，短纵向局面更适合单手触屏，因此选择竖屏。安全区额外加在外层，不把刘海或平台胶囊放入固定逻辑视口。短屏优先压缩标题、目标与棋盘间留白；棋盘和三候选根据可用空间一致缩放，主按钮热区不低于 44 px。宽屏居中限制内容宽度，保留竖屏构图。

游戏页仅显示当下目标、组数、棋盘、候选和两个必要工具，不铺满规则文字。第一步完成后的即时短句取代长教程；帮助在玩家主动触发后进入独立状态。不可放块保留轮廓，标记禁用；合法/非法预览除颜色还使用边框与禁止反馈。交叉消除与连击采用短促光晕、数字与轻震，不延长强制等待。设置可关闭振动、声音与强闪光。

选关卡片 58 px 宽、73 px 高，五列；已通关卡片显示星，当前关深绿突出，未来关浅色并有锁图标。锁定状态不能只靠颜色。结算的主操作距底部安全区充足，失败沿用布局但显示具体原因，提供实际可用的撤销或重开。

H5 全屏入口在暂停/设置中出现一次；原生平台隐藏。暂停图标为两根实心竖条，SVG 原图已使用 rect 绘制。主页积木插画是品牌识别核心，避免以大量文字说明代替画面。
