# H5 首页、退出与开发权限调整

效果图先于本次界面实现生成，390 × 844 手机竖屏。延续奶油纸感、墨绿主按钮和彩色软积木，不改变直接拖放玩法。

主页把关卡进度与“开始 / 继续”作为主操作，选关和无尽用并排卡片，榜单、帮助和设置放底部轻入口。主操作、卡片和图标按钮保持至少 44 px 热区，短屏压缩插画留白。

游玩左上角显示“首页”，直接保存离线当前局并回主页；暂停页另有明确“退出关卡”，一键放弃当前离线局。开发试玩退出只结束试玩，保留原有真实存档。在线对局保留服务端确认、结束结算与网络恢复机制。

开发模式使用公共 SmallGamesDev.isEnabled。普通选关页全关可点，每次选关明确进入隔离试玩；主页开始和继续仍执行普通成长规则。开发工具页按需进入，集中授权任意关、参考解、撤销补充、重置、清棋盘与受校验参数 API；扩展动作经过相同模式校验与隔离上下文。普通模式隐藏这些入口。

页面关系：主页 → 开始 / 继续 或 选关 → 关卡说明 → 游戏；游戏 → 首页（保存）或暂停 → 退出（放弃）；开发主页 / 选关 / 暂停 → 开发工具 → 隔离试玩。

## 实现与实测

首页设置仅放右上角，底部保留排行榜和玩法帮助，减少重复。390 × 844、360 × 640、320 × 568 的手机浏览器实测首页全部控件留在视口内；游玩保留 8 × 8 棋盘、三候选和撤销 / 提示热区。开发模式截图中的深绿“开发”浮动按钮来自公共调试面板，可直接拖动；普通玩家不显示。实际 H5 截图为 `home-dev-actual-*`、`game-dev-actual-*`、`levels-dev-actual-*`、`pause-dev-actual-*` 和 `developer-tools-actual-*`。测试环境是 Chromium 手机视口模拟、真实浏览器触屏输入，不是真机验收。

开发接口仅在公共开关开启时注册 `window.ThreeChooseTwoDev`。`permissions` 返回集中授权表；`snapshot()` 返回独立副本；`level(id)` 直接开始指定关卡的隔离试玩；`solution()` 返回从初始局面开始的参考解。`refillUndo(count)` 补撤销；`restart()` 恢复关卡原始配置；`clearBoard()` 清试玩棋盘；`setParameters({undoRemaining,groupLimit,discardBudget,goalLines})` 校验后调整独立配置。增加组数可恢复组数耗尽的试玩，额外候选使用确定库存；参数变更不会写入普通存档。`registerActions([{id,label,permission,run}])` 为后续扩展提供统一校验与安全 API，`run` 接收同一开发接口，不持有真实存档或在线会话的可变引用。

玩家在 dev 模式点击首页开始 / 继续仍按普通规则解锁、成长和结算；dev 选关与调试修改会进入隔离试玩。在线和无尽的调试状态修改被明确拒绝，任意关试玩可保留在线恢复数据后独立开始。活跃在线局从游戏直接回首页后主按钮恢复原会话及未确认队列；已主动结束但待确认的在线成绩保留单独查看 / 重连入口，首页主操作仍可恢复本地关卡。

开发模块语义单测 3 项通过，覆盖参数校验、写入前隔离、扩展每次调用的模式检查、快照副本、在线状态拒绝，以及组数耗尽后的正确续组。浏览器正式行为回归与公共 dev 开关检查由本次交付的统一验证记录汇总。

最后触控检查将首页开发入口补足 44 × 44 CSS px；以源码预览重新验证上述三种手机尺寸，开发入口实测宽 48 px（320 px 视口为 44 px）/ 高 44 px，页面无纵横溢出，重新保存首页截图。
