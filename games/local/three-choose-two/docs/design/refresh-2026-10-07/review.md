# 独立审查记录

审查日期：2026-10-07。审查范围为本次关卡难度、H5 首页与导航、开发调试隔离、原生首页与退出流程，以及对应行为测试。当前已审代码未发现阻断缺陷。

## 代码结论

- **关卡与旧存档**：第 1–5 关保留教学配置，第 6–30 关改为固定规划棋盘与库存。关卡 ID、规则版本、进度版本保持稳定，最大组数未缩小。引擎继续读取保存状态中的完整 `config`，旧关卡可以按原棋盘、库存和目标完成，新开局使用新配置。完整参考解、跨组铺垫、弃格预算与旧第 6 关恢复用例均已审阅。
- **H5 返回与退出**：游玩页首页入口保存未完成局面，主页继续恢复该局；显式退出只清除当前本地局，保留已获得星级、解锁和练习纪录。开发试玩退出保留原正式存档。动画回调检查状态与局次，避免旧回调处理新局。
- **开发权限隔离**：普通玩家仍遵守解锁顺序。开发选关可访问全部关卡，准备页与真正试玩状态分离。改棋盘、撤销、参数或重置前保存正式局，再进入独立试玩；试玩不写星级、解锁、练习纪录或广告续局凭据。扩展动作和 API 写操作每次检查统一开发开关，快照为深拷贝，在线与无尽状态不能通过这些操作改局。启用开发模式仍可按正常规则进行普通成长和在线对局。
- **在线恢复**：直接回主页保留同一在线会话、序号与未确认落子；跳入试玩前保存在线恢复数据，再断开内存引用。显式本地退出不清除独立在线恢复队列或结束意图。新增入口未绕过原服务端确认与结算流程。
- **原生流程**：本地退出清除当前状态、局次与待处理本局奖励，保留正式进度和独立在线恢复信息。帮助页记录进入来源，首页无对局时的后台切换不进入空状态暂停页。广告异步结果检查局次与运行 ID，备用点击路径同样阻止后台或广告期间输入。
- **旧局展示窄修**：原生主页、帮助、游玩和结算优先读取保存状态的标题、提示与配置，缺失时回退到关卡目录。该窄修已单独静态审阅，避免新难度文案误导仍在进行的旧局。
- **Shell 契约**：已审阅 `standalone-game-checks.mjs` 和 `pages-smoke.mjs` 中新增直接首页、继续、显式退出及正常锁关断言。入口仍使用语义动作标识，嵌入游玩与返回主页继续检查宿主导航的隐藏和恢复。

## 审查中修正的问题

1. 新增原生首页帮助入口后，后台切换可能把无对局帮助页切到暂停页；已通过来源记录和生命周期条件修正。
2. 原生旧广告结果可能在退出或换局后继续处理；已增加局次与运行 ID 检查，并补齐备用点击入口的输入限制。
3. 开发参数增加组数后，耗尽状态原先仍停在失败；现在正确开启下一组确定库存，并检查棋盘是否仍有合法落点。参数改变也清除会恢复旧参数的撤销快照。
4. 原生旧局标题与提示原先读取新目录；已改为保存配置优先、目录回退。

浏览器手机尺寸和 CDP 触屏属于桌面模拟。原生验证使用 mock 平台 SDK、登录或广告能力；H5 新在线导航用例使用 transport fixture。它们不等同于真机、真实平台登录、真实广告或真实线上排位服务的验收。独立审查未进行额外截图人工视觉验收。
