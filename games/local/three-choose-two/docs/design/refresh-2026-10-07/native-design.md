# 原生 Canvas 改版先行方案

使用既有竖屏纸色与三色积木风格，390 × 844 为基准；320 × 640 使用统一缩放和内容压缩。

首页将“继续闯关”和“选关”并列为第一排；无尽练习保留独立整行入口与个人纪录；设置置于右上角，排行榜与玩法提示留在下方。原生首次“继续闯关”沿用共享平台烟测契约。

游玩页左上明确“首页”，触屏直接返回并保存棋盘。暂停页保留继续/重开，并增加“退出关卡”；退出本地局面清除 currentGame 与原生本局奖励凭据，不修改关卡纪录、线上恢复凭据或排位结算。练习保留“结束练习”的个人纪录结算，并单独提供退出练习。在线结束继续调用现有 endOnline 服务端权威结算。

原生使用宿主全屏与平台调试，不显示 Web 全屏入口或 SmallGamesDev 按钮。概念图仅用于实施前布局依据；交付截图使用构建后的实际 Canvas 运行结果，均属 Chromium 触屏模拟，非平台真机验收。
