## 关键决定、资源与修改边界

- React 管理菜单/HUD，Three.js 管理画面；位置和相机不通过 React 每帧更新。核心模型、探索、机关、碰撞、存档校验可脱离 Three.js 测试。
- Y 向上、XZ 平面；显式房间图统一生成通路、墙体、碰撞、锚点和地图。房间间距 8、净宽约 6、通道 2.3、角色半径 0.24。位移子步 ≤0.07，分轴圆/AABB 保留墙边滑动；大帧间隔模拟上限 0.25 秒。
- 20 份确定布局不使用随机生成。各关都有 seed 与布局版本，当前装饰也确定；未来任何随机装饰必须从 seed 派生，不能破坏图结构。
- 所有交互都经距离、面前视锥与实体线段遮挡判断。镜子只参与渲染与实体碰撞，倒影不会生成目标或记录。
- Reflector 标准 512² / 轻量 256²，每帧最多两个近处反射器，最多一层；离屏反射时隐藏其他反射器并保留实墙背板。超出近处预算时不展示旧反射。不会用静态背景或金属度冒充关键镜子。
- 程序纹理、窗景、家具和合成提示音全部随本地代码生成，无远程素材链接。静态几何按材质合并；切关清理 RAF、事件、音频、纹理、材质、几何及反射目标。
- 小地图只依赖已发现内容，展开地图/设置/标记/暂停时计时停止。A 转 B 是永久本局记录；五类标记不限制次数，每锚点一个，已排查为玩家判断。
- 主存档和独立进度备份分离；三秒节流+关键事件+生命周期保存，升级/损坏不白屏。异常不静默吞掉，提供提示和恢复按钮。
- Shell 新增 manifest、workspace 依赖、锁文件、实际操作 smoke 分支与目录说明。保留先前的 `AGENTS.md`、其他游戏和 prompts 未提交工作，没有提交或推送。
- 曾遇开发端口与另一游戏服务冲突，已改为独立 `4437`；误打开其他游戏的诊断图片已移除，最终报告均来自本游戏。
