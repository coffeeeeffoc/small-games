# 迷境漫游

可独立运行的 3D 第一人称探索游戏。20 个手工房间图、五种主题、A 无地图 / B 迷雾地图、实体标记、镜面核实、永久开关与捷径、逐关解锁和本地成绩。没有战斗、追逐、倒计时、广告或联网服务。

## 启动与检查

在仓库根目录，使用仓库指定的 **Node.js 24.21.0+、pnpm 12.6.0**：

```powershell
pnpm install --frozen-lockfile
pnpm --filter @coffeeeeffoc/maze-wander dev
```

打开 <http://localhost:4437>。手机与电脑在同一网络时，使用启动输出中的电脑局域网地址和 `4437` 端口；浏览器防火墙访问权限由本机配置决定。优先横屏，竖屏仍可玩。暂停菜单可请求浏览器原生全屏；不依赖强制方向锁。

```powershell
pnpm --filter @coffeeeeffoc/maze-wander typecheck
pnpm --filter @coffeeeeffoc/maze-wander test
pnpm --filter @coffeeeeffoc/maze-wander build
pnpm check:games maze-wander
```

以下三个浏览器检查需要上述开发服务保持运行。首次使用 Playwright 的环境先执行 `pnpm exec playwright install chromium`。

```powershell
pnpm --filter @coffeeeeffoc/maze-wander test:browser
pnpm --filter @coffeeeeffoc/maze-wander test:themes
pnpm --filter @coffeeeeffoc/maze-wander test:mobile
```

可以通过 `MAZE_URL` 指向另一个地址。测试显式添加 `?dev=1`，使用统一开发模式下的快照和全关试玩入口获取状态；移动、转向、贴牌、地图、暂停和出口均使用浏览器实际输入。独立页面、Shell iframe 与正式构建均支持此开关；也可设置 `localStorage.setItem('dev', '1')` 后刷新，`?dev=0` 优先于存储并关闭，普通模式不显示该入口。

```powershell
# 先 build；测试自行在 127.0.0.1:4438 启停生产预览服务
pnpm --filter @coffeeeeffoc/maze-wander test:release

# 人工查看生产包（先停止占用 4437 的 dev）
pnpm --filter @coffeeeeffoc/maze-wander preview
```

生产输出为 `dist/`，相对资源路径，可部署在子目录；React 19.2.8、Three.js 0.180.0、Vite 8.2.2 均沿用仓库已安装版本。所有图片由本地 Canvas / 几何体程序生成，无外部 CDN、素材下载或账号依赖。音效为 Web Audio 合成的轻柔提示，可关闭。第三方库随依赖保留其许可（React / Three.js / Vite 为 MIT，Playwright 为 Apache-2.0）；没有搬运第三方游戏美术。

## 操作

| PC            | 触屏     | 行为                                                            |
| ------------- | -------- | --------------------------------------------------------------- |
| WASD / 方向键 | 左摇杆   | 平面移动，斜向不加速                                            |
| 鼠标          | 右侧拖动 | 转向，俯仰受限                                                  |
| E             | 检查     | 近距离检查开口、镜子、控制牌、出口                              |
| Q             | 标记     | 对准实体“＋ 标记”牌，选择来过、方向箭头、已排查、待回访、参考点 |
| M             | 地图     | B 打开已探索大图；A 先明确确认永久转为 B                        |
| Esc           | 暂停     | 暂停与保存，点击继续才恢复                                      |
| H             | 知道了   | 跳过当前关卡教程                                                |

PC 点击“进入迷境 / 继续探索”才锁定鼠标；解锁、失焦、隐藏页面自动暂停。锁定被浏览器拒绝时可选拖动转向。触屏使用独立 pointerId，松开和取消触点会清除输入；按钮不会转动视角。教程可跳过，按实际输入方式显示。

每个房间门框旁都有分支标记锚点，实墙也有参考牌；镜面牌贴在镜子的实体表面。箭头由玩家选择世界方向，其地面指示固定在空间里。已排查是玩家自己的判断，不保证这条路没有出口。没有标记数量或次数上限。

## 模式、进度与存档

- 第一次只开放 01，任意模式通关解锁下一关。开始过的关卡记为重游；A/B 成绩分开保存，仅为本机个人回顾，不做公平排行。
- A 没有任何地图、出口方向、距离或房间编号。打开地图前显示“查看后，本局按迷雾地图模式记录。”；确认后永久变成 B。收起 B 地图不会获得 A 成绩。
- B 区分到访房间、看到候选开口、核实性质、亲自穿过连接。看到门洞或镜中倒影不会发现背后的房间；地图包围盒只取已发现房间及留白。
- 存档主键 `maze-wander:v1`，独立进度与设置备份 `maze-wander:v1:profile`。每 3 秒节流保存，交互、菜单和页面生命周期另行保存。版本不兼容回到安全入口；主存档损坏尝试保留独立进度备份，存储不可用仍可游玩并提示。
- 暂停、设置、大地图、标记和确认菜单都停止世界与活动用时。重开需确认，只清当前局。
- 开发环境选关页提供全部关卡试玩，试玩不写入正式进度和成绩。完整布局只经开发 API 检查，没有正式完整地图菜单。客户端仍含关卡数据，不能据此声称防作弊。

## 代码与关卡

| 路径                          | 职责                                                             |
| ----------------------------- | ---------------------------------------------------------------- |
| `src/config.ts`               | 游戏名称、文案基调、存档键；Shell 目录标题为登记元数据           |
| `src/game/core/`              | 纯规则、坐标、几何与碰撞、探索、交互、地图投影、存档校验         |
| `src/game/levels/levels.ts`   | 20 份显式坐标/边/主题/地标/教程/条件与逐关设计说明               |
| `src/game/levels/validate.ts` | 合法网格、回环及位置+机关位图状态搜索                            |
| `src/game/runtime/`           | 帧循环、暂停、低频 HUD、音频生命周期                             |
| `src/game/render/`            | 统一权威几何的 Three.js 画面、镜面、实体标记、资源回收           |
| `src/platform/`               | 浏览器输入、localStorage 适配；核心规则不依赖浏览器或 Three.js   |
| `src/features/`               | 迷雾地图、触屏控件和 SVG 暂停图标                                |
| `tests/`                      | 规则/布局/碰撞路径重放、真实浏览器输入、主题、手机和生产异常检查 |

坐标约定：Y 向上、XZ 地面，北为 -Z；房间中心相距 8，房间约 6×6，通道净宽 2.3，角色半径 0.24、视高 1.62、速度 3.3。每帧最大模拟间隔 0.25 秒，位移细分到不超过 0.07，圆/AABB 检测后分轴滑动。装饰的实体底座也有碰撞。

没有随机迷宫生成。每关保留版本和明确 seed，几何、机关与装饰均确定；后续若加入随机装饰必须从该 seed 派生，不能改变房间图。全部关卡节点数与任务表一致，20 为允许范围内的 30 节点。

镜子采用 Three.js `Reflector` 平面反射，标准 512² / 轻量 256²，每主帧最多两个近处反射器、最多一层。反射渲染时暂时隐藏其余反射器，露出实墙背板，避免相互递归；远处镜面不显示陈旧反射。镜中镜不进行无限反射，不影响真假通路与现场检查答案。纯渲染倒影不生成目标、探索记录或第二枚标记。贴牌与镜面留出明确的空间偏移。静态网格按材质合并，几何/材质/纹理复用，退出或切关释放事件、RAF、音频和反射目标。

本期只针对 PC 浏览器与手机 H5。**未接入微信、Bilibili 等原生小游戏平台**；平台接口分离不等于已经适配原生平台。

实际验证、截图、性能采样和真实限制见 [实施状态](docs/IMPLEMENTATION_STATUS.md)。图搜索与自动路径重放不代表人工完整游玩了 20 关。
