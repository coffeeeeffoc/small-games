# 无尽伤害说明、图标操作与更大弹丸

## 本次局部设计

沿用星云游乐场的 Cocos 场景与竖屏布局，实施前保存 [局部效果图](concept.svg)。

- 奖励弹窗只展示强化卡；移除底部“保存离开”和“激励补给”，收紧空余高度。选择强化后继续，顶部原有返回/设置路径仍可用。
- 开始/继续、重开、激励补给、收回、返回/离开、关闭、下一关、分享和设置开关使用绘制图标。模式名称、奖励效果和确认事项保留必要文字。图标保留动作名称、开关状态、禁用状态和至少 44 CSS px 热区；暂停仍是两根实心竖条。
- 弹丸半径从 6 增至 8，显示和碰撞共享 `FIELD.radius`。不更改伤害、速度、技能概率或关卡数据。
- 闪电连锁绘制源目标到受伤目标的连线；爆裂显示金色邻近三乘三格范围。减弱动态时仍保留静态连线/范围轮廓，避免数字无来源地下降。帮助内解释伤害、穿透和次生伤害。

## 调查与修复

22 表示每轮的发射球数，不是总伤害上限。基础每击 1，重击最高每击 4，暴击翻倍，共鸣有 8% 概率额外 +1。穿透本身不放大伤害，离开目标后经反弹再次进入可以再次命中。单个 170 血目标的确定性场景中，22 球、4 伤害、2 阶穿透会产生 43 次真实命中、共 172 伤害；基础 1 伤害时相同往返只扣 44。

另有真实 bug：穿透入口沿速度各分量符号微移，可能把擦边接触推回轮廓外；下一次循环清掉 `ignored`，同一次接触随即再次计伤。单球在圆形/六边形擦边时可连续扣三次。修复删除穿透分支的这两次微移，保留准确接触位置，让正常行进离开目标后再解除忽略。反射分支的法线微移保留。

邻近目标掉数来自三种已有机制：爆裂余波（每阶 10% 概率、最多 30%，邻格各扣当前伤害）、闪电连锁（每阶 12%、最多 36%，另一颗扣当前伤害）、爆裂晶体击碎（邻格扣自身满血的 45%，向上取整，并可连爆）。普通命中不会无条件损伤周围球珠。此前连锁事件存在，但画面未消费该事件，本次补上。
