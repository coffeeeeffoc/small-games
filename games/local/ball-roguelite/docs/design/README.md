# 星轨弹珠 · 移动端设计

最新圆球、节拍与双模式改版见 [rhythm/README.md](rhythm/README.md)，该目录包含改版前效果图及改版后触屏验证截图。以下保留初版设计与验收记录。

先生成 `concept.png`，再实现主页、核心游玩和选关界面。视觉采用午夜蓝星空、薄荷青与紫色倒角砖、发光弹珠及轨道线，场景对象使用 Canvas 2D 几何绘制，菜单使用原生按钮。概念图用于风格和信息层级参考，运行界面以实际截图为准。

选择竖屏：从底部向上发射、砖块逐轮下降，纵向空间便于观察砖阵与危险。逻辑画布为 390 × 620，手机横屏和桌面等比缩放；尺寸与全屏变化不会重置对局。触点按实际 Canvas 边界映射，多余留白不接收发射。主页、选关、帮助在横屏下重排或滚动，主操作热区至少 44 CSS px。

主页突出开始/继续，提供选关和无尽挑战；玩法规则收在帮助页。游玩只显示关卡、波次、分数、球数、暂停与回收。强化、暂停、结算通过页面切换组织。暂停图标由两根实心 SVG 竖条组成。六种强化改变球数、伤害、穿透、爆裂、闪电和暴击，可组合叠加。

Canvas 限制 DPR ≤ 2、180 个碎片、15 个冲击圈和20条闪电；支持减少动态效果。音效由 Web Audio 短音合成，点击后才启用，暂停时挂起，离开时释放。设置保存音效和震动偏好。

运行验证及实际截图由 `tests/browser.mjs` 生成。验证为 Linux Chromium 的手机触屏模拟，不代表手机真机、微信/抖音原生小游戏或 iOS/Android 设备验收。

Chromium 151.0.7922.173 的实际触屏检查覆盖 390×844、320×568、844×390；走通主页、普通玩家选关、瞄准取消、发射、飞行中暂停、帮助返回、回合恢复、自然通关、三选一强化、下一关解锁、无尽失败及重试。独立和同源 iframe 均通过；实际进入/退出全屏、尺寸变化和失焦暂停通过。URL/存储开发开关、显式关闭、试玩隔离及禁止存储的降级通过，未捕获到页面错误或资源 HTTP 错误。详细结果见 `browser-report.json`，截图包含瞄准、命中、强化、暂停、成功及失败。

16 项规则和存档测试包含六关在 24/60 fps 下使用实际物理自然通关、12 fps 连续碰撞、穿透接触去重、爆裂连锁、收球、警戒线失败、超时回收、强化叠加、重复结算、存档校验/迁移与试玩隔离。
