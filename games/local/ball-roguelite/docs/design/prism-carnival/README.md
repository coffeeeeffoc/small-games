# 星轨弹珠 · 星云游乐场

## 产品方案（效果图先行）

保留 Cocos 3.8.8 Web 引擎、竖屏拖拽瞄准、关卡/无尽双存档与主动激励补给。本轮从玩法难度、回收过程与页面导航改进，不增加全屏按钮。

- 风格：蓝紫星云、青色轨道、粉色与金色行星/彗星、透明彩色球珠。背景边缘活泼，战场中心降低对比以保持数字辨识。场地四边完整发光，顶部明确反弹边界。
- 首页：继续、关卡、无尽入口；全局齿轮打开设置。无尽已有存档时同时提供继续与重新开局，重开需确认。
- 游戏：左上返回、右上设置、独立双竖条暂停；返回直接弹出确认，取消回到原状态，确认保存回合检查点并退出。暂停仅承担暂停/继续。设置内提供声音、振动、帮助；关闭后回原页面。设置/确认/奖励/补给均暂停模拟，不自动续玩后台对局。
- 所有选择弹窗居中：局部半透明遮罩、三张强化卡或两张补给卡，保留面板四周战场。确认返回和重开为明确两按钮，禁止重复确认导致两次创建或发奖。
- 关卡保留既有稳定ID，调整为偏折射/绕行的布局，逐步引入吸收器，再增加两关专家挑战。关卡列表分页，锁定状态、机制说明和已完成进度清楚。
- 吸收器：紫色涡旋核心与向内箭纹，先扣耐久，未击碎则吞掉本轮该颗发射球；不扣永久球数。突破、避开或先击破形成策略。外观/帮助/事件反馈说明机制。
- 手感：允许约7°浅角，弱重力与弧线、受限邻珠折射及轻微撞击损能。手动或超时回收均经过约1秒逐渐加速的弧形召回；自然落地汇入发射点，有收集涟漪与计数反馈。回收可暂停，全部归位才下降一轮。
- 破裂：目标受损出现裂痕，击碎产生彩色半透明多边形玻璃碎片、短暂高光，碎片旋转后受重力落下并淡出。减弱动态时保留静态状态/短淡出，关闭旋转和粒子。
- 无尽：减缓加球，四波左右才出现加球点，不再靠连续击碎每轮无限增长；保留强化上限及后期压力。

## 验收

先生成 `concept.png`，再改 UI。以 390×844、320×568、844×390 触屏检查设置/返回/重开/居中弹窗及核心玩法。检查吸收器、浅角、多次反弹、损能、召回暂停、超时召回、自然收球、裂痕碎裂及存档恢复。用固定策略比较关卡可达性与难度，不能只证明一个脚本通关；保存实际截图、数值报告与验证记录。完成准确候选验证后推送 dev。

真机与真实广告 SDK 仍是独立验收范围；不得将浏览器触屏模拟称为手机真机。
