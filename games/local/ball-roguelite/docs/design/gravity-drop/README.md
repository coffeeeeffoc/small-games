# 重力落珠交互 · 2026-10-25

参考用户提供的 20.03 秒录屏理解重力落珠与目标间往返碰撞，保留星轨弹珠的星云玻璃风格和 Cocos 3.8.8 运行层。录屏仅作交互参考，素材未复制。按用户明确反馈，回收在底部完成。

## 当前交互

- 顶部中央发射，松手位置决定方向和初速度：近处轻投，远处快投。力度和轨迹预览使用同一套重力计算；取消、失焦、多指不误发射。
- 没有撞到珠子就直接下落；撞到珠子后继续受重力影响并反弹，可以在两颗目标之间往返。复用 240Hz 连续圆形/六边形扫掠和有限折射，真正离开目标后再次接触才扣血。
- 接触容器底部立即移除球的物理实体，停止碰撞。收集光效只在底部短暂下沉消散；不再把球吸回顶部，也不为装饰动画延迟回合。顶部仅准备下一轮球。
- 主动收回或 24 秒超时，剩余球在原横坐标向下加速落底，放弃剩余伤害。等所有在场球落底或被吸收、连发完成后，目标才上升。暂停冻结整个过程。
- 拖尾保留反弹拐点，重叠轨迹限制透明度，球形残影与实体区分。支持减少动态。八关、无尽、强化、吸收器、失败和重试保留。
- 存档输出 schema 4，兼容 1/2/3，保留双模式进度、解锁与已消耗奖励；旧规则存档禁止混版成绩分享。Shell 接受 v1–v4 链接交给游戏识别。

布局见 [concept.svg](concept.svg)。修改范围包括 core、main、render、levels、调用这些规则的测试/策略脚本、Shell 分享和发射消费者，以及 [上架资料](../../../publishing/STATUS.md)。
