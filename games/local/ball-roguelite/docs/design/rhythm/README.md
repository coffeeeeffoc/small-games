# 圆球、节拍与双模式

本轮改版先生成 `concept.svg`，再实现界面、物理和渲染；`concept.png` 为该设计图的导出。三个手机画面分别描述主页双模式入口、关卡选择及无尽游玩。概念图的长轨迹用于说明真实反弹拐点，实际游玩采用短而渐隐的轨迹，避免遮挡砖阵。

沿用竖屏：弹珠从底部向上弹射，七列砖阵逐轮下降，主页、选关和对局均采用同一方向。横屏等比缩放场地、重排菜单，保持触点与 Canvas 坐标一致。主页主按钮继续上次模式，两张并列卡片分别进入关卡选关和无尽挑战；关卡选择提供继续入口。两种模式独立保存，暂停、强化、结算均有返回主页路径。

球体半径从 4.5 增至 6 逻辑像素，使用圆形轮廓、体积渐变和高光。核心计算圆球与砖块边缘、角落的连续接触，角落斜反弹产生真实路线变化。120 BPM 节拍中穿插四组双连发，碰撞给予最多 28% 的速度提升并指数衰减，不改变玩家的初始瞄准方向。轨迹记录真实位置及碰撞拐点，不用假曲线偏移碰撞位置。99 球在 6.125 秒内全部出场，14 秒自动回收上限保留。

声音采用轻量 Web Audio 合成：重拍低音、轻拍短音、随连击变化的五声音阶碰撞声。最多 10 个同时发声节点，无后台计时器；暂停、静音和页面离开清理待发声节点。减少动态效果保留静态圆球，关闭拖尾、跳动装饰与震屏。

核心规则、存档迁移和浏览器测试沿用 `tests/`。`browser-report.json` 与 `mobile-*.png` 为本轮实际运行证据，不是效果图。验收环境为 Linux Chromium 手机触屏模拟，不代表手机真机或微信、抖音、B 站原生小游戏验收。

2026-10-06 验证：28 项规则和存档测试通过，包含六关在 24/60 FPS 下自然通关、144 FPS 运动一致性、99 球发射上限、旧存档墙边位置兼容、双模式强化和结算隔离。Chromium 151.0.7922.173 的 9 组浏览器检查通过，覆盖 390×844、320×568、844×390 的真实触屏输入、圆球贴图像素与等比显示、模式切换与刷新恢复、自然通关、失败重试、暂停、全屏、音效开关及减少动态效果；无页面或资源错误。

Shell 定向构建和嵌入游玩、返回、手机触控通过；统一开发者模式检查覆盖 61 款游戏，5 项规则测试与 10 项定向浏览器检查均通过，包含独立、Shell 及 iframe 入口。
