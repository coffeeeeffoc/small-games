# Cocos 改版验证

## 实现与设计对照

先生成 `concept.png` 四屏参考，再实现 Cocos 呈现。最终主页保留玻璃珠星轨、主开始按钮与双模式入口；战场以玻璃圆珠/六边形水晶取代切角方砖。实际球珠为程序生成纹理，细节简化以控制包体，但透明暗心、弧形高光、彩色折射边缘、三种尺寸与材质均已落实。全部游戏画面由 Cocos WebGL 绘制。

自动强化底部面板约占手机高度 40%，上方战场不加整屏遮罩。补给改为两张并排选择卡，适配横屏触点。横屏选关改紧凑双列，避免续玩入口挤压卡片。透明 HTML 语义按钮用于无障碍、全屏公共机制和 Shell 自动化，位置与 Cocos Button 对应，视觉仍由引擎绘制。

## 已执行验证

- Node 24.21.0 / pnpm 12.6.0；47 项规则、存档、异步广告测试通过。
- 六关在 24/60fps 下自然通关；12fps 高速扫掠不穿透，24/60/144fps 速度轨迹一致。圆珠边角无矩形隐形碰撞；六边形边与顶点符合实际轮廓。
- 强化每五轮、等级/球数上限、重击分阶段开放、旧档能力与目标耐久迁移、独立存档槽、挑战隔离均有测试。
- 通用广告适配器另有 20 项契约测试通过，覆盖 TapTap H5、微信、抖音、B站的 SDK 代理、超时与取消；此处使用 SDK fixture，不代表真实渠道广告验收。
- 广告完成／取消／失败／不可用／并发／重复／换局／退出后的迟到回调均验证。通用平台选择支持 TapTap，实际宿主广告位未配置。
- `balance-report.json` 为三种固定种子、三种策略的无广告模拟：固定直射 8–23 轮，危险目标直射 131–178 轮，搜索反弹路径 194–237 轮后失败。上限固定、后期仍有压力，路线选择明显影响寿命。模拟策略强于普通玩家，不把该轮数当作真人保证。
- 官方源码运行时被从干净压缩包与冻结依赖锁重新编译，产物 SHA 一致。WebGL1/2、DPR2、真实 Cocos 组件、触屏、动画、暂停/恢复及动态横竖屏均经过独立引擎冒烟；记录见 `cocos-*-evidence.json`。

实际生产浏览器全流程结果和截图在 `actual/`，以其中 `browser-report.json` 的最终 `passed` 为准。Chromium 对非 cancelable 的模拟 touchcancel 会输出平台提示；测试仍断言手势取消不发射，其余页面/网络错误均阻断。

## 验证边界

Linux Chromium 的手机触屏模拟不等于手机真机。尚未验证实体 iOS/Android、TapTap 真实广告展示、原生平台包或 Creator 编辑器导出；本交付是 Cocos 3.8.8 官方源码 Web 引擎版本。远端 CI/部署状态另行记录，不能由本地通过推断线上发布成功。
