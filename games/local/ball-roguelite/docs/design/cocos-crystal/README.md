# 晶莹星轨 · Cocos 重写设计

设计日期：2026-10-22。先生成四屏效果图 `concept.png`，再实现代码。

## 产品与画面

保留星轨弹珠的七列、拖动瞄准、松手连发、回合下降与关卡/无尽双模式。竖屏适合观察纵向落差和拇指瞄准；横屏使用居中完整逻辑视口，不裁切场地。390×844 为主参考，兼容 320×568。主页、选关、战场、暂停、帮助和结算使用 Cocos 场景节点。主要触点至少 44 CSS px，保留平台安全区、手势取消、后台暂停、全屏及开发模式契约。

效果图的四屏依次是主页、核心战场、底部强化面板、选关。深海军蓝底色，薄荷、紫晶、琥珀、冰蓝玻璃材质；球体以透光暗心、弧形高光、折射边缘和可见透明度区分。目标为大小不一的球珠与多面水晶，数字表示剩余耐久。碰撞轮廓必须对应实际外形，不保留不可见方形碰撞框。粒子、震屏和拖尾设预算，减少动态设置尊重系统偏好。

## 手感、成长与广告

连续扫掠碰撞避免高速穿透；曲面自然改变反射角，可控的小幅折射辅助增加邻近目标连击，不能掉头追踪或穿墙。发射与碰撞加速短促回落，球体沿接触法线轻微压缩回弹，拖尾记录实际轨迹。每轮独立碰撞计数驱动清脆音阶，碎裂音优先于普通接触音；暂停和失焦清理声音。

强化由每三轮降为每五轮一次，三选一仅占底部区域，上方战场保持可见。所有强化有上限，满级不重复提供，球数与概率受限。无尽耐久与成长曲线通过固定种子模拟调整，既有战略空间又保留后期压力。保留旧关卡 ID、存档 key、双模式槽与设置迁移。

广告接入公共平台适配能力，提供一次局内小幅持续增益及一次底部两行应急清除。仅完整观看可发奖；取消、失败、重复、迟到回调和更换对局不发奖。清行不计分或连击；好友同场挑战与试玩隔离。无 SDK/广告位时明确不可用，开发模拟必须标记，不将模拟当真实广告。TapTap 接入通过统一 provider 配置，不侵入规则层。

## 引擎与验收

使用官方 Cocos 3.8.8 源码构建运行时，记录真实来源、许可证与哈希，不伪称 Creator 导出。纯规则和关卡模块与引擎/广告保持解耦，完整替换旧 Canvas/DOM 游戏呈现。

验收包含六关、长局策略、连续碰撞与帧率一致性、升级封顶、旧档迁移、广告状态机、手机触屏主页/选关/游玩/暂停/结算/返回、手势取消、小屏/横屏/iframe、生产开发模式与实际截图对照。Linux Chromium 手机模拟与真机/渠道 SDK 验证分别说明。
