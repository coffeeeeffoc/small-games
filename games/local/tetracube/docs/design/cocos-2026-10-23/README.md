# Cocos 改造记录

保留原规则和操作语义，采用深蓝太空方舱、薄荷绿方块旋转、紫色容器旋转、琥珀色主要操作。圆角按钮保留边框、顶沿高光、底部阴影和按下位移。没有新增关卡或改写经典无尽规则。

[概念效果图](concept.png) 为生成式设计参考，不是实机截图。实际构建使用同目录 actual 中的 Creator Chromium 截图；背景与图标为本次生成资源。游戏实际画面保留原透视投影及数字层高，Cocos 渲染立方体与 UI 节点。

范围覆盖首页、玩法说明、游戏、暂停、结束、广告确认；窄屏把六个方块旋转与三个容器旋转分组，横屏把操作放在右侧。后台保持暂停、触摸取消清理拖动、旧存档读取失败保持原内容。

[实际浏览器报告](actual/browser-report.json) 记录环境与通过项目。核心规则与存档／奖励单元测试独立于渲染。正式原生设备、SDK 真实广告填充不在浏览器证据范围内。
