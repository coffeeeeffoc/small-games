# 实战快捷操作区

本轮依据[用户标注截图](user-control-reference.png)：移动方块与观察旋转必须各自常显；移除工具和层面检查的全屏遮罩，低频功能点击展开后仍可操作棋盘。沿用当前深蓝、薄荷绿选中态及暖金落下按钮，仅改实战操作区，不改玩法、存档或线上服务。

## 布局与操作

- 第一行：移动方块、观察旋转、直接落下。两个手势模式独立显示并标记当前模式。
- 第二行：平转、前后转、左右转、反向，旋转始终可直达。
- 第三行：视角、层面、更多。再次点击收起，切换类别直接替换二级按钮。
- 视角：四个预设视角，以及缩小、适配、放大、单指平移；双指缩放/平移始终可用。
- 层面：实时俯视格图、上下选层、隐藏上方层、跟随落点；不在默认实战常驻占用格数和微型图。
- 更多：暂存/换入、免费左右翻舱、180°辅助及其公平排行提示。保留次数、奖励资格和取消语义。

竖屏二级区展开在固定主操作区上方，并为棋盘重新分配空间；横屏在右侧操作栏内展开。所有按钮与棋盘触控区分离，不画蒙层、不更换 playing 状态、不重置模拟计时。暂停、奖励确认、结算继续使用其必要的独立状态。

## 验收

验证 320×640、390×844、844×390、1280×800 的按钮大小、无互相重叠、无棋盘遮挡。展开二级区时实际拖动移动和观察、旋转、落下，验证自动下落继续、取消不误触、暂停后收起；保留旧有缩放/多指/广告回调回归。更新真实截图与两类视频，图标和宣传插画复用。

另覆盖 640×360 短横屏和 34px 底部安全区（触发 resize 后宽度 641）；右栏紧凑布局缩短按钮和层标题文字，保持至少 44px 热区。详见[验证记录](verification.md)。
