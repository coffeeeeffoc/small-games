# 重力方舱 · 容器颠倒改版

本次先依据玩法与交互方案生成 [手机游玩效果图](container-flip-reference.png)，再实现界面和渲染。保留深海蓝、薄荷青配色，方块全部为实心材质；只有容器与落点使用线框。旧版参考保留在 [reference.png](reference.png)。

容器扩大为 6×6×12（432 格，比旧版增加约 73%）。采用竖屏突出纵向下落，压缩底部操作区，让场景占据手机画面主要面积。横屏矮视口将控件移至侧面，设备转向不重置对局。

重力始终向画面下方。点击「颠倒容器」先将整个容器与其中所有方块绕 X 轴转动 180°，再让每个小方块独立向下落，直到碰到底面或下方方块；检测完整水平层，消除、继续下落并累计连锁。当前操作中的方块也参与本次翻转并落定，结束后从新的顶部生成下一块。观察工具提供左右 90° 侧翻，转后容器宽高按真实几何交换。原底面的琥珀色角标随容器转动，帮助理解朝向。

触屏默认为「移动」：在场景中拖动，按当前观察角度把手势映射到水平网格，落点同步反馈。切换「观察」后拖动只改变镜头，提供立体、俯视、正视、侧视快捷按钮。两种模式明确分开，XY/XZ/YZ 始终只旋转方块。颠倒和直接落下是底部主操作，翻转与坍落动画期间锁住操作，避免重复提交。

页面关系：主页 → 经典无尽 → 暂停 / 危险干预 → 结算 → 重试或主页；帮助从主页和暂停页进入。只有经典无尽，不增加无内容的选关页。最后一次救场直接颠倒容器。首次局内短提示依次介绍拖动、旋转、落下、颠倒；旧存档迁移并保留得分、队列和随机序列。

验收覆盖真实浏览器触屏输入的移动与观察隔离、三轴旋转、落点、下落、完整层消除、翻转后逐格支撑、连锁、取消手势、多点输入、暂停恢复、旧存档迁移、存储不可用及尺寸适配。运行截图与记录保存到 ../qa/，注明浏览器模拟，不冒称真机验证。广告、排行榜、皮肤及其他特殊能力仍不在本次范围。

## 2026-10-07 交互与空间辨识优化

沿用现有竖屏场景和配色，先更新 [局部设计参考](interaction-reference.svg)，再调整实现。移动与旋转增加 75 / 120 ms 的短过渡，连续输入可中断并从当前画面继续，落点始终由真实碰撞结果计算。旋转按钮以立体方舱、对应平面高亮和方向箭头表示 XY 平转、XZ 前后转、YZ 左右转；每个平面均有反向按钮，键盘 Shift+Q/E/R 反转。避让限于所选平面且总位移不超过 3 格，先检查舱壁和舱顶的必要纠偏，不跨到无关的深度层寻找空位。

观察镜头解除俯仰边界，允许同方向连续越过俯视和水平位置，正常松手有短惯性，取消手势立即停止。透视投影体现近大远小；俯视预设保留约 17° 偏心角，让中央与边缘的同 XY 不同 Z 都能产生可见错位。移动输入按透视射线与方块所在水平面求交，在接近水平视线时采用有界降级，避免跨格跳动。

已放置方块保留原色系，按层叠加细微冷暖、明暗差异，并在可辨认的顶面标明从底部起的层号。标尺沿画面外侧舱边排列，落点层用薄荷色强调；移动模式底部同步提示实际落点层。控件热区至少 44 CSS px；四种视口和正常游戏流程截图见 [验收记录](../qa/README.md)。
