# 重力方舱 · MVP 设计

先生成 [移动端效果图](reference.png)，再实现页面与渲染。主色为深海蓝、薄荷青和少量琥珀色，立方体具有清晰的明暗面，落点使用虚线轮廓。效果图为方向参考，不作为游戏运行素材。

采用竖屏：5×5×10 的纵向方舱保留最大的可读高度，底部控件置于拇指区。桌面以居中的游戏舞台承载同一套操作，横屏矮视口把控件移动至侧面，不重置对局。

页面关系：主页 → 经典无尽 → 暂停 / 危险干预 → 结算 → 重试或主页；帮助从主页和暂停页进入。首版只有经典无尽，因此不添加虚假的选关页。主页允许继续本地保存的对局。

画面拖动只转摄像机，移动区只移动方块；XY/XZ/YZ 每次固定旋转 90°。重力改变后，移动轴改为与重力垂直的两轴，标签同步变化。重力方向选择暂停自动下落，确认后动画展示逐步压实与连锁；不消耗次数，便于验证 MVP。

完整平面以当前重力方向为法线，六个重力方向均有对应的出生面。先开放全部旋转和重力操作，通过首次局内短提示引导，不在 MVP 中添加局外养成、广告、排行榜或收费道具。

验收截图和运行记录写入 ../qa/，区分浏览器触屏模拟与真机验证。
