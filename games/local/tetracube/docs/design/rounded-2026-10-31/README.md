# 空间俄罗斯方块 · 旋转与圆角改造

2026-10-31，按用户反馈将“重力方舱”更名为“空间俄罗斯方块”。Game ID、包名、URL 和存档 key 保持 tetracube；没有修改碰撞、计分、墙踢、随机序列或广告规则。

## 设计与实现

延续 [Cocos 页面构图](../cocos-2026-10-23/README.md)，本轮局部调整方块材质与旋转反馈。立方体使用圆角边带与圆润角面，保留平整中心和格子边界；主方块、堆叠及下一块预览共用几何。去掉原本硬白描边，改为柔和明暗。仅剔除所有外向方向均被邻格遮挡的面片，保留外露倒角；完全包围的格子不绘制。旋转法线、面片与颜色在同类格子间复用计算，没有引入整帧缓存。

方块沿指定轴进行完整刚体 90° 旋转，顶点和法线一起旋转；重心平移吸收原规则墙踢。快速连按排队并加速追赶，不改变逻辑操作顺序；暂存、落下、生成和翻舱清除旧块动画。观察拖动即时跟手，松开后短暂衰减；再次按下、取消、多指、暂停、预设及模式切换立即停止。简化动态关闭这一缓停及块动画。保留原来的自动适配相机包围盒，避免自由旋转后容器裁切。
