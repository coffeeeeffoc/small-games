# 空间俄罗斯方块：清晰棋盘与挑战大厅

本轮依据用户 2026-10-31 的两张手机截图：层级不清、相邻方块有空隙、首页与对局相似，要求重做功能、布局和交互，并接入关卡榜、积分榜及可选激励入口。旧版圆角方案仅作为历史记录。

## 产品与画面目标

- 首页使用紧凑立体方块主视觉与明确的「关卡挑战」「经典积分」入口，不展示整座对局容器。继续存档、排行榜、玩法与设置均有独立路径。
- 关卡挑战采用独立目录与稳定 ID，分组展示 18 个递进挑战；目标、棋盘尺寸、星级与解锁关系明确。关卡目标以消层与操作约束为核心，不把重复数字当作新玩法。
- 对局以大棋盘为主：低纹理深蓝场地、完整格宽、外轮廓轻倒角、相邻连接边贴合。层尺与落点高亮清楚区分；层面检查显示选中层占用和二维格子。取消遮挡错误的块顶悬浮数字。
- 顶部只放当前模式/目标、得分、消层、暂停；展示实际已有的三块预告及暂存缩略图。底部主操作为三轴旋转、方向切换、直接落下；观察与整舱重排收进明确工具面板。手机热区至少约 44 CSS px，横屏两列布局。
- 用户追加：支持双指缩放、加减按钮和一键适配，放大后可平移；观察旋转按抓住眼前表面随手移动定义。用户明确不直觉的是拖动观察方舱，保留方块旋转规则和轴，不为此反转方块玩法。
- 结算区分通关、挑战失败和无尽结束，提供星级/成绩、重试、下一关、返回首页。暂停与设置不覆盖用户生命周期暂停状态。

## 公平排行与可选激励

- 复用现有 Runtime 身份、Game Services 与输入回放验分：关卡榜按最高验证通关关卡、积分榜按无尽得分；同关／同分按服务端重放的成功操作步数升序（协议 `steps`），本地结算另展示模拟用时。避免零 ticks 的即时操作伪造竞速优势。UI 不自造名次，不将本地存档上传成可信成绩。
- 联网开局采用服务端种子并记录实际操作和模拟 ticks；规则版本与纯核心共享。网络失败保留本地玩法，显示真实离线状态；异步回调不得污染新局或新页面。
- 「救援续局」「空间重排」是明确的可选奖励入口，确认页解释收益、次数与完整观看要求。只接受 completed，取消/失败/无库存不发奖，保留现有迟到回调与隐藏处理。
- 基础开始、游玩和通关免费。使用救援或额外辅助的局保留本地进度，但退出公平排行；开发试玩不写正式进度和榜单。
- 保留旧经典存档并扩展模式/关卡与成长记录；读取失败不覆盖原数据。

## 实现与验证边界

继续使用 Cocos Creator 3.8.8、现有纯 JS 规则、Cocos Graphics/Label/Sprite 与共享 Host。代码、内容、存档、广告和排行榜各用已有边界，不新增框架。

验收包含连接几何/层面投影、18 关配置与通关证明、进度迁移、广告四种结果/重入/迟到、公平回放验分/身份隔离、320×640 与 390×844 手机及 844×390 横屏真实浏览器操作。逐页截图对照本轮设计，更新受影响上架截图、视频与文案；引擎构建、浏览器模拟、真机、平台广告与线上服务分别留证。
