# 重力方舱 · 霓虹街机改版

本次采用竖屏：更高的 6 × 6 × 18 方舱承接纵向下落，底部固定拇指操作区，画面优先展示空间与落点。横屏矮视口沿用场景左侧、控件右侧布局。页面关系仍为主页 → 无尽对局 → 暂停 / 帮助 / 危险救场 → 结算 → 重试或主页。

先保存 [主页手机效果图](home-reference.svg) 与 [游玩手机效果图](play-reference.svg)，再实现本次界面。效果图为 390 × 844 CSS 像素的构图稿，实际 Canvas 方舱与方块由游戏渲染器绘制；不将效果图作为占位界面。

## 交互方案

- 移动与观察保留明确的切换按钮；观察只负责镜头拖动与四个预设视角。
- 「转动容器」常驻底部，左翻 90°、右翻 90°、颠倒 180°直接可点，无需先进入观察。方块三个旋转按钮与容器按钮用组名和颜色分开。
- 「落下」使用琥珀色主按钮，与场景下落方向呼应。旋转方块使用青绿边框，容器翻转使用靛紫边框。
- 方舱高度由 12 扩大至 18，增加 50% 容量。暂存按钮与三轴旋转并列；每个新方块可交换一次，显示已暂存方块名称或「空」，已用时明确禁用。暂存规则由核心引擎实现，界面不模拟。
- 所有主要按钮热区至少 44 CSS 像素。320 × 640 小屏保留全部主操作，缩小留白而不缩小热区；帮助独立滚动，暂停菜单保留清晰返回路径。

## 美术与反馈

深靛蓝太空背景、低对比网格与星光，舱体青绿发光轮廓，方块实体倒角与高光。主页标题采用街机字重与细英文副标，不铺设说明面板。得分使用数字等宽；落下与连锁在场景内体现速度、冲击环、粒子与短震动，控件持续清晰可见。减少动态效果偏好下减少闪光与震屏。

游玩顶部仅保留得分、消除层数、暂停、下一块与舱尺寸；下方仅保留落点提示与占用。控件布局：移动 / 观察 + 落下 → 旋转方块（三轴 + 暂存）→ 转动容器（三方向）。帮助说明统一放在帮助页面。

## 验收

用浏览器手机触屏模拟检查主页、游戏、暂停、帮助、救场、结算与返回；确认默认移动模式就能点击全部容器翻转，观察视角仅影响镜头，暂存每块只用一次，落下与翻转期间输入锁定，动画结束后状态一致。检查 390 × 844、320 × 640 与 844 × 390 布局，主要热区至少 44 像素，实际截图另存 QA 目录。真机与原生平台能力需单独实测，浏览器模拟不作为真机结论。
