## 结果

- `node --test tests/engine.test.mjs`：52 项通过。
- `node build.mjs`：生产静态构建通过。
- `node tests/browser.mjs`：10 组流程通过，未捕获页面错误。逐项记录见 [v2/browser-report.json](v2/browser-report.json)。测试通过实际按钮和 CDP 触屏操作触发行为，快照仅用于读取结果。

浏览器检查覆盖：

1. 主页、帮助、开始；6×6×12 容器；画面拖动移动方块，摄像机不变；三轴旋转与直接落下。
2. 观察模式拖动只转动摄像机，方块 XY 坐标不变；俯视/正视/侧视/立体切换；手势取消和多点触控后无遗留拖动。
3. 一键颠倒容器，世界重力始终向下，摄像机不变；当前方块只计入一次放置，之后生成队列下一块；翻转过程中暂停、继续正常。
4. 左侧翻后尺寸变为 12×6×6，右侧翻后恢复 6×6×12；每次侧翻都正确提交当前块并保持可玩。
5. 暂停停止模拟；返回主页、刷新、打开帮助、继续后，棋盘、朝向、方块队列及随机状态完整恢复。
6. 320×640、390×844、844×390、1440×1000 布局无横向溢出；落下、颠倒、模式、旋转的主要触控区域可见且至少约 44 CSS px。
7. 可见开发操作创建 72 格连锁局面，再按真实颠倒按钮；产生两次连续消层和 Combo ×2，原空中方块的 4 格保留。
8. 危险状态一键翻转救场、继续；危险状态结束、结算、重试。
9. 旧版 5×5×10、横向重力存档迁移到 v2：两个既有格子与空中方块保留，得分和放置次数不变，世界重力向下；继续落下、保存和再次读取成功。
10. 浏览器拒绝 localStorage 时仍可开始、落下与颠倒容器。

## 验证边界

本记录覆盖单游戏生产构建的浏览器体验；仓库准确候选版本、Shell 接入、CI 和 Pages 发布结果由对应发布验证记录单独确认。未执行 Android/iOS 真机、微信/抖音/B 站原生 SDK 验收。触屏操作由 Chromium 模拟，不代表已验证所有手机浏览器。
