## 结果

- `node --test tests/engine.test.mjs`：64 项通过。
- `node build.mjs`：生产静态构建通过。
- `node tests/browser.mjs`：15 组流程通过，未捕获页面错误。逐项记录见 [v3/browser-report.json](v3/browser-report.json)。测试通过实际按钮和 CDP 触屏操作触发行为，快照仅用于读取结果。
- 本游戏测试增加受限 iframe 的新交互断言。Shell 沿用开始、落下、暂停和返回的既有集成契约；没有修改共享浏览器检查器，Shell 与仓库准确候选版本检查由最终交付记录确认。

浏览器检查覆盖：

1. 触屏走通主页、帮助、开始；确认 6×6×18 方舱和常驻左翻 90°、右翻 90°、颠倒 180°、暂存按钮。
2. 画面拖动只移动方块；三轴旋转与自然下落均采样到动效；硬降采样到拖尾、落地冲击。
3. 暂存每个空中方块只用一次；重复触屏不会再次交换或得分；落定后恢复；交换已有暂存块不消耗下一块队列。
4. 观察模式拖动仅影响摄像机；四种预设视角；取消手势与双指操作后无遗留移动。
5. 一键颠倒、左右侧翻直接触发真实容器转动；世界重力和摄像机保持不变；空中方块只提交一次，随后生成下一块。左翻后为 18×6×6，右翻后恢复 6×6×18。
6. 重构期间禁用游戏动作，暂停冻结翻转动画与状态；触屏走通暂停、帮助、返回、继续。
7. 保存返回主页、刷新、查看帮助、继续后，棋盘、物理朝向、暂存与使用状态、队列、随机数状态完整恢复。
8. 320×640、390×844、844×390、1440×1000 布局；主要按钮触控区域至少约 44 CSS px，页面无横纵溢出。
9. 可见开发操作创建 72 格连锁局面，再按真实颠倒按钮；两次连续消层、Combo ×2，空中方块的 4 格保留；调试不覆盖正常存档。
10. 危险状态触屏翻转救场；结束、结算、返回主页、重新开始和重试。
11. v1 横向重力存档迁移到 v3 世界向下的 18×6×6 方舱；v2 存档扩为 6×6×18；均保留既有方块、队列、得分、放置次数与随机状态，继续游戏可用。
12. `prefers-reduced-motion` 下，触屏移动、旋转、暂存、落下与左右侧翻仍可用，采样记录无拖尾。
13. 首次教学按移动、实际旋转、落下、容器翻转推进；暂存不会提前完成旋转教学。
14. 生产 iframe 中触屏开始、暂存、直接侧翻、暂停、主页、继续；320×640、390×844、844×390 的宿主页与子页面均无溢出；显式 `dev=0` 不显示调试入口。
15. 浏览器拒绝 localStorage 时仍可开始、落下与颠倒容器。

## 验证边界

本记录覆盖单游戏生产构建的浏览器体验，以及受限同源 iframe 中的触屏和布局。Shell 实际集成、仓库准确候选版本、CI 和 Pages 发布结果由对应发布验证记录单独确认。未执行 Android/iOS 真机、微信/抖音/B 站原生 SDK 验收。触屏操作由 Chromium 模拟，不代表已验证所有手机浏览器；手机硬件震动需真机验证。
