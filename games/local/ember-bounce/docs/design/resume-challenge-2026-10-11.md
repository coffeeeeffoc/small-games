# 回合续玩与少轮数挑战

本文记录 2026-10-11 的续玩与挑战改动，当时以竖屏洞窟、金色主按钮和独立页面为基础调整状态与控件。目标平台为手机 H5；电脑仍可鼠标操作。`concept.png` 记录当轮主页、游玩、结算方案。历史范围不限制后续样式，用户新要求按对应认可图的完整视觉及[验收规范](../../../../../docs/game-development.md#新样式要求与完整视觉验收)落实。

## 局部界面方案

- 主页原「开始弹射」在有检查点时显示「继续第 N 轮」，原进度行显示关卡与已完成轮数，不新增信息面板。
- 暂停页原说明补充「离开后从本轮开始继续」。发射中返回主页或重载恢复发射前，已完成的轮次、剩余目标、分数和强化不会丢失；强化选择页也可恢复。
- 收到好友链接先停在主页，主按钮为「接受 N 轮挑战」，使用原进度行显示关卡与目标；其下显示「返回我的旅程」。需主动开局，挑战不解锁关卡、不覆盖普通续玩。
- 游玩沿用已有轻量角标显示「好友同题 · N 轮」，回合行显示当前轮次与目标。没有新操作影响拖动瞄准。
- 成功结算在现有按钮列添加「邀好友比轮数」。同关固定布局、相同初始球数，玩家自由选择强化；少于好友轮数胜出，相同轮数为追平。成绩为好友自报、本机对比，不冒充权威排行。
- 共享系统分享、复制链接与手动复制降级；关闭系统分享不发奖也不丢进度。低屏高下结算可滚动，触区至少44px。
- 普通局仅在自然结算提供公共模拟插屏机会，每三次结算才参与一次、冷却一分钟、每会话最多六次；好友同题与核心操作期间不展示。沿用公共明确模拟标识和随时关闭能力，不影响免费重试。

## 数据与验收

进度升级为 v2，沿用原存储键，迁移 v0/v1 的关卡、成绩和偏好。独立 v1 检查点只记录回合边界，读取时校验内容指纹、配置目标、数值及强化阶段；坏检查点不影响已完成进度。普通局与好友挑战分别保存，试玩不写二者。

覆盖正常回合、强化前/后、飞行中重载、主页继续、存储禁用、旧版本迁移、终局清理、手势取消/失焦；分享链接拒绝重复参数、未知版本、未知关卡和非法轮数，不含 dev。浏览器使用生产制品和触屏事件，记录实际截图；不将模拟器称为真机。

触屏检查发现原先仅按旧按钮目标过滤浏览器的合成 click，页面切换后该 click 可能落到新页面按钮。现改为在已处理 touch pointerup 的短窗口中抑制兼容 click，真实鼠标与键盘事件继续工作；避免从结算返回主页后立即误开下一局，或恢复强化页时误选强化。

## 实际验证

- Node 24.21.0 / pnpm 12.6.0：36 项规则、存档与邀请校验测试通过；静态构建通过。
- Linux Chromium（Playwright chromium-1193），生产制品：13 组浏览器回归通过，无页面错误或缺失资源。390×844、375×667、320×568、844×390 与桌面视口覆盖；输入为浏览器真实触屏事件及鼠标，并非物理真机。
- 三轮真实弹射通关，检查一次强化、分享携带真实 3 轮成绩、取消不改变进度、好友三轮追平、普通未完成关卡仍可继续；覆盖飞行中重载回退本轮、强化待选状态恢复、边界失败清理及重试。
