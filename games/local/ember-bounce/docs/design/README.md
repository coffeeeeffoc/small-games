# 熔光弹珠 · 移动端设计

设计于 2026-10-06。先生成 `concept.png` 的首页、核心游玩及选关效果图，再实现页面与渲染；截图和验收记录均来自实际运行的生产静态制品。

## 页面与操作

采用竖屏：顶部发射、下部目标、纵向波次上移需要完整的上下空间。手机横屏和桌面通过等比缩放保持玩法，尺寸或全屏变化不重置对局。画布固定逻辑坐标 390 × 600，触点按实际等比显示区域映射，不把多余留白作为游戏场地。

首页突出开始弹射，提供选关、帮助、音效及全屏入口。选关按稳定 ID 显示正常解锁与星级。游玩隐藏品牌和目录，只保留暂停、关卡、分数、球数、目标进度与回收。通过拖动场地完成瞄准和发射；手势取消不发射。暂停、强化、结算使用独立页面，结算提供下一关、重试和返回；开发选关只在公共开发面板中出现。

## 原创视觉

蓝紫洞窟、远景石桥、月光与水面构成低对比背景，金色发射门与球、青色玻璃目标、紫色真实三角及珊瑚爆裂球形成可读层级。目标形状、加号与数字同时提示类型和状态。碰撞使用短时压缩回弹、涟漪与小碎片；爆裂增加有界冲击波；弹珠有金白核心及逐渐消失的拖尾。有限粒子和 DPR ≤ 2 控制手机开销。系统“减少动态效果”缩短拖尾、减少粒子并关闭屏震。

`concept.png` 是原创生成效果图。运行背景 `assets/cavern.webp` 另行生成无 UI 纯背景并压缩至约 56 KiB；其余可交互美术由 Canvas、CSS 和 SVG 绘制，声音由 Web Audio 合成。附件只用于观察通用机制和动画反馈，没有抽取其画面、名称、角色或声音。

## 验证证据

实际手机截图包括首页、选关、瞄准、发射、强化、暂停、成功和失败；小屏与横屏截图证明同一对局在尺寸变化后继续。浏览器报告记录测试环境与真实触屏流程。验收为桌面 Chromium 的手机模拟，不能替代微信真机、iOS 或 Android 原生平台验收。
