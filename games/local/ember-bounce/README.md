# 熔光弹珠

移动端优先的竖屏重力弹射游戏。松手位置决定角度与速度，让弹珠沿弧线进入夹缝，在相邻晶体与侧墙之间连弹。弹珠首次触底就向下回收；收齐才推进目标，清空波次通关，目标越过顶部警戒线失败。

本作独立编写规则、渲染及音效，未从参考视频提取代码、图像或音频。原创洞窟背景、玻璃目标、金色拖尾、命中变形、碎裂粒子和爆裂冲击波共同构成画面；程序合成音效不依赖音频下载。通用弹射规则可以借鉴，但直接复制他人的代码、素材、角色、名称或高度近似的整体画面可能涉及著作权、商标或不正当竞争；是否涉及特定专利等仍需结合原作判断。

## 运行

在仓库根目录执行：

```sh
pnpm --filter @coffeeeeffoc/ember-bounce dev
pnpm --filter @coffeeeeffoc/ember-bounce test
pnpm --filter @coffeeeeffoc/ember-bounce build
PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/chromium pnpm --filter @coffeeeeffoc/ember-bounce test:browser
```

默认开发地址为 `http://localhost:5197/`。可使用 `--host` / `--port` 指定监听；`node server.mjs --dist` 预览正式静态产物。运行代码零外部依赖，构建输出为 `dist/`。Shell ID 为 `ember-bounce`，独立入口为 `/games/ember-bounce/index.html`，大厅路由为 `#/games/ember-bounce`。

## 玩法与内容

- 8 个依次解锁的关卡，每关 5–8 个波次、12–24 颗初始弹珠；增加墙边夹缝和对向棱镜布局，逐步引入三角反射、爆裂、加球与强化。
- 松手距离控制 260–920 逻辑像素/秒的发射速度，重力为 580 逻辑像素/秒²。240 Hz 固定步长与连续碰撞保证不同帧率下的同输入一致；低速静止接触不会重复扣血。三角按真实斜面反射，预览共用物理，在首次击碎目标时截断。
- 底部是回收口：不论是否命中晶体，首次触底即停止碰撞并向下缩小淡出；顶部不是回收条件。主动回收放弃剩余撞击，收齐后推进一轮；16 秒飞行上限避免卡住。球可互相穿过，拖影限时、限密度，数字与实球始终在上层。
- 加球从下一轮加入；关卡内选择多发两球、撞击增伤或扩大爆裂范围。
- 通关保存星级、最佳分数与最少轮次，正常解锁下一关。每轮发射前与强化选择前后保存检查点；返回主页或重载后从本轮开始继续，已完成轮次、剩余目标、分数与强化保留。飞行中的未结算伤害不会写入检查点，终局清理对应续玩。存储被禁用时使用内存继续游玩。
- 通关后「邀好友比轮数」生成同关挑战，好友先确认再开局；固定布局与初始配置相同，强化由玩家自行选择。少用轮数胜出、相同轮数追平；分享成绩是好友自报，不是服务端排位。邀请挑战单独存档，可进入尚未解锁的同题，但不解锁普通关卡，也不覆盖普通续玩。返回我的旅程会退出并清除本次挑战续玩。
- 系统分享取消不发奖；不支持系统分享时依次尝试复制链接、手动复制。公开链接仅包含挑战版本、关卡和目标轮数，不携带开发开关或当前页面其他参数。
- 普通局自然结算接入明确标注的模拟插屏：公共适配器每三次结算才提供一次机会，至少间隔一分钟、每会话最多六次，随时关闭；瞄准、弹射、强化和好友同题均不会弹出广告。免费重试不受广告影响，未接真实广告 SDK。

`levels.mjs` 拥有版本化内容 schema、稳定 ID、波次与解锁配置；`core.mjs` 只处理规则，不访问 DOM、SDK 或存储。`render.mjs` 管理有限粒子、玻璃切面、拖尾与屏震，`audio.mjs` 管理声音与震动生命周期，`storage.mjs` 管理存档迁移和降级，`main.mjs` 连接页面及触屏输入。`checkpoint.mjs` 从配置重建并校验回合状态，进度 v2 沿用旧存储键兼容 v0/v1；`challenge.mjs` 校验邀请版本、唯一参数、稳定关卡 ID 和轮数范围。构建从公共 `platforms/h5/publishing.js` 复制分享与模拟广告适配器，游戏不维护其副本。

## 运行边界与验收

这是独立 H5 / Shell iframe 游戏，沿用仓库的本地存档模式。已移除浏览器全屏入口。开发模式复用 `SmallGamesDev`，支持 URL `?dev=1/0` 和 `localStorage.dev`，正式构建默认关闭。调试面板中的任意选关均标记试玩，不写入玩家成绩或解锁。

纯规则及存档测试覆盖 8 关在 60 fps / 24 fps 下自然通关、三角反射、防穿透、爆裂、回收、失败、成长、迁移和练习隔离。2026-10-25 的生产浏览器验收使用 Windows Chromium 手机触屏模拟，覆盖首关真实操作通关、强化、结算、下一关、存档恢复、取消手势、暂停、后台恢复、小屏与横屏、减弱动态及开发开关。效果图及实际截图见 `docs/design/`。未执行微信原生工程或手机真机验收；原生微信小游戏需要单独运行环境适配。
