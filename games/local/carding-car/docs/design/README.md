# 可爱赛车菜单

先生成 [双页效果图](cute-menu-concept.png)，再以同一方向分别生成乐园和车库背景。效果图与背景使用内置 imagegen 制作；背景缩放为 1280×720、JPEG 质量 84，总计约 270 KiB，无新增运行依赖。

- 首页：明亮的玩具赛车乐园、中央展示台、泡泡开赛按钮，底部生涯／商店／好友图标。隐藏累计数据与装备说明，保留等级和金币；开赛按钮呼吸、星星浮动、真实赛车轻微摆动。
- 选赛：暖色明信片，左边是所选主题和路线的实时赛道，右边是车库和真实赛车。短标签配左右箭头，机器人参数放在「更多」。两页有独立构图与背景。

生成方向：软陶与玩具质感、圆润造型、晴天、棕榈树、彩色护栏、格子旗；乐园前景留空展示台，车库留空转盘，背景不含按钮、文字和赛车。界面文字、触控和车辆由 Cocos 实时渲染，赛车、装饰、宠物与车手仍使用玩家当前装备。背景只在打开相关页面时加载；进入比赛恢复原来的追车镜头和场景。
