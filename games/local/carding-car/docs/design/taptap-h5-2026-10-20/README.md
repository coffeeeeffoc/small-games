# 浪湾卡丁车手机 H5 设计

横屏；竖屏手机沿用完整游戏容器旋转兜底。当轮采用低多边形赛道和车辆；后续新样式按最新认可图落实。

主页以车辆、赛道和开跑为中心，选赛道为次操作。暂停层缩为居中卡片：标题“已暂停”，仅一行名次和时间，大按钮“继续比赛”，下方“重开”和“主页”。排行榜、纪录说明、键盘快捷键不占用暂停界面。按钮有效热区至少约 44 CSS px。奖励入口以具体收益命名，配置缺失时隐藏。

concept.png 为实现前手机比例效果图；actual-* 为后续浏览器实际截图，均不代表真机验证。提示词见根 docs/plans/2026-10-20-six-taptap-h5.md 及本次生成记录。
