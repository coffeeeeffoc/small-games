## 可重复命令

在游戏目录运行：

```sh
node platforms/build.mjs wechat --config-only
node platforms/build.mjs bilibili --config-only
node platforms/build.mjs douyin --config-only
node platforms/build.mjs alipay --config-only
node platforms/build.mjs kuaishou --config-only # 当前有意报适配器缺失
node platforms/build.mjs wechat                # preview，仍需要真正 Creator
node platforms/build.mjs wechat --release      # 首先校验公开 AppID
```

将 `wechat` 替换为 `bilibili`、`douyin`、`kuaishou`、`alipay` 可得到对应目标。release 未配置 AppID 先于引擎检查失败，不接受 touristappid、preview-only 作为已配置微信/B站 ID。真实构建还需 `COCOS_CREATOR` 指向 Creator 3.8.8；B站需项目现有 setup 安装并校验官方插件。当前 Linux 云端 setup 不会自动安装 Windows Creator。

环境变量示例只留空，不提供假 ID：

```dotenv
COCOS_CREATOR=
WECHAT_APP_ID=
BILIBILI_APP_ID=
DOUYIN_APP_ID=
KUAISHOU_APP_ID=
ALIPAY_APP_ID=
```

公开 AppID 的语法校验不能证明归属或平台授权。支付宝官方引擎文档没有给出微信式 `packages.appid` 字段，本实现不编造它；公开 `ALIPAY_APP_ID` 记录在交付 manifest，生成的官方引擎目录需在支付宝 Studio 关联用户真实应用，身份关联待外部验证。

服务端 secret、AppSecret、签名私钥只放部署服务器或 CI 的服务端 secret store。不要传入客户端编译变量；包装器不会将它们写入配置或 manifest。当前没有接入广告/兑换凭据，不给假奖励；没有用户注册的登录凭据，不宣称真实登录。卡丁车竞赛/联机保持现有真实服务配置与鉴权降级，不伪造匹配。夜航没有新增登录/广告/分享入口；支付宝分享未实现时标记 unavailable。

## 产物和契约

真实构建成功才在目标目录写入 `platform-manifest.json`：游戏、渠道、preview/release、公开 AppID、Creator、源指纹、包装器指纹、全部包文件 SHA-256 和字节数。`verifyManifest(directory)` 拒绝文件篡改、漏文件、额外文件和符号链接；不把 stub 测试包作为平台成品。微信/B站/抖音仍经过原脚本的入口、SDK 适配器/资源分包和包大小校验。支付宝检查独立 `game.js`、`game.json`、横屏及总包 4 MiB 上限；过大明确失败，必须配置官方远端资源方案后验证，不假装微信 20 MiB 预算适用。

脚本入口：`platforms/build.mjs` 导出 `buildPlatform(channel, options)`，供九款统一矩阵构建使用；`--config-only` 返回 configuration-only，不写产物 manifest。`--release --config-only` 也执行必填 AppID 门禁。快手必须由官方开发者工具对微信格式引擎源包执行自动适配，生成并校验 kwaiadapter.js 及 game.js 引用；完成前明确阻塞。

契约验证：`apps/shell-minigame/scripts/cocos-platform.test.mjs` 覆盖五平台 release 先验门禁、跨平台 ID 拒绝、支付宝配置边界及 manifest 篡改/新增文件拒绝。模拟文件仅测试完整性算法，不代表宿主功能验收。
