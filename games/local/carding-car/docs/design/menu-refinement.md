# 菜单精修：准备、设置、生涯与商店

[五页面概念图](menu-refinement-concept.png) 由内置 imagegen 在实现前生成，是布局与视觉方向参考，**不是运行截图或真机验收记录**。概念图中的赛车、示例任务、奖励数值和商品名称仅用于表达效果；实现复用现有游戏内容、场景和资产，不把概念图作为运行背景。

## 视觉与尺寸

- 延续横屏手机体验，以 960×540 为逻辑画布；保留已有竖屏旋转兜底和安全区逻辑。
- 奶油底、象牙白卡片、焦糖棕文字，薄荷绿用于主操作，金色用于奖励与选中。减轻粗白描边、硬阴影与大面积高饱和块。
- 画布边距约 24，顶栏约 52；页面标题 25–28，主要文字 16–18，辅助文字 13–14。控件可见高度约 38–42，同时保留 60 逻辑像素的有效触控热区（844×390 下约 43 CSS px）。
- 文本、卡片和主按钮分别占据明确区域；主按钮上方始终保留锁定状态和价格行，禁止以重叠或裁切隐藏条件。

## 页面关系与交互

首页继续提供开赛、生涯、商店和设置入口。生涯的「去挑战」进入准备页；准备页返回首页；商店返回首页。设置为轻量单层卡片，关闭后回到原页面。

- **出发**：赛道和车辆预览双栏。车辆、车手各一行选择器；锁定状态和金币需求单独显示。允许浏览未解锁内容，但明确标为未解锁，禁用进入赛道；已购买的实际装备与浏览候选分离。
- **小伙伴**：使用左栏内部紧凑配置区，保留赛道上下文。将外观选择和对手数量放在短行中；减号、数字、加号邻近呈现，边界状态禁用。关闭路径固定且清晰。
- **设置**：约 440×300 的奶油色卡片，声音、教学、全屏按行排列，右侧给出当前开关状态或操作。避免深色大面板、巨型堆叠按钮和常驻无关说明。
- **生涯**：左侧车手护照显示等级成长条和赛事进度，任务具有可见的完成进度、奖励和状态。可领取目标优先，并区分待完成、可领取及已领取；未完成目标提供可执行的「去挑战」，达成目标可「领取」，领取后持久化且不重复发奖。
- **商店**：切换商品即更新预览，不再显示重复且无效果的「试试看／试穿」按钮。候选预览与当前装备分别标注。主按钮根据拥有状态显示购买、装备或已装备，金币不足时明确反馈；恢复当前装备提供真实可执行的操作。

实际验收为桌面 Chromium 844×390 与 390×844、Android UA、真实 CDP 触摸；正式制品已通过 `menu-refinement.mjs` 和 `compact-hud.mjs`，覆盖热区无重叠、金币提示无遮挡、设置禁用背景输入、购买与装备分离、领奖幂等、刷新恢复，以及驾驶、漂移、触摸松手与取消、暂停设置。171 项单元测试、类型检查与完整 Creator 构建通过。

`display-modes.mjs` 已通过设置进出全屏、暂停／重试／恢复、系统退出全屏、305／360／390 像素宽竖持视口的旋转与触点，以及全屏不支持／拒绝时的反馈。测试改用同步条件轮询完整画布几何，避免异步条件返回的 Promise 被提前视为成功。

完整触屏生涯回放也已通过，覆盖实际整圈完赛、奖励领取、购买装备和升级。该回放基于较早 Creator 引擎及导入素材、叠加本轮业务源码，逐模块核对 SHA；因 Linux 软件渲染较慢，使用 DPR 0.5 和 300 秒墙钟上限，不冒充正式制品的完整比赛验证。未进行手机真机验收。
