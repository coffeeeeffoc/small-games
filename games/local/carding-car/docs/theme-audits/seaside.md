# 浪湾海岸主题核对与接入

2026-09-19。海岸主题仍由 `ThemeView` 委派 `Track.ts:buildTrack`；公共 `ribbon` API、道路控制点、驾驶物理、检查点与共享护栏均保持不变。

## 实际查看与差距

已实际查看 `assets/carding-car/concept.png`、独立模型预览 `preview-shaded.png`，以及改造前实机 `reports/themes-routes/seaside-seaside.png`。效果图以蓝绿浅海、暖色岩岸、沙滩、棕榈和红顶灯塔为主；白帆船、木码头、红白遮阳棚、三角彩旗与木栏构成海湾度假区。原实机是固定半径浅绿色圆盘，海面只在地平线出现，少量树岩分散，固定看台只是裸台阶和彩色球，缺少岸坡与海湾配景。

原独立 GLB 能提供树木、岩石和灯塔，缺口是地形和小型海边建筑，不需要再生成一块含假公路的整体模型。

## 素材与运行接入

| 元素 | 准备方式 | 接入 |
| --- | --- | --- |
| 棕榈、阔叶树、礁石、灯塔 | 原有轻量 GLB，沿用素材清单的尺寸和包围盒；七组放大的岸石形成近中景悬崖 | `SeasideGeometry.ts` 安全摆位，`Track.ts` 使用共享 Prefab/材质实例化 |
| 沙滩、浅水、坡岸 | 6 米采样格生成路线周围的海岸曲面 | 使用主路、近道各自路宽和高程，地表始终低于附近道路 |
| 坡道路基 | 沿主路和近道的实际边缘生成窄侧壁 | 连接沥青下方与岸坡，避免高原路线呈现悬空薄片 |
| 红白遮阳棚、彩旗、木桌及看台 | 纯三角面与现有 `MeshBatch` 几何；每色合批 | 两座棚亭、一座带顶看台，整组先避路、平台连接海面 |
| 帆船、木码头、路牌 | 静态小型批次几何 | 六条白帆船、木栈道、黑黄转向牌；海上物件随最低海平面调整 |
| 远岛、稀疏云朵 | 少量批次形状 | 按当前路线包围范围生成，不再固定在原海湾世界坐标 |
| 沥青、红白路肩和护栏 | 复用原纹理及 `road-profiles` | `TrackBarriers` 仍同时约束真实碰撞和可见护栏 |

没有新增运行依赖、贴图或外部模型。原图、原始 GLB、`runtime/manifest.json` 等素材文件未修改。新增几何使用已有颜色合批，八条路线约 3.8–4.6 万个地形/建筑顶点、59 个模型实例；这些统计不代表真机性能已经验收。

## 任意路线适配

- 海面低于当前主路和近道最低点 3 米；沙滩、浅水和岸坡沿所选路线生成，不再用半径 213 米的固定圆岛。
- 地形高度限制考虑完整网格格子的周边道路和路段最低高程，防止插值三角面盖住坡路与近道。
- 灯塔岛、看台、棚亭、栈道、帆船、树岩和路牌均以整组包围圆检查主路及近道。遇到相邻道路或已摆地标，整体寻找下一处位置，不对单个零件裁切。
- 树岩按岸坡高度落地，并有接海面的局部岩基；看台/棚亭平台跟随选中路线高程。灯塔作为离岸地标使用独立岩岛。
- 起终点方格覆盖实际路宽，起终点和龙门架高度随路线起点变化；龙门架净宽随路线宽度变化。

## 验证与边界

`node --test tests/seaside-theme.test.ts` 通过：覆盖全部 8 张路线图和额外的 32 米主路、12 米近道、高原坡度组合，检查道路未被改写、必需地标存在、所有地标/模型/形状净空、有限几何及索引、岸壁/建筑三角面顶点和中心避路，以及地形三角面中心不会侵入驾驶面。`pnpm --filter @coffeeeeffoc/carding-car typecheck` 通过。迭代器统一用 `Array.from` 转成数组，避开 Creator 的迭代器展开转译差异。

本阶段没有单独执行 Cocos 构建或提交，由主任务统一构建和截图验收，重点检查海岸 × 近道连弯、宽街大环、连续爬坡。海面与帆船为静态装饰；未引入动态海水着色器或概念图中的全局光照，不把原效果图当作当前实机结果。

## 最终构建截图复核

实际逐张查看了主任务最终构建的九张游戏截图；本轮只读图并更新记录，没有修改源码、启动浏览器或再次构建。

- `reports/theme-views/seaside-{25,100,200,320}m.png`：25 米能看见左侧带顶看台、两侧海水/沙滩与右侧木码头、棚亭；100 米弯道能看见真实礁石和层次分明的近岸浅水；200 米白帆船、红白棚亭和彩旗可辨认；320 米连续弯道、棕榈、海面与浅滩保持正确组合。新增布景不是只存在于素材文件中。
- `reports/theme-views/seaside-highland-{25,100,200,320}m.png`：同一海岸主题保留海水、看台、码头、礁石和植被，高原路线的路形/高程确实改变。100–320 米坡道持续爬升；200 米右侧棚亭平台与岸坡随高程抬高，320 米能看到地形下降至海面。未见岸坡穿过路面、断路、大范围悬空或成组地标被裁残。
- `reports/themes-routes/seaside-highland.png`：起跑方格仍贴在高原路线沥青上，带顶看台、海湾及右侧岸坡已出现；该帧不包含龙门架，因此不据此单独声称龙门架视觉已验收。

这些截图中没有发现阻止继续驾驶的海岸主题严重缺陷。复核发现黑黄路牌原先统一显示左向符号，随后已修正：按最终摆位前方 35 米的实际弯向选择左右符号，直路省略，增加镜像弯道、角度跨越 ±π 和实际网格朝向回归。重新构建后再次实驾采集原路线及宽街大环的 25/100/200/320 米截图，原路线 100 米和宽街大环 200 米的右向路牌已正确出现；72 项测试及 64 种组合回归通过。

仍存在以下视觉细节：浅水/沙滩色带能看见规则网格台阶，高坡上部分树木岩基呈明显柱体，远岛与云团仍偏球体轮廓。这些效果距离原概念图的自然岩岸与光照还有差距，不应描述成效果图完全还原。

截图是指定位置的局部视觉证据；完整三圈驾驶、其余主题组合、手机或渠道真机验收以主任务单独记录为准。
