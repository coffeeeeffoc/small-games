# 七彩丹霞主题：效果图对照与接入

## 实际对照

已用图像工具查看 `assets/carding-car/expansion/scenes/danxia/concept.png`、相邻 `preview.png` 和改造前实机截图 `reports/themes-routes/danxia-danxia.png`。目标图是蓝天、自然红橙/赭黄/米白/灰绿地层、连绵起伏岩壁、深灰沥青和木质观景平台；旧版是橙色天空、棕色路面、孤立高饱和条纹丘、固定坐标栈道和远处含假道路的完整沙盘。

## 准备的实际素材

- 新增 `assets/scripts/DanxiaGeometry.ts` 作为可重建的独立山脊几何源。每个山脊包含八条自然色地层、高低两座相连山峰、倾斜层界与侵蚀侧面，单模块 480 个三角面。闭合轮廓形成完整厚度，山脚外展、山顶额外细分，地层不等厚且随种子起伏，跨色层平均法线保留圆润体积。没有道路、方形底座、亭子或碰撞逻辑，可按尺寸、朝向和种子重复使用。
- 素材通过 `ThemeScenery.meshes` 输入已有 MeshBatch，同色山体合批。无需新增 GLB 包、下载资源或新的材质系统；这是一份实际运行几何素材，不是效果图替代物。
- 已用现有 Three.js 与系统 Chrome 渲染该几何并实际查看 `reports/danxia-ridge-preview.png`，确认自然色地层、法线与正面朝向可见。该图只证明素材形状，不能代替 Cocos 游戏内视觉验收。
- 观景平台在 `themes/danxia.ts` 中用现有批处理基本几何组装：落地石基、木板接缝、两层围栏、亭柱、蓝灰层叠屋顶、柜台、长椅和导览牌。另备灰绿灌木与暖色碎石。
- 深灰道路复用已有 `asphalt/texture`；主题天空换为蓝色，路肩保留自然赭黄，护栏使用浅灰。移除所有完整丹霞沙盘与旧的高饱和小丘模型引用。

## 任意路线适配

山脊和平台均根据当前路线的沿程位置、切线、路宽和高度布置；`clearOfRoad` 用完整占地检查所有主路及近道。地面基准为当前路线最低高程减 0.12 米，支持坐标平移和负高程。近景起伏山脊与外围大型山链错位铺设，平台整体预留距离还包含共享渲染器逐部件的保守圆形包围盒，避免残缺栏杆或悬浮屋顶。灌木与碎石同时沿主路和近道布置。

各现有路线生成 47–77 组双峰山脊，22,560–36,960 个地形三角面、5 座完整观景设施。丹霞路线为 61 组、29,280 个地形三角面。地标不修改赛道坐标、碰撞、检查点或比赛规则。高架或爬坡路线旁的平台与山体均向地面延伸，灌木留在地面。

## 实机反馈修正

实际查看统一构建后的 `reports/theme-views/danxia-{25,100,200,320}m.png`：道路、自然色层与观景台正确，但初版条带几何把所有层缩到两端的地面尖点，形成明显折纸薄片。已将该几何替换为上述闭合轮廓双峰，并降低高宽比、减少重复模块数量。新增回归断言保证上方地层不再收束至地面；重新渲染并查看 `reports/danxia-ridge-preview.png`，确认宽厚山脚与圆钝山体。修正版尚待主智能体再次进行游戏内构建截图，未把旧截图当作修正版验收。
