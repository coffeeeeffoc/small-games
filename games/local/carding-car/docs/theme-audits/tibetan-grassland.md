# 青藏高原草原主题

## 效果图与接入前画面

实际查看了 `assets/carding-car/expansion/scenes/tibetan-grassland/concept.png`、同目录 `preview.png` 以及 `reports/themes-routes/tibetan-grassland-tibetan-grassland.png`。

效果图：低缓绿丘、开阔草甸、白黄野花、青蓝溪水和散石、白色锥顶帐篷、深色长毛牦牛、营地经幡、蓝天白云。

接入前：纯色平地；固定坐标的半球毡房、牛和水片；远处是带另一条道路、垂直厚土底的完整展台。该 GLB 的单 mesh 包含地形与预制道路，不能用作适配任意路线图的地形。

## 素材准备与接入

- 复用已存在的 `expansion/props/grass-hill`（14 × 10 米、4 米高）、草地纹理和共用沥青纹理。
- `GrasslandGeometry.ts` 实际制作了多边形帐壁、锥顶、腰带和檐边，以及可复用的低缓圆丘网格。主题文件组装门口、桩绳、木栏和五色经幡，四组营地共八座帐篷。
- 牦牛由深色隆背、低头、长毛裙边、四足、浅色双角组成；30 头沿所选路线的牧场分布。花瓣使用六面低模，避免大量球体的额外开销。
- 青蓝溪流由短水段与溪岸石组成。水段会避开全部主路/近道、营地和牛群；相邻水段可以重叠，遇到道路或地标安全中断。中景复用草丘模型，远景通过所选路线的包围范围生成缓丘与云朵。
- 完整展台模型不再在运行时摆放；保留资产源。没有新增依赖、在线资源或资产生成服务调用。

## 路线适配与边界

布置位置取自 `TrackData`。营地、牛和草丘先按完整包围范围检查全部道路分支，再落地；内侧空间不足会向外移动或改用道路另一侧。草丘避开溪流与营地，避免山体吞没地标。路线有高程时，营地、牛群、野花与溪流下方生成落到公共地面的草坡，地标不会悬空。

主题只影响美术；道路控制点、宽度、坡度、护栏碰撞、近道与比赛进度保持路线图定义。溪流是视觉环境，没有新增涉水物理；经幡、云和牛是静态美术。细草与水流质感仍是移动端的简化版本，不宣称与高分辨率效果图逐像素一致。

## 验证

`node --test games/local/carding-car/tests/grassland-theme.test.ts` 通过：8 张现有路线以及平移后的 32 米宽高程近道路线，检查营地和牛群完整性、模型完整占地、每个程序网格三角形的保守包围范围，以及溪流覆盖率。所有主题形状在进入渲染过滤前已安全。

`pnpm --filter @coffeeeeffoc/carding-car typecheck` 通过。草坡底部始终接地，整体抬升路线后帐篷同步抬升。源程序几何每种组合少于 35,000 个三角形；球体与复用模型由原有批次路径渲染。

根 Agent 统一 Cocos 构建、实际截图和驾驶验收；本主题 Agent 未自行构建或提交。
