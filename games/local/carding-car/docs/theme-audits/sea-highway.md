# 跨海高速主题

## 对照依据

- 美术目标：`assets/carding-car/expansion/scenes/sea-highway/concept.png`。实际查看后提取白色双柱斜拉桥、成组白缆索、灰色沥青与红白护栏、碧蓝海水、岩岛植被、红顶灯塔和白云。
- 实际源模型：同目录 `preview.png`。它包含两座桥塔和灯塔岛，但海水、道路、桥梁为不可拆的短地块；不能作为任意路线的桥面。
- 改造前实机：`reports/themes-routes/sea-highway-sea-highway.png`。驾驶视野主要是纯色海平面、普通护栏和细杆，缺少概念图最主要的白塔/缆索轮廓；水纹出现在桥肩上。

## 素材与接入

| 元素 | 准备方式 | 游戏接入 |
| --- | --- | --- |
| 桥面下的混凝土桥体 | `SeaHighwayGeometry.ts` 按当前主路、近道逐顶点生成 | `theme.scenery(track).meshes`，沿每条支路宽度与坡度装配 |
| 白色双柱桥塔、斜拉缆索、桥墩 | 同模块生成独立构件；不使用旧橙红色桥塔 | 首塔在起点前方约56米，后续随路线长度分布；近道独立采样 |
| 岩岛、灯塔、树木 | 复用已有 `coastal-rocks`、`lighthouse`、`palm`、`broadleaf` 运行模型 | 岛整体先避让所有道路，再按现有素材实际包围盒验证；最多65件模型 |
| 海面与浅水层、白浪、云朵 | 现有批网格形状；不新增贴图或依赖 | `groundDepth: 6` 使海面低于最低路面6米，`shoulderTexture: false` 移除桥肩水纹 |

未改写原始概念图、源 GLB、共享素材清单或比赛物理。独立模型原有来源、哈希及米制尺寸仍记录在 `assets/carding-car/runtime/manifest.json`。

## 路线适配与净空

- 桥底使用与实际道路相同的横向切线，顶面通常低于沥青18厘米；主路与近道均有完整桥体。
- 不同坡度的支路汇入口，桥底按另一条支路的最低高程进一步压低，覆盖相邻完整跨度，防止主路桥底盖住近道沥青。
- 每根塔柱、塔梁、桥墩和缆索生成前，按最多1.5米段长检查完整体积与所有支路的净空；不通过的整根构件不生成，不留下被截成碎段的缆索。
- 桥塔是分体白塔、上部横梁和缆索，不依赖会把整座跨路拱门过滤掉的模型包围圆。
- 桥塔与缆索保留6米驾驶净空；护栏仍来自共享 `TrackBarriers`，没有改动驾驶宽度、坡度或碰撞。

## 验证

`node --test tests/sea-highway-theme.test.ts`：两项检查通过。覆盖现有8条路线，以及额外的“高山高程＋不同坡度近道”组合；独立采样桥体、桥塔、桥墩、缆索全部三角形的顶点、边中点与中心，分别投影主路/近道，确认没有侵入驾驶空间。额外检查模型实际包围盒、最低海平面、桥体覆盖支路、塔与缆索确实生成、道路数据没有改变。

`pnpm --filter @coffeeeeffoc/carding-car typecheck` 通过。最终 Cocos 构建和实机截图由统一集成验证补充；概念图与模型预览不替代游戏运行证据。

目前采用轻量静态海面与批网格云朵，没有引入水体着色器或动态天气；桥塔保持白色双柱斜拉桥轮廓，未尝试把原概念图整幅地形复制成同一路线。
