# 生涯、车库与比赛准备

玩家从首页查看等级、成长点、金币和比赛进度，进入生涯领取里程碑奖励，在商店购买赛车、车手服、赛车装饰和飞行宠物，并升级发动机、轮胎及氮气。购买、装备和领奖使用同一份本机存档；存储失败时不扣款、不显示已购买。

比赛入口先选择主题、地图、赛车、车手服和比赛模式，所选资源直接显示在预览区。只请求默认/已装备/分享指定资源，以及实际浏览到的候选资源。小伙伴选项默认折叠，展开后缩短赛道预览并显示独立配置区，允许 0–7 个对手，选择与玩家相同装备或随机外观。未解锁赛车与车手可浏览，但出发按钮禁用，点击「去解锁」定位对应商品；共享挑战中的未拥有外观回退当前装备，保留路线、赛制、道具布局与借用零件等级。

进入赛道会装配全部参赛车辆与道具。装配完成后停留在待发状态，玩家再次点击“开始比赛”才显示 3、2、1。倒计时使用实际经过秒数，不沿用物理模拟的帧时间上限；暂停及切到后台会暂停倒计时。

商店浏览商品即更新实时模型；「查看已装备／查看此商品」用于对比。购买只解锁，随后明确点击「装备」才用于比赛，退出商店恢复实际装备。金币不足时展示差额，存储失败显示失败原因。

生涯展示等级成长、目标进度和已领取状态。可领取目标排在前面，支持一次领取全部达成奖励；未完成目标的「去挑战」打开比赛准备，探索目标优先未跑路线，冠军目标保证至少一名对手，不自动开赛。

设置使用暖色行式开关，打开时保留原页面背景并暂停其触控；关闭恢复同一页。浏览器提供全屏，原生平台隐藏该项。

单人赛只有真实完赛才结算成长与奖金；退出、重开、重复刷新结算不重复领奖。路线冠军、累计完赛与路线探索提供额外里程碑奖励。旧路线印章和个人纪录保留。

零件升级影响单人赛车的加速、抓地及氮气。分享的升级赛车挑战携带零件等级，挑战者临时使用相同等级，不能把借用配置保存为已购买装备。好友联机继续使用服务端统一参数；房主只能切换已拥有外观，成员未拥有房间赛车或车手时不能准备或进入比赛，可请房主换车或退出后解锁。房间创建会回退实际拥有的外观，本地经济不替代全站排位结算。

生涯数据存储在当前设备/浏览器的 `kart-career-v1`，机器人选项存储在 `kart-race-options-v1`；当前不提供跨设备同步。

`pnpm --filter @coffeeeeffoc/carding-car test:career` 检查默认资源按需请求、0/3/7 机器人、阻塞资源期间禁止开赛、卡帧后的实际秒数倒计时、多指取消、真实触屏完赛及奖励去重。另用明确标注的 5000 金币测试钱包验证全部购买、装备、升级和重载保存，不把测试钱包作为完赛奖励证据。浏览器环境为 Chromium、Android UA 与 CDP 触屏，覆盖 844×390 横屏和 390×844 竖屏持机；微信/B站真机验收仍需单独执行。

`pnpm --filter @coffeeeeffoc/carding-car test:menu` 使用手机横屏与竖屏触摸检查锁定、金币提示遮挡、按钮热区、设置背景输入隔离、实时预览、独立购买/装备和生涯导航。默认严格核验 Creator 构建源码；开发叠加预览须显式启用 `KART_ALLOW_SOURCE_OVERLAY=1`，逐模块核对当前源码，证据中标明不代表完整 Creator 构建。
