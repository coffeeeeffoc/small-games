# 橘风速递 · Tangerine Express

为手机横屏制作的原创 3D 海滨配送游戏。骑上薄荷色小摩托，去集市买齐橘子、面包和牛奶，再把货物送到小岛居民手里。

## 运行

```powershell
pnpm install
pnpm dev
```

- 电脑开发预览：<http://localhost:43117/>
- 手机和电脑在同一局域网时，打开终端显示的 `Network` 地址。本机当前为 <http://192.168.1.25:43117/>；电脑地址变化后以终端为准。
- 项目固定使用 Node 24.12.0，pnpm 通过 `.npmrc` 选择运行时，避免本机旧 Node 被脚本意外选中。

```powershell
pnpm test
pnpm build
pnpm preview
```

正式构建输出到 `dist/`；预览端口 **43118**，手机地址 <http://192.168.1.25:43118/>。所有引用使用相对路径，整个 `dist/` 可部署到静态服务器或 GitHub Pages 子目录。

## 怎么玩

1. 选择一份岛民订单，从路边出发。
2. 左摇杆上下前进/倒车、左右控制车头转向。倒车时左右含义不变，停下或撞墙后也能转头脱困。右侧按住加速，刹车减速，点按跳跃。拖动画面可以环顾四周。
3. 到橘风集市光圈停稳，点「下车取货」。摩托会停在原地。
4. 步行到三个摊位，逐件拿起面包、橘子、牛奶。拿齐后回集市入口上车。
5. 跟随目标光圈和地图沿街配送。碰撞、高速急转弯与高速跳跃落地会损坏货物；能量耗尽时需要松开加速恢复。
6. 3 分钟内送达，停稳后点「完成配送」。完整度和用时决定星级/小费。结果页可接下一单或返回。

电脑：WASD / 方向键驾驶，Shift 加速，Space 跳跃，E 交互，M 地图，P / Escape 暂停。刹车也可以直接点击右下按钮；松开方向键会自然减速。

共有三种可玩订单：海风咖啡、灯塔管理员、面包花园。中央路口需要绕开花坛；咖啡和花园方向各有两处错位花坛，减速交替过弯。海岸环路提供更长、更开阔的替代路线，并连接码头。大小地图显示相同的道路与障碍，虚线只指目标方向。

整个岛屿街区、海岸和码头可自由行驶；交通车辆和行人是环境装饰，建筑、货摊、部分树木、道路花坛及海岸有碰撞约束。

## 手机与保存

- 旋转手机横屏使用；竖屏显示提示并暂停订单。
- 独立的 Pointer Events 支持摇杆与加速同时触摸，触控取消/丢失捕获/失焦会清空输入。
- 打开地图、暂停或切换后台会停表。继续按钮恢复原订单。
- 本地保存已完成配送数、累计橘子币和静音设置。正在进行的订单不跨刷新恢复。
- 顶部全屏按钮取决于浏览器支持；iPhone 可使用浏览器的“添加到主屏幕”。
- 正式构建会生成离线 Service Worker。首次在 **HTTPS 或 localhost** 成功载入后，可断网重新打开。普通局域网 HTTP 可直接游玩，但不启用 Service Worker。
- 这是可静态托管的移动 H5 / PWA 项目，本次没有原生 APK 或服务端。

## 实现与素材

Three.js + 原生 JavaScript / DOM + Vite，无 UI 框架或额外物理引擎。所有角色、摩托、房屋、摊位、帆船、灯塔及环境均由本项目程序化生成；招牌用 Canvas 绘制；音效由 Web Audio 合成。运行时无需外部 CDN、模型、音频或账号。

设计参考 [Capybara Delivery](https://capybara-vibejam26.leocoout.dev/?ref=vibejam) 的骑行配送、实体拣货、货物反馈与小镇探索，以及用户提供的 `F:\playground\playground-ai\vibeJam\capybara-delivery\PROJECT_ANALYSIS.md`。没有复制原版发布 bundle、解包模型、图片或音乐。

文件职责：`src/map-data.js` 道路/建筑/花坛/海岸/码头的共享布局，`src/map.js` 大小地图绘制，`src/world.js` 3D 场景和模型同步，`src/game.js` 玩法/碰撞/订单，`src/input.js` 输入，`src/audio.js` 声音，`src/main.js` 相机/界面/生命周期，`src/style.css` 横屏布局。

维护约定：修改路网、建筑布局或绕行障碍先改 `map-data.js`，场景与地图读取同一份数据；花坛数据直接供碰撞使用。世界坐标向东为 +x、向南为 +z，车头角度 0 向北，正角度右转；Three.js 模型的 Y 轴旋转取其负值，统一由 `world.update` 同步骑行和停车模型。`createGame(progress)` 只接收存档，碰撞体由 `tick` 接收。

运行检查与实际浏览器结果见 [docs/verification.md](docs/verification.md)。
