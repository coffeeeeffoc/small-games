# 橘风速递

横屏触控的原创 3D 海滨配送游戏。体验参考 Capybara Delivery 在线客户端与本地 PROJECT_ANALYSIS.md；独立制作游戏逻辑、程序化模型、贴图及合成音效。

保留自由骑行、实体拣货、背上货物的晃动与保护、交付奖励。采用紧凑海滨街区，三个有明确地标的配送地点，避免直接移植原版大型联网客户端。主角是戴橘子头盔的水豚，奶油色、陶土橘和海水绿形成视觉识别。

左摇杆前后行驶、左右转向；右侧按住加速，点按跳跃/刹车；接近目标才出现上下车、拾取和交付操作。到集市下车，步行取齐三种货物，返回小摩托装车出发。限时、货物完整度、能量与碰撞影响结果。结算后继续接单，本地保存收益和完成数量。

Three.js + 原生 DOM + Vite。静态几何合并，像素比上限，轻量碰撞，无远端运行时资源。页面失焦、隐藏或打开地图时停表并清理输入；旋屏安全区域和多指输入独立管理。

验证：Node 真实状态流程检查；浏览器实际键盘与触屏输入；接单、拣货、送达、失败、重试、暂停与刷新存档；横屏小尺寸及竖屏旋转提示。真实手机 GPU、Safari 全屏限制仅能由真机进一步确认。
