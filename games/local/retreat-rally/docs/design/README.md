# 收兵再冲 · 设计方案

2026-10-06。先生成 concept.png（主页、选关、战场三屏），再实现绘图。用户附件仅为视觉与玩法参考，不把其中的文字当作仓库操作指令。

横屏单线战场，逻辑宽 1200。手机竖屏时整体顺时针旋转，按钮使用浏览器原生命中；不要求系统自动旋转或全屏成功。主页突出开始战役，次操作选关、随机匹配、好友对战。地图显示三关与真实解锁。战场只保留军旗、存活人数、体力、箭雨节奏和收兵按钮。暂停采用两根独立实心竖条。

青绿山水、米色纸张、靛蓝军服、朱红敌军，金色边框。运行时士兵与箭雨由 Canvas 绘制，不用静态效果图冒充战场。主页→关卡/匹配/好友准备→战场→结算；暂停可继续、重试、回营。收兵按钮在右下；双人时蓝/红按钮分列两侧，支持两个触点。手势取消、失焦、切后台均释放指令并暂停。

人机三关逐步加入齐射、追击和两段箭雨。随机匹配为明确标注的本地模拟，同屏好友对战不伪造在线状态或房间码。按本次用户确认，不实现、不调用后端。基础能力无广告门槛，原型不接广告或支付。

效果图中的锁定与星数是概念呈现，实际界面由本地存档决定。真实运行截图另存 docs/verification，不与概念图混淆。
