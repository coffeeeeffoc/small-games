# 多回合弹射改造

2026-10-09。目标是短局中的多次攻防：接近 → 找角度 → 逼边 → 击落。正常开局应给玩家多次尝试机会；每次行动保留真实落点，命中后通常先产生位置优势，靠边的准确撞击才容易终结。

## 规则与操作

- 保留竖屏单指反向拖拽、蓝/红/橙依次行动、所有运动停止后交接、完全出界才淘汰、最后一人获胜及同时出界平局。
- 缩短最大滑行距离至约擂台直径的三分之一，较远目标需要先接近。减小实际碰撞圆盘，人物显示与碰撞范围一致，拖拽起手热区仍为 32 逻辑像素半径。
- 五个摆位保留稳定 ID，起始站位错开并留足边缘余量。取消默认的贴边连锁送出局阵型。无需最少命中数或无敌回合，击落仍由方向、力度与位置决定。
- 对手与玩家共用物理规则；对手会接近、推位、保持安全落点并在对手靠边时争取击落。所有选择与误差通过已有种子生成器保证可复现。
- 前五个完整回合保留完整擂台。之后每轮提前显示下一条边界，在完整回合交接时短暂、连续地收圈；收圈过程使用相同固定步长，暂停冻结、回放保留、出界原因可辨认。
- 蓄力显示按真实速度与摩擦计算的无碰撞射程和停点。遇到圆盘后的实际落点仍需玩家判断；不能把无碰撞标记作为碰撞终点。当前边界与下一次收圈预告必须同时可见。
- 沿用武馆木纹、原创三色小侠和现有页面结构。主页文案强调走位逼边，帮助解释射程、落点与收圈；局内只保留行动者、回合、玩家出手次数和必要危险提示。

## 验收目标

- 首版试玩调节目标为约 30–60 秒、玩家约 4–8 次出手；这是节奏目标，不能把全场 AI 出招数算成玩家操作，也不能声称每局时长固定。
- 五摆位的开局直瞄满力出手不能直接送对手出局。满力远射需要接近；擦碰与正碰产生不同结果。中央命中通常保留双方，靠边的有效正碰仍能淘汰。
- 多种种子下记录完整回合数、总出招数、蓝方存活时实际出手次数及模拟运动时间，检查短局、长局与防守策略，避免仅证明“没有死局”。
- 手机触屏走通主页、摆位、拖拽/取消、多次出手、预告收圈、暂停/恢复、结算、回放、重试和返回；覆盖小屏与横屏缩放，并核对效果图。
- 保留存档兼容和开发模式战绩隔离；核心不依赖 DOM、渠道 SDK 或浏览器，平台规则一致。
- 提交后以最新远端 dev 的准确 SHA 验证最终候选，保留正常 hooks，同步并行提交，再推送 dev。线上 CI 与 Pages 结果单独核对。

## 规则与节奏验证

最终物理参数：初始擂台半径 158、圆盘半径 14、最大速度 220、摩擦减速 205、恢复系数 0.72、固定步长 1/120 秒。满力无碰撞射程为 118.9667，约为初始擂台直径的 37.6%；首次满力直瞄各对手的 10 个样本全部需要先接近，0 命中、0 淘汰。

前五轮保持完整边界，第六轮起每次完整交接缩小 18，持续 0.75 秒，最小半径 18。先完成整个预告的收圈再结算，避免中途只剩一人时宣布其胜利，但其位置实际上仍会在本次收圈中出界。下一行动者如被收圈淘汰，继续跳过。双方使用相同规则，AI 在比较落点后才施加瞄准误差，不预先知道误差造成的结果。

使用 Node 24.21.0 / pnpm 12.6.0 执行游戏规则测试与 `node games/local/flick-arena/scripts/pacing-check.mjs`。五摆位 × 60 种种子共 300 场模拟，全部自然结束，蓝方胜 60 场、无平局；这不是人类玩家胜率统计。玩家出手次数中位数 6、p10 为 4、p90 为 10、最多 11，214/300（71.3%）在 4–8 次范围。全场出招中位数 19、p90 为 27、最多 31，分别记录，不互相替代。

节奏估算计入精确模拟的运动与收圈时间，再假设玩家每次思考 2 秒、AI 每次等待 1.25 秒：中位数 47.03 秒、p90 为 69.53 秒、最多 78.59 秒，不含匹配与结算。这是可重复的估算，不是浏览器墙钟时间或真机实测；多数达到 30–60 秒目标，部分局仍会更长。另有 100 场玩家始终逃回中央的防守模拟，全部结束，总出招中位数 27、最多 35，没有无限撤退死局。

校验还覆盖普通中央命中推位、临边准确撞击可在第一轮终结（无回合锁）、连续碰撞、动态出界、同时出界平局、收圈期间暂停、触控热区与有限射程提示，以及不同显示帧率下的物理时间回放。

## 实际运行验收

规则与运行时测试 21 项通过；Shell 沉浸与入口契约的两组测试共 83 项通过。完整触屏流程见 [浏览器记录](browser-validation.json)：Chromium 桌面模拟 390×844、DPR 2，通过真实触摸事件完成普通对局，玩家 7 次出手、7 回合、全场 18 次出招，游戏时钟 39.396 秒。开发模式对局自然到达收圈，并验证收圈暂停；同时覆盖取消拖拽、第二根手指、失焦恢复、回放不重复结算、重试、存档隔离、横屏与 320×568 小屏。82.3 秒是整组测试的墙钟时间，不是单局时长。

[Shell 记录](shell-validation.json)使用源代码 Shell 与本次游戏构建产物，真实触摸验证外层导航在游玩和暂停时隐藏、回主页恢复、返回目录销毁 iframe，以及缩放与全屏拒绝后的普通视口可玩；13.3 秒、无页面错误。全屏请求未进入，未声称验证全屏成功。以上均为桌面浏览器手机模拟，尚未进行真机或原生小游戏宿主验收。
