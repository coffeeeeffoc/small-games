# 多角色复查与 120 关扩展

2026-10-11。应用项目级 `game-ui-ux` 与 `game-feel` 技能，沿用已认可的武馆竖屏画风和每章五关的手机页面。方案在本次实现前保存；局部效果图见 `levels-concept.svg`，没有新增主页面。

- 玩家/内容设计：保留原二十关与五个练习摆位。增加青锋、逐浪、苍岚、星河、天绝五条二十关进阶路线，共 120 关、24 章。通过相对出生距离、柱体大小、冰面范围/摩擦、缺口深度、AI 风格/实力及收圈节奏组合形成不同攻防，而不是只转动同一张地图。原 ID、解锁顺序和已获星数继续有效。
- 移动交互：沿用每章五关与上下章入口；目录总数、满星总数与最终关结算从关卡配置读取。屏幕/画布尺寸改变取消正在进行的拖拽，保留完整对局；缩放后玩家圆盘至少有 44 CSS px 热区。
- 手感/竞技：保留精确反向拖拽、真实轨迹预告与现有短音效/击落反馈，不改变权威联机时序。人机局玩家已出局时缩短机器人思考等待，减少无操作观战等待。
- 稳定性/存档：校验全部出生点、地形与解锁链，模拟每一关的自然结束及可获胜种子；验证旧二十关存档继续到第 21 关、最终关完成态、回放不重复奖励。
- 验收：Node 规则与运行时测试、生产构建；Chromium 手机触屏完整闯关与暂停/回放/返回，扩展章节入口、第 120 关、小屏/横屏及尺寸变化中手势取消。模拟浏览器不等于手机真机，联机服务与平台真机验证明确记录边界。
