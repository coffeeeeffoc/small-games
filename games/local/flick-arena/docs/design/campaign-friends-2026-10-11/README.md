# 闯关与好友擂台

2026-10-11。依据已确认的玩法方案实施；保留竖屏单指反向拖拽、短射程接近、真实碰撞、完全出界淘汰、整轮预告收圈的核心。竖屏适合圆形擂台与单手拖拽，手机比例、木纹武馆材质与细节按本次认可效果图落实。

## 本次范围

- 20 个稳定 ID 关卡，4 章，每章 5 关：初出茅庐（双人控力/侧击/保位）、三足鼎立（三人借力/目标选择）、借力破阵（石柱反弹/局部冰面）、巅峰擂台（缺口/提前收圈/组合）。每章末为有打法风格的守关战。敌我使用相同物理规则；难度来自决策和场地，AI 不默认结盟。
- 胜利解锁下一关，每关胜利星和两个独立可选挑战星；普通选关遵守进度，开发选关不污染正常存档。累计星解锁称号和纯外观，全部基础力度相同。旧局数/胜场/声音设置保留。
- 同机双人三局两胜，在线好友 2–4 人。双人每局交换首手，平局重赛。3 人赛打 3 小局、4 人赛打 4 小局，轮换出生位置与先手；每比一名对手存活更久得 1 分，唯一幸存者额外 1 分，同次弹射/收圈淘汰者并列，最终同分者一起加赛直到唯一冠军。
- 每小局固定行动顺序；好友局每手默认 10 秒，可选宽松 15 秒，超时跳过。第 3 个完整行动轮结束开始收圈，提前预告。目标每小局约 1–2 分钟，淘汰者观战并保留下一局席位。
- 创建/加入房间、准备、分享房间码/链接、断线恢复、合法出手与服务端裁定、下一局和再战。真实玩家席位不伪装 AI。在线对局在本机后台仍按服务端时间推进；返回后同步最新状态。
- 2v2 是下一批范围。本次不添加未实现的组队入口。

## 页面与视觉

主页突出继续闯关，提供章节选关、好友擂台、练习和帮助。选关每页一章五关，显示锁定、已获星和下一目标；关卡准备显示本关技巧与挑战。游玩保持擂台占主要面积，上方当前行动者与回合，下方拖拽反馈/危险预告，暂停按钮为两根实心竖条。双人同机交接明确标示当前玩家。

好友页分同机双人、创建房间、加入房间；房间页展示 2–4 席玩家与准备状态，房主选择人数/计时。进入对局后隐藏外围房间表单。小局结算显示积分/比分、下一局准备；最终结算显示冠军与再战。各页返回路径明确，最小触屏热区约 44 CSS px。小屏保持可点，无文字遮挡擂台。

原有武馆配色、圆盘小侠、金色木纹按钮沿用。新冰面为半透明蓝白圆区、石柱为灰金立体圆柱、缺口为可辨识暗色切边；目标虚线依据相同物理积分预览地形路径，仅忽略其他圆盘碰撞。下一次收圈保持橙色虚线。

效果图在对应 UI 实现前生成并保存于本目录；只是设计参考，不直接充当运行资源。实现后保存实际手机截图及浏览器验证记录并逐项对照。

## 规则与技术边界

复用现有 Game Host/CanvasGameTarget、存储、开发模式、全屏与运行环境适配。核心和关卡配置无 DOM/SDK；关卡声明独立，新增既有机制关卡只改内容配置。地形、2–4 席、轮次顺序、超时跳过、淘汰批次属于共享规则；赛制独立纯函数，供同机/在线共用。

联机复用已有 runtime-api 身份与竞争房间能力，以服务端状态为准；客户端不得提交比分、任意盘面或代替其他席位行动。版本、行动序列、重复请求和恢复需有明确处理。保持其他已接入游戏的双人规则与 API 兼容。

- 20 关配置有效、解锁可达、旧存档迁移、挑战独立累计、开发隔离、重复结算幂等；人机模拟检查无死局、难度与规则公平。
