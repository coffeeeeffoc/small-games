# 移动端发布改进 · 2026-10-11

## 方案与效果图依据（先于实现）

十二层固定路线，连穿按 100 × 连落倍率（上限 5）计分；普通平台可喘息但重置倍率。结算增加分数反馈及同路线挑战分享，挑战独立于正常解锁。保留免费续关；只在自然结算转场允许公共频控模拟插屏。

沿用 [既有手机效果图](../concept.png) 的竖屏游戏场景、色彩和信息层级，仅在既有主页/结算操作区添加同场挑战按钮与轻量状态行，不新增主要页面。核心游戏画面继续占据主体，触控主操作保持原位置。新按钮至少 44px；安全区、暂停图标与原有全屏机制保持一致。

## 验收

规则测试覆盖收益、断连/上限、存档隔离和初始种子。手机 Chromium 触屏走通开始、手势取消、暂停/恢复、结算重试、挑战复制/打开。广告必须标识模拟、可取消，关闭/失败不授予奖励；不在游玩中打断；记录桌面浏览器触屏模拟与未验证真机限制。

## 实测结果

- 2026-10-11，Linux Chromium 151.0.7922.173，触屏模拟：390×844、320×568、844×390，并覆盖桌面。已检查新结算分享按钮、公开链接、同场入口、免费重试、暂停/失焦/手势取消、iframe 与全屏。
- 三款现有与新增规则/存档/host测试合计 97/97 通过。浏览器记录见 [browser-report.json](browser-report.json)，关键新截图保存在本目录。塔自然触屏通关，救援自然指针输入胜负与可选广告取消，弹珠自然通关以及同种子触屏失败/再试均通过。
- 救援真实 host 契约另覆盖 unavailable、dismissed、failed 不发奖励，completed 仅补球一次。模拟广告仍需真实平台资质、广告位 ID 与设备验收后才能启用真实变现。
- 当前是桌面 Chromium 的触屏模拟，未执行真机或原生小游戏平台验收。

分享 URL 还包含有界的好友目标（塔/弹珠成绩、救援人数与连救），复制链接也保留目标。主页与挑战结算明确标为“好友自报”，显示是否达成，不把 URL 数值当作服务器认证成绩。真实广告可在初始化配置中传入 `adMode: 'host'` 和统一渠道 `provider`；`publicUrl` 可由宿主指定公开独立入口。

额外发布专项见 [publishing-browser-report.json](publishing-browser-report.json)：真实触屏第三次转场显示模拟广告；后台取消保持结算；再次进入正常继续；好友目标达成不写入普通进度。该专项使用显式 dev 结算 fixture 验证 UI，真实操作通关仍由主浏览器套件覆盖。专项发现并修正了 pointerup 打开新浮层后兼容 click 误点关闭的问题，最后再次跑完塔全部 13 项触屏回归。
