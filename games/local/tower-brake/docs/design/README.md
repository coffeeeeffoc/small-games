# 《转塔留一脚刹车》界面设计

先生成 [三屏概念效果图](concept.png)，再实现主页、游玩与选关界面。原始生成提示词见 [concept-prompt.md](concept-prompt.md)。效果图是设计参考，实际运行截图由浏览器验收记录保存，二者不互相替代。

## 方向与视觉

本游戏采用竖屏：连续下落沿纵向展开，手机高度用于预览相邻楼层，底部拇指区域用于刹车，场景内横向滑动用于转塔。桌面和物理横屏仍保留完整的竖向游戏区域，调整尺寸不重置对局；没有必须旋转手机才能继续的阻塞界面。

深海蓝背景保持场景聚焦，青色厚圆环表示普通平台，橙红斜纹表示危险区，亮色球与轨迹突出垂直运动。危险区除颜色外还有纹理和落点文字。用 Canvas 绘制几何立体感，不依赖大型三维库或外部美术素材。主页、选关与游玩共用同一套圆环形态、字体层级和配色。

## 页面关系

- 主页突出“开始下落”和“选择路线”，帮助、外观与声音为次要入口。
- 选关页显示八条路线及真实解锁状态；返回主页有独立按钮，锁定路线不能从普通入口启动。
- 游玩页只保留路线、楼层、连穿、落点预告、刹车和暂停。整座塔可直接拖动，落点预告在底部单独展示，不依赖透过上层平台观察。
- 暂停使用独立页面，提供继续、重试、返回主页和全屏。恢复继续原对局，不消耗冻结期间的物理时间。
- 结算说明失败原因或通关结果，并提供重试、下一条路线、可用时的免费续关和返回主页。纯净成绩与续关成绩明确区分。
- 帮助集中呈现规则，设置集中呈现声音与免费外观，避免游戏画面常驻大段说明。

## 从概念到可玩界面的修正

概念图的“按住刹车”改为“点击使用”：用户要求一次主动触发、固定 0.8 秒的修正机会，松手不会提前结束刹车，持续按住也不会延长。按钮显示当前次数和冻结反馈，球冻结期间继续接受转塔输入。正常落地与使用刹车都清零连续穿层，连续穿三层补回一次，容量始终为一。

效果图中的星星属于概念占位。实际选关显示游戏真实进度与成绩，不添加没有规则来源的星级评价。失败后的续关明确标注免费，本地版本不伪装广告播放。暂停图标使用两根实心竖条，避免字体字符带来的形状偏差。

核心手感目标是“连续穿层 → 刹车补充 → 危险预告 → 点击冻结 → 滑动救回”。每次碰撞由规则层的角度区间判定，绘图读取相同布局；渲染可以插值，碰撞不能依赖屏幕像素。转向手势取消、切出窗口和暂停应停止输入，恢复时不补算后台时间。

## 验收方式

以实际运行的 390 × 844 及更小手机视口对照效果图，检查主页、选关、游玩、暂停、结算和返回路径。用原生触屏事件检查拖动与取消、刹车点击、锁定关卡、屏幕变化及全屏拒绝后的普通视口。桌面浏览器的触屏模拟不能称为真机验证；真实手机、WebView 与原生小游戏平台仍需分别验收。
