# 《转塔留一脚刹车》设计效果图提示词

生成一张精致的中文竖屏手机街机游戏设计效果图，包含三个并列的完整手机页面，从左到右：主页、核心游玩、选关。每个页面内部比例为 390 × 844，手机页面之间间隔整齐，无设备外壳，没有品牌标识，整体是用于指导实际开发的清晰高完成度游戏 UI 设计图，而非插画海报。

游戏名称《转塔留一脚刹车》。原创几何游戏模型与精品极简街机界面，不模仿任何已有游戏 UI。深午夜海军蓝背景（#071525），微妙径向照明。核心主视觉：冰青色简洁 3D 厚圆环塔、深蓝色圆柱中轴、发光象牙白小球、危险橙红扇区搭配清楚的深红斜线，刹车效果为电光青。厚圆环是有一块缺口的可旋转水平平台，主要为哑光冰青色顶面与偏深青色侧壁。近正交视角，从前上方看塔，几何清晰，无写实材质、无复杂背景、无花哨装饰。控件有足够空间，至少 44px 触控高度，大量可呼吸的场景留白，字体为清晰现代中文黑体。

左侧主页：顶部很小的品类标注“旋转 · 下落 · 刹车”。两行大标题“转塔”“留一脚刹车”，其中“刹车”用电光青。标题下极短副标题“转过危区，稳住每一次下落”。中央一座五层圆环塔，发光象牙白球在顶层平台上，少量轨迹光点，橙红危险扇区清楚可辨。底部大号电光青圆角主按钮“开始游戏”，下面深蓝描边次按钮“选择关卡”。页脚细小提示“滑动转塔 · 按住刹车”。

中间核心游玩：顶部左侧小字“第 03 关”，中间大号层数“03 / 12”，右侧一个简洁暂停图标按钮。顶部下方细线进度条。中央占据页面大部分空间，为近正交 3D 圆柱与五层带缺口的厚圆环；白球悬停于橙红斜线危险区上方，球周围有电光青刹车光圈、微细水平能量线，并用清晰数字标注“0.8s”。平台形态与球的位置足以让玩家理解“正在刹车”。下方留出独立的小型下一层落点预览：短标签“下一层落点”和小圆环俯视图，展示青色安全段、橙红斜线危险段、缺口与一个小白点。在页面下部放置大型 80px 高电光青圆角触控按钮，左侧简洁刹车符号，中心文案“按住刹车”，下方用短进度条表现剩余冷却/能量。最底部浅灰小字“左右滑动，旋转圆环”。核心场景要大且清楚。

右侧选关：顶部左边返回箭头按钮，标题“选择关卡”。小副标题“每一次下落，都留一点余地”。2 列 × 4 行共 8 个关卡卡片，卡片内部留白适量，大号码 01、02、03、04、05、06、07、08 与简单微型圆环关卡图标。01 已完成：三枚小青色星星；02 已完成：两枚小青色星星；03 当前：电光青高亮边框和小标签“继续”；04 到 08 深色锁定外观，清晰小锁图标。卡片旁保持整齐间距。底部小进度文案“已解锁 3 / 8”。

整体要求：三个页面视觉系统严格统一，所有重要中文准确清晰，UI 在真实手机尺寸下可读，明暗对比良好，控制区域符合拇指触控，场景几何光影优雅，现代高级、极简、爽快，非卡通贴纸风。输出高分辨率横向三屏并列设计图，不添加图外说明、设计注释、色板或尺寸线。
