# 穿云落星

转动轨道，穿云而下。一款用 Cocos Creator 3.8.8 制作的竖屏 3D 下落游戏：左右滑动青玉轨道，让星光球穿过缺口；踩到普通平台会反弹，碰到红色斜纹会失败。刹车可以定格球体 0.8 秒，连续穿过三层补回一次。

## 两种旅程

- **30 关航线**：每关 12 层、固定一种环境，短时间内集中展示天空与大一些的沿途物体。1–8 关星际空间，9–15 关稀薄大气，16–22 关中层大气，23–30 关表层大气。
- **无尽下落**：保留局部空间与云海，场景按真实下落距离缓慢移动。每段跨度 72 层，最后 24 层渐变；星际→稀薄→中层→表层→中层→稀薄→星际循环，始终通过相邻环境过渡，不显示完整地球。长期只缓存最多 36 层。

背景图负责远方天空；带厚度与倒角的轨道、球体、空间站、飞机、鸟、近远云层均由真实 Cocos 3D 网格渲染。不同距离的运动、透视、光照和逐渐加深的雾提供空间感。装饰不会参与碰撞，雷达始终说明下一落点。

| 出现位置 | 新机制 |
| --- | --- |
| 第 5 关 | 缺口中的护盾，抵挡一次危险撞击 |
| 第 9 关 | 往返自转的轨道与轻柔侧风；首个平台保持安全 |
| 第 13 关 | 加速环与刹车补给 |
| 第 17 关 | 缓降道具，持续 4 秒 |
| 第 19 关 | 远景薄雾；雷达不受影响 |
| 后期 | 组合机关、雨雪、近处云海 |

空间、稀薄、中层、表层对应球体大小 100% / 80% / 92% / 115%，基础速度 100% / 116% / 96% / 82%。无尽模式连续插值；碰撞与雷达都使用实际半径。HUD、提示和扩散光环说明变化，减少动态设置会收敛视觉动效。

## 操作与完整流程

触屏左右滑动、点刹车；鼠标拖动、方向键或 A/D 转塔，空格刹车，Esc 暂停。主页、分章选关、帮助、设置、暂停和结果均由 Cocos 绘制。按钮至少 44 个屏幕像素，横屏居中显示竖版舞台。

每局关卡挑战可免费续关一次；无尽不续关。外观全部免费，没有模拟广告或付费路径。设置包含声音、减少动态与三套外观。切到后台或窗口失焦会暂停，恢复后需主动继续。

沿用 Game ID、独立地址和存档键 tower-brake-v1；不清空旧解锁、最快成绩和无尽纪录。清理浏览器数据会丢失本机进度，存储被禁用时仍能游玩。好友挑战、开发试玩与续关成绩不计排行榜，好友挑战和开发试玩不解锁普通关卡。

## 开发与构建

在仓库根运行：

~~~sh
pnpm --filter @coffeeeeffoc/tower-brake typecheck
pnpm --filter @coffeeeeffoc/tower-brake test
pnpm --filter @coffeeeeffoc/tower-brake build
pnpm --filter @coffeeeeffoc/tower-brake dev
# http://127.0.0.1:4452/
pnpm --filter @coffeeeeffoc/tower-brake test:browser
~~~

构建需要 Creator 3.8.8，复用仓库的 carding-car/scripts/toolchain.mjs。也可提供 TOWER_BRAKE_PREBUILT_DIR，但必须通过引擎版本、源码和发布文件摘要校验，缺少引擎不会退回 Canvas。dev / preview 服务实际导出的 dist/，修改源码后重新构建。根 index.html 只是工程说明。

- engine.mjs / levels.mjs / progress.mjs 是唯一规则和存档源；准备脚本生成忽略的 assets/scripts/core，供 Creator 使用。
- assets/scripts/TowerBrake.ts 连接页面、输入、音频、固定 120Hz 模拟和存档。
- TowerWorld.ts / TowerUI.ts 分别渲染三维世界与 Cocos UI。
- startup/host.js 连接共享身份、排行、分享和 Web 无障碍按钮，不另建网络协议。
- 纯只读 __tower.snapshot() 支持验收。开发按钮只在公共 SmallGamesDev 启用时出现，试玩不写普通进度。
- 排名规则为 tower-ranked-v2，后端仍直接导入同一规则。部署时前后端要一起更新；服务缺失或版本不匹配只影响排行，本地正常可玩。
- COMPETITION_PUBLIC_API_URL 在构建时注入；页面 __COMPETITION_CONFIG__ 可覆盖。只允许无凭证、查询及片段的 HTTP(S) 基础 URL。

未使用 Hyper3D：本版所需形体可用小型程序网格完成，便于保持统一风格、体积和手机性能；空间站是可辨认的风格化结构。
