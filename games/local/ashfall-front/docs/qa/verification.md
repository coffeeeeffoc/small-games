## 手机流程

844×390 下从主页查看锁定关卡，开始行动；同时移动、跳跃、射击，取消手势后无残留输入。暂停后计时和生命保持不变。重新开始后自然战斗通过两次清场、选择散射和穿甲，击败两阶段 Boss：游戏时间 32.32 秒，剩余生命 42，三个战区均完成，`trial=false`。脚本只通过开发模式只读快照选择按键，不修改生命、伤害、敌人或结算。刷新后保留解锁与最佳成绩。

另验证自然受击失败、重新行动状态重置、390×844 整屏旋转后的方向映射、568×320 所有主要热区至少 44 CSS px、失焦自动暂停、全屏进入与退出。桌面 1440×900 验证键盘、鼠标瞄准和 Esc；长按 Esc 不反复切换状态。默认生产入口无开发面板，存储被禁用时仍可开始。

关键回归：上一房间仍按住的触点在升级页松开，不得自动选择卡片；新页面要求新的按下动作。增援出现提供短时保护，避免生成位置造成即时接触伤害。

## 验证边界

以上是桌面 Chromium 的触屏模拟，未在物理手机、Safari、微信/抖音原生小游戏宿主运行。模拟器没有实际刘海；旋转 safe-area 方向已按坐标变换处理，仍需带刘海设备确认。娱乐性、首次真人通关时长与重复游玩价值需要玩家试玩反馈，自动通关不能替代这些判断。
