## 视觉语言

冷黑背景 `#0B1513`，灰绿金属 `#2E3730`，结构高光 `#73765A`，奶白主文字 `#EEEADD`，次文字 `#A3AC98`，橙色主操作／火光 `#D89956`。危险敌弹使用 `#ED6E46`，并配合轨迹、危险标线和前摇形状。大场景低对比，玩家、枪火和可交互物对比高。

场景有远处烟囱轮廓、中层墙板与管道、可碰撞平台、前景钢梁四层。固定细节包括铆钉、通风栅、危险条纹、磨损划痕、点状灰烬与轻雾。金属多用硬边直角，角色用低分辨率块状轮廓与少量高光，避免光滑矢量吉祥物观感。阴影和雾化只影响氛围，不遮挡敌弹或角色轮廓。标题 48–50 逻辑 px，页面标题 21–26，卡片名称 19–20，行动按钮 15–18；描述 11–12，装饰英文 8–10。

## 布局与触控

UI 使用横屏参考视口 844×390，并按边角锚定与容器适配。世界为 2400×720，摄像机负责转换到可见战场；不能非等比拉伸角色，也不能按 UI 坐标处理物理碰撞。比例不同时使用等比场景缩放与适量视野裁切／扩展，保证地面和角色可见。

UI 基础边距左右26、上18、下20，结合环境 safe-area 向内移动。效果图中装饰标签允许更靠边；按钮热区和关键状态必须留在有效安全区。844 宽以下优先缩短装饰文案、缩小间隙，保持主要热区约44 CSS px；不能只缩小整张界面导致无法点击。主页角落声音／全屏图标可见框为44×36，实际热区补足44×44。帮助与返回按钮同样补足44×44。

移动、跳跃、冲刺、射击可多点同时操作，按下有亮边／缩放反馈。所有菜单按触屏直接点击，键盘焦点作为补充；不依赖 hover。升级和暂停接管输入并冻结世界，退出状态清空 pointer 集合。按压取消、失焦、旋转和退出时释放输入。

## 动态与实现建议

- 地图场景缓慢雾动和极少量灰烬，前后景轻微视差；主要动作节奏保持快速。
- 命中使用短闪与方向性火星，爆炸用圈扩散、碎片、暖光和最多6 px震屏。震动仅影响呈现层，HUD／输入映射保持稳定；降低动态设置可关闭震屏和削减粒子。
- 用单一 screen 状态协调 home / levels / playing / upgrade / paused / result；DOM HUD只在值改变时更新，Canvas呈现快照，核心循环不读取DOM。
- 建议动作接口 `moveLeft`、`moveRight`、`jumpPressed`、`dashPressed`、`fireHeld`；输入适配层将多点触控和键盘统一成每帧动作，不让UI直接修改角色。
- 关卡对象建议提供 `id/title/platforms/barrels/waves/exit/reward/unlockNext`；成长对象提供 `id/name/description/effect`。渲染读取同一份可展示配置，避免规则和文案不同步。

本设计依据仓库 AGENTS.md、ADR-0007 与本地 [game-ui-ux 技能](../../../../../.agents/skills/game-ui-ux/SKILL.md) 制定。交付实现后应另存实际截图与验证记录，并按产品验收标准逐页对照。

## 对照实现说明

效果图保留实施前的构图和数值示例；实际运行截图见 `../qa/`。最终实现将角色出生位置右移，避免左手控件遮挡；选关改为直接点击卡片；生命值收敛到 120，回收治疗收敛到每击杀 15。实际规则由关卡和升级配置驱动。
