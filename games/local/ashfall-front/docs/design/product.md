# 灰烬防线 · 产品方案

## 产品目标

一款手机横屏优先、可独立运行和嵌入 Shell 的 2D 横版射击 Game。让玩家在 1–2 分钟内感受到冲刺闪避、连射命中、环境爆炸和一次局内构筑的完整乐趣。采用原创灰绿工业战争场景、暖橙火光和奶白界面，借鉴题材与互动类型，不复制参考作品素材。

核心循环：进入房间 → 移动与跳跃接敌 → 射击或利用爆炸桶清场 → 三选一升级 → 推进下一房间 → 击败拆解者 → 结算与重玩。

## 页面与路径

- **主页**：左侧游戏名和“开始行动”主按钮，次入口“行动地图”，右侧工业场景和待命角色；角落提供帮助、声音和 H5 全屏。没有未实现的商店或成长入口。
- **行动地图**：三个关卡按进度从左至右呈现，显示已完成、可进入、未解锁状态。点击可用关卡开始；返回主页。普通玩家遵循存档解锁，开发跳关独立处理。
- **游玩**：全屏场景，顶部生命、房间目标和暂停。底部两侧拇指控件，战斗目标与角色尽量保持在中间可见区域。首房间用一条渐隐短提示介绍当前动作。
- **战利品升级**：清场后进入独立轻量选择状态，背景冻结并变暗，三张卡片直接点击选择，只有“选择一项继续”的必要说明。一次选择只结算一次。
- **暂停**：继续行动、重新开始、返回主页；声音和 H5 全屏放在此处。暂停冻结模拟、计时与音频，清空持续输入。
- **结算**：胜利显示任务完成和行动时间，失败显示倒下位置；主按钮为重新行动／再战一次，次按钮为返回地图。

## 手机横屏与控制

- 全部页面共用 **844×390** 的横屏 UI 逻辑视口；世界模拟采用 **2400×720**，摄像机与缩放负责映射，禁止把 UI 按钮放到世界坐标系。
- 基础安全区：左／右 26，顶 18，底 20。再叠加环境 safe-area；布局不依赖浏览器全屏成功。
- 左下两个独立方向控件，支持按住和多触点；右下射击最大，跳跃、冲刺为次按钮。所有热区至少 44×44，常规射击 78×78。
- 触屏：长按左右移动；跳跃支持按下触发；冲刺沿朝向；长按射击，自动瞄准面向方向内最近的可见敌人，缺少目标时水平射击。爆炸桶可被射击引爆。
- 桌面补充：A/D 或左右移动，空格跳跃，Shift 冲刺，J 或鼠标按住射击，Esc 暂停。鼠标瞄准可作为桌面增强，不能成为通关条件。
- 横屏物理方向与竖屏视口旋转兜底都须可玩，所有页面、弹层和触控映射采用同一变换；旋转及退出全屏不重置 Game Session。
- pointerup、pointercancel、失焦、暂停、页面切换立即释放输入；禁止页面滚动、长按选择文字或按钮触发浏览器手势。

## 关卡与成长

| 稳定 ID          | 房间        | 地形与敌人                                                                   | 成长与目标                                       |
| ---------------- | ----------- | ---------------------------------------------------------------------------- | ------------------------------------------------ |
| foundry-entry    | 01 运输车间 | 平地与一块低平台；巡逻射手、追击兵；两组连锁爆炸桶；两波射手、追击兵与无人机 | 引导移动和射击；清场后解锁下一房间，选择一次升级 |
| furnace-crossing | 02 熔炉走廊 | 两层平台；射手与追击兵分波出现；跨层爆炸范围                                 | 引导跳跃和冲刺；清场补给，进入核心机库           |
| dismantler-core  | 03 核心机库 | 宽敞场地与两块躲避平台；Boss 拆解者                                          | 冲撞／扇形射击交替；低血量加快节奏，击败通关     |

局内升级给出可感知的变化：**散射弹匣**（每次开火 3 发，单发伤害折减）、**穿甲弹芯**（子弹贯穿 1 名敌人）、**战地回收**（爆炸击杀回复生命，每次爆炸有上限）。第二次选项还可出现**高速供弹**与**轻量推进**，并排除已获得的改装。升级名称、描述与逻辑必须由同一配置驱动；重玩清空局内升级。

正常存档至少记录 schemaVersion、已解锁关卡、最佳完成时间和声音设置。保存完成房间后获得的进度，禁止死亡或重复点按额外领取奖励。行动地图从已解锁房间开始新的尝试，文案不得暗示精确恢复尚未保存的战斗瞬间。独立运行使用 Game Host 存储接口的本地实现，存储不可用时降级内存，不阻断游戏。

## 战斗手感与可读性

- 命中闪白约 60 ms，敌人受击有小幅击退；枪口短闪、弹壳与火星方向随射击方向变化；击杀有碎片和迅速淡出的冲击圈。
- 普通射击轻震屏，爆炸约 6 px；相机震动只影响世界，不改变 HUD、瞄准坐标与触控坐标。
- 跳跃提供约 100 ms 土狼时间与输入缓冲；冲刺约 150 ms、冷却约 0.8 秒，带残影和短暂无敌；受伤后约 0.7 秒无敌，轮廓闪烁表达状态。
- Boss 攻击前摇至少 0.5 秒，用地面危险线／亮起的核心显示范围；攻击后留出约 1 秒输出窗口。半血切第二阶段，不能仅增加血量。
- 敌弹用暖红，玩家子弹用奶白／金黄，爆炸桶有条纹与危险图标，危险状态不只靠颜色表达。
- 战斗画面不铺教程、数值列表、功能介绍；关键反馈“连锁爆破”“房间已清空”以短暂场景文字呈现。

## 实现边界与接口

- 核心模拟处理角色、碰撞、敌人、伤害、奖励和状态流转；不直接依赖 DOM 或平台 SDK。
- 关卡独立配置地图、平台、爆炸桶、波次、Boss、目标、奖励、解锁关系。新增同机制房间只新增配置和目录登记。
- 游戏拥有内容 schema 与校验：ID 唯一、引用有效、起点安全、出口可达、解锁图无环。遵循 ADR-0007。
- 运行环境适配层复用 Game Host、公共 SmallGamesDev 与 H5 全屏能力；当前交付 H5 独立与 Shell iframe，原生小游戏适配不在本次范围。
- UI 状态建议：home → levels / playing → upgrade / paused / result。renderer 读取快照，input 向模拟提交动作，不让绘制决定结算。

## 验收标准

1. 用手机尺寸触屏从主页完成三个房间、升级、Boss 和胜利；失败可重试，返回主页和选关路径清楚。
2. 五种升级配置可产生不同战斗效果；爆炸桶可伤害范围内敌人并产生连锁；Boss 有可避让的攻击预警。
3. 暂停和后台切回不继续受伤，按键／触点不粘连；重玩没有旧子弹、旧敌人或升级残留；奖励和解锁仅结算一次。
4. 844×390 横屏、390×844 竖屏旋转兜底、小屏及全屏退出均无控件截断；支持移动＋跳跃＋射击多点触控。
5. 选关正确显示锁定和解锁状态；刷新后进度与设置恢复，存储不可用时仍能开始。
6. 保存四张概念图，实际运行逐页截图对照，并记录独立、Shell、iframe 的实际支持入口验证。桌面模拟不能称为真机验证。
7. 相关规则与内容校验通过，执行仓库要求的 dev-mode 检查和生产浏览器验证，再按仓库流程提交与推送 dev。

## 实现后的数值收敛

玩家初始生命 120；清场回复 30，普通击杀回复 2。散射每发三颗 9 伤害弹丸，穿甲额外穿透一名敌人，回收每个爆炸击杀回复 15、单次爆炸上限 30。增援出现时提供 1.2 秒保护，避免在生成位置接触受伤。Boss 在明显预警后冲撞或发射弹幕，攻击后 1.15 秒暴露核心，半血增加弹幕段数。熟练自动操作约半分钟可通关，首次真人体验时长和娱乐性仍需要试玩反馈校准。
