# 灰烬防线 · 当前产品方案

移动横屏优先的Cocos Creator 3.8.8横版射击游戏。原3关后新增20关，共23关。保留灰绿工业场景、暖橙枪火、连锁油桶、五种战地改装及两阶段拆解者Boss。

进入战区后，移动/跳跃/冲刺接敌，长按射击或拖动瞄准。每关5–7处中继阵地；靠近中继且敌人没有侵入争夺范围时接通进度，持续增援迫使玩家战斗，离开或争夺时停止推进。全部阵地完成后抵达出口，完成当前关并保存解锁。指定关卡的Boss只在最后阵地出现。

23条显式路线各自配置地形间距、上下层平台、增援编组与驻守预算。单关目标约6–9分钟；纯输入抽样第1/3/23关约354.5/363.8/412.8秒，第一关略低于6分钟参考值。这是自动操作样本，真人时长仍需试玩校准。

首页提供继续、战区选择、从头战役、帮助和声音。选关四页，每页最多六关，正常进度依次解锁；开发跳关标记试玩。清场改装排除已拥有项目，五种均取得后免费继续，避免空选择页阻断战役。单关模式完成即结算；连续战役继续改装和下一关。

触屏左右移动、跳跃、冲刺、长按开火，多点可同时操作；开火拖动方向用于自由瞄准。保留键盘移动、I/J/K射击、Esc暂停与鼠标场景自由瞄准。采用等比逻辑视口、Creator竖持旋转、引擎安全区及至少44 CSS px触控目标，暂停/取消/失焦/后台清空输入。没有浏览器全屏控件。

正常开始、通关、重试和改装免费。可选暂停补给恢复40%生命、失败续战恢复50%，各每关一次；确认页说明完整观看收益并可返回。只有公共奖励端口严格completed后，当前run/关卡/request均有效才发奖；广告切后台保持等待，旧局迟到回调无效，辅助行动不计最佳时间。App998795当前未开通广告，发行默认关闭。

规则、关卡、存档和奖励保持纯模块；Creator原生Sprite/Graphics/Label、输入、AudioSource及生命周期负责运行。旧Canvas绘画仅为离线美术源，烘焙成PNG，发行包不运行旧DOM/Canvas入口。保留旧三关进度与声音设置，旧短战役最佳时间不迁入23关纪录。
