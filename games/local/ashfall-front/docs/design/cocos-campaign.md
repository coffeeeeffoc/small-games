# 灰烬防线 Cocos 战役扩展实施方案

**Goal:** 将 Canvas 游戏迁移到真实 Cocos Creator 3.8.8，保留射击手感和旧存档，新增20关成为23关的移动横屏战役。

**Architecture:** 复用 src/core.mjs、levels.mjs、progress.mjs 和 Host 存档格式；Creator TypeScript 组件负责场景、图形、输入、音频和生命周期。公共 H5 奖励端口管理 SDK，纯规则负责补给与续战资格、限次及发奖。

**Tech Stack:** Cocos Creator 3.8.8、TypeScript、现有 ESM 规则、Node test、Playwright。

## 产品与范围

- 保留原3个稳定关卡ID并在其后增加20关。战役按战区编组、分页选关、完成一关即保存，独立选关无须广告。
- 单关目标6–9分钟，采用多处推进阵地、敌人增援和出口目标组成有效操作时间，Boss只在该关前置战斗完成后出现；不能仅增加敌人生命或强制空等。实际时长以玩家操作而变，测试证明结构和节奏边界，真人耗时另验。
- 改装耗尽后提供免费继续，不能卡在空选择页；保留旧关卡进度/声音设置，旧三关最佳时间不能冒充23关纪录。
- 暂停补给恢复40%生命，每关一次；失败续战恢复50%生命，每关一次。进入确认页说明完整观看收益，可取消；严格completed、当前局/关/请求未过期且未重复才发奖。辅助局可解锁关卡，但不计普通最佳时间。
- 横屏参考844×390，兼容568×320及窄长手机；竖持提供可用横向适配，44px有效触控、安全区、多点移动/射击、拖动瞄准、输入取消、后台暂停。
- 复用灰绿工业废墟、像素式角色、橙色枪火及现有效果图，更新23关与补给概念图后实现；真实截图独立保存。
- 不新增联网、排行榜、插屏、Banner、强制观看或其他引擎。

## 实施顺序与文件

1. 设计与原型：现有 docs/design/ 记录差异、效果图及流程；核查原 README、入口和实际渲染。
2. 内容与规则：src/levels.mjs、core.mjs、progress.mjs；增补波次推进、23关解锁、完整战役/独立选关、无可选改装的继续行为及奖励纯规则。tests/\*.test.mjs 验证内容、可达性、胜负、时长边界、旧存档及奖励幂等。
3. Creator：assets/scripts、assets/scenes、settings、startup、scripts/prepare.mjs、build.mjs、artifact.mjs、typecheck.mjs、serve；真实节点/图形/精灵/音频，不在Canvas/WebView运行旧页面。源码与运行制品摘要严格校验，默认Cocos logo替换为游戏标志。
4. 接线：package.json、pnpm-lock.yaml、turbo.json、Creator验证/制品复用、H5构建与奖励配置、CI Producer/下载消费、Shell/Pages入口契约；仅添加本款真实消费者，不规避门禁。
5. 验收：规则、类型、真实Creator构建；手机横屏/小屏/竖持、首页/选关/游玩/暂停/改装/胜负/重试；模拟SDK四种结果、取消、前后台、重复与迟到回调；记录真实环境与局限。
6. 交付：补齐publishing/八类资料与STATUS.md；同步远端dev，保留hooks，提交本次改动并非强制推送；核对远端SHA及CI/Pages真实状态。

## 本体实施与阶段证据

23条显式路线定义5–7处据点、间距、上下层平台、不同增援编组与驻守预算；Boss只在指定关卡最后据点出现。中继附近且敌人未侵入接通半径时推进可见进度，持续增援，离开/受争夺则停止推进；全部据点完成后到出口结算。满改装免费继续，每关保存解锁；旧3关存档和声音设置保留，旧最佳不迁入23关纪录。

正式纯输入模拟抽样（seed 0x41a5f00d，60Hz，不改生命/敌人/朝向）：第1关354.5秒、132击破、剩120HP；第3关363.8秒、136击破、剩90HP；第23关412.8秒、172击破、剩96HP，均胜利。第一关约5分55秒略低于6–9分钟参考目标，记录实际差异；这些是自动策略证据，不等于新手/真人耗时。主会话另行全关诊断曾有第5/10关Boss失败，不能宣称所有策略必胜。

当前已完成真实Creator构建、共享CI接线、六尺寸触控和基础上架资料；准确证据见../qa/verification.md，真实平台上传与审核尚未执行。广告SDK由公共端口管理，隐藏只暂停，pagehide/重开/返回主页才取消请求，不设置成功展示后的墙钟超时。
