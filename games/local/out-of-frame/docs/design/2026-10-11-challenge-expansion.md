# 框外静止 · 本轮局部优化

目标平台：Web / H5，横屏优先，保留触屏。沿用原有材质与配色，只调整挑战入口、结果反馈和必要的触控布局。

核心到观察框边界的距离与运动/冻结状态同屏呈现；分享同关计时挑战，挑战成绩和中途局面不写入正常存档。

流程：首页 → 普通关卡或链接挑战 → 游玩 → 暂停 / 免费重试 → 结算 → 分享 / 回到首页。分享通过统一 H5 publishing 的系统分享或剪贴板，不宣称联网对战或已送达好友。链接参数严格验证且不传播 dev 参数。分享失败展示可复制链接。

挑战保持相同规则和免费提示；没有付费取胜。结算广告复用公共频控，前三次自然结算仅第三次可显示模拟广告，关闭不影响成绩或重试；真实能力由宿主配置注入。

验收：真实浏览器键鼠与触屏操作，检查分享再打开的关卡/规则一致、挑战不污染本地正常存档、重试/暂停/取消/返回，以及横竖屏布局。手机比例局部示意见 `challenge-layout.svg`；实际截图与验收记录另存。

最终对照：已按原风格实现局部状态/挑战入口与结算，手机横屏保持≥44px按钮热区，旋转兜底和物理横屏均可触摸通关。实际截图与报告见 [验证记录](../verification/2026-10-11-challenge-expansion/README.md)。
