# 持续军令与军衔匹配

2026-10-28。维护 `tianxia-chalu`（现名《夺城令》，原名《天下岔路》），沿用 Creator 3.8.8、水墨城池素材、100 关及旧存档。遵循[通用开发规范](../../../../../../docs/game-development.md)，本次不迁移引擎或增加原生渠道。

## 画面与操作依据

[手机效果图](reference.png)在实现前生成，四栏分别为首页、地图总览、城池细节和战绩。图中额外兵种、装饰勋章只是概念表现，不作为已实现功能；实际使用现有城池和规则。竖屏优先，保留横屏投影适配。首页增加军衔、经验和真人匹配入口，战场保持紧凑战力栏、返回及地图控件。

- 截图三条青蓝直线来自河流地形装饰，改为柔和弯曲河道，与道路和军令区分。
- 点己城再点邻城，或从己城拖至邻城，添加一条持续军令；已有其它路线保留。重复设置幂等。箭头中央浅色 X 取消对应路线，已出发部队继续原目的地。
- 鼠标悬停可操作城池及撤线点显示手型与高亮。手机双指缩放、桌面滚轮缩放，空白拖动平移；“地图／城池”与加减按钮支持无需精确手势的操作。第二指、手势取消和失焦不产生军令。
- 驻军与行军人数用逐名小兵表达，批量绘制并裁切视口，保留数字读数。总览与细节呈现同一真实战局，不切换模拟。
- 返回展示“投降并退出”的二次确认，对局继续。真人匹配不允许暂停；掉线重新查询权威状态。军情浏览不成为暂停手段。

## 战斗与公平性

旧每城每两秒最多八人的固定吞吐会把兵力优势压成相同波次。改为每城共享派兵时钟，按可用兵力扩大随机波次、缩短间隔，连续出兵进一步提速。多目标均分共享波次并轮转余数，不复制兵力。随机由对局种子驱动；保留原有 HP、兵器、将领与同步伤害机制。

优势兑现以相同部署、产兵、兵种和增益条件为验证前提，不能承诺兵力较多者无视战术必胜。规则回归覆盖不同种子的优势对攻、多目标守恒、撤线及捕获重置。

## 成长与匹配

军衔共 45 级：新卒、伍长、什长、百夫长、校尉、都尉、将军、统帅、传说，每档 1–5 级。第 L 级晋升需要 `100 + 30 × (L−1)` 经验。正常人机胜／败／平分别 20／8／12；真人匹配 100／35／50。投降或掉线计败而不给失败经验，开发试玩不产生正式经验。各模式分别记场次和胜率，结算 ID 防重复。

离线练兵档案保存在本机；联机军衔由服务持久匿名玩家档案维护，不上传客户端经验或胜率作为可信匹配依据。凭证按服务地址隔离。匹配只选择真实排队玩家，按等级及平滑胜率筛选并随等待扩大范围；无人时等待，不以机器人冒充。双人地图同起点条件、无装备卡、无 AI，席位归属、军令序号、结果视角彼此隔离。服务原子保存档案及结算收据，恢复时从权威战报补齐。

## 验收与构建

使用本地 `game-ui-ux`、`game-feel` 技能，反馈仅在呈现层，不改变权威时钟。此次规模较大，由主会话明确分配互不重叠的规则、渲染、客户端、服务文件范围；共享安装、构建与浏览器验证由主会话串行安排，复核只读。
