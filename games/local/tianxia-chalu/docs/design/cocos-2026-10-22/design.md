# 天下岔路：Cocos 百战山河设计

确认日期：2026-10-22。依据本聊天确认的 13 点与补充规则实施。本文是本轮产品、规则、视觉与验收的共同依据；旧版 README 的“三关、固定出生、强制留守八兵、无将领广告”不再是新版目标。

## 产品定位与完整循环

竖屏、单指为主的架空古代兵流策略。观察双向路网 → 选择城池行军方向或屯兵 → 争夺产能、关隘和点将台 → 利用局部增益与道路时差合流 → 排名结算、免费抽卡 → 可选广告保证升阶 → 下一关。保留纸本山河、深青漆器、朱红军旗与旧版原创山水素材；Cocos Creator 3.8.8 实际承载沙盘、军队、武器、特效及触屏交互。

画面以 390×844 手机为主，最小检查 320×568；横屏保持竖屏沙盘居中并适配安全区，不重置对局。这是离散节点单指策略，继续采用竖屏，无横屏旋转兜底需求。Web 在暂停/设置页提供一个公共全屏入口；原生宿主不显示浏览器全屏。

## 页面与触屏

主页：标题、纸本山河与城楼、继续征战主按钮，山河图/图鉴/军备次入口，帮助和设置。只显示已实现内容。

山河图：10 章切换，每章10关，编号、名称、完成星级、锁定原因；普通玩家按稳定目录解锁。开发选关独立于正常进度。

出征准备：地图预览、各方出生城、关卡重点、已装备局部卡；可重新布阵。开战前可选择路线；按开战统一开始产兵。重试保留原 seed，重新布阵生成新 seed。

战场：顶部关卡/计时/暂停与各方城数，中央沙盘，底部军情入口和选中城军令。所有道路默认显示为稳定无向线，活动军令额外标方向箭头。点己城选中；点相邻目标提交；在己城/箭头上拖到邻城可直接改道；已选己城的箭头可轮换出口，屯兵始终有明确按钮。预览只显示虚线和目标高亮，松手成功命中才提交；取消、第二触点、失焦不改变军令。所有主控件至少约44 CSS像素。

军情：打开时本地对局暂停；服务端模式需确认服务暂停后才能称已暂停。列出本场所有有效来源，按阵营标记；显示类型、范围、强度和剩余时间，点选回到战场定位并显示范围。普通战场不永久铺满光环。

暂停：继续、重试同布局、帮助、声音/音乐、全屏、返回主页。返回主页保留关卡进度；主动放弃不发卡。

结算：胜/负/和、完整排名、夺城与用时；免费卡已入库并显示具体效果；符合条件时显示“观看广告，替换为…”，完成后原卡升级且不可再次领取；下一关/重试/主页清晰。

图鉴：城池、将领、兵器三个页签；未发现显示轮廓和发现方式，发现后显示效果与应对办法。奖励卡/库存在军备页面管理，最多装备一张日卡和一张一次性战术卡。

## 道路、驻军与交战

每条普通道路只在配置中声明一次，运行时自动提供两个方向。地形阻断用山脉/河流表示，线条几何交叉不产生路口。每城2～4个邻接为主，少数重点城可更多。

各阵营初始城归属由seed决定，基础驻军0、保留数0，初始屯兵；奖励“援兵”仅在装备后作为明确例外。普通中立城驻军0、无主时不产兵。关隘的城防与武器独立于驻军显示。

行军军令按固定短间隔派出可用兵，不强留驻军；屯兵停止新派兵但仍生产、接收友军和防守。已经出城的部队保留目的地。新占领城默认屯兵，旧驻军、军令、点将进度不能被新主人继承利用。

城内容量有上限；生产满员暂停。援军超过城内容量进入可见城外驻扎队列，不凭空丢失。队列可被攻击，并优先按该城当前行军命令离开。城池失守时旧主驻扎兵不能无条件变成新主兵。

相同道路上的相向敌军在相遇处停下交战，胜方继续原方向。友军可通行；不在不同道路的几何交叉点战斗。战斗按固定逻辑步长进行，攻击力、攻击间隔、防御与生命真实参与伤害；动画、音效、帧率不影响结果。同一时刻伤害聚合后结算，避免数组遍历让一方先手。

攻城部队在城前交战。城防先承受攻城伤害，守军和武器参与防御；守军与城防清空后，仍有存活攻方才能占领。0兵城保留原归属直到敌军实际进入。普通兵采用统一基础属性，将领有独立属性与带兵光环。

## 城池、道路与武器

| 对象 | 初始设计值/行为 | 取舍 |
| --- | --- | --- |
| 普通城 | 基础产能，容量60 | 稳定补给 |
| 兵营城 | 约1.35倍产能 | 抢产能但城防普通 |
| 关隘 | 较高独立城防，产能较低 | 正面慢、可绕行 |
| 点将台 | 连续占领积累点将进度 | 需要保护到进度完成 |
| 驿道 | 约1.35倍行军速度 | 快速增援/突袭 |
| 山路 | 约0.7倍行军速度 | 必须预先调兵 |
| 弓弩 | 高频低伤，集中单一来兵队 | 防小股连续进攻 |
| 投石器 | 慢速区域伤害 | 对密集集结有用 |
| 火炮 | 长冷却、高伤 | 利用冷却窗口进攻 |

数字是首轮可测试起点，不宣称已平衡。武器有自身冷却、范围和可辨认弹道；占领后有整备时间才为新主人工作。火炮不同时拥有最优攻速、伤害和范围。

## 将领与局部增益

点将台在持续占领且未被围攻时积累进度，围攻暂停，易主清空。每座点将台至多一名在场将领，每方至多两名；达到上限不积攒瞬间连发。将领随军或驻守，不需要技能按钮；战败退场，重新招募有冷却。

初版至少提供猛将、统帅、守将、疾行、弩将、军医六种不同定位。每名将领有攻击、攻速、防御、生命，突出一个自身特长和一个局部影响。光环以实时逻辑地图距离判定，对符合阵营/对象类型的邻近单位生效。将领死亡、离圈或城池失守后立即失去持续加成；已经生产的兵不倒扣。

同种增益取最大值，不累乘；不同种增益组合有明确上限。日卡的“当日”是期限，不表示全地图作用；日卡和一次性卡绑定出生城等具体来源。开始对局时固定本局已装备效果，跨午夜不突然改变正在进行的对局。

特殊地图对每个阵营配置相近预算的基础局部效果。玩家装备卡时若地图原本没有基础效果，也为每方生成基础来源；玩家的高阶卡可带来有限优势，AI不随玩家升级卡实时等量变强。难度改变AI反应与选择，不秘密修改基础战斗值。

## 100地图与随机开局

10章：初识军令、补给合流、驿路疾行、沃野争粮、雄关险隘、兵器争锋、将星入阵、四方逐鹿、奇策纵横、百战归一。每章10个稳定ID地图；原三关ID保留用于旧存档迁移，后续稳定新ID。关卡文件描述城池、道路、出生组合、阵营、特色机制、目标、时限、解锁和资源引用；核心不按关卡ID特判。

每张图有独立名称、路网/坐标、战略目标与不同布置。生成辅助工具只产出经校验的显式配置，100图不可只靠旋转、换色、随机seed充数。检查归一化路网/坐标签名、可达性、出生城数量、无单向遗漏、阵营完整性和至少一条扩张路径。

出生仅从配置允许的合法组合选择，阵营在候选出生点间轮换。出生点的类型、产能与武器预算保持公平；特殊战略城通常中立。教学图只使用教学可达的组合。随机发生在创建新布阵时；同seed和同指令得到相同结果。

## 教学、图鉴与成长

前四关引导改道夺城、屯兵积累、后方合流、查看军情，按真实动作推进；第五关独立实践。每步短句、场内高亮，支持跳过和重看。武器、将领在首次相关章节做单次提示。教程完成、图鉴发现和掌握、卡库存、章节进度保存；存储不可用明确标记仅本次会话。

普通玩家逐关解锁，开发模式通过公共SmallGamesDev，可任意试玩但不解锁、不发卡、不消耗正式库存。继续兼容旧存档已完成的三关；新规则版本不读取旧对局快照冒充新版对局。

## 排名、抽卡与广告

消灭条件：无城池、无驻扎/交战/在途普通兵，也无仍可行动将领。失去最后城池但仍有远征兵时继续。最后存活阵营获胜；时限结束按存活优先、城池数、普通兵总数比较；已淘汰者按淘汰时间晚者在前，相同条件并列。普通关180秒，复杂关可240秒，按配置控制。

卡等级：普通、精良、稀有、史诗。按相对名次划分：领先档30/40/25/5，中间档45/35/17/3，末位档65/25/9/1（百分比）；两方第二是末位，四方第二是中间。并列共享档位。完整结束的非开发正式对局每局免费一张，主动退出不发；按对局ID幂等结算，不靠重新打开结果页重复抽取。

卡类型至少覆盖援兵、产兵、攻击、攻速、防御、生命、行军、将领、武器和城池特性。来源限定一城/一支部队/局部区域，不直接赠送额外出生城。日卡和一次性卡在军备页可查期限、作用与装备位置；一次性卡在正式开战时消耗，准备/取消不消耗。

日卡按北京时间午夜到期，正式开战再次核验；准备跨午夜时保留 seed 和预设军令，移除失效卡后重建开局。开始后本局效果冻结。重试不返还已消耗的一次性卡。城防倍率作用于实际可承受伤害，刷新不自动修复城墙；军队拆分、出城和增援按兵数比例迁移已有伤势，不能通过换队清除伤势。

广告最多升阶一次，只替换本局免费卡为同用途高一级卡，观看前展示替换结果。已最高级、开发试玩、无真实广告能力时不显示可兑现的升阶承诺。completed确认才替换；dismissed/unavailable/failed保留原卡；重复回调不重复奖励。保存本局奖励事实后再交互，不让刷新成为免费重抽。使用现有GameHost/公共激励广告能力，浏览器测试provider仅在测试中注入；不把模拟观看作为实际渠道广告验收。

## 音频与反馈

改道、屯兵、恢复出兵、攻城、己城失守、将领出场、阵营覆灭、胜负均有独立短音；行军与交战按部队群产生低音量持续声音，武器有射击/命中区分。重要事件压低环境层，限制同时发声数与频率，避免每兵独立声源。音乐/氛围与事件音效分别设置，静音保留视觉事件；用户手势后开始音频，后台/暂停停止，恢复不补播过期战报，退出释放资源。

## 实现边界与复用

纯核心与内容继续通过包 ./engine、./levels 导出；共享序列化fixed-step、seed、指令、快照，服务端复用同一版。Cocos管理场景、触屏与实际渲染；Web页面负责现有Shell/iframe/公共dev与fullscreen桥接、可访问菜单与宿主能力。游戏规则不直接访问DOM或SDK。服务端指令补充屯兵/预设路线并保留ownership、类型、范围、频控校验；本地与服务端模式展示真实状态，不伪造多人匹配。
