# 青花拾光

2026-10-25，已根据用户确认的设计开始实施。

## 产品与画面

移动端竖屏优先（390×844 基准），因为瓶身、碎片工作台和纵向长廊均适合纵向观察；桌面保持居中竖屏舞台。采用 Cocos 3.8.8 真实引擎的 2.5D Sprite/Graphics 场景，程序动画呈现宝宝与摔碎，实际拼图为固定视角二维碎片。无 Creator 编辑器时使用仓库可验证来源的官方引擎源码 Web 构建，不伪称 Creator 导出或原生平台验收。

主色为米白、青花蓝、浅青，暖金作为完成反馈；主页展示完整青花瓶和宝宝，主入口“开始闯关”，次入口“器物长廊”“好友闯关”。玩家文案使用“关卡挑战”“挑战这一关”“邀请好友闯关”，不用“同题挑战”。主要页面：主页、曲折长廊、拼图、暂停、限时结束、完成、收藏、好友房。

## 规则

- 100款原创程序化器物：10种轮廓搭配10组材质/纹样，覆盖青花、彩瓷、玻璃、镜面等。每款拥有稳定ID、名称、轮廓、配色、纹样；游戏内可完整观看与收藏，不把未生成内容当成现有美术。
- 100个主线关卡，按章节采用有种子的无放回抽取；同一关、重试和分享使用同一器物、切法与初始布局，后期增大片数，同时保持可触控面积。配置与规则核分离。
- 碎片按轮廓内采样生成不规则 Voronoi 分区，避免微小空片；正确相邻的碎片/整组在容差内吸附成为整体，允许任意位置拼组。音效、微震、金色连接闪光仅影响表现。
- 每关限时，开场演出结束才开始计时。单人暂停/切后台隐藏拼图并冻结计时；继续恢复原局。超时冻结输入、保留组状态，提供“看广告·再添时光”“重新挑战”“返回长廊”。每次挑战最多续时一次，时长由配置决定；取消、失败、无广告位、重复或跨局回调都不发奖。
- 单人提示有免费额度，额外提示预留激励广告；竞速采用统一免费额度，不在比赛内播放广告。
- 宝宝开场拿起、下摔、笑；游玩期间从安全边缘随机出现多种表情动作，有冷却和去重；完成后抱器物点头并跑向下一关，玩家可返回或继续。
- 正常存档保存解锁、收藏、最佳成绩、设置和未完成局；开发者操作不污染正常解锁或成绩。使用仓库统一 SmallGamesDev 入口。

## 好友与平台

2～5人各自拼相同配置，统一倒计时和每轮限时；完成者等待本轮其他活跃玩家完成、超时或跳过，再统一进入下一关。主动离开移出等待列表，断线设重连宽限，房主转移，剩一人可继续，中途加入下一轮参与。服务端确认操作、进度与结果。分享分成果、关卡挑战、房间邀请，链接不携带开发参数。

优先复用现有 Game Host、广告、存档与服务能力。广告未配置时不得假播放或假发奖；在线服务不可用时明确提示，单人玩法仍可用。正式商业广告、跨设备公网及原生 SDK 验收需真实配置。

## 验收

规则测试覆盖100款/100关、确定性、切割及邻接、整组合并、限时边界、续时幂等与迟到回调、重试/恢复、解锁、好友退出/超时/换房主/下一轮。手机触屏浏览器验证主页、长廊、拖拽吸附、取消手势、暂停、超时、重试、完成、收藏、分享与房间；保存实际截图并与先行效果图对照。构建验证真实 Cocos 来源，执行适用的仓库配置/开发者模式检查，再按准确候选流程提交推送 dev。
