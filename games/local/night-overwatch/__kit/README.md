# 夜航守望 · 历史原型需求包

本目录记录初建 M0/M1 阶段的产品、素材和执行需求，保留用于追溯。现有游戏已超出该阶段；灰盒停点、占位素材和不做多人等历史约束不再适用于维护。全部历史性能、关卡和数值为当时建议起点，不是当前状态或真机验证结论。

## 文件

- GAME_REQUIREMENTS.md：产品定位、玩法、任务、输入、帮助面板、素材规范、跨平台路径和验收。
- CODEX_TASK.md：历史开发提示词，不再直接交给代理执行。
- ASSET_MANIFEST.example.json：素材台账样例，没有随包提供任何第三方模型、音效或字体。
- SOURCES.md：公开参考资料与事实边界。

## 使用

维护当前游戏时，使用 [游戏 README](../README.md)、[设计索引](../docs/design/README.md) 和仓库通用规范。

可直接发送：

> 请先阅读游戏 README、docs/design/README.md 与本次相关规范，核对当前源码、有效设计和已有验收。按当前视觉与交互约定维护真实可玩版本；区分功能验证与按效果图的视觉验收，保留存档、联机协议及触屏取消行为。不要重新执行历史 M0/M1 灰盒任务，也不要虚构构建、真机或渠道结果。

用户提供的参考操作截图可以一同附给代理，但只要求学习“操作说明可随时查看”的信息组织方式，不复制其 UI、素材和文案。
