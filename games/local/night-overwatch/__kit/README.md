# 夜航守望 · Codex 开发需求包

这是产品/素材/执行需求，不是成品游戏代码。全部性能、关卡和数值为建议起点，未声称已经真机验证。

## 文件

- GAME_REQUIREMENTS.md：产品定位、玩法、任务、输入、帮助面板、素材规范、跨平台路径和验收。
- CODEX_TASK.md：可直接交给 Codex + Astra 的开发提示词，含首轮与三轮后续任务。
- ASSET_MANIFEST.example.json：素材台账样例，没有随包提供任何第三方模型、音效或字体。
- SOURCES.md：公开参考资料与事实边界。

## 使用

将这些文件放入项目根目录的需求文件夹，在 Codex 中附加/引用 CODEX_TASK.md 与 GAME_REQUIREMENTS.md。对已有项目先让代理检查，不要直接覆盖。新项目按提示词确认本地 Creator 环境。

可直接发送：

> 请先阅读 CODEX_TASK.md 和 GAME_REQUIREMENTS.md，按其中要求检查当前工程，然后实施 M0 与 M1。先得到一关键鼠和触控都能玩的灰盒，再停下来给我试玩验收。缺失的模型用程序化占位素材；不要虚构构建、真机测试和平台兼容结果。

用户提供的参考操作截图可以一同附给代理，但只要求学习“操作说明可随时查看”的信息组织方式，不复制其 UI、素材和文案。
