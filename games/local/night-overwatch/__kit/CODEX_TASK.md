# 夜航守望：当前项目开发与视觉改版提示词

2026-10-28 更新。本文替代早期“只做 M0/M1、完成灰盒后停下”的执行方式，可直接用于当前项目的继续开发。先读取根 `AGENTS.md`、[通用开发规范](../../../../docs/game-development.md)、[游戏 README](../README.md)、[当前设计入口](../docs/design/README.md)与验收记录，以及本轮用户要求，再实施；不要只输出方案。

## 当前任务与参考优先级

1. 检查当前入口、源码、构建、资源、存档和未提交修改，保留无关工作。以本轮用户要求和认可效果图确定范围；已有联机、成长、关卡及操作契约不得被早期单人首版方案覆盖。
2. [GAME_REQUIREMENTS.md](GAME_REQUIREMENTS.md) 保留早期玩法研究与参数来源，历史关卡数、输入表和技术阶段不是当前功能上限。核对现有实现，避免重新从第一关起步。
3. 用户要求新样式时，至少完整实现本次涉及页面、场景及状态的对应样式；可以重做素材、控件和呈现层，不能以保留旧画风、旧 HUD 或旧低模为理由只改框架。
4. 《Spectre Command》的公开资料只用于理解玩法类型和操作信息，不复制其代码、商标、素材或任务文案。这个来源边界不削弱用户认可的本项目原创效果图的视觉要求。

## 实施顺序

### M0：核对当前工程与本次视觉目标

- 确认当前 Creator 版本、真实构建入口与平台工具；已有可运行工程直接增量修改，不无理由重建或维护两套完整渲染器。
- 固定本次认可图及对应页面、状态、手机比例。已有认可图直接使用，缺页补图，不另画更简单的图替换目标。
- 提取构图、主辅色与明暗、字体和字重、间距、图标、插画、模型轮廓、材质、光影及交互反馈，列出所需资产与现有差距。
- 新资源先验证单件导入和渲染，再批量生产。临时几何只能用于内部坐标、拾取或管线验证，不能作为最终场景或 UI。

### M1：本次范围的完整玩法与视觉实现

- 按本次设计实现相关首页、任务选择、游玩、暂停、结算及其他页面；场景、角色和按钮同步达到认可图要求，不能只做精美首页或保留旧战场。
- 保留真实武器冷却、弹药、弹着、友伤、车队和胜负规则；样式修改不得暗改伤害、模拟时序、网络状态或存档。
- 准星、弹道、目标标记与真实世界坐标对应；热像实体具有实际热特征，不能以整屏滤镜冒充完成。
- 保留触屏完整可玩、独立多指、UI 不穿透及手势取消。键鼠、缩放、传感器、车队控制与帮助读取现有动作绑定，不照搬早期输入表覆盖已认可操作。
- 帮助、设置、后台、广告等暂停原因相互独立；关闭一个界面不恢复仍应暂停的模拟。动态数据、快捷键与说明由真实状态产生。

### M2：逐页视觉对照与实际操作

- 按[完整视觉验收](../../../../docs/game-development.md#新样式要求与完整视觉验收)，同尺寸并排查看认可图和当前真实构建截图，逐页核对构图、配色、字体、间距、图标、插画、材质、光影和状态反馈。
- 保存差异清单，修正后重新取图；只保留色系、按钮数量或大致布局不算达到效果图。构建、功能测试、热区检查和截图生成不替代视觉验收。
- 用实际触屏走通首页、选关、游玩、暂停恢复、胜负结算和返回；覆盖本次相关的小横屏、安全区、多指取消、前后台及缩放映射。
- 根据改动选择规则、类型和真实构建检查。视觉与功能分别报告，不为文档或样式变更重复无关后端/全关卡检查。

### M3：资产、反馈与性能收尾

- 补齐所有影响目标画面的资产与细节，不只替换少量重点资源。图像、模型、字体、声音记录来源、授权、商用条件与必要署名；来源不明的资产不用。
- 按当前工具与授权使用原创制作或合法现有素材。确需未授权收费服务时说明具体阻塞，继续其他可完成部分；不能把未购买或工具缺失变成默认交付占位素材的理由。
- 枪声、爆炸、烟尘、残骸、按钮与告警的表现相互一致。降低动态选项保留必要信息，视觉震屏和停顿不改变权威模拟。
- 性能按目标设备实测。优先图集、合批、实例化、按需加载和资源回收；需要改变视觉方案时记录证据、影响及认可的调整，不默默删除材质和细节。

### M4：当前目标平台与交付

- 使用真实 Creator/平台工具构建；缺工具时记录缺项及复测步骤，不能伪造产物、截图、帧率或设备结论。
- 仅对本次实际支持的平台验证 SDK、资源、输入、音频、存储和生命周期；未支持接口明确失败或不支持，广告只依据有效完成回调幂等发奖。
- 更新当前设计、差异清单、实际截图和上架资料状态。区分概念图、桌面触屏模拟、真实引擎构建、平台工具与手机真机证据。
- 依用户本轮授权完成提交／推送，遵循仓库增量发布规则；不要沿用旧提示词自动停在灰盒或强制等待“下一轮”。若用户明确只要阶段交付，标明尚未完成的视觉与功能，不称完整验收。
