# 昵称输入与战况入口修复（2026-10-28）

基线 `55088354a6e65ae75a05b8368f6cba670b1304b2`。本次沿用[战术仪表设计](design/2026-10-28-tactical-ui.md)，只调整对战记录、公共表单输入与战况入口；不修改战斗、联网协议、存档格式或奖励。

## 修复与范围

- 对战记录不显示设置，也隐藏对应的浏览器无障碍按钮；首页与战斗仍可进入设置。
- 旧版在844×390视口缩到844×260时销毁正在编辑的输入框，焦点从 `INPUT` 落到 `BODY`。现在编辑期间延迟尺寸／输入方式引起的重建，同一表单的异步刷新也等待编辑结束；切换页面仍正常关闭输入。
- Cocos 默认多行模式在绑定文字标签时将其设为顶对齐。先绑定完整标签、再设单行并恢复垂直居中，避免重复自动标签；左右内缩10px。昵称、房号和密码共用同一修复。
- 战况入口放在小地图下方，右边缘对齐，间隔6px；88×44热区、圆角细边与 `#101a1e88` 底色（约53%不透明度）。查看战况仍继续战斗。
- 原生暂存器的 HUD 源码摘要同步更新，校验规则保持。
