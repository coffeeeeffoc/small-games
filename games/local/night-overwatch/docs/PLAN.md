# 第二轮：火控体验与撤离地图

目标：在 Cocos 3.8.8 护送规则上改善可读性、地形、机载感和火力反馈。

1. Actions/HUD/Platform：完整中文操作提示；敌我文字与形状；友方红字、独立友伤警报；常驻全屏与退出反馈。
2. Data/Simulation/Overwatch：230×144 区域、16 节点山路和桥梁、三个区段与有限伏击；128 秒行车、185 秒撤离窗口；统一边界与弹道快照。
3. World：程序化山地、河流、桥梁、村落、农田、林地、营地；车轮、车窗、炮塔模型；热成像与 glTF 导入保留。
4. Effects/HUD：传感器边框、飞行轨迹、航向与小图；三档弹道、冲击波、火球、烟尘；即时发射反馈与弹着倒计时。
5. 验证：核心规则/类型检查 → 两个 Web 目标串行构建 → 三种视口、全屏、敌我识别、帮助、触控、成功失败与重试；更新真实证据。

参考：2026-09-28 实际查看 Spectre Command 官方页面与训练画面，借鉴机载火控与弹着反馈的表达。地图、模型、UI、数值独立制作。

完成：上述五项均已落地；同一最终源码的实际验证结果见 STATUS.md / verification.json。实体手机与小游戏宿主保留为下一轮验收。
