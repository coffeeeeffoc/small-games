# 夜航守望：沉浸 HUD 与成像验收

2026-11-03。设计先于实现，见[方案、内置 imagegen 效果图及完整提示词](design/immersion-2026-11-03/README.md)。本次只改呈现、输入与偏好，不修改 MissionCatalog、Simulation、服务端规则或回放版本。

## 当前实现

- 主设置增加“语音提示”“优先标注”，默认开启并保存。总静音仍优先；关闭语音立即停止播放并解除撤离语音等待，武器/引擎音不受此开关影响。字幕、敌我识别、友伤警告保留。
- 关闭优先标注会移除附加优先框、小地图优先圈和相应点击热区；由于既有普通优先录音明确指向红框，该提示在关闭标注时改为通用文字，危急语音仍保留。未重录音频。
- 默认夜景，支持增强和热像；纯材质切换，不重建场景。倍率、镜头中心、观察角度、准星和模拟不变；设置中可预览，后台/失焦/方向暂停仍禁止操作。观战可切换成像。
- 左上“战术”紧接单行友军/撤离/威胁，战术中查看战况与双方装配并可返回。武器热区44px高，可见底板34px；开火热区68px、细环58px。透明空白不再整条拦截瞄准；禁用控件仍消费点击以防穿透。原生胶囊预留及安全区保留。

## 验证依据

最终 Creator 3.8.8 web-mobile 源码摘要：`02b287e3ecc7b37c08e123b2e28e7c04906db67295087ceb433ec3d6e2be02f5`，构建总量59,205,493字节。浏览器均先以 `acceptanceBuild()` 核对当前源码、指定摘要与 HTTP 制品。

- `input-mode`、`hud-interactions`、`extraction`、`priority` 共92项通过，覆盖偏好重载、关闭语音后实际推进到撤离成功、普通音效独立、优先框/热区隐藏、系统暂停、观战和三尺寸技能布局。
- 原生源码与宿主边界8项通过。标题遮挡收尾后HUD/宿主44项通过；最终仅将有底板的两个顶栏按钮改为白字后，原生宿主1项再次通过。保留 canonical SHA 校验，没有绕过未知源码检查。
- 类型检查通过。`tests/immersion-browser.mjs` 检查568×320、844×390触屏和1280×720桌面：开关重载、三视图暂停预览、真实相机/模拟不变、战术与装配导航、触控取消、中英文。证据见[运行回执](design/immersion-2026-11-03/runtime/evidence.json)。
- `tests/immersion-equipment-browser.mjs` 使用明确隔离的资产fixture检查无人机/追踪、激光/EMP以及本地机器人战况/装配。这些QA画面与普通玩家正式素材分开。
- 旧 `loadout-browser.mjs` 本轮尝试停在准备页 `Cannot scroll to equip:emp-match`，尚未到达本次战斗界面；不列为通过，也不扩展修改军需页。专项直接从已保存的有效fixture方案进入训练与本地机器人，覆盖本次受影响控件。
