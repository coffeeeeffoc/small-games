# 作战基地、军需与关卡

封面点击进入基地。单人和双人分别记住上次选择，最多三项，也可以空槽出击。先确认配置，再选任务或进入大厅。单人使用实际拥有的档位；双人只准选择自己拥有的永久装备，两边的同款都按标准档计算。

| 商品 | 标准 | 单人精调 |
| --- | --- | --- |
| 增压装药 | 初始拥有，威力 +8% | 900 金币，威力 +16% |
| 高速弹芯 | 初始拥有，飞行速度 +12% | 600 金币，飞行速度 +22% |
| 长燃配方 | 初始拥有，燃烧 28 秒（基础 25 秒） | 600 金币，燃烧 31 秒 |
| 扩散喷口 | 300 金币，燃烧面积 +25% | 750 金币，面积 +44% |
| 电磁脉冲 | 1,200 金币；两发，命中敌车停驶 2.5 秒，冷却 18 秒 | 无 |
| 应急冷却剂 | 80 金币一份；仅限单人，占一个槽，实际成功清热才扣除 | 无 |

正式单人任务首通 300 金币，同一关再次通关 80。热身、试玩和失败不发金币。签到每天 60；完整看完可选激励广告，每天可抽一次 40 / 80 / 160 金币，概率 60% / 30% / 10%，按北京时间换日。双人结算只记对战积分，不能在商店消费。联网金币与库存由服务器按身份结算，相同请求重试不重复扣款或发奖。
