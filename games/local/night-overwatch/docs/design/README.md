# 飞行作战设计基准

[三面效果图](flight-concepts.png)由内置 imagegen 生成，展示飞行作战、任务暂停、旋转观察。用户已确认并要求严格按图实现。它是设计图，实际运行截图存放在 reports/flight-overhaul/。

生成提示词要求：NIGHT OVERWATCH 中文机载炮手护送游戏的三面设计板，深石墨/青绿界面；大幅主图为黄昏斜俯视连绵低山、弯路、村落、田地、树林，多处敌方菱形与四组友方方框；左上机载炮口发射长轨迹，顶部高度/斜距/弹着时间，右上全屏和暂停，左侧顺逆盘旋/高度/轨道控制，底部三武器和开火。第二面为同场景压暗后的暂停卡片，圆暂停图标、标题、摘要、青绿继续按钮及声音/效果/帮助/全屏。第三面为另一旋转角度的同一战场，稳定轻车文字与提前量轨迹。低模 Cocos 可实现风格，无浏览器外框或水印。

实际实现使用实时 Cocos 三维场景、Blender 原创可编辑模型及真实输入；不会将此图贴在画布上冒充游戏。
