# 在线玩家、好友、私信与约战

本次按用户要求补齐全局社交与战后留房，只准备服务端上线材料，不部署服务端。

沿用夜景、金色主操作与蓝色次操作。首页人数为44px入口，大厅左侧在房间/在线/好友间切换。在线玩家按ID每页50人，可翻页查看全部；好友包含离线成员，绿/橙/灰状态点分别表示可约战、游戏中、离线。在线口径为5秒心跳、20秒失联过期，按认证身份去重，仅返回公开昵称和玩家ID。

好友申请须对方接受，支持取消、拒绝及删除；删除关系不会删除双方历史。单人最多200个好友、50个待处理发出申请，接收申请上限100，并限制申请频率。全局名单只列在线玩家，已建立会话和好友均可离线留言。

私信复用文字校验、3秒限频、请求幂等、举报与本地屏蔽，独立存入018私信表，读取/举报/已读操作必须属于双方。服务端持久保留历史，每次打开最近50条，可加载更早消息；公共消息仍为最近24小时、100条。全局每5秒更新会话摘要/未读数，收到消息显示通知，无论首页、仓库或战斗均可回复进入独立会话面板；关闭后回到原页面。战斗不会因聊天暂停，输入操作与权威模拟隔离。后台页面停止轮询，重新进入恢复未读。当前版本屏蔽是本机通知和显示过滤，不是跨设备服务端黑名单。

定向邀请复用公开等待房和邀请卡，未建房时自动建房；服务器拒绝离线或游戏中的目标，客户端同步禁用按钮。双方仍须准备，公开房仍可能被其他玩家加入；私密房保留房号/密码流程。房间满员、开始、过期、规则不兼容或房号复用时卡片不可加入。发送/建房期间固定收件人，失败重试保留请求编号，私信不会降级为公开消息。

真人结算默认保留房间，可主动退出或再战准备。再战内部创建新局以保留旧战绩，原双方各自进入并再次准备，预留席位避免被随机匹配抢占；退出释放对应席位。重复旧局退出不影响已重新进入的新局。已过期再战房须退出后重新建房。

更新日志放在客户端 UpdateLog.ts，追加稳定ID条目，设置中可滚动查看随本包保存的全部历史，离线可读。重大条目首次进入首页突出提示，查看或关闭后本机记住已读。当前从本次改动建立首条记录，不伪造过去发版；版本运营公告仍由既有服务端功能承担，与客户端更新日志分开。

兼容策略：新客户端连接旧服务仍可显示人数，未支持的列表/社交明确不可用；运行中回滚重新协商能力。私信独立表避免旧Runtime读取公共频道时泄露。准备脚本及迁移顺序见 [待上线说明](../../../../../../docs/operations/night-server-preparation.md)。

浏览器结果与构建身份见 [验收回执](../../../reports/2026-11-12-social/evidence.json)。截图为QA，正式上架媒体保留原采集身份；本地验证不代表实体手机、TapTap宿主或生产部署通过。永久历史随数据量增长需要继续观测查询/存储成本，当前未做长期容量压测。
