## 界面目标

- 首页：保留主要行动，增加带图标及文字的「在线玩家」「好友」直接入口；「大厅」只打开公共交流。右上角使用红点与短文字提示新版本，不弹中央通知。
- 在线/好友：首页窗口宽约 420，锚定对应顶栏按钮下方并延伸至底部安全区；其他入口按内容收缩。单行 52px，左侧状态点、昵称和编号，右侧三个 44px 热区的 18px 图标。正常在线不再重复文字，游戏中/离线保留必要说明。好友管理在列表处理。
- 私信：宽约 400、高不超过 330，右侧小会话窗；标题、消息气泡、输入和发送，关闭回到原页面。历史消息按需加载，失败可重试。无移除、邀请或刷新工具栏。
- 大厅：公共交流独立页；对战入口仍为房间/在线/好友与公共交流双栏。两个入口都没有私信列表与私信标签。
- 表单/设置：复用窗口外壳，支持尺寸、位置、标题、关闭操作及按钮文案；深蓝圆角面板、细描边、轻阴影，标题与内容区留白，次按钮低强调、主按钮暖金。输入错误留在原窗。
- 火控热身：点击直接开始；明确它是三类靶标的入门练习（切枪、提前量、避免友伤），不扩写权威关卡/奖励规则。

首版目标图：[在线玩家小窗](players-target.svg)、[私信小窗](conversation-target.svg)，844×390，背景仅示意。后续用户补充了首页、聊天、战斗结果与准备室截图；以末节最终跟进和实际截图为准，不宣称首版示意图已获用户确认。
