# 二级页面顶部安全区修复

2026-11-06。基线 `dcc5d0ed24e1c2558e584d92f82ae8812e6afd85`，针对 Redmi K90 / TapTap H5 顶部工具栏下移反馈。

## 修改与边界

`ProgressionView.header()` 以前从 `safe.top` 绘制整条背景，因此非零安全区上方会露出独立的游戏背景空带。背景现在从屏幕顶部绘制至原下边缘 `safe.top + headerHeight`，与首页处理一致；所有使用此 header 的军需二级页面共用修复。

返回键、文字、金币、胶囊避让、主体内容与触控坐标保持原值。`safe.top=0` 时新旧绘制参数相同。本次修复背景覆盖，不把安全区清零、不按 Redmi 型号设置负偏移，也未确认 K90 的 CSS / SDK 安全区上报是否过大。

- 读取真实 Cocos Graphics 几何，确认背景上缘为 0、下缘保持 `safe.top + max(52, height*0.1) - 6`；返回键 Y 坐标保持 `safe.top+3`，Canvas 位置与尺寸不变。每个场景通过实际触屏点击返回首页；同尺寸安全区变化重新布局，页面异常 0。
