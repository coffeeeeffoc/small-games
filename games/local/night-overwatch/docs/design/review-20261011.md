# 夜航守望 · 120 任务与多角色复查方案

保持现有 Cocos 3.8.8 运行层、横屏/竖屏旋转和战场操控。参考已认可的 `mobile-concept-20261009.png`，局部更新任务选择与通关操作，不增加战斗 HUD 信息。

- 玩家：3 个任务重复游玩后缺乏推进目标。保留前三个任务与 ID，扩展至 120 个正式护送任务；另外保留 60 秒热身。
- 关卡策划：以两种地形、静态/机动目标、分批伏击、部署微调组合 10 章，每章 12 任务。控制每场 24 敌上限与既有弹药；逐步调整警戒间隔与时间余量。每个任务用同一模拟器验证有弹药、无友伤通关。
- 移动 UI：沿用三张大卡片，每页 3 任务。标题同行右侧显示关卡范围、上一页/下一页；全部热区至少 44 逻辑像素。显示编号、通过/待解锁状态，锁定关卡有明确文字，点击不误切关。返回/热身/出发维持底部三按钮。
- 成长与存档：新增独立 v1 正式任务进度，前三个旧任务继续开放。通关解锁紧接下一任务；结算提供下一任务、重试和主页。旧任务偏好 ID 和补给库存不改变。非法、损坏、超大存档回退；存储拒绝时当前会话照常推进。
- 稳定性：普通 URL shortcut 遵守解锁；显式开发模式可试玩任意任务，但不得推进正式进度。任务 URL 同步保留 `dev=0/1` 等其他有效参数，不改变统一开关语义。

验收：120 配置唯一/不可变/范围与时限合法；逐关正常弹药模拟通关；存档损坏/重复结算/旧 ID/开关隔离；568×320、844×390、390×844 手机浏览器触控走通任务分页、训练、暂停、设置、帮助、全屏与取消。生产运行验收必须基于真实 Creator 源码匹配构建，旧制品只能记录基线，不用于证明本次改动。
