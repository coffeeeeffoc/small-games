# 战术仪表界面统一（2026-10-28）

用户指出旧结算、按钮色块缺少游戏感，本轮统一首页、任务卡、设置/手册、联机大厅/榜单/历史/昵称表单、补给/退出/广告和战斗按钮。参考[效果图](2026-10-28-tactical-ui-concept.png)，仅用于视觉层次与材质方向，示例武器和装饰不新增玩法。

使用现有 Cocos Graphics 统一切角面板：炭灰半透明底、石墨色分层、细倒角和低饱和青绿状态边，黄铜色只用于主要操作/结果，不再铺大面积亮黄。保留 44px 热区、原有动画、减弱动态和触屏/键鼠逻辑。结算缩至640×324上限，用时和积分分列仪表卡，底部返回按钮收窄居中。

只改 HUD 绘制与对应原生源码指纹，战斗/网络/存档/结算规则保持本轮已验收契约。验证限于 HUD 布局、类型、真实 Creator 构建与568/844/1280横屏界面操作；不重复后端或全关卡测试。
