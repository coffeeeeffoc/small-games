# 追踪弹与高倍镜头

目标：每次广告完成获得一发追踪弹；广告升级倍率上限。Web 当前使用可立即关闭的模拟广告，不要求等待或真实播放。

沿用横屏夜航火控界面。新增追踪弹入口放在车队指令旁，小屏紧凑排列；倍率入口在其下一行，打开后显示缩小、放大与广告升级。已有主页、任务选择与三种普通武器保持原流程。广告仅使用一层暂停覆盖卡片，关闭领取后回到原界面。参考图为 `rewarded-homing-concept.png`，由内置 imagegen 基于当前 844×390 运行截图生成（两幅横屏手机状态：追踪锁定和模拟广告）。

追踪弹从机身炮位发射，每个固定模拟步追踪发射时锁定的存活敌人，绘制实际轨迹和跟随目标的四角锁定框。仅命中锁定对象，伤害 240；友军、空地、保护区或暂停状态不能发射且不扣弹。目标提前死亡或进入保护区时终止制导，不更换目标。普通炮弹继续原来的重力弹道。库存保存，重试和换关不补发。

镜头默认 0.65–5×；每次广告解锁下一档 10、20、40、80、160×。所有滚轮、按键、双指缩放和临时放大共用已解锁上限；真实视场角随倍率缩小。解锁持久保存，损坏或禁用存储时降级到内存玩法。

广告边界沿用 RewardOpportunity/RewardOutcome 语义：completed 才发奖，dismissed/unavailable/failed 不发奖。Platform 预留 SDK provider，Web 无 provider 时返回 mock 并显示模拟广告；原生无 provider 时显示不可用。请求防重入，关闭只领取一次，广告期间清除触摸和按住开火、停止音频并冻结模拟。

验收：规则测试验证移动目标命中、追踪逐帧变化、暂停和无目标不扣弹、目标失效、存档校验；生产构建浏览器用真实鼠标和触屏走通主页/选关/广告/锁定/命中/倍率升级/暂停/重试/返回，覆盖 844×390 和 568×320，保存截图。核对源码 hash，执行准确 SHA 的增量发布校验，正常推送 dev，区分远端 SHA 和 CI/部署结果。真机和广告 SDK 验收另记未完成。
