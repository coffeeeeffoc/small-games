# 实时在线人数 · 2026-11-07

首页签到区上方及对战大厅右上显示“当前在线 N 人”。沿用现有皮肤、字号和安全区，加深色底保证复杂夜景中的文字对比；不新增操作入口。

## 统计口径与实现

- 统计最近20秒内成功上报心跳的认证玩家，包含首页、单人、对战和观战；同一玩家多个页面、会话或设备只计1人。不同游客身份仍是不同玩家。
- 前台每5秒调用一次；后台停止，恢复前台立即刷新。关闭、断网或后台后最迟约25秒在其他客户端反映。请求失败立即清空旧值；旧服务未声明能力时显示“在线人数暂不可用”，不请求不存在的接口。
- PostgreSQL `night_presence` 以玩家ID为主键，服务器决定时间并返回总数，不返回在线玩家列表。实例共用同一库；现有5秒房间清理任务每次最多清理500条过期心跳。人数变更只更新显示，不改规则、计时、奖励或存档。
- 采用心跳方式；仅统计房间席位会遗漏首页和单人玩家，另建WebSocket连接则扩大现有HTTP架构。现有服务桥负责认证、身份切换及8秒请求超时，游戏控制器负责前后台及销毁边界。
- 旧客户端没有心跳，不会纳入这项人数；跨环境不汇总，测试环境与生产环境各自统计。
