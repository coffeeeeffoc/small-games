# 房间大厅与作战体验（2026-10-28）

本轮按用户16项要求扩展现有 Creator 游戏和 Game Runtime Service，不迁移引擎、不复制渠道后端。视觉参考为[本轮效果图](2026-10-28-lobby-concept.png)，由内置 imagegen 生成，作为界面构图、配色、字体、材质、装饰细节及连续火带表现的完整视觉依据；图中示例昵称、房间与积分由真实数据替换，不削弱视觉还原要求。

本页认可图继续用于首页入口、大厅和场景色调对照；统一分工见 [视觉与交互规范](interface.md)，以下行为与边界继续维护。

## 行为与边界

- 首页左上显示昵称并可编辑，主入口为单人模式、对战大厅、排行榜及飞行手册；设置使用常规齿轮。
- 大厅展示公开等候房和进行中的对局，支持创建、房号加入、随机匹配、人机与观战。随机匹配无真人时创建等候房，不自动转人机。私房使用房号和密码，密码不出现在列表或分享链接。服务端串行抢位，只有一人能取得最后席位。
- 双方就绪后播放短入场过程，不显示数字倒计时。单人和双人改用已用时间，不再以比赛限时判负；支援剩余时间、武器装填和敌人攻击预告保持真实含义。
- 网络暂断或主动离开显示红色“昵称 已下线”，30 秒内原成员可重连接续；超时才由较弱机器人接管。真人开局局在超时后同时幂等记录退出者负（40分）与留下者胜（120分），继续机器人不重复得分；双方都离开时各记一负、0分。实际入场前退出不记战绩。
- 新增对战记录入口：只展示本人真人开局对局的概览（胜/负/平/场次/真实胜率）和逐场结果、对手、时间、原因及本局积分；稳定游标分页。初始人机与关卡不进真人战绩。
- 通关榜按不同关卡数；关卡榜按各关最短验证用时；积分榜累计成功通关（含重复）、真人胜负和人机结果；胜率榜展示胜场/场次。所有公开分数由服务端验算及幂等结算，离线练习不伪造公开成绩。
- 常规浏览器入口仍无全屏；用户本次授权的带参数分享入口提供进入/退出全屏按钮，宿主不支持时保持普通视口可玩。该例外不扩展到其他游戏。
- 结算保留最后战场，播放完成语音和短动画，展示结算面板及关闭按钮，由玩家关闭后回首页/大厅。声音与减弱动态偏好继续生效。
- 燃烧区以连续起伏火带替代密集独立火苗，只调整呈现；运动平滑只影响呈现，不修改权威伤害、弹药或胜负。

## 实现范围与必要验证

游戏涉及 Online、Overwatch、HUD、Effects、Platform、Duel/Simulation/Replay、音频素材和相应规则/界面测试。共享服务涉及身份昵称、房间协议/匹配、验证结算、排行榜、SDK/桥接和数据库迁移；既有房间与其他游戏保持原协议兼容。构建消费者为夜航实际 Web 制品、共享服务及直接协议调用者。

只运行这次变更的必要检查：房间并发/密码/权限/旁观、掉线接管、幂等积分和榜单、机器人节奏、无倒计时、画面平滑、昵称和窄屏流程、全屏参数与退出、真实 Creator 构建、生产部署健康和相关接口冒烟。不重复全关卡、全游戏或大范围浏览器回归。提交与部署保留准确 base/head、源码和制品身份，不把模拟测试当成真机或生产验证。

## 初始卡顿证据

在真实 Online.pump 路径上，以60帧/秒驱动两秒、无网络延迟的固定模拟，120帧仅产生10次战场更新（5Hz，更新间隔200ms）。因此即使网络正常，原画面仍按快照阶梯跳动；修复需用可重复的平滑采样测试以及实际浏览器画面确认。设备端额外渲染瓶颈另以采样证据判断。
