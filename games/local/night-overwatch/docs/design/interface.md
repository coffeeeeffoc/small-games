# 夜航守望 · 视觉与交互维护规范

更新：2026-10-28。适用于现有 Cocos Creator 3.8.8 游戏的完整界面。共通要求只引用[小游戏规范](../../../../../docs/game-development.md)；玩法、联机协议与存档以当前实现及[大厅契约](2026-10-28-lobby.md)为准。

## 视觉基准及实际素材

当前视觉以用户最新要求及认可效果图为准，逐页采用 [独立首页](2026-10-25-dedicated-home-concept.png)、[大厅](2026-10-28-lobby-concept.png)、[战术结算](2026-10-28-tactical-ui-concept.png)；[整合效果图](interface-concept.png)补充设置与控件主次、材质参考，不能仅因文档日期较新就覆盖已认可的页面目标。深海军蓝仪表面板、细钢色边线、黄铜主操作、清晰图标与字号层次是需要落实的设计，不只是配色建议。皮肤使用实际九宫格 Sprite；分隔线、功能图标和动态战斗标记使用 Graphics。实现技术服务于视觉结果，不限制必须程序画矩形，也不要求重写战斗引擎。

运行资产为 `assets/resources/ui/panel.png`（面板）、`button.png`（主操作）和 `insignia.png`（结算／品牌徽章），均由内置 imagegen 生成；首页继续使用现有 `home.png`。另有透明银钢字标 `title-metal.png`、两组三联任务插画 `mission-atlas.png` / `mission-day-atlas.png` 和 `terrain-surface.effect` 地形材质。人数、昵称、分数和控件文案/状态由引擎实时绘制，不烘焙进图片；静态品牌字标独立使用透明 Sprite。生成图中的等级、在线人数、4/8人房和装饰性地图缩略图是概念示例，游戏不实现这些新功能；大厅只展示真实双人房数据，场景缩略图仅为装饰。

素材生成约束：面板为正交正面的满幅深海军蓝拉丝金属、细钢色边线、角部细节限制在外沿，中央安静可拉伸；按钮为满幅横向深黄铜皮肤、细暖金高光、空白中心，无文字图标；徽章为透明底对称羽翼罗盘，暖金材质，无现实部队标识和文字。上述运行素材均须实际加载；降级绘制仅保障资源失败时可操作，不算视觉验收通过。

## 控件与页面

- 主操作使用有材质的黄铜皮肤，同一区域只突出当前最重要动作；次操作用轻边框，返回、分页、刷新等用图标／文字入口。热区至少约44逻辑像素，可见底板内缩；不得为了填满一行把分页箭头放大成主操作。
- 首页保留夜航背景、游戏标题与简短文案，单人模式为主，其余入口为次；宽屏四入口横排，小屏两行。昵称与战绩位于顶栏，不遮挡主标题。
- 设置按分隔行展示声音、语言、特效及导航，声音有明确开关状态；窄横屏使用分栏行而非堆满等重按钮。飞行和倍率沿用实时预览、即时生效与原暂停语义，数值边界明确不可用。
- 大厅上部显示真实房间列表，下部分开房间操作与工具栏；空列表给出具体下一步，不显示假房间。分页不可用时不响应。请求处理中阻止重复提交，保留返回和退出。
- 结算保留最后战场，徽章、标题、用时与积分形成层次；数据使用有细节的分栏仪表，保留金属边线和内凹层次。玩家关闭后再返回，不自动消失。关卡结果仍显示原有评价、失败原因、纪录及下一任务。
- 任务、手册、补给和确认页复用材质与主次规则；战斗 HUD 只保留必要信息，武器选中和热量必须可辨，不用材质遮挡目标或增加权威模拟负担。

## 交互不变量

鼠标悬停与鼠标／触屏按下立即反馈；按住后移出原按钮即取消，松开不穿透战场。触控取消、失焦和页面切换清理反馈及输入；视觉反馈不缩放点击坐标、不改变战斗计时。减少动态继续关闭过渡动画，静音设置继续生效。输入框聚焦期间不因数据刷新或软键盘缩屏重建。

普通入口无浏览器全屏；只有既有分享参数例外，详见大厅契约。对战菜单不暂停服务器，关卡设置保持暂停，战况查看继续战斗。任何视觉调整不得改变这些语义。

## 验收与维护

功能验收覆盖568×320、844×390、1280×720，另查安全区、中英文、鼠标拖出、触屏取消、表单焦点、帮助滚动、分页边界、暂停恢复、结算返回；测试隔离外部服务，不能用真实账号制造成绩。

视觉验收必须打开同尺寸运行截图，与当前效果图逐项比较：主次操作、留白与密度、字号、材质真实加载、图标与边线、可见尺寸和热区、按下及不可用状态。构建／测试通过与截图保存只证明其对应事项；任何仍像占位控件的页面继续修正后复看。素材和证据身份记入现有 [STATUS](../../publishing/STATUS.md)，保持正式上架素材与本轮运行画面一致。
