# 夜航守望界面改造

2026-10-23 先使用内置 imagegen 生成四屏概念图，2026-10-24 实现与实机对照。概念图不作为实机截图。

[概念图](2026-10-24-tactical-ui-concept.png)：海军蓝指挥台、琥珀主操作、青色友军、红色威胁；首页任务简报、昼夜任务卡、紧急目标、紧凑暂停和补给卡。生成提示要求横屏手机、中文、无全屏按钮，保留场景可见面积。

实现保留现有 Cocos 飞机、车辆、地形模型；没有把概念中的额外直升机模型当成已交付资源。首页与选关共享实际任务目录，补给卡复用现有三种奖励。所有输入仍通过原控制器执行。

前三关为白天固定炮位，敌数 4/6/8，默认爆破炮；第4、5关黄昏，12/16敌；第6关引入夜间，后续昼夜交替。原120个任务ID及存档解锁保留。光学昼夜与热成像独立。

紧急提示依据实际地面攻击目标、射程、冷却与出生保护时间，最多显示一个优先目标；红框、小地图圈和可点击定位提示同步。语音为 Windows 系统本地合成的中英文电台音频，不依赖浏览器语音服务；暂停、后台、静音停止，恢复不补播过期队列。源文字见 Platform.RADIO，重建见 scripts/generate-radio.ps1。

触控拖动从稳定准星投影计算屏幕位移；抬手只释放手势，不把准星放到手指位置。追踪弹保留短点选锁定，按起点累计位移区分点击与慢拖。

实际截图、录屏与验证记录见 [交付状态](../../publishing/STATUS.md)。

## 2026-10-24 精简战斗 HUD

用户截图反馈：顶部仅保留友军、撤离、威胁、环境和时间数值，取消整条底色、阴影和进度线。战场只保留设置齿轮、必要射击控件、小地图与可点击的优先标记。飞行、车队、倍率、补给、声音、特效、帮助、语言收入同一暂停设置面板；飞行和倍率在面板内展开。静音复用既有偏好，喇叭波纹/划线随状态切换。

广告中断/失败信息仅放在支援卡片与底部操作之间，移除重复的底部提示条；成功奖励仍使用现有三秒准备和战场安全区提示。不使用或留到下次立即继续，不做倒计时。返回基地先确认“将会中断本次游戏并退出”，取消继续原局，确认才清理。

短点战场设置准星，累计位移或仅抬手产生的大位移不视为点击，拖动仍保持最后有效位置。优先红框与其说明使用同一个至少44像素热区，点击镜头与准星一起定位。

[四状态效果图](2026-10-24-compact-hud-concept.png)由内置 imagegen 根据用户两张截图生成，仅作为设计参考。提示：保留低模山谷与海军蓝/青色/琥珀风格，四屏分别为无底色精简HUD、集中设置、无遮挡支援反馈和返回基地确认；无全屏入口、不增加玩法。图中“游戏倍率”实际实现为视野缩放倍率，不改变游戏速度。

影响范围：HUD布局/绘制/点击区域、Overwatch控制器及其真实调用者、既有输入/HUD单测和浏览器流程、操作文案与上架媒体。复用Platform静音、Simulation暂停与既有广告端口，不改存档键、奖励发放条件或渠道配置。允许仅设置/手动暂停时调整飞行和车队命令，回放规则版本升至v5；后台/失焦/广告暂停仍禁止。验证覆盖小屏、安全区、后台恢复、单点/拖动/取消/双指与广告四种结果。

追加山地表面细节：保留权威地形高度，以地表顶点颜色混合裸土、草地和坡面砂石，再用两批静态网格添加低矮草簇与碎石。按坡度和斑块分布，避开道路、河道、建筑和田地；不增加碰撞、不改变弹道或单位寻路，热像使用低亮度冷色。批次数和16位顶点预算在真实构建中检查，新版截图以最终地表为准。
