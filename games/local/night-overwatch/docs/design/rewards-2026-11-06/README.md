## 资产与兼容边界

- 复用v3钱包库存的fragment:weapon / fragment:skill；严格craft命令只接受现有配方，扣材料与发装备同事务，requestId幂等。不得允许出售负数、非法目标或重复永久合成。
- 首通按服务器准确关卡历史判断，覆盖旧版通关归并与历史best，且在写入本次成绩前判断；沿用账本锁保证同关并发只有一次。不得以客户端进度、最高关序号替代逐关历史。
- 新字段可选，旧客户端和旧回执保持可读；新客户端连旧服务时不得展示可执行但服务端不支持的合成。奖励规则与客户端说明须配套发布，不只上传前端。
- 已有金币、经验、库存、永久资格与存档不删除。广告流程与弹道/伤害规则不变。
