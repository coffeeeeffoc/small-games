# 首页与背景加载优化 · 2026-11-03

本轮仅调整前端加载体验，按用户要求完成后推送 dev。沿用当前首页插画、金属字标及 [startup 原设计](design/startup.md)，保留玩法、存档与服务端协议。

## 行为与范围

- 首页背景、标题、按钮皮肤、首页图集及字体全部就绪，HUD 绑定背景并完成后续绘制，才撤下启动画面。失败保持大图与可键盘操作的重新连接按钮，加载期间阻断隐藏首页的键盘操作。
- 现有 1920×1080 加载图以 WebP 数据内嵌 HTML，覆盖整个视口，不再等待一次独立图片请求。首页图片未到时不会先露出按钮与黑底。
- 首页就绪后以两路后台请求预载其他页面实际使用的背景、插画与结算素材，复用同一份纹理，不预载当前未使用的旧图集。
- 快速打开尚未就绪的页面时保留已加载的大背景，显示标题与加载提示；所需图片齐备后自动显示内容。失败可原页重试或返回。结算、选关、配装待确认请求各自保留返回语义，无关插画不阻塞昵称或排行榜。
- 图片回调避开正在编辑的输入框，实例销毁后不再创建素材。实际 Creator 编译对 Set/Map 展开存在兼容差异，新增集合读取与重试使用 `Array.from`；浏览器中已验证真实重试成功。
- `night-native-project.mjs` 只同步 HUD 的精确规范化摘要，保留拒绝未知源码的门禁；未修改原生功能或构建渠道包。
