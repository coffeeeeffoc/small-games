## 本轮交互覆盖

- 不再有单独展开按钮；同一个按钮名称与可访问标签随状态切换，同一个 F 键执行两种操作。
- 从远离纸边的空白处向内滑动可折叠；已折叠时，任意水平向外滑动可展开。第二关验证左向右，第十关验证从另一侧直接选择允许的反向折痕。
- 竖滑、方向不合法、短滑、Esc 取消不增加折叠次数。操作期间冻结角色；角色在折入平台上时展开被明确拒绝。
- 手势阈值按 CSS 像素计算，不随画布比例变化；空白区域判断排除角色、平台与触发器。
- 触摸预览被系统取消后保留原世界和计数；移动／跳跃按钮不触发折纸。
- 所有 16 个关卡名称、三层提示、按钮、菜单、状态与错误信息均已中文化。
- 新的文字长度检查验证中文内容存在，不再要求英文长度；提示仍须与正式操作序列吻合，并且不能改变游戏状态。

## 核心逻辑覆盖

点与矩形正确反射、连续两次反射复原、矩形宽高与边界、移动侧选择、跨折痕平台拆分、不可拆触发器和越界配置拒绝；不可变原图与每次重建世界。

落地／静止／固定侧／安全带检查，目标平台或尖刺压住玩家时整次拒绝；旧位置碰撞删除、新平台真实可站立；重叠平台并集碰撞；展开恢复几何但不传送角色；钥匙 ID 保留与重开复位；50 次无坐标漂移。

墙壁不产生落地与无限跳，天花板碰撞，跳跃缓冲、土狼时间、实测关键缺口不可跳过；真实坠落与尖刺死亡、快速重试；固定步长追帧上限、超长帧丢弃、失焦／暂停与输入清理。

存档损坏或不可用时安全退化，最少折叠成绩不回退，旧十关存档迁移；取消／拒绝不推进提示，漏拿钥匙或改用其他操作序列给出恢复提示；浏览器逐步比较未完成角色的落地高度。

## 本轮发现并修复

1. Phaser 3.90 的 touchcancel 处理无条件 preventDefault，真实触摸取消会产生控制台错误。使用 touch.capture=false，由现有 canvas 的 touch-action:none 阻止浏览器滚动；完整触摸回归后控制台为零错误。
2. 第十关参考控制器可能在跳跃途中触门完成，而浏览器先落地再走入门；测试只在两边都未完成时比较落地高度，仍检查最终真实完成、钥匙和折叠次数。
3. 纸边中文文字原先覆盖第十五关高处钥匙，移到纸面上缘后截图确认不再遮挡。
4. 最后一项纯文案修正：无钥匙的阶段不再要求拿钥匙。完整浏览器路线回归后重新运行 40 项测试与生产构建，并在内置浏览器检查第七关二级提示。

完整路线回归产物为 index-DbREsNVE.js；最终纯文案修正后产物为 **index-DICfApMh.js**（1,530.28 kB，gzip 355.51 kB），CSS 为 index-BeAsyJux.css。Vite 大于 500 kB 分包提示主要来自 Phaser，不影响构建通过。
