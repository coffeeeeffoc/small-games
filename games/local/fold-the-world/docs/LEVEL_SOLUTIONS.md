# 100关参考解与正式输入路线

100关产品经过多agent设计、独立评审与R1–R4修订后才实现。每关保留一条可重复执行的参考解，另有19条替代/补漏路线；这些不是最短解或唯一解证明。自动输入用时不包含玩家观察与思考，不能当作首见通关时间。

A/B/C对应折痕一/二/三；←右侧向左、→左侧向右。走/跳后数字是测试中的角色左缘目标坐标，只控制输入，不传送角色。完整关内中文提示按阶段描述空间关系。
