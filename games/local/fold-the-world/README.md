# 折叠世界（Fold the World）

原创纸面平台解谜原型：16 个手工关卡、两个竖直折叠方向、同时最多一次有效折叠。前十关学习规则，后六关组合三道折痕、三把钥匙和多次往返。名称为工作名，未作权利检索声明。

## 启动、测试与构建

在 small-games 仓库内使用 Node 24.12.0、pnpm 8.14.1，由根目录 pnpm-lock.yaml 统一锁定依赖。游戏源码来自 prototypes/games2，原型目录保留；后续开发以本目录为准。

从仓库根目录运行：

```sh
pnpm install --frozen-lockfile
pnpm --filter @coffeeeeffoc/fold-the-world dev --port 4314
pnpm --filter @coffeeeeffoc/fold-the-world test
pnpm --filter @coffeeeeffoc/fold-the-world build
pnpm check:games
```

大厅入口为 `#/games/fold-the-world`，独立页面为 `games/fold-the-world/index.html`。游戏已接入 Shell 的 workspace 依赖、构建复制、Pages 就绪检查和真实操作回归。H5 使用现有 iframe 交付；未新增原生小游戏适配。以下命令在本游戏目录执行：

```sh
pnpm install --frozen-lockfile
pnpm dev --port 4312
pnpm typecheck
pnpm test
pnpm build
pnpm preview --port 4313
```

开发地址 http://localhost:4312/ ，生产预览 http://localhost:4313/ 。dist 可直接静态部署，无需后端、账号、密钥或在线素材。

另开终端执行浏览器验收（默认使用已安装的 Chrome）：

```powershell
$env:GAME_URL = 'http://localhost:4313/'
pnpm test:browser
```

BROWSER_CHANNEL=msedge 可改用已安装的 Edge。自动化操作真实按键和触摸，运行需要几分钟；结果及截图写入 test-results/。

## 操作

| 动作 | 电脑 | 手机横屏 |
| --- | --- | --- |
| 左右移动 | A/D 或方向键 | 左下角左右按钮 |
| 跳跃 | 空格 | 右下角跳跃，可同时按住移动 |
| 折叠／展开 | **同一个 F 键或同一个按钮** | 中间按钮随当前状态切换名称 |
| 纸面折叠 | 在允许移动侧的空白纸面向内拖动 | 在同一区域向内滑动 |
| 纸面展开 | 已折叠时，在空白处向任一侧边缘拖动 | 向任一侧边缘滑动 |
| 切换折痕 | 1/2/3，或 C 循环 | 点折痕一／二／三 |
| 提示 | H，再按逐步揭示 | 提示 → 再提示一点 |
| 重来 | R | ↻ |
| 暂停／取消预览 | Esc | 暂停；短滑或滑回起点取消 |
| 操作说明 | ? 按钮或 / | ? 按钮 |
| 选关／音效／全屏 | 暂停菜单 | 暂停菜单 |

手势根据起始侧和水平滑动方向选择合法折法，优先采用已选折痕；从另一侧滑动时可切换到该方向允许的折痕。不会创建新折痕。平台、角色、钥匙、尖刺和出口不作为空白区域，移动与跳跃按钮也不触发折纸。横向移动 10 CSS 像素后开始预览，60 像素后松开确认；小幅滑动或滑回起点取消。阈值与画布缩放无关。

实际游玩没有页面大标题、说明页头或常驻计时器，只有关卡编号、钥匙、有效折痕、折叠次数和必要按钮。时间与标题放在暂停／通关面板。手机触控目标至少 44×44 像素，横屏优先，竖屏提供旋转提示。

## 规则与提示

折叠或展开前，角色必须落地站稳，完整位于固定侧，避开折痕两侧各 12 像素安全带，并由固定平台完整支撑。新平台或尖刺不能直接压住角色。角色不会随纸移动，展开也不会回到出生点；危险操作会显示中文原因。

点纹表示固定平台，斜纹表示折入平台；尖刺始终显示在上层。重叠实体按并集碰撞，接缝标记由实际几何生成。每次从不可变原图重新构建世界，没有旧位置的隐形碰撞。钥匙按唯一 ID 收集，展开后仍保留；重来才清空本关钥匙与次数。只有成功折叠增加折叠次数，展开单独计数。跌落或碰刺后 0.35 秒重试。

提示暂停游戏，依次提供空间线索、带金色目标标记的动作、当前阶段详细路线。标记跟随变换后的未收集钥匙，再指向固定落脚点或出口。提示不移动角色、不送钥匙、不消耗折叠次数。取消／拒绝操作不推进提示；选择其他折法或漏拿钥匙会显示恢复指引。它采用已验证的手工路线，不是通用求解器。

## 架构

| 文件 | 职责 |
| --- | --- |
| src/levels.ts | 16 关原始数据、中文名称与短提示 |
| src/geometry.ts | 校验、平台拆分、点和矩形反射、碰撞世界与接缝 |
| src/physics.ts | 独立角色运动、轴向碰撞、跳跃缓冲与土狼时间 |
| src/game.ts | 纯状态机、安全检查、原子提交、钥匙、死亡与通关 |
| src/gestures.ts | 空白区域与滑动意图识别，独立于 Phaser |
| src/hints.ts | 手工路线对应的三层中文提示与目标 |
| src/paper.ts | Phaser 纸面压缩翻转、阴影、预览与角色绘制 |
| src/main.ts | 输入、单按钮状态切换、场景、原生 HTML 界面 |
| src/strings.ts | 通用中文文案；关卡文案集中在 levels/hints |
| src/progress.ts | 本地进度、最低折叠次数、音效偏好与存档校验 |
| src/sound.ts | 代码生成短音效，无下载素材 |
| tests/routes.ts | 显式移动／跳跃／折叠路线，使用正式碰撞逻辑 |

纸面 1200×600，镜头显示 y=180–560，使用 Phaser FIT 缩放。只变换被掀起的纸面及其物体，固定侧、角色、界面不翻转。模拟固定为 120 Hz，普通追帧最多 12 步，丢弃超过 150 ms 的间隔。失焦、隐藏页面清空输入并暂停，需手动恢复。预览／动画期间冻结模拟，取消、触摸中断或缩放不会提交操作。

window.__foldSnapshot 仅返回只读快照。没有传送、解锁或强制胜利接口。浏览器测试逐关通关来解锁，高级触摸测试复用真实取得的存档。旧十关存档保留成绩，并在已完成第十关时解锁第十一关。

## 新增关卡

1. 在 levels.ts 添加 defineLevel，配置出生点、唯一出口、唯一实体 ID、预设折痕和允许方向。
2. 平台跨折痕时自动拆分；钥匙、出口和尖刺必须完整处于允许折痕的一侧。原始和折后矩形都应位于纸内。
3. 在 tests/routes.ts 添加 walk/jump/fold/unfold 路线。坐标只是输入控制目标，不能赋值给角色。用正式运动参数验证跳跃距离与固定落脚点。
4. 在 hints.ts 添加操作序列以及每阶段三层提示、固定目标和优先钥匙 ID；同步 docs/LEVEL_SOLUTIONS.md。
5. 执行单元路线、浏览器路线及生产构建，成功后才记录可解。选关和存储上限随 levels.length 更新。

## 已知边界

只实现预设竖直折痕的两种方向，无嵌套折叠、自由折痕、重力旋转、编辑器、后端或在线服务。画面和短音由代码生成。提示不保证覆盖任意替代路线。存储不可用时仍可玩，但不会跨页面保存。

Phaser 使产物约 355 kB gzip，Vite 大分包提示不是构建失败。手机验证使用 Chromium 触摸模拟，不等于 Android/iPhone 真机验收；未声称支持原生小游戏 SDK、Safari 或商店发布。

详见 [关卡解法](docs/LEVEL_SOLUTIONS.md)、[实际测试记录](docs/TESTING.md)。
