# 积分、联网好友与触屏反馈

保留现有竖屏木质棋社风格与页面结构。主页增加「好友对战」入口，进入独立房间页：创建房间或输入房号加入；房间展示房号、两位玩家的就绪状态、邀请与准备操作。双方使用各自手机出杆，棋盘以自己的底线朝下；服务器校验回合并结算，断线重连后恢复房间状态。

本色棋子每枚 1 分，红后成功同杆或下一杆补进后加 3 分，未补进不计分；犯规返还的棋子扣回分数。本色清台且红后完成补进后结算，积分高者胜，同分由清台方胜。练习仍按完成目标和杆数评星。双方席位显示积分和入袋数量，结算显示双方积分。

击球子路径使用浅色虚线，目标球方向采用青蓝实线、深色描边与箭头，避免仅凭颜色区分。未命中目标时灵敏找角度，出现目标球撞击线后降低灵敏度；保持回到起点收杆、取消手势与松手稳定的行为。

摆位输入只更新必要状态，移除高频全量 HUD 更新；渲染复用棋子和尺寸缓存，静止时按需重绘；存档离开触屏松手的同步路径，退出前刷新。验证采用 Chromium 手机尺寸及 CDP 触控，覆盖房间两端、回合同步、红后积分、取消和恢复；结果记录不等同于真机验收。
