# 慢调手感与棋社界面

本次保留竖屏方形棋盘、回拉出杆和已有页面流程。先生成手机效果图，再按图实现，最后用正式构建截图与触屏输入验证。

## 手感

初次回拉决定大致方向，后续横向移动以较低增益微调角度；极小移动设死区，避免短回拉时角度被放大。沿当前方向回拉仍改变力度，回到起点可收杆。采用 CSS 像素定义移动阈值，保持不同屏幕宽度的稳定性。指尖停止后预览不继续漂移；松手只提交最后稳定的预览，过滤临近松手的短暂偏移。手势取消、捕获丢失、失焦和页面切换不出杆。

## 视觉

深孔雀绿桌毡、胡桃木框、枫木棋面和黄铜雕刻形成同一套桌面棋社风格。主页突出完整棋盘与黄铜铭牌主按钮；选关用木质练习牌与真实缩略棋盘；游玩强化上下席位与刻度摆位轨，回合提示为嵌入席位的黄铜牌。减少圆形工具头像与空泛装饰，用黑白棋子徽章呼应玩家身份。瞄准时显示简洁角度刻度、力度和轻微的目标反馈，棋盘始终是画面主体。

主要比例 390×844，兼容 320×640 和 844×390；暂停、取消及调整控件保留至少 44px 热区，触控区不覆盖棋盘目标。主流程、解锁和旧存档格式保持兼容。

## 验收

验证短回拉微调、单像素抖动、快速真实转向、静止后松手、临近松手偏移、回到起点收杆、多触点、取消与失焦；测试真实落袋、暂停恢复、胜负、选关解锁与存档。实际截图对照效果图，记录测试环境，不将桌面手机模拟称为真机验证。
