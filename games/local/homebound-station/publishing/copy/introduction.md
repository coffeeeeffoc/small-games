# 归途站

车站又迎来一班旅客。看清出租车的箭头，点开前方畅通的车，让大家坐上回家的车。

每次点击都会按顺序为车辆绑定一组旅客和等候站门，多辆出租车可以同时出库、前往接客。车辆沿入站道和待车线排队，抵达上客位时再停靠；路口会自动让行，候车不用绕圈。观察停车场里的阻挡关系，接完旅客并让全部车辆离场，就完成了这一班。

100 个关卡逐步展开：从3×3的小车场，到6×9、最高50辆车的密集车阵，出车顺序越来越需要思考。首页直接演示发车过程，独立箭头让方向更清楚；小屏上可上下拖动车场查看后排。支持音效设置、暂停、重试及进度保存。

正常游戏使用免费1×速度。点开顶部倍速按钮，在平台提供激励视频时，可自愿完整观看，分别解锁本局2×、3×或5×加速；没有可用广告也能正常游玩和通关。
