# 归途站

车站又迎来一班旅客。看清出租车的箭头，点开前方畅通的车，让大家坐上回家的车。

旅客先从站门来到候车区。每次点击都会为车辆绑定一组已出站的旅客，多辆出租车可以同时出库，在站台旁横向停靠。上一拨全部上车，下一拨自动走出车站；旁边的通过车道保持畅通，合流时车辆会自动让行。观察车阵里的阻挡关系，接完旅客并让全部车辆离场，就完成了这一关。

100 个关卡逐步展开：从3×3的小车场，到6×9、最高50辆车的密集车阵，出车顺序越来越需要思考。从独立的站前首页开始游戏，车顶箭头标明方向，按下和受阻都有清楚反馈；小屏上可上下拖动车场查看后排。支持音效设置、暂停、重试及进度保存。

正常游戏使用免费1×速度。点开顶部倍速按钮，在平台提供激励视频时，可自愿完整观看，分别解锁本局2×、3×或5×加速；没有可用广告也能正常游玩和通关。
