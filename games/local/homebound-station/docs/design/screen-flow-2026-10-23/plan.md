# 归途站：画面比例与站前动线

2026-10-23。先生成并展示 [整体效果图](concept.png)，再实现。效果图用于确定构图与风格，不能当作运行截图或承诺其画面中不存在的规则。

本轮把可操作的停车场作为视觉主体。顶部保留紧凑关卡、接送进度、倍速和暂停；站名与门面完整可见，上客位紧邻站门，待接旅客从门内出现。取消空广场、大面积花园边框、零碎小椅子路灯和底部四倍速工具条。倍速折叠在单个按钮中，仍只有 1× 免费，2×/3×/5× 需本局激励广告完成。

首页直接展示有方向箭头的出租车棋盘和自动发车演示，标题、玩法提示与开始按钮共同解释“看箭头，点动车，接大家回家”。演示独立于实际关卡进度与广告状态。暂停使用深色遮罩和紧凑卡片，继续、重开、回首页、音效、帮助在拇指可达区域。移除本游戏全屏入口和通用规范中的默认全屏要求。

道路采用明确的入站收集道、待车线、直穿上客位和独立离站道。点击即绑定乘客及其站门位置；物理泊位在车辆实际到达时使用。北向车辆不再为了上客绕到停车场底边，不通过绕圈消解交通占用。并发与碰撞安全需模拟测试和真实运行共同验证。
