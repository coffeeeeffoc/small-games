# 归途站 · Cocos 移动版改版

2026-10-22。核心循环：观察车头上方独立的方向标 → 点击可出库出租车 → 当下按点击顺序绑定未预订的合适乘客组及固定等候位置 → 多车独立出发 → 自动上客离站 → 清空车场。路线交汇仅做局部避让，不以另一辆车完成接客为发车条件。

采用竖屏（390×844 设计基准），适合单手点击车阵；横屏等比完整呈现。页面为加载 → 首页 → 章节选关 → 游戏 → 暂停/设置 → 结算。首页聚焦“继续接班”、选关、设置。游戏仅显示关卡、已接人数、暂停、倍速和短提示；操作直接发生于车上。主要按钮有效热区至少44 CSS px；安全区保留。窗口隐藏和广告播放暂停模拟，不在恢复时补算离线时间。

视觉沿用车站、立体乘客与出租车；暖奶油底色、松石绿站房、琥珀黄出租车、浅灰蓝道路、陶土色屋顶、圆冠树、路灯、花坛和人行道构成微缩街区。车身有挡风玻璃、车灯与 TAXI 标识；方向使用车外深绿圆形底牌上的白色几何箭头，容量用另一枚小数字牌。图标为圆角松石底上的黄色出租车与白色站牌；引擎启动与资源加载使用同一图标。

100关分10章，每章10关：6至20辆车，逐步增加阻挡深度、方向组合、乘客人数和时间评星压力。固定种子生成独立可验证配置；每关通过拓扑剥离和完整模拟证明可解。普通模式顺序解锁且兼容v2存档；dev由公共SmallGamesDev读取URL/存储，任意选关，试玩不写正常进度。

倍速仅1×免费；2×、3×、5×分别完成激励视频后解锁当前局（用户2026-10-22确认）。仅收到广告完成的rewarded结果发放；取消/失败/不可用不发放。未配置广告平台时明确提示暂不可用，不用倒计时伪装广告。广告期间游戏暂停，异步回调按对局身份校验，重开或退出不把奖励写入别的对局。

工程以Creator 3.8.8为目标，纯TypeScript规则/关卡/进度与Cocos呈现分离。真实Creator构建与匹配引擎类型声明为发布前置条件，不以其他引擎预览替代Cocos验收。保留现有Web入口作为迁移期间规则与交互回归入口，标明验证边界。
