# 归途站：横向停靠与先候车后派车

2026-10-24。针对用户六项反馈，先生成[效果图](concept.png)，再修改真实 Cocos 场景。图中城市远景仅为美术参考，运行仍复用现有透明站房、八方向出租车和旅客图集。

## 合理性审核与取舍

- 原场景把停车场放大、外圈与站前道路单独压缩，车辆又根据所在路段动态缩小。改为全场统一坐标比例与固定车身长度；4座/6座只由票签区分，不再在移动中改变车型大小。
- 原四个泊位垂直贯穿站前道路，旅客要跨车道。改为车头向右、长边平行站台的横停位；候车点在站房与泊位之间，人行区域不与通过车道交叉。泊位外侧保留一条向右的连续车道。
- 车辆斜入/斜出时维持原有3.43单位中心安全距离。通过区不设会堵住邻车出口的临时停车点，进入前预留完整路段，合流让先行车离开；不加绕圈路线、不扩大外圈藏排队问题。
- 开局四个站位已有旅客。每一组全部上车即触发下一组从对应站门走出，独立于下一辆车是否派出；保留约一秒真实移动。仅已开始出站的旅客可绑定车辆，未出站时给出短提示；点击绑定后不换组、不换站门。多个站位仍可同时接客。
- 首页主按钮按存档显示“开始游戏”或“继续游戏”；好友邀请显示“开始挑战”。关卡与章节单独显示，去掉“开始接班”与混在按钮里的关卡号。顶部预留由140px降到64px，标题缩至32px，门面压至64px以内。
- 保留100关、旧存档、正常解锁、小游戏入口、可选倍速广告与暂停/重试闭环。此次不加货币、养成或额外菜单。

## 影响范围与验证

规则改动在core的geometry/simulation/station-traffic；呈现改动在StationWorld/StationHUD，StationGame只扩展只读画面诊断。同步规则测试、真实构建触屏测试、README及上架资料。legacy规则导出与18个历史回放保留，测试明确区分历史多组预订与现代候车规则。

验证实际Creator 3.8.8 Web Mobile构建；使用390×844、320×568、844×390触屏模拟，检查同一车身尺寸、横停方向、无后车时独立补客、暂停/恢复、通关与保存进度。效果图不替代运行截图，Web触屏模拟不替代物理手机或原生宿主验收。
