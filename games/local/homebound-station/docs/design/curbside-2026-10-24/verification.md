## 可复现命令

在游戏目录运行：

```powershell
node --test --test-concurrency=1 tests/*.test.ts tests/*.test.mjs
node scripts/typecheck.mjs
node scripts/build.mjs web-mobile
$env:CAPTURE_GAME_EVIDENCE='1'
node tests/cocos.browser.mjs
node scripts/serve.mjs
# 保持预览服务运行，在另一终端录制1×实玩并导出两类MP4：
node tests/recording.browser.mjs
```

录像脚本只读取快照并发送真实触摸，不调用内部派车/推进接口。完整实玩不剪辑、不变速；宣传片保留首页、核心接客与结果片段。均为390×844 H.264静音视频，完整解码与抽帧检查通过；具体时长以媒体清单为准。
