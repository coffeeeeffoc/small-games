# 无界滑行 · 产品与分批实施方案

## 定位与核心循环

横屏移动优先的超现实速度闯关。观察前路 → 转向避险/减速过门 → 收集偏离安全线的星屑 → 连续衔接载具 → 失误结束 → 同路线重试或生成新旅程。风景提供新鲜感，读路、控速和路线记忆提供可学习的难度。

失败不能靠随机突袭：障碍提前进入视野，碰撞、离开边界和未减速通过限速门都会结束本局，并显示原因。没有自动躲避、复活广告或永久数值强化。重试保持 seed、章节、规则版本与全部地形；换路线换 seed。重玩同局可以学会更好的路线。

每局变化来自种子控制的障碍左右位置、门位、星屑风险路线、弯道、风向与远征章节组合。随机数不在渲染中消耗；动态障碍按进度而非墙钟运动。先生成可行走廊，再放障碍；约束相邻走廊横移、最大速度、障碍间隔及转场缓冲。难度有上限，远征不会无限加速成必死局。

## 首批可玩范围

- 五种画面：雪山、古树、瀑布、云海、海浪。
- 三种真实参数不同的载具：滑板（响应快）、滑翔机（惯性与横风）、冲浪板（较强漂移）。三者共享左右控制与按住减速；空中减速明确降低前进速度，不模拟失速。
- 三条依次解锁的航线，随后继续无限远征；远征入口首局即开放。航线的章节顺序固定，种子改变路线；无尽每一轮根据合法连接模板选择场景序列。
- 障碍：固定岩石/树桩、沿可预判轨迹移动的障碍、必须对准且减速的窄门。偏离路线边缘有短宽限和红色反馈，持续偏离则坠落。
- 星屑只增加成绩，不是通关门票；通关与最佳里程保存在本地 Game Host 存储。
- 主页、航线选择、游戏、暂停、失败/完成、帮助设置；实际功能之外没有占位入口。

## 操控与画面

默认触屏左右区域/拖动控制方向，右下独立按住减速；支持多点触控。可在设置中主动开启设备方向传感器、校准自然握姿；权限拒绝、设备无数据时继续触屏。键盘方向键/A D 与空格是补充。前后倾斜加减速不纳入首批，因为握姿调整容易误触，后续通过同路线对照测试决定。

16:9 至长屏横向构图，所有页面跟随容器旋转；竖屏手机且系统锁定时 CSS 旋转整个游戏并映射触控坐标。主要触点至少44 CSS px。第三人称稳定地平线、低多边形山体与分层雾气、象牙白文字、青绿色气流、橙色危险。轨道占据画面中心，下方两个拇指区不遮挡前方判断。暂停按钮用两根实心竖条。

生成设计图后再实现。效果图覆盖主页、航线、核心游玩、失败重试四个横屏手机状态。实机截图逐页核对，实际限制写入验证记录，不把概念图或桌面模拟称为真机。

## 转场契约

每段最后 55 米开始预告，最后 35 米和下一段前 45 米无碰撞障碍；相邻走廊连续，速度保留并平滑进入新载具参数，转场中仍可转向。场景色彩/远景在交界处混合，角色载具形状在交界处切换并显示简短名称；镜头不切换、不闪黑。

| --------- | -------------------- | ------------- | ------------------------------ |
| 雪山→古树 | 雪坡接入巨木桥       | 滑板→滑板     | 提前看见树干路缘               |
| 古树→瀑布 | 枝梢跃出峡谷         | 滑板→滑翔机   | 自动展开翼面，继续左右选线     |
| 瀑布→云海 | 水雾接入上升气流     | 滑翔机→滑翔机 | 横风在缓冲后渐入               |

## 后续批次与验收门槛

1. **本次 P0：规则与手感原型。** 上述五场景三载具、种子路线、失败重试、三航线解锁、无限远征、触屏/体感降级、存档、Shell 接入。采用 Canvas 透视绘制，不声称完整自由3D。
2. **P1：地面与移动平台。** 城市车顶/列车/屋顶、草坡、冰湖；轮滑以低坡道与连续接地为特征，冰刀低摩擦长滑移；鹰背/恐龙背复用移动平台。每个新增载具必须改变至少一个可感知决策，并有提示和安全练习段。
3. **P2：空中高度与灾变。** 滑翔伞利用上升气流延长航程，降落伞低速精确落点；龙卷风外围上升带、火山热流、预告地震和海啸。滑翔机→伞通过减速开伞区，伞→地面设备通过可见落点；不使用随机无预告伤害。
4. **P3：近地轨道与宇宙。** 空中发射平台进入飞船固定航道，飞船→返回舱在明确分离段，返回舱耐热/姿态挑战后→降落伞→滑翔机/地面载具。空间站、彗星、陨石采用可读的引力航道。只有P0/P1反复游玩证据成立后扩展。
5. **P4：内容生产与真实设备。** 成对关卡模板组合、每日固定种子、回放/幽灵、外观收藏；实机姿态与性能、无障碍、各小游戏平台分别验收。暂不加入多人联网或付费数值成长。

首轮10—15人定性体验比较触屏/倾斜、是否能解释失败、同种子第二次是否改善、看完景观后是否主动再玩；不能以该规模推断商业留存。每批验收后再调整内容量，不以堆景观替代核心玩法。

## 工程与验收

核心模拟、配置/schema、渲染、输入/显示、进度/Host 分离；新增采用已有机制的航线只改配置。schema校验唯一ID、合法场景连接、范围、解锁图；存档版本化并清洗坏数据。无运行时第三方依赖。可选权限/存储失败不能阻断游戏。

规则测试覆盖同种子一致与不同种子差异、安全走廊可达、碰撞/离轨/限速失败、三载具切换、重试、章节解锁与开发试玩不写进度、无限生成与难度上限。浏览器触屏验证主页→选线→开始→暂停/恢复→失败→同种子重试→正常通关→解锁→刷新恢复，及旋转兜底、多点取消、失焦暂停、独立与Shell入口。通过后提交同步远端dev，对准确合并候选执行增量验证再推送。
