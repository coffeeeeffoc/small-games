# 无界滑行 · 原型验证

日期：2026-10-28（北京时间）。版本0.1.0。运行文件指纹见 [runtime-sha256.json](runtime-sha256.json)，避免把概念图、未提交草稿或旧构建当作本次实录。

## 已完成的验证

- 规则：9项 Node 测试；1000个种子的完整五场景航线使用真实固定步长、转向、惯性、横风和刹车模拟全部可达；无尽50段验证内存上限与难度封顶。样本验证不等于数学证明。
- 失败：不操作会撞击，持续转向会离轨，错误对准或超速过门会失败；碰撞与到达终点同一步时优先失败。
- 种子：同种子相同障碍，重试原样复现；不同种子改变布局，无尽序列遵守连接表。
- 手机 Web：Chromium桌面模拟触屏，在844×390、390×844、667×320和1280×720运行。使用CDP真实多点触控事件，测试通过只读快照选择方向；未修改角色、碰撞、生命、时间、通关状态来制造通关。
- 完整流程：主页、航线锁定、帮助、设置、实际转向与同时刹车、手势取消、暂停恢复、失焦暂停、自然失败、同种子重试、三航线依次正常通关、刷新恢复、全部三种载具、换种子、无尽入口。
- 存储：禁用localStorage后仍可开始/失败/重试；已有存档暂时读取失败时，设置不会覆盖旧存档。
- 开发模式：公共脚本一致性和语义测试；显式dev=0不提供游戏诊断。试玩动作不写入正常进度。
- 画面：检查实际横屏、竖持旋转、失败与成功状态截图；暂停使用两根独立实心竖条；转场色彩、弯道、边景逐步衔接，安全区随旋转换边。

完整功能记录：[report.json](report.json)。最后一轮转场/画面复验：[visual-report.json](visual-report.json)；该轮用前两航线已解锁的明确测试fixture进入末航线，然后用真实触屏完成五场景，仅用于最终视觉复验，不替代前一轮正常解锁证据。

## 已知边界

这不是手机真机、真实陀螺仪手感、Cocos Creator或原生小游戏渠道验收。自动控制证明触屏输入可以通关，不证明真人首局难度、眩晕程度或长期留存。需按产品方案邀请10—15位玩家试用，校准转向、限速门间距和难度曲线。

首次直接执行Shell测试因共享package的dist尚未构建而无法解析game-contract/ad-config；属于环境准备问题，需构建release-contract依赖后复测。准确base/head的提交候选门禁、Shell真实入口与推送记录由最终交付日志单独记录，不把本地单游戏通过称为远端部署成功。
