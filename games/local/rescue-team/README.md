# 小城救援队

接报出发，到场救援。调度三辆救援车处理民居火情、公园寻宠、道路清障和配电故障；疏通道路会让同伴更快抵达。

## 运行

```powershell
Set-Location F:\playground\playground-ai\small-games\games\local\rescue-team
npm start
```

独立服务默认 `http://127.0.0.1:4404/`，支持 `/rescue-team/`。运行时无第三方依赖。Shell 入口 `#/games/rescue-team`，发布资源 `games/rescue-team/index.html`。

## 操作与规则

- 点待处理事件卡片，地图高亮出事地点，卡片旁显示当前空闲车辆及预计到场时间；每辆候选车都有同色连线指向实际位置，再点车即可派出。正在赶路、进出场或处理任务的车不会列入候选。
- 派车后，事件卡片带移动动画收进默认折叠的“已分配”。点击展开可看地点、已派车辆和实时状态；点击其中的事件会高亮现场，并连到执行车辆的当前位置。再点区域标题可收起，完成事件自动消失。关闭动效时直接收起。
- 也可直接拖车到现场，或选车后点地图现场；点击或拖到地图任意位置可精确停靠，不再显示固定路口占位圈。车辆沿道路驶向附近入口，再到所选坐标，停好后可继续派去救援。没有空闲车时显示提示，车辆空闲后会自动进入候选列表。
- 事件实际发生后才显示卡片和现场标记。等待时间从零增加，到场后显示正向累计的处理时间和进度条；不会预告未来事件。
- 任务卡明确说明接报多少秒后会恶化。火情和停电延误扣 2 格，寻宠和清障扣 1 格，累计 3 格结束；清障和停电恶化后仍可维修，扣分不返还。
- 车辆沿道路到达入口，再花 1 秒驶入具体庭院、花园、作业区或配电站，停车后才开始服务。完成后留在现场，再派单先花 1 秒驶出。进入和离开现场时暂不能改派；路上改派先走完当前路段。
- 第一次派单即开始。选车、取消与拖动不会暂停其他车辆；主动暂停或切后台后必须点“继续”。键盘支持 Tab、Enter 和 Escape；聚焦地图后方向键选择停靠位置，Shift 加大步长，Enter 确认。
- 只有两条路线不同时才显示路线选择。预计完成时间包括进出场、行驶和服务；同伴提前完成清障可能缩短时间。
- 三关事件数分别为 4、5、6。确定性零延误回放分别在 27、34、38 秒完成。每关可直接选择和重试。

## 验证

```powershell
pnpm --filter @coffeeeeffoc/rescue-team test
pnpm --filter @coffeeeeffoc/rescue-team build
pnpm check:games
```

在本目录启动服务后，使用仓库已有 Playwright 运行浏览器验收：

```powershell
node playtest.mjs ../../../node_modules/@playwright/test/index.mjs
```

检查使用真实墙钟、鼠标和浏览器触控，覆盖三关零延误、接报后显示、正计时、车辆进入现场、拖放与取消、短屏横竖布局、暂停和后台恢复。模拟断言同时验证无清障和绕路的反事实、进出场连续性、完成边界、服务锁定与原地停车。

交互验收同时检查卡片两次点击派遣、空闲车辆实时筛选、屏幕缩放后连线端点、已分配区域的动画/展开/收起、执行车实时连线、完成与过期清理、键盘和减少动画设置。截图：[待派车选择](./docs/playtest-dispatch-picker.png)、[展开已分配](./docs/playtest-assigned-expanded.png)。

手机证据来自 Chrome 视口/触控模拟，未做手机实机验证；本次不代表已部署线上。
