# 外滩 · 一江入梦

竖屏优先的外滩沉浸式滚动叙事。国风纸感插画从晨光过渡到夜色，滚动带动镜头、船影、薄雾和飞鸟。支持桌面、手机横竖屏与键盘章节导航。

## 运行

在仓库根目录运行：

```sh
pnpm install
pnpm --filter @coffeeeeffoc/travel2 dev
pnpm --filter @coffeeeeffoc/travel2 build
pnpm --filter @coffeeeeffoc/travel2 test
pnpm --filter @coffeeeeffoc/travel2 test:browser
```

开发地址 `http://localhost:4182`。`dist/` 是独立静态站点，Vite 使用相对资源路径，也通过 Shell 的 `/games/travel2/` iframe 加载。浏览器检查可用 `PLAYWRIGHT_EXECUTABLE_PATH` 指定 Chrome。

上滑或滚轮前进，也可点击底部横向章节导航或继续漫步。每幕点击探索入口，阅读后点击「盖上这一枚」。重复收集不会增加计数。手账可跳回任一幕，12 枚集齐后可下载本地生成的 PNG 明信片。重走不会清空手账，旧版四枚印章继续有效。

每幕占 150svh 滚动距离，前 32% 用于平滑推进或拉远，其余留给看景与探索。四张场景插画通过相机焦点、缩放和跨图淡化组成 12 个镜头；反向滚动按相同进度还原。`src/journey.ts` 是章节、景别、图片与相机参数的唯一列表；导航、旅程长度、完成条件和明信片数量由列表计算。新增一幕需给定唯一 ID、叙事文案、图片类型和归一化相机焦点，并检查相邻镜头的景别节奏。

存档键为 `travel2:bund:stamps:v1`，仅保存有效的印章 ID；损坏数据忽略，无法写入存储时保留当前会话并提示。声音默认为关，用户点击后使用 Howler 播放原创合成江风与盖章音；隐藏页面暂停声音和 Pixi ticker。减少动态效果模式直接切换各幕构图，取消连续缩放。WebGL 不可用时 Pixi 优先回退 Canvas；场景渲染器均不可用时使用同一相机计算驱动 HTML 插画，保留全部场景和集章功能。

## 实现与素材

React + TypeScript + Vite 管理页面，PixiJS 渲染场景，GSAP ScrollTrigger 把原生文档滚动映射为 0–1 叙事进度，Zustand 管理集章，Howler.js 管理音频。不依赖可选角色动画库。

四张运行时插画共约 1.50 MiB，见 [美术来源](art-notes.md)。音效由 `node scripts/generate-audio.mjs` 可重复生成。Google Fonts 可用时加载思源宋体，离线回退本机宋体；场景与声音均随站点提供。叙事时间用于表现虚构的一天，场景是艺术化构图，不是精确地理、航线或营业时间指南。

验证包含存档和镜头边界检查、真实浏览器滚动/触摸/盖章/重载/明信片，以及 Shell 入口和 iframe 返回。浏览器模拟不代表已在实体手机或微信内完成验收。
