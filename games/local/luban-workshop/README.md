# 榫间 · 鲁班锁

以触屏操作体验为重点的 3D 榫卯解谜原型。首版提供三件原创叉槽机关，分别由 3、4、5 根彩色榫条组成，练习选中、试探、观察阻挡、拆解与复原。这些结构是入门玩法设计，不是历史鲁班锁的精确复刻。

每根榫条固定沿一条轴平移；玩家可以旋转整体观察视角，不能旋转单个零件。当前没有自由刚体模拟、金属环扣或九连环。

## 运行

在仓库根目录安装 workspace 依赖后运行：

```sh
pnpm --filter @coffeeeeffoc/luban-workshop dev
pnpm --filter @coffeeeeffoc/luban-workshop typecheck
pnpm --filter @coffeeeeffoc/luban-workshop test
pnpm --filter @coffeeeeffoc/luban-workshop build
pnpm --filter @coffeeeeffoc/luban-workshop preview
pnpm --filter @coffeeeeffoc/luban-workshop test:browser
```

开发和预览端口为 `4338`；预览前先构建。遵循仓库的 Node / pnpm 版本要求。Vite 输出到 `dist/`，使用相对资源路径，可部署在子目录。运行环境需要支持 WebGL 2 的浏览器；无法创建画布时会显示重新尝试入口。

## 操作

- 点场景中的榫条，或底部对应的颜色 / 字母按钮选中零件。选中后显示高亮和移动轨道。
- 沿轨道拖动零件或场景中的 ± 手柄；点按手柄或底部 ± 按钮，每次微移半格。零件被遮挡时仍可通过底部按钮选中。
- 拖动空白处旋转视角；双指捏合缩放，双指平移也可调整视角。右侧提供缩放、还原视角和透视观察按钮。
- 受阻时相关零件变红并显示反馈；手指反向移动可立即退回。移动轴接近正对镜头时，按提示转动视角或使用微移按钮。
- 拖动中连续跟手，松手后吸附到经过碰撞验证的邻近半格位置，与 ± 微移的步长一致；一次有效拖动只记一次移动，完全受阻的尝试不增加次数。
- 撤销、重做、一点提示和重新开始均可触屏操作。提示根据当前状态寻找下一步，只指出零件和方向，不替玩家移动。
- 全部抽出后点“开始复原”，保持当前散开位置，亲手将各件送回零位；完成后可进入下一件机关。
- 电脑可用方向键微移，`Ctrl / ⌘ + Z` 撤销，`Ctrl / ⌘ + Shift + Z` 重做；鼠标滚轮缩放。

触点取消、失去捕获、窗口失焦或切到后台会回退尚未完成的拖动；双指接管镜头前也取消当前零件拖动。观察与零件移动分别处理，镜头操作不计入移动次数。

## 结构与边界

| 文件                            | 职责                                                        |
| ------------------------------- | ----------------------------------------------------------- |
| `src/levels/index.ts`           | 三件机关的名称、颜色、轴向、实体盒体、活动范围及抽出距离    |
| `src/core/types.ts`             | 关卡、零件、位移、状态、拖动事务和提示的数据接口            |
| `src/core/collision.ts`         | 盒体集合的轴向连续碰撞检测，返回合法位置及阻挡零件          |
| `src/core/game.ts`              | 拆解 / 复原状态、计步、拖动提交与取消、撤销重做、完成判定   |
| `src/core/hints.ts`             | 从当前状态搜索合法移动，给出下一步提示                      |
| `src/core/persistence.ts`       | 存档序列化，校验位置、碰撞、范围及历史路径合法性            |
| `src/view/PuzzleScene.ts`       | Three.js 场景、盒体并集表面、选中与阻挡效果、拾取、镜头投影 |
| `src/input/gestures.ts`         | 单指零件拖动、空白旋转、双指镜头、取消与监听器清理          |
| `src/input/taps.ts`             | 触屏按钮松手激活、移动/取消过滤，以及浏览器补发点击去重     |
| `src/storage.ts`                | 可降级的浏览器 localStorage 适配                            |
| `src/main.ts` / `src/style.css` | 页面组装、界面状态、手柄位置、存档时机与响应式布局          |

规则、提示和关卡数据不依赖 DOM、Three.js 或浏览器时钟。渲染与碰撞读取同一份 `boxes`，可见表面由实体盒体并集生成，阻挡关系来自实际几何接触，不在关卡中写死拆解顺序。

碰撞检测检查整个移动区间，不只检查终点；快速长拖动和松手吸附都不能穿过其他零件。每次拖动先产生预览状态，松手统一提交历史，取消则恢复手势开始前的完整状态。

提示使用有界搜索，探索实际状态下能到达的接触点、轴向端点与零位，最多扩展 12,000 个状态。适用于本版的小型轴向机关；复杂结构需要重新评估搜索空间与操作设计。

## 关卡扩展

1. 在 `src/levels/index.ts` 添加稳定且唯一的关卡 ID、零件 ID 和说明。现有 ID 用于存档，发布后应保持稳定。
2. 用 `boxes` 定义每个零件的连续实体；指定 `axis`、合法 `range` 和确实离开原始结构的 `removedAt`。初始偏移均为零，初始装配不能互相穿插。
3. 同时验证正反方向移动、局部松动后的让路关系、完整拆解和复原。增加关卡应扩展规则测试；新增旋转、关节或非轴向运动需要同时改变规则、提示与交互接口。
4. 更新机关匣当前写定的“三件 / 03”文案，检查机关匣、进度、镜头包围范围和触控热区；仅增加数据不足以覆盖新布局的体验验证。
5. 修改已有几何时考虑存档版本与迁移。当前版本会拒绝非法或碰撞存档并从该关初始状态开始。

## 存档与接入

游戏无后端、账号、广告或外部素材请求。Three.js 随构建打包；关卡进度、拆装状态、撤销历史和完成记录存于当前浏览器的 `luban-workshop:v1:` 命名空间。存储不可用时仍可完成本次游戏，界面会提示无法保存。

作为独立 H5 Game 接入现有 Web Shell，通过同源 iframe 装载；目录登记在 `apps/shell-web/src/standalone-games.json`。当前未接入 Game Host 云存档，也未适配原生小游戏 Canvas SDK。

按仓库 [Pages 三环境部署规则](../../../docs/deployment/github-pages.md)，`dev` 分支发布成功后的独立入口为 `/small-games/dev/games/luban-workshop/`，大厅分享入口为 `/small-games/dev/#/games/luban-workshop`。提交推送不代表部署已经成功；实际发布结果以 Pages 工作流和线上版本为准。同一站点的 main / dev / test 路径共用 origin，因此本地存档也共用命名空间。

## 验证

`test` 覆盖实体连通性、初始无重叠、钥匙释放关系、动态提示的拆装路径、长距离拖动防穿透、事务取消、计步、撤销重做及非法存档拒绝。

浏览器回归脚本 `tests/browser.mjs` 使用 Playwright 与 Chromium CDP 触摸事件，检查实际场景选择 / 拖动、阻挡反馈、镜头操作、拆装闭环、取消与存档恢复。Shell 冒烟检查另覆盖选关、微移、撤销和重做。

手机尺寸和触屏输入模拟不能替代实体 Android / iOS 设备的性能、手感与兼容性验证，当前尚未完成真机验收。
