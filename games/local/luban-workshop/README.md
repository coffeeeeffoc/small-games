# 榫间 · 鲁班锁

以触屏直接操作为主的 3D 互锁木构解谜。共 11 关：第一关是原创的两件半搭接入门练习「初识 · 一提一合」，向上拖开、向下放回，无需旋转或组合；其后收录按公开制造图或逐层结构资料重建的十件完整机关：三组六根锁、KNOXLI 三件锁、Crystal Ball 阶梯球，以及五件方块与套匣结构。每关从完整装配开始，可拆解、复原，或边拆边装。

几何依据、作者、尺寸转换和未纳入的结构见 [结构资料与建模记录](docs/puzzle-sources.md)。机关匣也提供每关的来源链接。这里收录的是经过几何和拆装验证的结构，不代表穷尽鲁班锁的所有变体；现代作品按其真实作者与名称标注。

## 运行

在仓库根目录安装 workspace 依赖后运行：

```sh
pnpm --filter @coffeeeeffoc/luban-workshop dev
pnpm --filter @coffeeeeffoc/luban-workshop typecheck
pnpm --filter @coffeeeeffoc/luban-workshop test
pnpm --filter @coffeeeeffoc/luban-workshop build
pnpm --filter @coffeeeeffoc/luban-workshop test:browser
```

开发端口 `4338`，构建输出到 `dist/`，使用相对资源路径。需要支持 WebGL 2 的浏览器；无法创建画布时显示重试入口。

## 操作

第一次建议从「从这里开始」的两件入门关体验一次拆装；它以简短操作提示引导，旋转栏仅在主动打开辅助工具后出现。

从主页选择机关进入沉浸式游玩；游玩时隐藏品牌顶栏、关卡介绍和目录，返回主页可换关，进度自动保留。

- 轻点零件选中，再点取消；依次轻点多件组成多选，轻点空白清空。拖动已选件移动整组，直接拖动未选件切换为单件操作。
- 拖动根据当前镜头下的手势方向选择世界 X / Y / Z 轴，一次手势锁定一个轴。松手吸附到合法的半格位置；辅助工具提供方向选择与半格微移。
- 选中后下方出现旋转栏。选择 X / Y / Z 和角度（默认 90°，可选 5° / 15° / 30° / 45°），再点正向或负向旋转。单件绕材料参考中心，多件绕各参考中心的平均点作刚体旋转。正向遵循右手定则；转动途中受阻会整步拒绝并高亮阻挡件，应先移开更多空间。
- 右上角始终显示完整结构，与主画面保持同一观察朝向。拖动主画面空白或参考小窗都能同步转动两者；小窗只调整视角，不改变零件。主画面双指缩放，桌面可滚轮缩放；参考小窗也支持方向键观察。
- 随时点“尝试复原”或“继续拆解”切换进度目标，保留所有位置、朝向、操作次数和撤销记录。两种状态都允许自由拆装。选中偏离原位的零件会显示装配位置的虚线轮廓；归位检查位置与实际形状，接受对称等价的朝向。
- “一键复原”直接回到完整形态、重置本轮操作并重新探索，保留已经获得的印章，不计作复原完成。
- “拆解提示 / 复原提示”读取当前位置和朝向，点击一次自动执行一个经碰撞验证的步骤，可撤销。详细方案见 [状态提示与重新探索](docs/assistance-design.md)。
- 辅助面板默认收起，包含零件字母、透视、看全机关、撤销、重做和思路提示。小屏幕的看全 / 透视按钮在零件行，避免遮住完整参考；缩放用双指手势。
- 每次有效拖动、微移或旋转记一次操作，组合也只记一次。受阻且未移动的尝试不计步。手势取消、窗口失焦、切到后台或双指接管会回退尚未提交的拖动。
- 电脑补充操作：`Esc` 清空选择，`Shift` 拖动加选，方向键微移，`Ctrl / ⌘ + Z` 撤销，`Ctrl / ⌘ + Shift + Z` 重做。

全部零件彼此分离才获得“解开”印章，整体搬走装配体不算拆解。部分拆开再复原也可完成复原目标，但不会补发“解开”或“独立”。完整拆解后再复原且全程没有使用思路 / 下一步提示，才获得独立印章。计步仅作个人记录；撤销、透视与观察不影响独立资格。

## 几何与状态

渲染、碰撞和提示读取同一份实体盒体。平移检查整个运动区间；多选作为刚体检查与外部零件的接触。旋转存储为正交旋转矩阵，支持小角度；正交姿态保留快速碰撞检测，斜向姿态使用有向盒连续平移检测。

旋转使用整个角度区间的包络、分离轴与有界位移递归验证，不只检查起点、终点或采样角。无法证明安全的紧贴转动会保守拒绝，需要先移开一些空间；不是自由刚体物理模拟。

提示结合可选的关卡姿态条件规则和通用几何搜索。它依据当前单件 / 组合状态规划合法操作；复原时支持绕行、旋回原朝向与历史路径校验。每次执行前重新验证当前状态及完整路径，找不到可靠下一步时不自动移动。关卡示例、扩展约束和未来 A/B 小角度解锁方式见 [设计文档](docs/assistance-design.md)。

## 存档与接入

独立模式无后端、账号、真实广告或外部素材请求，Three.js 随构建打包。模型由本地数据生成，来源链接仅在玩家主动打开时访问。

浏览器命名空间仍为 `luban-workshop:v1:`，内容升级为 v4，保存每件的位置和朝向及完整撤销 / 重做历史。v1 单轴位移和 v2 三维位移补上初始朝向后迁移，兼容 v3 的 90° 旋转与旧支点历史；读取时重新校验几何和每一步平移 / 旋转路径。非法存档被拒绝，并从完整形态开始。浏览器存储不可用时仍可本次把玩。

真实结构使用新的稳定关卡 ID，原演示关卡的进度不会误套在新的实体上，也不会删除原存储。旧演示模型仅保留在测试 fixture 中用于历史物理回归，不进入生产机关匣。

独立 H5 Game 通过同源 iframe 接入 Web Shell，登记在 `apps/shell-web/src/standalone-games.json`。当前未接入云存档或原生小游戏 Canvas SDK。

已预留 `window.lubanWorkshopHost` 奖励机会接口，拆解与复原使用独立机会 ID。未注入宿主时提示免费；注入后仅明确完成的奖励可执行一步，取消、失败、超时和过期回调不会移动零件。实际渠道广告尚未接入，宿主接入契约见 [设计文档](docs/assistance-design.md#奖励机会接入)。

按仓库 [Pages 三环境部署规则](../../../docs/deployment/github-pages.md)，`dev` 发布后的独立入口为 `/small-games/dev/games/luban-workshop/`，大厅入口为 `/small-games/dev/#/games/luban-workshop`。提交推送与线上部署成功分别以 Git 和 Pages 工作流状态为准。

## 验证

核心测试覆盖真实结构连通、初始无重叠、可拆可装、旋转后提示复原、全路径碰撞、刚体组合、对称归位、事务取消、撤销重做、存档迁移和非法历史拒绝。

`tests/browser.mjs` 用实际按钮、鼠标和 Chromium CDP 触摸事件验证全部生产关卡，以及单件 / 组合小角度旋转、受阻、保存恢复、双向同步参考、阶段切换、触点取消、主页 / 游玩切换、一键复原、双向自动提示、奖励取消与迟到回调、手机布局。诊断快照只读，不向页面注入解法或状态设置器。手机视口包含 `320×568`、`360×740`、`390×844`、`568×320`、`740×360`、`844×390`。

触屏模拟不能替代实体 Android / iOS 的性能与手感验证；当前尚未完成真机验收。
