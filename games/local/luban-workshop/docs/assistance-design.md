# 当前状态提示与重新探索

提示是一条可执行的合法操作，不是依次播放的解法。玩家可以拖到一半、换轴、移动组合、旋转或撤销，再请求下一步。设计不依赖网络模型；关卡几何、实时位置和朝向决定建议，执行与手动操作共用物理规则。

## 两种复原

- **一键复原**：取消手势和待完成提示，创建本关的完整初始状态。清空本轮操作、撤销重做、提示计数与拆解记录，回到拆解目标，重置镜头和旋转步长为 90°；已获得的印章和其他关卡进度保留。它开启新一轮探索，不计作完成复原。
- **复原提示**：保留当前零件，点击一次只执行一步，计一次操作、一次提示，并可撤销。按实际状态逐步腾挪、调正朝向、回到装配位置。

主页负责选关和展示介绍、来源与记录。游玩时隐藏品牌顶栏和关卡介绍，保留轻量的返回主页、目标、提示、完整形态参考与按需展开的工具。返回主页保存当前状态。

## 提示管线

1. 当前阶段已完成或已是完整形态时不请求奖励、不改变状态。
2. 优先重新验证当前姿态已经规划好的完整恢复路径，避免局部规则打断它；没有匹配路径时，`guidance.ts` 检查本关 `hintRules` 的阶段、零件位置、位置范围和朝向条件。规则只提供候选，不能跳过碰撞。
3. `hints.ts` 验证候选；不适用或被阻挡时，使用通用搜索。通用层搜索单件和组合平移、接触位置与让位空间；复原时还可调正朝向、验证并逆向使用短历史路径，或规划分离与绕行。长探索历史不会被逐步完整倒放。
4. `getHint` 为结果附上当前状态指纹。搜索和缓存有上限，找不到经验证的步骤时返回空，不尝试穿透或强行移动。
5. UI 获取一次提示授权。请求期间禁用重复点击；复原、返回主页、换关和切换目标会取消等待。手动操作后的状态引用不再相同，迟到结果也会失效。
6. `applyHint` 再检查状态指纹与完整运动路径，通过后提交一条可撤销操作。受阻、失效或无效的建议不允许执行半步。

使用提示会失去本轮独立印章资格；撤销不会抹去已使用提示的事实。完整拆解和手动/提示逐步复原仍可获得对应印章。

## 关卡定制

`Level.hintRules` 是数据化的条件规则，包含 `id`、`phase`、`when` 和 `action`。可选的 `relativeToPieceId` 让位置条件与平移目标相对某个零件的实时位移计算；用户整体搬动机关后仍能识别相同的槽口关系。朝向条件仍使用世界坐标下的矩阵。条件支持：

| 条件                        | 用途                               |
| --------------------------- | ---------------------------------- |
| `pieceId` + `offset`        | 某个零件处于特定位置               |
| `offsetRange: { min, max }` | 接受用户拖动到某段通道中的中间位置 |
| `orientation`               | 某个零件已转到指定朝向             |
| `tolerance`                 | 匹配数值误差，默认物理容差         |

生产示例在 `src/levels/index.ts`：双对榫在完整形态解释通钥；迂回三榫在不同通道区间提供双向换轴步骤。它们读取当前状态，不依赖操作次数。其他零件无论停在哪里，候选都要重新通过真实碰撞检查。

新增“A 与 B 分别转过少许才可解锁”的关卡时，使用 `rotationOrientation` 生成期望矩阵，在规则中同时约束 A、B 的位置与朝向，然后提供带 `rotationDegrees` 的旋转或解锁平移动作。旋转规则必须约束所有被旋转零件的起始朝向，防止只检查不变的位置而重复旋转。条件中的逻辑限制不代替实体结构：对应缺口与挡肩也必须在几何模型中真实存在。

每条关卡规则应验证：初始姿态、范围中间值、边界、反方向、其他件阻挡、不同朝向、撤销后重试、连续提示无循环以及完整拆装。不要添加只适合默认解法、离开后无法继续的候选路径。

## 小角度旋转

默认步长保持 90°，界面提供 5°、15°、30°、45°、90°，`Level.rotationSteps` 可以补充或调整选择。物理层与提示动作支持大于 0°、不超过 180° 的角度，包含非整数角度。旋转轴为世界 X/Y/Z，单件绕材料参考中心、多件绕各参考中心的平均点作刚体旋转，因此正反旋转不会让偏心零件漂移。

朝向使用正交旋转矩阵。正交姿态使用快速轴对齐盒检测，斜向姿态使用有向盒的分离轴检测；旋转路径以区间包络和有界位移递归证明安全，无法证明的极紧间隙保守拒绝。零件归位仍需要位置与实际占用形状一致。小角度功能是未来旋转解锁机关的基础；本次新增关卡没有声称需要特殊旋转才能解开。

存档升级到 v4，保存完整姿态和可验证历史；读取 v1/v2/v3，保留旧 90° 组合旋转支点路径的校验兼容。

## 奖励机会接入

目前独立模式免费，无真实广告。`hint-access.ts` 只预留与 Game Host 相容的奖励机会接口；渠道接入由 Shell 提供，不在 Game 内引用广告 SDK。

同源宿主可以在游戏窗口注入 `window.lubanWorkshopHost`，结构为 `session.capabilities` 含 `advertising` 且有 `ads.offer(opportunity)`。机会 ID 分别为 `luban-workshop.hint.disassemble`、`luban-workshop.hint.reassemble`；`reward` 仅含 `levelId`、`phase`、`action`、`steps: 1`。宿主按既有会话的 Ad Authority 选择内容与校验完成。

只有返回 `{ status: 'completed' }` 才授予一步。取消、无库存、错误、无效响应、超时（最长 45 秒）均不移动或扣提示次数，也不回退成免费奖励。没有注入宿主时的免费提示是明确的独立模式策略，不伪造广告完成。

真实广告接入前还需由 Shell 完成宿主注入、玩家激励广告说明与完成校验，并对渠道运行环境验收。当前同源 iframe 只运行游戏，尚未接入上述宿主。
