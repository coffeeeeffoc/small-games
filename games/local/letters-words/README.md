# 词了个词 · 教材词库拼写游戏

零依赖 H5 游戏，合并 `letters-words` 的字母库存玩法和 `letters-words2` 的严格遮挡玩法。在本项目运行即可使用四种组合模式。

## 使用

```sh
npm start
npm test
```

打开 <http://127.0.0.1:4186>。Node.js 18+；不需要安装运行依赖。端口可用环境变量 `PORT` 修改。

1. 点击「词库管理 / 选择练习」，选择出版社，用复选框多选年级，也可勾选「全部年级」。下载只请求这个范围内的书；每个年级包括上下册或全册。未选任何年级时不下载，出版社和下载年级会记住。
2. 练习区自动显示当前出版社已加载的书，无需再次选择出版社；切换出版社会清空其他出版社的练习勾选。可按年级一键勾选该年级所有已加载的书，也可细选整册或已有标注的单元。部分选择显示为半选；未下载齐的年级显示已加载本数。下载操作不会更改正在进行的练习。
3. 开始前选择「随机 N 个」（默认 10 个，可输入 1 到当前不同拼写总数的整数）或「随机全部」。先从所选词库无重复抽取，再随机分批，每批最多 6 个词、80 个字母与符号，完成一批后自动继续，练完本次数量就结束。新的一局、再次练习和切换模式会保留原词库范围与抽取数量，重新抽取；随机全部则重新打乱全部词汇。

界面优先适配手机：词库弹窗使用全屏布局，数量输入唤起数字键盘；竖屏时开始区域停靠底部，主要控件加大点击区域。开始练习后自动定位棋盘，顶部说明收起，平铺棋盘改为五列。保留页面缩放、横屏及桌面支持。

| 字母重叠 | 按预期单词顺序 | 规则 |
|---|---|---|
| 关闭 | 开启 | 数量棋盘；显示当前词义和拼写长度，填满自动检查，依次练习 |
| 开启 | 开启 | 独立牌叠放；当前目标可解，被压住的牌不能选 |
| 关闭 | 关闭 | 自由选字母，不提示目标长度；点击中文词义确认 |
| 开启 | 关闭 | 自由选择露出的字母，再点词义；需要时免费重新排列 |

自由模式中的英文字母仍需按正确拼写顺序排列。匹配成功才消耗字母并移除词义，失败保留选择。点击任意已选字母只放回该字母，也可撤回一步或清空。重叠牌选中后仍阻挡下层，整词消除才解锁。支持短语、重复字母、数字及词库中的常见标点，空格无需输入。

下载保存于当前站点的 IndexedDB，刷新或关闭页面后仍可使用；清除浏览器站点数据会删除它们。可移除词库、取消下载、重试剩余下载；保存成功的书不会因后续失败丢失。每本书以 SHA-256 校验版本及完整性。已缓存的目录在目录请求失败时可继续使用；游戏页面本身仍需静态服务器，不承诺整站离线启动。练习进度当前只保留在本次页面会话。

## 词库来源与重新生成

源库：仓库根目录的 `assets/english-dict/精简词库/英语词库.sqlite`（从游戏目录访问为 `../../../assets/english-dict/精简词库/英语词库.sqlite`）。保留原库，不在浏览器中加载约 71 MB 的 SQLite。

```sh
npm run export:dict
# 或指定源文件；脚本只使用 Python 3 标准库
python scripts/export-vocabulary.py --db "F:/path/assets/english-dict/精简词库/英语词库.sqlite"
```

输出：

- `assets/english-dict/publishers.json`：可独立维护和复用的出版社列表；`listPrefixes` 将源词表 ID 归入出版社。未配置或重复匹配会中止导出。
- `assets/english-dict/catalog.json`：书名、出版社、年级、册次、单元索引、来源、版本摘要及下载大小。
- `assets/english-dict/books/<词表ID>.json`：每书一个词库，保留来源序号、原始拼写、中文、音标、单元字段。

已导出 22 本、9,974 条源记录，约 1.17 MB：人教版 13 本、外研社版 6 本、综合词表 3 本。练习时统一小写和弯撇号，并合并同一拼写的释义，不漏掉选中范围的不同拼写。使用 `vocabulary` 视图，缺音标词条仍可参加拼写练习。

现有词表是历史版本，尚未核验对应新版教材，也没有可靠的单元标注。因此这些书显示「暂缺单元标注，可练整册」，没有虚构第 5 单元。之后可以在原库中补充 `unit`，或提供核对后的序号映射：

```json
{
  "PEPChuZhong7_1": {
    "1": "第1单元",
    "2": "第1单元"
  }
}
```

上例只说明格式，不代表真实教材分单元结果。映射键是 `vocabulary.ordinal`，不是单词或自行推算的页码。

```sh
python scripts/export-vocabulary.py --units "F:/path/reviewed-units.json"
```

生成器校验书 ID、来源序号和单元名称；重新生成并更新下载后，界面自动显示真实单元选项。部分词条有单元标注时，整册仍包含未标注词条。新增书后需重启开发服务器，让白名单包含新文件。

来源与固定版本保留在 `catalog.json.sources`；ECDICT 许可证在 `LICENSE-ECDICT.txt`。不同第三方数据保留各自的权利说明，ECDICT 的 MIT 不覆盖其他词表。

## 验证与部署

```sh
npm test
python scripts/test-export.py
npm run build
# 先运行 npm start，再执行浏览器回归
npm run test:browser
```

浏览器回归需要已有 Playwright 和系统 Chrome；可设置 `PLAYWRIGHT_MODULE` 为 Playwright 的绝对 `index.mjs` 路径，`GAME_URL` 指向实际端口。覆盖四种模式、错配保留、任意字母放回、随机 N / 全部、数量校验、重新抽取、跨批完成与统计、按需下载隔离、失败重试、刷新持久化、移除、目录离线回退，以及 1440×1000、390×844、320×740、844×390 的点击/触摸操作。截图保存在 `artifacts/`。这是浏览器模拟验证，不是真机或手机软键盘验收。

`npm run build` 将页面、游戏与词库模块、样式、图标和 `assets/english-dict/` 下的导出文件复制到 `dist/`，供 small-games 的 Web Shell 和静态部署使用。生产使用 HTTPS，`.mjs` 需返回 JavaScript MIME。无需上传原始 SQLite、测试、脚本或其他项目目录。
