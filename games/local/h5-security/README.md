# 来电之间

一部模拟手机里的防诈骗生活游戏。第一章「搬家第一天」已经可以完整游玩：改投路由器、预约宽带、缴电费，在真实业务与两条诈骗事件链中自行核验、作出操作并查看后果。

## 运行

需要 Node.js 22 或更高版本。

```sh
npm install
npm run dev
```

打开 http://127.0.0.1:4173。运行时没有第三方依赖；开发依赖 Playwright 只用于浏览器验证。

```sh
npm run build
npm run preview -- --host 0.0.0.0 --port 4174
```

`dist/` 是可部署到任意静态站点的完整产物，支持子路径。手机与电脑在同一网络时，可通过电脑的局域网 IP 和端口访问；实际连通取决于防火墙和网络设置。

## 已实现

- 手机桌面、通知中心、消息与历史记录、电话与拨号、购物订单、宽带服务、生活缴费、钱包、备忘录及模拟网页。
- 三项任务的实际输入、查询、选择、提交、回执和余额同步；拒绝所有联系不会自动完成任务。
- 假赔付引诱提交新设备登录码、假安装保证金两种分支。仅打开网页不扣款，泄露和付款分别结算；提交幂等。
- 可中断来电、通话中切应用、中文字幕、37 句本地中文配音及通知铃声；静音和后台暂停。
- 联系记录报告、钱包新设备保护、逐项复盘、继续办事与恢复最近关键节点。
- 本地自动存档、表单草稿与滚动位置保留、窄屏与减少动态效果适配。

本章所有身份资料、号码、网页、验证码和支付均为虚构游戏数据。没有真实拨号、短信、转账、远程控制或外部表单提交。聊天输入采用固定情境回复，通话采用已录制的剧情与回应，不提供任意语音对话。

## 检查

```sh
npm test
npm run build
npm run test:browser
```

浏览器测试需要先启动服务器，默认测试 http://127.0.0.1:4173，使用已安装的 Chrome。

PowerShell 中可以覆盖地址与引擎：

```powershell
$env:GAME_URL = 'http://127.0.0.1:4174'
$env:TEST_BROWSER = 'webkit'
npm run test:browser
```

如没有 Playwright 的 WebKit 运行文件，先运行 `npx playwright install webkit`。测试截图和报告写入 `artifacts/`，不随生产构建发布。

状态检查覆盖安全通关、拒接不通关、两个诈骗分支、输入校验、支付幂等、迟到事件、通话调度及存档恢复。音频检查覆盖播放解锁、异步取消、静音、暂停续播及全部配音映射。浏览器脚本通过界面执行完整安全与受骗路径，额外检查草稿中断、刷新、关键节点恢复和模拟前后台切换。

桌面浏览器和移动视口验证不能代替真实 iPhone、Android 或微信内置浏览器测试。当前未完成这些真机环境的验收。

## 内容与文件

- `src/game.js`：章节数据、事件与业务状态。
- `src/app.js`：手机界面与交互。
- `src/style.css`：手机与桌面呈现。
- `src/audio.js`、`public/audio/`：音效与本地中文配音。
- `scripts/generate-audio.ps1`：使用 Windows 中文声音及 FFmpeg 重新生成配音；日常运行不需要这些工具。
- `docs/game-design.md`：设计范围与后续章节候选。
