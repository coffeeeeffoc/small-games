# 乌龙城：可选机关指引与 Android APK

## 产品取舍

沿用竖屏纸艺小城、主页—选关—游玩—提示/暂停—结算的流程。保留三级免费文字提示，不加金币经济或强制视频。在提示页增加次要入口「看广告 · 机关高亮 30 秒」；玩家看完并通过 SDK 奖励验证后，当前关卡的可交互对象显示描边与标记。只消耗实际游玩时间，暂停/广告/后台不计时；重试、换关清空，不叠加、不重复领取正在生效的奖励。没有可用广告时可继续免费提示和正常游玩。

备选的付费式详细提示会改变原有免费体验；结算翻倍缺少现有货币/成长依据，因此均不采用。广告机会 ID 为 `wulong-city:hint-highlight`，奖励不改变关卡解锁、收藏或主线存档；分享挑战和开发试玩不展示广告。

## 页面与触屏

保持现有提示卡、返回和「再明确一点」按钮，下面增加描边广告按钮，最小热区 44 CSS px。390×844 为参考，320×568 下允许提示页面滚动。加载时禁用重复点击，支持取消等待；完成后停留在提示页，用户点击「回去试试」才继续。高亮是轮廓加圆点，不只靠颜色区分，尊重减少动态设置。

`hint-concept.png` 为在现有截图上更新的效果图（内置 imagegen）；`actual/` 保存实现后的真实浏览器证据，两者不替代 Android 真机验收。

## Android 路线

输出安装式 Android APK，使用系统 WebView 离线加载包内 Canvas/DOM 游戏资源，原生 Java 层接 TapADN；不是 TapTap H5 ZIP，也不是 Tap 小游戏转换包。保留 JS 核心规则，不迁移引擎；美术按本次认可效果图实现，匹配目标的资产可复用。WebView 仅允许包内 HTTPS 源，限制桥接、网络导航与文件访问；APK 启用宿主全屏，隐藏浏览器全屏入口，系统返回键遵循游戏页面和暂停逻辑。

默认调试 APK 在缺少广告参数时禁用广告。正式包必须提供真实媒体 ID/key、广告位 ID、包名、版本、隐私政策地址和正式签名，缺失即失败，不能生成假成功正式包。SDK 在用户自愿请求广告并同意说明后才初始化；拒绝不影响免费玩法。广告关闭/跳过/失败不等于奖励验证成功。

## 验收

- 触屏走通主页、选关、三级免费提示、广告完成/取消/无填充、机关高亮、暂停恢复、结算、返回；校验计时冻结、重复和迟到回调隔离、试演隔离。
- 验证生产构建与统一 dev 模式；Android 资源随包、原生 bridge 契约、配置拒绝、签名入口及能执行的真实 Gradle 构建。
- 提交准确候选，保留 hooks，验证后推送 dev；广告真实填充、TapTap 后台审核和物理手机验收独立记录。
