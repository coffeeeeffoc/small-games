# 乌龙城 · 移动端小游戏视觉方案

设计基准：竖屏 **390 × 844**。七张同名 PNG 是本次各页面的独立效果图；`implemented/` 放真实运行截图，用于逐页对照。采用竖屏是因为本作的 480 × 520 短场景、场景点按/拖动和底部双拇指操作适合一屏完成。主页与每个内容页独立切换。

## 风格与公共参数

- 手绘 2.5D 乌龙小城：青绿瓦檐、奶油墙、石板街、暖金灯光，材质、光影和小岔保持一致。青绿色 `#234f51` / `#76aaa0`，奶油 `#fff4d8`，黄 `#efc466`，橙 `#d98047`。
- 主按钮采用厚实金黄形状，次按钮用青绿或奶油；有浅色内高光、2 px 外边、底部实色投影。按下时下移约 3 px，减少投影；不依赖悬停状态。
- 页面标题 26—32 px，主页题字约 70 px；正文 13—16 px。标题可用楷体回退，功能文字保持清晰。长标题、目标和提示允许必要换行。
- 每个圆形工具按钮有效热区至少 44 × 44；左右键约 66 × 72，跳跃约 84 × 84。暂停图标只使用两根等宽、等高、分离的实心竖条。
- 顶、底边加宿主安全区。小屏优先压缩装饰画高度和留白，保留触控热区、真实目标、反馈与谜题场景。原生小游戏由宿主全屏承载；效果图的“全屏”仅用于 H5 暂停页。
- 页面标题、当前关、章节、提示、结算、解锁和记录均读取真实内容数据。没有生命心、星级评分或虚构收集品。

## 七页布局

表中位置以 390 × 844 为视觉锚点；安全区和长文本可增加必要内边距。艺术背景可以裁切，场景必须保持 480:520 比例。

| 页面 / 效果图 | 布局与必要内容 | 主操作与返回 |
| --- | --- | --- |
| 主页 `home.png` | 上方“乌龙城”题字和一行副题；中央大幅小城插画；右上小图标入口；下方一个金黄开始/继续按钮，下面选关。底部主按钮约 y 650，次按钮约 y 740。 | 开始/继续 → 游玩；选关 → 选关；手记 → 记录；帮助/设置按需进入对应页。 |
| 选关 `levels.png` | 返回、页标题；一张奶油章节卡，含章节名和 **5 列 × 2 行、每页 10 关**；当前关金黄，已通关用“过”印章，锁定关显示锁；卡底左右翻章与 `1 / 10`；总进度 `已完成 n / 100`；继续按钮。 | 十章可翻阅，普通玩家只能进入已解锁关；继续进入当前目标关；返回主页。 |
| 游玩 `play.png` | 顶部仅返回、关卡标题、暂停；一行当前目标；中部场景约 x 15 / y 150 / w 360 / h 390；场景下独立反馈条；底部左/右按钮、提示和跳跃。L01 为“出口很害羞”，奶油室内、会走的小脚木门、黄色帽子小岔，无生命条。 | 场景直接点按/拖动；左右移动和跳跃可多点触控；提示 → 提示页；暂停 → 暂停页；返回 → 主页。 |
| 暂停 `pause.png` | 独立页面，“稍作歇息”；中央喝茶插画和当前关牌；下方依次继续、重试、返回小城；音效开关，H5 可显示全屏入口。 | 继续恢复原局；重试重置当前关；返回主页。暂停及切页释放持续输入。 |
| 提示 `hint.png` | 独立页面，“小城提示”；上方少量点按/拖动/移动/跳跃图示；奶油卡只显示当前一级提示和 `提示 n / 3`；“再给一点提示”；底部回到关卡。L01 插画演示背对门。 | 逐级显示真实三段提示；回到关卡保留探索状态。 |
| 记录 `records.png` | 独立页面，“奇遇记录”；小手记插画与 `已发现 n / 100`；奶油记录列表，一屏约 3 条，每项只显示关名、短记录与完成印章/锁；较多记录在内容区滚动。 | 返回主页；记录由通关事实产生，无额外收集机制。 |
| 结算 `result.png` | 独立页面，“奇遇完成！”、红色“过”章；欢呼插画；当前关、笑点与一行奇遇记录；金黄下一关，下方再玩一次和返回小城。L01 笑点“下次别这么直接。”。 | 下一关按配置推进；再玩重试；返回主页。第 100 关替换为完结主操作。 |

章节真实名称依次为：出门就有乌龙、街坊各有想法、日常不按常理、沿河慢慢逛、云巷的小麻烦、老街的新办法、街角藏着答案、夜市也有脾气、屋顶上的奇遇、百日乌龙大会。效果图中的章节名和已发现数量是展示状态；实现使用上述真实配置和存档。

## 先图后实现的生成记录

1. 先并行生成七页竖屏构图和无 UI 城市场景。最早完成的游玩、选关图在实现前提供给主代理，确定青绿小城、暖金灯光和厚实按钮风格。
2. 核对真实谜题后，用 `image_gen` 编辑游玩与选关图：L01 改为会走的害羞门室内；删生命心；选关改为每页 10 关、10 章、通关印章。两张最终图落盘后主代理开始实现 UI。
3. 继续编辑暂停、提示、记录和结算，使标题、三级提示、谜题记录和结果都来自真实关卡，并去掉星级机制。初版保存在 `concepts/`，仅供美术过程追溯，验收以根目录七张 PNG 为准。
4. 在最终游玩图指导下生成空室内背景和透明小岔；保留原图，常规裁切/缩放后导出产品素材。四个内容页插画由最终效果图无 UI 区域裁切。
5. 主代理保存实际 390 × 844 运行截图到 `implemented/`，逐页核对艺术素材、页面关系、场景比例、触控区域和真实数据。运行截图属于浏览器/宿主模拟验证，不能代称真机验证。
