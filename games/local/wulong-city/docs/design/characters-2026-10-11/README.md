# 多人关卡角色区分

2026-10-11，沿用 `mobile-2026-10-06` 的竖屏构图、青绿与奶油色小城，以及暖光立体童话角色风格。

小岔继续使用黄帽、绿衣、橙围巾和背包。新增八个人物素材：围裙服务员、蓝制服值班员、银发眼镜爷爷、卷发红衣阿姨、长辫紫裙姑娘、绿帽大叔、紫背心演员、蓝帽邮差。脸型、年龄、发型和服装同时区分，不仅换衣服颜色。

## 分配与绘制

- 「本店只准堂食」使用小岔、服务员和值班员三种形象。
- 「队伍已经扎根」的三位排队居民使用爷爷、阿姨和姑娘；进入窗口的小岔仍是主角。
- 排队居民的申请表移到胸前，保留完整头脸和发型，避免表格遮挡人物辨识特征。
- 长话阶梯、贺卡房屋、长话桥和庆祝会分别使用爷爷、大叔、阿姨和演员。
- NPC 不读取主角移动状态，不随主角走动一起晃动。重复游玩时人物身份保持稳定。
- 地图拖动预览、狗背上的小岔和记忆窗里的过去小岔保留主角形象。「奖杯颁给画外的你」只绘制一个小岔。
- 透明人物按脚部基线绘制；素材按需加载，缺失时使用各角色独立的发型、帽子、服装和眼镜等 Canvas 降级形象。

八个人物的完整透明设计图保存为 `character-sheet.png`；产品素材位于 `assets/art/characters/`。大叔和邮差等素材可继续用于后续关卡。现有点击、拖动、碰撞和存档坐标保持原有契约。

## 验收

在实际生产构建中检查 390 × 844 与 320 × 568 的手机浏览器模拟画面：餐厅三人形象不同，队伍三人形象不同，素材无底色、未拉伸、脚底对齐。使用真实触屏输入完成送饭、服务队伍与演员庆祝会，覆盖主页、选关、游玩、暂停、结算和返回；另验证素材加载失败及迟到加载的降级行为。完整结果见 [验证记录](verification.md)。浏览器模拟不等于手机真机或原生平台验收。
