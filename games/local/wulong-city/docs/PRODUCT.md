# 乌龙城

这座城市，总差一点才正常。原创二维短关卡喜剧解谜，小岔的一日维修工单。

旧《贴纸维修所》、贴纸版《乌龙维修所》与暂停/反向/变轻统一能力主线全部作废。固定走、跳、点、拖，谜题由场景对象各自的行为产生，不设检修模式、能力树或统一道具配对模板。

原生 HTML / Canvas / JavaScript，零运行依赖，`npm start` 后浏览器访问 http://localhost:4174。也可以直接打开 index.html。手机竖屏优先；电脑方向键/A D 与空格，触屏底部按钮。带把手物件可拖；场景操作点支持 Tab/Enter，拖拽点支持回车抓取、方向键小步调整、回车松开。仅 L03 有明确抓取姿态的主角可被拖动。重要拖拽抓取区至少44 CSS像素。

前四章各五关：先出得了门、街上的东西各有想法、邻居的问题不止一点点、逛完这里就回家；第五章“回家以后，还有新乌龙”五关，第六章“明天，也很不正常”一关，总计 26 关。依次解锁，保存本机维修记录；三级提示无限制。真实暂停、选关、重试、声音、全屏永远可靠。没有账号、联网后台、广告、付费或设备权限。

分享体验通过唯一的 `challenge=1..26` 公开参数选择一关，与主线进度独立；朋友可以直接尝试同一道谜题，解完后从结算分享自己的邀请。已完成旧 L20 / L24 的存档分别自动开放 L21 / L25，其余旧记录与当前关保留。

首关展示两个“今日试演”入口，让第一次进入的人直接试心事称重或遥控距离的笑点，不必先通24关。试演沿用分享体验的进度隔离，重玩不解锁主线；返回恢复进入前的首关状态和提示级数，不清空刚才的探索。主线仍按原来的顺序继续。

实现顺序：L02 → L08 → L09 → L11 → L13 → L18，各自实际输入试玩后继续；再补齐其余14关。可用 `?dev=1&level=2` 开发选关，普通界面不提供自动过关。逻辑结果完成才结算。全部采用原创程序图形、合成音效，不声称市场查重或正式素材验收。

设计取舍：以固定世界坐标保证触屏缩放与碰撞一致；共用绘图、输入与轻平台物理，每关保留独立因果状态。没有引擎、服务器业务、资源下载或新的全局解谜能力。
