## 目录、入口、环境和玩家

- 目录：`games/local/vibeJam-myself-history-guess`，主仓库普通目录，非子模块。包名 `here-and-then`。
- 核心循环：观察历史想象全景 → 在现代地理底图落点/搜索 → 推断年代 → 揭晓双维误差与线索/来源 → 下一幕/手记。目标是愿意阅读、喜欢历史地理推理的轻度玩家；不定位为精确历史考证。
- 已有目标：独立 H5 / 桌面 Web（`dist/index.html`），Shell 聚合路由 `#/games/vibeJam-myself-history-guess`，打包后静态入口 `games/vibeJam-myself-history-guess/index.html`。本游戏没有微信/B站等原生小游戏适配或原生产物，不将浏览器运行当作原生验收，也不新增平台。
- Three.js 全景与 Leaflet 本地 Natural Earth 底图；28 张本地图片、本地场景 JSON、浏览器本机存档和可选 Web Audio。无账号、服务器、多人或运行时外部地图/字体请求。资料外链为可选阅读，不影响游戏完成。没有跨设备同步或 Service Worker 离线首开。
- 本轮独立预览：`http://127.0.0.1:4188/`。已比较 HTTP HTML 与当前 `dist/index.html` 完全一致。Shell/同源嵌入的发布集成由总负责人继续验证。

## 优先问题、实际修改和通过条件

1. **确认缺陷：手机全屏被隐藏，首页/结算缺入口，旧按钮没有状态同步。** 复现：基线 390px 或 305px 打开游戏，`#fullscreen` 被 `display:none`；首页也没有按钮。玩家不能按需求主动全屏。改为复用协调者的公共 `fullscreen.js` 和 `data-game-fullscreen`；游戏请求完整文档，保留 HUD、地图、年代控件，首页/游玩/结算/原生 dialog 都可切换。通过条件：完整普通→全屏→操作→退出→继续，保存数据不变，失败/不支持反馈准确。对应浏览器回归通过。
2. **确认体验缺口：进入场景后只能返回首页查完整规则，窄屏规则字过小。** 复现：基线场景中仅有场景提示，查计分/公元前需要离开。新增同一份 `help()` 的“玩法”入口，移动首页规则字体恢复 12px，保持 44px 触点；没有复制教学或增加强制步骤。通过条件：305px 可打开、滚动阅读、关闭后同幕同分同输入；限时规则仍明确说明持续计时。CUA 和脚本均通过。
3. **未证实的长期瓶颈：28 幕熟悉后是否只剩记忆答案。** 保留为体验假设，没有用额外场景/签到/排行榜掩盖。优先验证跨日重玩和推理迁移，再决定是否投入有史料依据的主题内容。

显示切换同时取消全景尚未结束的 Pointer 手势并刷新尺寸，复用现有 `cancel()` / `resize()`。首轮没有改计分、题库、历史事实、后台倒计时或存档格式。

## 主要排位 / 好友挑战规则

固定五幕题组共 450 秒，所有挑战和玩家使用同一组条件；地点与年代原算法各 2500 分，总分上限 25000。完全完成五幕才能上榜，提前退出或到期未完成为非合格成绩。每幕提示最多一次、扣 500 分，重复提示/提交均拒绝；揭晓后才能进入下一幕。总有效分高者在先，同分按服务端耗时少者在先；完全相同分与时间的并列、全榜排名、每人最佳由共享后端处理。与本机五幕纪录、离线练习明确隔离。

初始/后续题目视图只给当前图片与观察线索，不给场景 ID、地点、经纬度、年份、标题、完整题库或未使用的提示。提交后才返回当前幕答案、误差、扣分和解释。服务端校验真实地图范围、公元前 3000 至公元 2026 的整数年代且排除 0 年；未知操作及客户端 `score` 等额外字段被拒绝，分数用已有 `scoreGuess` 重算。开始、截止、身份、房间成员、持久化与动作序列幂等仍由共享服务负责。

图片以 SHA-256 前 16 位命名，`public/assets/competition/*.webp` 共 5 张约 1.69 MB；不将含城市名的文件名交给排位客户端。规则版本包含五幕内容及图片内容散列，内容改变隔离榜单。更新原图后需同步生成该目录的同散列图片；测试会检查文件与原始资源逐字节一致，防止发布过期或漏资源。`world.json` 和 `cities.js` 为公开地理参考数据，与题目答案隔离。

固定公开题组会被记住，图片也可被识别；当前防护不能证明玩家没有检索或辅助工具。该榜衡量此固定挑战的最佳合法操作成绩，不等于历史掌握程度。服务端用时不采信客户端，客户端 Canvas 内不重复计算比赛截止，由共享 HUD 展示服务器 deadline。
