# 此时·此地原生移动入口设计

竖屏 Canvas，安全区外不放操作。复用现有全景图片、地图与评分规则，原生宿主图片/触摸/存储能力，无 DOM、WebView。现有 Web 存档不改动；原生存档单独命名并按场景 ID 校验。

主页 → 继续/五幕旅途 → 观察场景、地图落点、年代数字键盘 → 提交 → 解说/地图对照 → 下一幕 → 总结。选关提供全部28幕单幕练习；主题旅途复用三条现有路线。设置选择全域/中国与每幕90秒或悠闲模式。帮助、暂停使用独立页面，返回路径单一；原生不展示全屏按钮。

原生旅途记录完成场景与最高成绩，无虚构联网成绩或奖励。好友挑战只有已配置服务且宿主支持时才提供真实回调入口。学习解说展示原有史料和AI艺术复原声明。

触摸按下和抬起须属于同一触点，滑出、移动超过14像素、取消和多指均取消该次按钮操作。后台自动暂停，恢复须主动继续；倒计时只累计可见游玩时间。旋转/安全区变化重排且保留局面。页面主要热区至少44逻辑像素。
