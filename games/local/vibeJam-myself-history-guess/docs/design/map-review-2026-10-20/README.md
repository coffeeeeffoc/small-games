# 地图替换：来源与接入范围

用户目标：修复 TapTap 反馈的“游戏、实机视频涉及中国地图问题”，保留观察历史场景、选择地点和年代的玩法。

## 已核实的问题

- `scripts/prepare-map.mjs` 直接使用 Natural Earth 1:110m Admin 0 Countries；仅简写名称、压缩坐标，没有国内地图内容审核依据。
- `public/data/world.json` 在台湾岛处的要素名称为“中华民国”；`src/map.js` 将其按 `country-label` 绘制。
- “中国”要素包含大陆和海南岛两个面；现有绘制没有南海诸岛及相关线段。
- H5 的 `src/map.js` 和原生/竞技的 `competition-renderer.js` 共用此数据，必须同时处理。仅剪掉视频中的地图不能修复游戏本体。
- 当前工作区存在其他会话的 H5 布局和构建改动，本任务保留这些改动。

## 已验证的官方素材

- 发布页面：[湖南天地图标准地图服务](https://hunan.tianditu.gov.cn/sc/subApp/tjxz/index.html)，页面标明主办单位为湖南省自然资源厅。
- 页面直接引用的[世界地图 JPG](https://hunan.tianditu.gov.cn/sc/subApp/tjxz/images_old/4o28b0625501ad13015501ad2bfc0104.jpg)已下载并目视检查。
- 图内审图号：`GS(2016)2956号`；署名：国家测绘地理信息局监制。此编号属于该原图，不能据此声称本游戏已获地图审核。
- 原始文件长度：350762 字节。
- SHA-256：`c3f871680197cda6aa64eb4bf8868a71aa2bb0e7f7d28b1231b95fa83f12dcbc`。
- 原图投影与目前 H5 的 Web Mercator、原生的经纬等距投影均不同，不能只替换图片地址而继续沿用原坐标变换。
- 官方页面要求保留审图号、监制署名；对地图内容再次编辑（包括放大、缩小和裁切）改动后的公开使用要求送审。该页面没有明确豁免游戏中缩放、点位叠加的交互用法。

## 已评估的接入路线

1. 联网地图服务：使用开发者本人申请的 Key 和相应授权，保留服务商地图标识及审图号。需要确认 H5 与原生平台支持、网络域名、坐标系、请求限制和失败恢复，不允许用未授权的公开瓦片地址或第三方 Key。
2. 官方标准原图：保留完整原图与编号，独立校准坐标映射，保持离线。交互展示方式是否需要再次送审应向审核方/主管部门确认；不将“官方来源”写成“游戏已合规”。

2026-10-20 用户要求复用移动端缩放和点位标记；了解高德费用后，明确要求寻找免费方案，必要时自行实现简单地图。尚未替换运行数据、重新打包或提交平台审核。

## 高德方案与费用核实

- [高德技术服务许可说明](https://lbs.amap.com/faq/advisory/authorization/43168)将个人研究学习用途的免费配额与商业使用许可区分。公开上架、广告变现不能据免费配额推断免费商用。
- 2026-10-20 查询[官方定价](https://lbs.amap.com/upgrade)：技术服务许可基础版标价 50,000 元/年，高级版 100,000 元/年；具体账号权益、适用许可和商务报价仍需确认。
- 页面同时列出初创/小微企业“乘风计划”，现阶段为定向邀请，不假设本账号已符合或获准。
- [JS API 世界地图说明](https://lbs.amap.com/api/javascript-api-v2/guide/map/world-map)：世界地图属于高级能力，需通过工单商务咨询并为 Key 开启权限。不能把国内动态地图权限当成海外详细地图权限。
- [安全密钥说明](https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode)：JS API Key 与安全配置应在 SDK 加载前设置；生产环境推荐 `serviceHost` 代理，不把服务端安全密钥写入公开包体。
- 技术上，H5 可沿用 `createGuessMap` 的对外接口，替换内部实现为 `AMap.Map` 和 `AMap.Marker`。需保留高德标识、处理现有题库坐标系与地图坐标系差异，并验证加载失败、重试、隐藏页面、销毁与恢复。
- 纯 Canvas 原生小游戏不能直接使用依赖 DOM 的 Web JS API；不得把 H5 接入完成称为原生平台已适配。
- 高德已不作为当前零付费目标的首选；未购买服务、未调用第三方 Key。

## 免费候选：天地图 + 现有 Leaflet

2026-10-20 核对结果：

- [国家平台开发许可申请说明](http://lbs.tianditu.gov.cn/authorization/authorization.html)明确允许在控制台免费注册申请开发许可 Key，并实行 API 调用配额管理。该页仍以“2020版”描述配额机制，未给出本游戏账号当前的额度，不能据此承诺无限量免费。
- [国家基础地理信息中心的平台说明](https://www.ngcc.cn/zdchgc/tdtjs/)明确包含面向企事业单位服务和中小微企业增值应用开发。当前公开[服务条款](https://www.tianditu.gov.cn/about/service)中未发现高德式固定商用年费规定，但“未发现收费条款”不等于已取得本游戏用途的全部授权；账号申请协议、应用审核与配额仍需核对。
- [湖北省自然资源厅2021年使用手册](https://zrzyt.hubei.gov.cn/bmdt/zrzyyw/202109/P020210913416524745240.pdf)第8页明确该省节点服务无偿、二次开发需 Key。此依据限于该节点和文件年份，不扩展为所有天地图节点的现行商用承诺。
- [国家平台地图服务文档](http://lbs.tianditu.gov.cn/server/MapService.html)提供 HTTPS WMTS 服务，包含 `vec_w` 矢量底图和 `cva_w` 中文注记，支持球面墨卡托投影。不必为 H5 再加入新的地图 SDK；已有 Leaflet 可以直接加载这些图层，保留拖动、双指缩放、落点和本地城市搜索。
- 官方 API 导航当前指向[应用管理](https://cloudcenter.tianditu.gov.cn/center/development/myApp)和[开发者认证](https://cloudcenter.tianditu.gov.cn/center/development/developerAuth)。旧 `console.tianditu.gov.cn` 在本次环境中连接失败，不应把旧控制台失败误报为地图服务不可用。
- 尚无用户自己的 Key。未借用官网、示例、其他应用的 Key，也未用模拟瓦片冒充真实服务验证。

### 最小接入范围

1. H5 保留 `createGuessMap` 及其调用接口，将旧 GeoJSON 底图和国家标签替换为同一来源的底图、注记图层；保留原有真实经纬度及存档格式，按实际接口坐标系核对地标，不盲目加入 GCJ-02 偏移。
2. 地图来源和与实际图层匹配的审图号应可见；不能沿用当前隐藏全部 Leaflet 控件的 CSS。地图加载失败时提供重试与已有城市搜索，不回退到本次被拒的数据。
3. Canvas/原生入口单独处理瓦片绘制、图片网络域名和触屏输入；H5 接入不能代替原生验收。`competition-renderer.js` 仍在引用旧底图，正式发布前必须一起处理。
4. 影响范围包括 `src/map.js`、地图样式、`competition-renderer.js`、原生图片加载与配置、旧地图生成脚本、素材/发布说明、地图数据测试及浏览器加载失败用例。拿到可用授权后，先做真实底图和手机比例设计参考，再修改运行代码。

自行实现拖动、缩放并不能解决底图来源问题；现有 Leaflet 已经提供这些免费能力。若最终完全不接外部服务，可评估完整官方标准图加本地交互，但必须解决投影校准、清晰度和使用方式确认，不能把本次低分辨率标准图直接按经纬等距贴上去。

## 实施与验收

- 按本次认可效果图落实手机页面的完整样式；替换前保存对应地图页设计，原始地图本体不由 AI 生成或重绘。
- 同步 H5、Canvas、原生资源声明、素材来源说明、下载脚本及地图相关测试。
- 校验地图点选/城市搜索与评分坐标一致，不能只用投影正反算互相验证；另以地图地标核对。
- 验证缩放、拖动、手势取消、小屏布局、暂停恢复、返回、资源失败重试。
- 构建产物中确认旧底图与错误标注不再使用，保存真实浏览器截图与验证记录。
- TapTap 实机视频需要使用修正后的实际包体重新录制；桌面触屏模拟不代替真机或平台复审。
