# 此时此地：移动端多角色复审

本次保留已有竖屏档案与旧地图风格，按 `game-ui-ux` 项目覆盖规则检查触屏热区、信息密度、安全区和生命周期。方案与局部效果图先于代码保存；实际截图对照原 10 月 9 日概念图及本目录 `local-adjustments.svg`。

| ---------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |

| 存档与成长 | 存档题组可串关；已完成关或旧称号可能受扩关影响                  | 核对关卡、题组、结果 ID、有效年份与布尔开发标记；保留已完成关重玩与旧 3/6/9 关称号，增加 42/84/126 关成长里程碑     |

126 关是 28 幕公开场景的主题复习与横向比较，包含 378 个可玩回合，不宣称增加 126 幅新历史图像。新增观察章为 35 秒，比较章为 30 秒，综合章为 25 秒；原第二、三卷仍为 25 秒，在线竞技仍遵循服务端 25 秒截止时间。全部关卡正常逐关解锁。

## 实际验证

环境为 Debian Linux、Node 24.21.0、pnpm 12.6.0、Chromium 151.0.7922.173；生产预览 `http://127.0.0.1:4175/`，使用 Playwright touch 与 CDP 真正的触摸事件。未把手机模拟称为真机验收。

- `pnpm test`：39 项全部通过，覆盖目录/schema、126 关可达性、旧 ID/记录、损坏/串关存档、评分、私有响应、在线截止时间、原生资源加载等现有回归。
- `pnpm build`：通过；构建阶段检查章节内容引用和唯一题组。沿用的公共 fullscreen 普通脚本有 Vite 非 module 提示，不阻断构建，未修改公共全屏实现。
- `PLAYWRIGHT_EXECUTABLE=/usr/bin/chromium pnpm test:review:browser`：完整通过，126 关 / 378 幕全部正常触屏答题、逐关解锁、结算与刷新保存。未创建在线 session、未改变旧五幕最佳分，最终手记为 126 / 126 与 28 幕足迹。
- 手机视口 320×568、390×844、430×932、横屏 844×390：无横向溢出，已显示控件均有至少约 44 CSS px 热区。覆盖主页/帮助/选章/选关/准备/游玩/暂停/结算/返回、真实全景拖动/取消/双指捏合、地图点选、中文搜索、键盘候选/Escape、公元前与非法年份、重复提交、全屏进出。
- 实际等待 45 秒触发新手关超时，恰好记录一次零分；存储拒绝仍能游玩；真实地图请求失败后重试成功。
