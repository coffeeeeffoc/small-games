# 此时此地 · 时空档案与好友挑战

## 产品与美术方案（实现前）

2026-10-09。先完成玩法方案与四屏美术效果图 `concept.png`，再改造代码。效果图展示首页、章节、限时猜测与评分/分享页；其中示例分数和榜单人物仅属于美术排版参考，实际游戏只显示真实成绩和空榜状态。历史影像使用现有 AI 艺术复原素材，不将它们称为史料照片。

以手机竖屏为主：观察影像、上下浏览档案和拇指操作适合竖屏。320–430 CSS px 手机、横向视口及桌面均保留完整流程。纸色 #f3ebdc、墨绿 #203f35、朱砂 #b84e35，中文衬线标题、旧地图线条、邮戳与档案编号；图像承担氛围，操作文案保持简短。主要触控热区不小于 44 CSS px，底部适配安全区。

页面路径：首页 → 探索章节 → 章节小关卡 → 准备 → 观察 / 地图选点 / 年代输入 → 评分 → 下一关或分享。首页另有好友 PK、全站竞逐；玩法、设置和个人手记为独立子页面。游玩时隐藏外围导航。练习提供暂停与本机续局；正式挑战按服务端截止时间计时，返回或切后台不暂停、不重置。

## 核心循环与积分

- 每题观察历史复原图，猜地点与年代，默认 25 秒。结算只显示总分、两个维度评分和超时状态，不公布正确时间、地点、距离或年份偏差。
- 三章各三个小关卡，练习逐关解锁；个人最佳和成长用于记录探索进度，不能上传为竞技成绩。
- 好友 PK：发起者完成五题后获得 24 小时战书；朋友使用同一冻结题组、相同限时，各人一次机会。分享只携带不可猜测的邀请码与战绩，不携带题目、答案、种子或开发参数。
- 全站日榜：可信身份每天一次正式五题，开始即占用当天机会。按统一难度结构轮换题池，服务端判分。
- 全站周榜：北京时间周一换周，累计本周最高五天成绩，允许缺席两天。同分并列，不用网络延迟敏感的速度作加分。
- 成长积分、每关最佳和好友胜负与全站竞技分分离，避免靠刷时长、反复练习或互刷小号上榜。

## 后端与答案边界

预实现可独立运行的 Node 24 + SQLite 服务，持久化身份、题库版本、冻结对局、一次性答题记录与每日成绩。服务端只投影当前题的公开信息；答案评分接口使用截止时间、唯一约束和事务。开发/游客可练习和好友挑战，正式榜要求受信身份。SQLite 适合单实例起步；多副本部署需迁移至共享数据库。

正式题库与客户端练习隔离。现有素材是启动用种子题库，上线前需补充未公开的题目并定期轮换；隐藏答案和限时能提高整理成本，无法杜绝常识传播、截图搜图与串通。不得承诺绝对防作弊。前端离线练习的答案存在客户端，仅作为不计榜的练习；正式比赛仅信任后端。
