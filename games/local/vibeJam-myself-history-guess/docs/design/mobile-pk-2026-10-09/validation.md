## 已验证

- Node 24.21.0、pnpm 12.6.0，生产 Vite 构建通过。
- 游戏规则、章节与 HTTP/SQLite 共 35 项测试通过，其中服务端集成测试 14 项。
- Chromium 手机模拟：320×568、390×844、430×932 与 844×390。无横向溢出，可见触控控件至少 44 CSS px；完成全景拖动、捏合、取消、地图落点、中文输入、公元前、暂停、恢复、重载与真实 25 秒超时。
- 从正常存档走通三章九关共 27 幕，确认逐关解锁、存储不可用降级和素材失败重试。
- 两个独立浏览器完成真实好友 PK 共十次作答，逐题检查图片一致、同猜测同分、只返回评分、邀请分享清洗、重复点击、分享取消、战书回访和服务端计时恢复。
- Shell 生产产物的嵌入入口、返回目录和 390×844 触屏游玩通过；独立入口需经过主页、准备页再开始，评分验证不依赖旧答案浮层。
- 统一开发模式静态检查、5 项规则测试与 10 项生产浏览器检查通过，覆盖独立/Shell 开关、显式关闭、触点取消、拖动面板和 iframe 模式传递。
- Docker 实际构建、非 root 只读运行、健康检查、数据库持久化、重启及替换容器后账号/成绩恢复通过。
- Vite 开发服务拒绝访问 `server/private/questions/*.json`（HTTP 403），私有服务代码和数据库不进入开发静态服务。

详细手机证据见 [verification.json](verification.json)，容器证据见 [container-verification.json](container-verification.json)。已有原生/旧竞技入口的评分隐私验证另见 [native-privacy-2026-10-09](../native-privacy-2026-10-09/verification.json)。

## 统计与公平性

每日正式首局通过可信身份和数据库唯一键限次；周榜查询本周最高五天，同分并列。跨日后不能补交非零分回填，放弃的未答题最终记零。好友挑战与成长均不进入正式榜。普通访客可以好友 PK，其次数约束以访客身份为单位；正式日榜要求稳定可信账号。

服务端测试覆盖冻结题图、幂等与并发提交、完整请求体到达时间、身份签名及 nonce 防重放、跨日/邀请截止、请求字段注入、反向代理限速和数据库重启恢复。

## 实际边界

本次没有发布公网后端、接入真实账号供应商、执行生产压测，也没有进行真实 iPhone、安卓设备或原生小游戏宿主发行验收。手机截图来自桌面 Chromium 触屏模拟。

现有 28 幕是公开种子内容，离线练习可被分析；正式运营需配置独立私有题库并持续更新，清理素材 EXIF/GPS 等元数据。SQLite 采用单实例持久卷，横向扩容前需迁移共享数据库。部署步骤与配置见 [server/README.md](../../../server/README.md)。
