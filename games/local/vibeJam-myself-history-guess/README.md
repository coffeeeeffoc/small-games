# 此时 · 此地

中文历史全景猜谜游戏。参考 `../vibeJam/wenware/PROJECT_ANALYSIS.md` 中的玩法和技术分析，在此目录独立实现：观察全景、选择现代地图坐标、猜测历史年份，再阅读解说。

## 启动

需要 Node.js 20.19+ 和 pnpm。

```powershell
pnpm install
pnpm dev
```

电脑打开 <http://localhost:4175/>。手机与电脑连接同一局域网后，打开终端列出的实际局域网地址及端口 `4175`。若手机不能连接，请检查网络隔离及系统防火墙是否允许该端口。

```powershell
pnpm build
pnpm preview
pnpm test
pnpm test:browser
```

`dev` 和 `preview` 使用同一端口，不要同时运行。`test:browser` 使用本机 Chrome，测试前启动预览；可通过 `PLAYTEST_URL` 指定另一 HTTP 地址。测试截图与结果保存在 `artifacts/`。

构建产物为 `dist/`，可部署到普通静态托管和子目录；资源路径采用相对地址。不要通过 `file://` 双击 HTML。没有原站服务端、账号、联机或排行榜依赖，也没有外部地图瓦片与字体请求。没有实现 Service Worker 离线缓存，重新打开仍需要访问所部署的静态站点。

## 已实现

- 28 幕本地场景（保留原 8 幕，新增中国 10 幕、世界 10 幕）：共中国 15 幕、世界 13 幕。每局抽 5 幕且不重复，优先随机抽未探索场景，全部探索后从最久未玩的场景开始；「中国足迹」从全部中国场景抽取。
- 首页可指定任意一幕练习，收集足迹但不计入五幕最佳分。所有列表、数量、搜索地点随题库自动生成。
- Three.js 球面全景，单指拖动、双指缩放、滚轮与键盘操作；没有 WebGL 时使用可拖动缩放的平面全景。
- 本地 Natural Earth 世界底图、中文地区名称和中文城市搜索，支持长安、汴京等古地名。搜索支持方向键选择候选、回车选点和 Esc 收起，收起后的回车不会误选隐藏候选；拼音输入确认不会提前选点。地图用于地理示意，没有街道瓦片与历史疆域切换。
- 手机竖屏切换观察与地图，底部选年与提交；横屏采用紧凑操作区，兼容安全区域。年份支持滑杆、时代快捷按钮和公元前输入。
- 首页、游玩和结算均可切换整个页面全屏；浏览器不支持或拒绝时明确提示并保留正常布局。游玩中可打开规则，显示切换不会重开场景或丢失输入。
- 不限时漫游、每幕 90 秒挑战、双维度计分、答案坐标对照、完整五轮结算、音效开关、历史资料链接。
- 已发现的场景、最佳分数与未完成旅途保存在本机浏览器；刷新或返回首页后可继续原题、原地点与年代，揭晓进度不会重复计分。限时旅途保留原截止时间，回来时超时会自动揭晓。另开旅途会替换原进度；不保留全景视角。计分发生在客户端，适合休闲游玩。
- 揭晓页串联场景提示、三条观察线索与历史说明，区分艺术复原线索、游戏设定年份和可查阅资料。

每幕满分 5000，地点和年代各 2500。地点误差 30 公里内满分；年代允许按题目区分的误差范围，超出后平滑衰减。公元前与公元换算排除公元 0 年。限时模式切到后台仍继续计时，超时按已填答案计分，未填项为 0。

## 三幕主题旅途

首页一键走进「街巷有回声」「跟着水路走」「石头也会说话」三条路线。每条三幕、不限时，共九个已有来源资料的场景；每幕先给一个不含城市或年份答案的观察问题，揭晓后收录一张观察手记并回看线索与资料。完成后可重走同题，也可直接换下一条主题。

主题旅途满分 **15000**，进度及最近一个主题的本机最佳分独立保存，不覆盖普通或每日旅途，也不提升普通五幕纪录。主题只保存当前一条未完成路线，进入另一主题会替换这份主题进度。AI 图像仍是历史想象复原，不能作为史料，具体年份仍是游戏设定。

分享只含 `route=market|harbor|craft&v=1`，首次打开直接进入所选路线的第一幕，已有同题进度时续练。未知主题、重复参数、与 `daily` 混用或不支持的版本会被拒绝；链接不含场景 ID、坐标、年代或其他查询参数。普通 / 每日入口会清除自动进入主题的邀请状态，避免刷新后跳回旧主题。

```sh
pnpm test:routes:browser
```

## 每日五幕与同题分享

首页「每日五幕」按北京时间换新，同一日期与旅途类型固定五幕及顺序，不受已探索足迹影响。可以使用「中国足迹 / 世界漫游」与 90 秒限时开关；限时与不限时使用相同场景，方便先漫游学习，再尝试限时。结算可同题再练，并保存本机该次同题最佳；已知题重玩不计入普通五幕最佳分。

普通旅途与每日旅途分别保存。进入同题邀请不会覆盖原来的未完成旅途；刷新可通过「继续每日五幕」恢复地点、年代和限时截止时间，原普通旅途仍可通过原来的继续入口恢复。一次保存一条每日进度与最近同题纪录，开启另一日期 / 规则会替换每日进度，普通进度不变。

分享仅包含 `daily=YYYY-MM-DD&v=1&region=all|china&timed=0|1`，不携带场景 ID、地点答案、年代答案或当前地址里的其他查询参数。日期严格校验为 2000–2099 年有效公历日期，重复参数和其他版本被拒绝；分享取消或复制失败有对应反馈。链接用于邀请同题观察，成绩为本机休闲记录，不是线上排行榜。

```sh
pnpm test:challenge:browser
```

## 内容与素材

图片是本项目新增的 **AI 历史想象复原**，不是历史照片或精确考古复原。部分细节可能不符合对应年代；题库明确区分「游戏设定年份」和历史资料支持的事实。完整来源与限制见 [ASSETS.md](ASSETS.md)。

- `src/scenes/*.json`：每幕独立配置；添加 JSON 和图片即可接入，无需修改清单或渲染代码。
- `src/rounds.js` / `src/catalog.js`：自动发现、统一校验、补齐初始视角、生成中文地点搜索；`src/cities.js` 保留通用城市底库。
- `vite.config.js` / `scripts/check-catalog.mjs`：开发和构建入口检查配置、重复 ID 与缺失素材。
- `src/game.js`：距离、年代、计分、抽题与倒计时计算。
- `src/viewer.js` / `src/map.js`：全景与地图输入、资源生命周期。
- `src/main.js` / `src/style.css`：首页、游玩、揭晓、足迹和移动端布局。
- `scripts/prepare-map.mjs`：从 Natural Earth 重新生成精简中文底图，正常运行无需执行。

自动验证涵盖桌面与手机模拟、触控事件和完整流程；不等于真实 iPhone Safari、微信内置浏览器或安卓设备实测。

场景扩充步骤与架构决策见 [场景接入说明](docs/scene-authoring.md)。新增素材的完整提示词保存在 `scripts/scene-art-prompts.json`。浏览器回归逐幕验证整个题库，不依赖固定的五个中国题目。
