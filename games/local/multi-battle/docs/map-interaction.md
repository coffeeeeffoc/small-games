# 地图与拖拽交互

更新：2026-09-13。此文记录地图交互实际规则；卡牌能力、伤害、金币收入与流派保持原设计，见[规则与验收](rules-and-validation.md)。

## 场景与阶段

- 整局在「青苔遗迹」地图中展示，角色使用带武器的透明全身棋子；地面、石柱、溪流、树林和火盆构成共同空间。
- 备战阶段商店、手牌和金币栏悬浮于地图边缘。六个己方位置保留前后排意义，点击或拖动均可操作。
- 低高度横屏把经营面板移到右侧、部署位置集中左侧；竖屏采用顶部商店、底部手牌。固定五个货位全部可见，手牌可用左右按钮翻页。
- 战斗阶段移除商店、手牌、金币/升级、详情与排名面板。地图中只保留简短回合信息、菜单/音效和暂停/倍速/快速结算控制；结果在地图上居中显示。

## 拖拽规则

| 起点 | 落点 | 行为 |
| --- | --- | --- |
| 商店角色 | 己方空位 | 一次购买并部署，最终手牌容量不增加 |
| 商店/手牌角色 | 不同角色的战场位置 | 购买（如需要）并部署，原角色回手牌；场上角色调位则交换位置 |
| 商店/手牌/战场角色 | 另一个同名角色 | 显示等级叠加预览，确认后消耗材料；商店来源确认时才扣金币 |
| 商店商品 | 手牌区 | 只购买，进入手牌 |
| 手牌角色 | 己方空位 | 出战；场上角色拖到空位则移动 |
| 场上角色 | 手牌区 | 撤回，容量不足则不改变状态 |
| 商店/手牌装备 | 场上或手牌角色 | 购买（如需要）并穿戴；满两槽时选择替换，旧装备回手牌 |
| 商店/手牌单目标法术 | 合法角色 | 购买（如需要）并立即施法；目标区域限制仍按卡文 |
| 商店/手牌双目标法术 | 合法角色 A | 进入选目标阶段，继续点 B，核对后确认；取消不购买、不消耗 |
| 无目标法术 | 地图或商店 | 执行全队/刷新效果；定向进货拖到商店后选择类型，也可直接拖到对应类型商品 |
| 自有角色或手牌 | 出售区 | 卖出获得1金；高于L1或携带装备的角色先确认 |

同名角色拖放默认叠加预览，需要仅交换同名角色位置时可点选「调整站位」，再点目标。手牌中的非角色道具不会成为法术或装备的角色目标。

## 原子性与取消

购买附带使用通过 `buy.use` 复用已有部署/叠加/装备/施法规则，一次提交、一次保存。以动作完成后的手牌容量检查：满10张手牌仍可直接购买并部署到空位；购买并替换占用位置若产生第11张手牌则整体失败。失败不扣金币、不移除商品、不写经营记录、不推进随机序列。

使用 Pointer Events，移动超过8像素才进入拖拽；轻点继续走卡牌详情路径。抬手按实际命中的目标结算。非法落点、Escape、`pointercancel`、窗口失焦、隐藏和尺寸变化会结束拖拽；产生过拖动的手势不会再触发一次点选。可拖卡牌禁用原生拖图和浏览器手势，手牌左右翻页按钮解决卡牌拦截横滑后的访问问题。

## 战斗表现与生命周期

战斗结算仍由纯模拟器生成真实事件序列。展示层读取每次事件的行动者、目标和前后状态：近战接近目标挥砍，远程发出弹道，目标反击；命中时同步血条、护盾、数字和音效。治疗、召唤、阵亡分别使用恢复光效、出现和消散动作。

每个事件默认1100毫秒，2倍速缩短为550毫秒；动作命中点为事件时长46%。动画使用 Web Animations，同一动画时钟决定命中；暂停保留当前动作和剩余播放时间，失焦或隐藏自动暂停。地图重建前销毁旧动画。减少动态效果偏好下直接呈现结果，保留游戏进程。

角色移动是战斗表现，不重新计算射程、碰撞或寻路；前排优先、嘲讽、攻击顺序及同时反击仍使用已有规则。刷新恢复战斗会从锁定阵容的事件序列开头重播，结算只执行一次。地图展示不会消费游戏随机数。

## 维护与验证

- `src/scene.js` / `src/scene.css`：地图、全身棋子、战斗动画。
- `src/arena-ui.css`：悬浮经营、手牌翻页及手机布局。
- `src/drag.js`：统一鼠标/触控手势与取消。
- `src/app.js`：拖放目标规划、预览、阶段切换和动画播放。
- `src/economy.js`：购买附带使用的原子结算。
- `npm test`：经济与游戏规则；新增满手直购、非法操作回滚检查。
- `npm run test:map`：真实鼠标拖动、CDP触控、取消、购买/部署/法术/装备/转移、动画位移及横竖屏布局。
- `npm run test:browser`：保留点击操作、完整对局、存档恢复与图鉴的回归。

最终验证结果见[实现记录](implementation-status.md)。浏览器模拟尺寸与触控通过不等于物理手机设备已实测。
