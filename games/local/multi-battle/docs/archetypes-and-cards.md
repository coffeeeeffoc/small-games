## 1. 目录范围与卡面约定

本版设计 6 个流派，各 3 角色、2 法术、1 装备；另有中立 4 角色、4 法术、4 装备，共 **48 张：22 角色、16 法术、10 装备**。临时召唤物单独定义，不属于商店卡牌，不计入 48 张。中文名可以改，流派 ID 和卡牌 ID 保持稳定。所有数值都需要实测，不代表已经达成平衡。

流派是构筑指南，不是阵营人数羁绊。凑到三名同流派角色不会凭空增加属性；卡面列出的事件和条件才产生效果。三角色骨架只是搭配示例，玩家可以只用一个组件或混搭六个流派。

| 卡面术语 | 本目录的精确定义 |
| --- | --- |
| T / L / P | T 为固定品阶，L 为角色永久成长等级，P 为指挥官等级。商店只产生 T ≤ P 的卡。角色初始 L1，同名叠加使目标 L += 材料 L，材料销毁。 |
| 基础攻/血 | 表中是 L1、无装备时的 A0/H0。成长后 A=A0+(L−1)，H=H0+2×(L−1)。L 无玩法上限；T 不随 L 改变。 |
| 成长 +N〔gain〕 | 永久 L += N，一次加 N 只产生一次成长事件。 |
| 联动 +N〔link〕 | 永久 L += N，但不再触发任何成长监听，阻断共鸣自我连锁。 |
| 升级事件 | 仅来源 gain、merge，且发生了正增长；transfer、link、购买 L1 角色、换装都不属于升级事件。 |
| 转移事务 | 等级移动的统称，包括全量转移 LevelTransferred 和交换 LevelsSwapped 两种独立事件。只移动 G=L−1；全量转移使 A 变 L1、B 增加原 A 的 G，交换则对调 G。每次操作只发对应的一种事件，交换不发两次转移事件。A/B 必须不同，装备、卡牌身份和准备效果不随 G 转移。 |
| 其他 / 最低等级 | “其他”排除技能持有者；“最低等级”只看指定区域中的 L，平局按前排左至右、后排左至右选择。手牌目标平局按手牌从左至右。 |
| 下场战斗 | 指本回合紧接的战斗；增益附着角色实例，到该场战斗结束全部清除，未上场也清除。不能跨回合囤积，不能通过转移等级移动。 |
| 护盾 N | 战斗内可相加的 N 点吸收伤害值；先消耗盾，再扣生命，不影响最大生命、成长或出售收入。 |
| 回合 / 每场次数 | 角色和装备实例各自计数，离场、回场、换装不重置；同名角色叠加后，各对应效果已用次数取目标与材料的较大值。材料实例销毁，不将其剩余次数叠加给目标。 |
| 在场时前 N 次 | 该实例在战场上实际监听到的前 N 次符合条件事件，不是指挥官全局动作序号；同名角色或装备的不同实例分别计数。无合法目标时不触发、不占次数。 |
| 成功施法 | 法术目标和区域校验通过，扣除手牌并完成效果后产生一次 SpellCast。无目标、取消操作、目标无效均不消耗法术，也不计数。 |
| 默认生效区 | 角色被动和装备被动默认只在战场生效；手牌里的同名角色不会旁听事件。法术从手牌使用，合法目标区域在卡文中明确列出。 |
| 普攻 / 技能伤害 | 只有主动普通攻击产生“攻击后”；反击不产生攻击后。技能可按卡文选全部存活敌人，无视前后排和嘲讽，但正常扣盾、扣血。 |
| 随机敌人 | 效果真正结算时，从所有存活敌人中等概率选一个；每次独立重选。无存活敌人则该段效果结束。 |
| 生命增加 / 恢复 | 装备生命是固定最大生命加值；战斗开始满血。恢复不超过当前最大生命；恢复不会提高永久成长。 |
| 卡面产金 | 角色出售基础 1 金之外的奖励，受每玩家每回合额外产金合计 3 金上限约束。免费刷新不是付费刷新。 |

角色原价均 3 金、法术 2 金、装备 3 金，与 T 无关；卖出角色固定 1 金，其他手牌道具卖出 1 金。装备品阶和附加属性固定，不随 L 缩放；每角色最多两件装备，同名装备不能同时佩戴。普通换装免费，单纯装上或脱下装备不触发成长、返金或免费牌。

商店固定为 **3 个角色槽、1 个法术槽、1 个装备槽**。卡面折扣只属于当前商品实例，购买或刷新替换后消失，冻结保留该实例时保留；折扣最低成交价 1 金，不折现、不返金。除明确写出的折扣外，其他价格不变。

## 3. 共鸣成长（resonance）

**核心循环：** 给一个角色施加 gain 或 merge，令战场上的共鸣组件输出受限的 link 增长。每张组件有明确次数限制；link 不触发下一轮监听，因此连锁是有限分发，不是无限升级。通过更换本回合主动培养对象，把多份收益留在不同角色身上。

- **前期 P1–2：** 鸣律学徒、回声卫士配中立前排；用齐鸣练习制造两次独立升级事件，先保证两个角色能上场。
- **中期 P3–4：** 找合奏领主，安排本回合仍有可用触发次数的角色接受合并或训练。不要把所有金币都花在无目的刷新上。
- **后期 P5：** 用资质点拨、传承法术把已积累的成长投入高品阶战斗核心；保留多少共鸣辅助取决于剩余养成回合。
- **三角色骨架：** 回声卫士在前，鸣律学徒与合奏领主在后；另外三格可放承伤、军械或咒术输出。
- **转型与混搭：** 咒术角色的施法成长、商贸角色的刷新成长都可成为共鸣输入；传承可把辅助角色积累的 G 搬给输出位。
- **弱点：** 辅助占战场格；一次大合并只算一次事件，不能按合并等级重复刷触发。把辅助留在手牌也不会生效。

## 4. 传承换核（legacy）

**核心循环：** 先在容易获得的角色上积累 G，再通过全量转移或交换，把成长配置给具有适合当前对手技能的角色。传承组件只在真实等级变化后给当回合战斗补偿，不因反复转移创造永久成长。

- **前期 P1–2：** 提前部署薪火幼徒，等待后续回合开始时成长；用普通战斗角色承接压力，并留意中立的薪火交接。
- **中期 P3–4：** 用传承之契把幼徒或其他已养成角色的 G 交给继承剑士，并取得接收者的本场护盾；换位授业可以交换两种战斗定位的成长，避免重新培养。
- **后期 P5：** 传世守望为真正的转移提供本场保护；按对手阵容把成长投给破盾、开场伤害、治疗或军械核心。
- **三角色骨架：** 薪火幼徒供养，继承剑士输出，传世守望承伤；完成转移后，供养位可继续培养或出售腾格。
- **转型与混搭：** 共鸣能提供多份可转移成长；军械护盾随新核心 L 变强；咒术准备效果留在原角色上，换核时需重新规划施法目标。
- **弱点：** 转移后来源会退回 L1；同一份 G 不能同时留在两边。T、装备和战斗准备效果不会跟随等级搬家。

## 5. 商贸刷新（commerce）

**核心循环：** 付费刷新寻找想要的卡，同时兑现少量成长、临战攻击或当前商品折扣；决定什么时候买、什么时候卖，才能避免刷新成本吞掉收益。这个流派仍然要付刷新费，不提供无成本无限买卖。

- **前期 P1–2：** 巡街掮客配旅行算盘，把本来就要进行的第一次付费刷新变成收益；盘账掌柜只补贴有限的一次角色出售。
- **中期 P3–4：** 云市巨贾让新刷出的第一张角色降价；定向进货用于缺法术或装备时重抽对应槽，不能喂付费刷新组件。
- **后期 P5：** 通过运营更容易找到目标牌，再把金币转为合并、装备和高阶法术；刷新本身不能替代战斗实力。
- **三角色骨架：** 巡街掮客保留成长、盘账掌柜帮助卖旧核心、云市巨贾提供折扣；真正开战前可按收益需要替换已用完次数的商贸组件。
- **转型与混搭：** 掮客的 gain 能带共鸣；更便宜的角色可合并成传承资源；找法术、找装备分别帮助咒术和军械补组件。
- **弱点：** 卡面次数很快用完；免费刷新和定向 effect 刷新不触发 PaidRerolled。商店没出现角色时，相关折扣不会转成金币或积攒到下一次。

## 6. 咒术连施（arcana）

**核心循环：** 每次成功施法既完成法术本身，又给战场咒术组件提供成长、开场射击或全队临战攻击。法术之间没有自动复制，触发能力也不会凭空增加施法次数。

- **前期 P1–2：** 用中立承伤角色和成长法术过渡，P2 寻找烛火学者；在学者上场后再施法，才能获得本回合收益。
- **中期 P3–4：** 符文炮手、充能法典和两三张法术构成可预期的开场爆发；需要保留一部分金币维持下一回合施法。
- **后期 P5：** 万卷术主放大全队攻击，星落仪式把高等级角色的当前攻击转为群伤；法术落在哪个实例上比单纯施法数量更重要。

## 10. 品阶覆盖与重点观察

| 类型 | T1 | T2 | T3 | T4 | T5 | 合计 |
| --- | --- | --- | --- | --- | --- | --- |
| 角色 | 6 | 4 | 4 | 4 | 4 | 22 |
| 法术 | 4 | 3 | 4 | 3 | 2 | 16 |
| 装备 | 2 | 3 | 2 | 2 | 1 | 10 |

每种类型都覆盖 T1–T5，因此 P1 的五个固定商店槽均有合法候选；T5 装备目前只有不屈挂坠，同品阶重复出现属于本版小卡池的已知限制。先观察其出现频率和对局影响，再决定调整概率或增加另一张 T5 装备，不提前扩充整套卡池。

以下组合已纳入规则检查或机器人组合检查；仍需真人试玩确认体验与强弱：

1. **共鸣有限联动：** 鸣律学徒 L1 在F1、回声卫士 L1 在F2、合奏领主 L1 在B1，无装备且次数未用，对学徒使用基础操练。学徒先到L3；学徒给卫士link+1，卫士自身监听再link+1，领主排除自身与主目标后再给卫士link+1。结果分别L3/L4/L1；只有一个gain事件，三个link均不继续广播，事件链结束。
2. **换核守恒：** A=L11、B=L3，全量转移后 A=L1、B=L13，总 G 始终 12。再转回不能凭空增加 G；继承剑士/余火护符的临战补偿各只兑现允许的次数。
3. **免费刷新边界：** 开市号角、定向进货都能换商品；巡街掮客、云市巨贾、旅行算盘的付费刷新监听不应被触发。只有实际付 1 金刷新才发 PaidRerolled。
4. **手牌边界：** 手牌中的回声卫士不响应其他角色成长；给手牌角色使用基础操练可增长 L，但不伪装为战场事件。卖手牌角色可触发战场盘账掌柜。
5. **施法因果：** 基础操练先完成目标成长，再发 SpellCast；烛火学者得到的 gain 可触发共鸣一次，但不产生额外施法事件。开场射击也不算施法。
6. **装备无循环：** 同一件装备在多个角色间免费移动，不增加永久成长、产金或施法次数，不重置实例计数。锻炉行者只在真实回合开始检查两件装备。
7. **牺牲边界：** 赴火誓约导致战斗快照中目标阵亡，可触发女王及纸偶；永久实例和 L 在下一次备战恢复。不屈挂坠不能阻止该主动阵亡。
8. **召唤压力：** 验证满六格、同时多名阵亡、已成功召唤 12 次、核心与纸偶同时阵亡；不超格、不延迟补召唤、不让已死核心结算奖励。
9. **临时属性隔离：** 焰印/星落准备效果、旅行算盘攻击、军械护盾、收割者战斗攻击均不能混进转移 G，也不能在下一回合累积。
10. **经济观察：** 比较同等投入下六流派的成长、即时战力和后续现金；重点记录共鸣是否压倒单核、T5 法术是否过于划算、牺牲开场是否过强以及商贸是否被迫每轮刷新。
