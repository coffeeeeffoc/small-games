# 万象旅团 · multi-battle

单人H5构筑自走棋。花金币刷新商店、购买角色/法术/装备、升级指挥官解锁高阶道具，用无限叠级和等级转移构筑阵容，对战7名本地模拟玩家。

**当前状态：地图交互版，2026-09-13。六流派48张卡全部接入；支持悬浮商店/手牌拖拽、全身角色地图战斗、淘汰排名、本地存档、图鉴和音效。数值仍待真人试玩校准。**

## 启动

需要Node.js 22或更高版本。游戏没有运行时第三方依赖；测试使用Playwright。

```sh
npm ci
npm run dev
```

浏览器打开 [万象旅团](http://127.0.0.1:4177)。点击「开启新旅程」；商店角色可直接拖到地图购买并上场，也可拖进手牌。法术和装备拖到角色使用，合并/双目标法术会预览确认。手牌左右箭头可翻页，也保留点选操作。经营没有倒计时，点「准备完成」收起经营界面，观看地图交锋。

```sh
npm test                # 规则、卡牌、大厅、存档检查
npm run test:browser    # 启动服务后运行真实浏览器回归
npm run test:map        # 地图战斗、拖拽及手机真实触控事件回归
npm run test:balance    # 六流派各30局AI经营烟测
npm run build          # 生成dist静态文件
npm run preview        # 从dist提供预览；与dev使用同一端口，请先停止dev
```

浏览器测试自动查找Windows Chrome/Edge；其他环境先执行 `npx playwright install chromium`，或设置 `BROWSER_PATH`。可用 `TEST_URL` 指向另一预览地址，服务端口用 `PORT` 设置。

发布时将 `dist/` 托管到静态网站即可；所有资源使用相对路径，无需业务服务端。本轮没有部署公网或打包APK。

## 保存与继续

每次完整操作后自动保存到当前浏览器。可从菜单导出/导入JSON备份；战斗中断后从锁定阵容重播，结算不会重复扣血或发金币。清理网站数据会清除本地进度，换浏览器或设备请使用导出文件。
