# 词屿 · 字母叠叠乐

一个手机和桌面浏览器都能玩的 H5 单词游戏：看中文释义，从错落叠放的字母牌中拼出英文单词，逐步清空棋盘。

## 本地运行

安装 Node.js 后，在此目录运行：

```sh
npm start
```

浏览器打开 <http://127.0.0.1:4175>。无需安装依赖，也不需要构建；`npm run dev` 使用相同的本地服务。可通过 `PORT` 环境变量更改端口。

```sh
npm test
npm run check
```

`npm test` 检查游戏规则，`npm run check` 检查 JavaScript 语法和静态服务的路径限制。

浏览器回归使用环境中已有的 Playwright 和 Chrome。保持本地服务运行，在另一个终端执行：

```sh
node tests/browser.test.mjs
```

可选环境变量：`PLAYWRIGHT_MODULE` 指向已有 Playwright 的 `index.mjs` 绝对路径，`PLAYWRIGHT_EXECUTABLE` 指向浏览器可执行文件，`GAME_URL` 更改待测地址。测试通过真实点击覆盖桌面和 390px 手机布局、遮挡规则、错误拼写、撤回和切词、导入校验、重复字母及符号、完整通关和重玩。

## 怎么玩

- 进入时随机抽取一组 6 个单词及中文释义，再随机生成带遮挡关系的棋盘。
- 先选择中文释义，再按顺序点击字母或符号。只要一张牌与更高的牌有任何面积重叠，即使只压住一点边角，也不能选取。
- 选中的牌在完整拼写正确前仍留在原位置，继续遮挡下方的牌；拼对后，这一整个单词对应的牌才从棋盘移除。
- 同样的字母可以有多张牌，每张只能消耗一次；撇号、连字符等符号也需要逐个点击。
- 可以撤销或清空当前拼写。切换中文释义会退回尚未完成的选择。
- 完成所有单词即通关；正确消词造成余牌无完整可拼词时自动免费整理，保留进度。同字母仍可自由使用，任何面积遮挡仍不能取牌。
- 自动保存已完成单词、棋盘位置、当前词义与尚未完成的拼写；刷新或切到后台后可接着拾词。旧存档或棋盘记录损坏时，保留已完成词并重新摆放余牌。实际使用字母提示或拼错的词会进入结算复习，未解锁词的操作建议不会加入复习。

## 三词主题小岛

首页顶部直接开局「早餐开张」「海边拾光」「星空出发」：每岛三个真实单词，拼对便点亮一份主题收获，不设倒计时，也不放宽拼写与遮挡规则。相同主题的初始棋盘固定，完成后可同题再练；先收满三份收获，再换一座小岛。

三词、每日与普通 / 教材练习分别保存。三词小岛只保留当前一份进度；暂停后可返回原普通棋盘。分享只含 `mini=dawn|shore|orbit&v=1`，首次打开直接进入对应小岛，不带英文答案；未知主题、重复参数、与 `daily` 混用或不支持的版本会被拒绝。

```sh
npm run test:mini:browser
```

## 每日同题词岛

「每日词岛」按北京时间换新，轮换森林、海风、生活、宇宙、甜点、街角美食、天气与动物八个主题。相同日期的初始牌局和词义一致，目标是零提示、零手动重排、零拼错清空；提示和重排仍可使用，并在结算记录次数。自动免费整理不计入手动重排。同题重玩回到相同初始牌局，适合复习和邀请朋友比较求助次数。

每日与自由拾词 / 教材练习分别保存。刷新保留每日未完成拼写，返回自由拾词可恢复原来的棋盘。每天保留一座每日词岛进度；另一日期的邀约替换每日进度，不覆盖普通练习。

「邀请朋友同题」或结算分享只带 `daily=YYYY-MM-DD&v=1`。日期要求 2000–2099 年的有效公历日期，重复参数与其他版本被拒绝；不会复制地址中的其他查询参数、词单答案或片段。浏览器分享被取消时保留进度；复制不可用时可手动选取链接。分享为当前静态游戏页面的同题邀请，未实现排行榜或异步好友对战。

```sh
npm run test:challenge:browser
```

## 教材单元练习

入口「选择教材单元」依次选择出版社、年级、教材册次 / 版次和真实 Module / Unit 名称。教材按需下载并验证 SHA-256，保存至 IndexedDB 后，已打开的游戏在断网时仍可练习该册；每批最多 6 词、80 块牌，最后一批允许 1 词。短语保留空格显示，空格不作为牌，撇号和其他符号仍需拼入。拼写不区分大小写，完成词单、续练和错词复习保留教材原有的 I、Ms 等写法。

数据由 `assets/english-dict/精简词库/英语词库.sqlite` 的现有导出器生成，再叠加 `assets/english-dict/完整素材/reviewed-units/catalog.json` 与 `books/*.json` 中带核验依据的数据。`pnpm --filter ciyu-word-tiles vocabulary:sync` 更新游戏内资源；构建只复制已生成资源，不需要线上访问词库仓库。历史词表明确显示「未核验教材单元与当前版次」，只提供整册，不能冒充已核验单元。

`pnpm --filter ciyu-word-tiles test:library:browser` 用真实触控完成新版单元的全部 31 词、6 批与 1 词尾批，检查刷新续练、提示词复习及同册离线缓存。

`npm test` 会核对下载哈希、与核验源字节完全一致、教材单元隔离、批次完整与牌数上限。PDF/源教材核验进度见 `RELEASE-REVIEW.md`。

2026-10-02 对应关系复核后，目录保留 42 份词库：26 册 PDF 核验教材（313 个学习分组）、13 份人教历史词表和 3 份综合词表。六份存在主编误标及词形错误的外研历史词表由同册陈琳 PDF 核验版本替代，不再重复提供选择；原始采集素材仍保留。复核范围、修正依据及未核验边界见 [VOCABULARY-AUDIT.md](VOCABULARY-AUDIT.md)。

## 自定义词组

打开词组编辑入口，每行填写一个英文单词和中文含义，以空格或制表符分隔，例如：

```text
apple 苹果
cloud 云朵
don't 不要
ice-cream 冰淇淋
```

每组 2–8 个不重复单词或短语，合计最多 80 个字母和符号。英文中的符号会作为独立牌保留，空格自动补齐。

## 静态部署

运行 `npm run build` 后发布 `dist/`。其中包含页面、脚本、样式与按册下载的 JSON 词库。游戏无需后端；本地服务仅公开页面资源和限定路径的教材 JSON，且只监听本机地址。
