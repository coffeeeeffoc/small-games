# 词屿移动端交互改造

设计先于生产界面实施。`design.html` 是自包含的页面效果稿，`tokens.json` 记录统一参数。`home.png` 至 `share.png` 为 390 × 844 手机视口效果图，`contact-sheet.png` 为十页总览；`friend.png` 补充已有好友赛入口，`settings.png` 为独立设置页。`island.svg` / 透明 `island.png` 是可复用小岛素材。

## 页面和入口

1. 首页：开始/继续拾词为唯一主操作；两个大入口分别去主题词岛、学习入口；每日词岛、好友同题是小入口；帮助和设置在右上角。
2. 主题词岛：沿用真实三词小岛「早餐开张」「海边拾光」「星空出发」，每张卡直接进入对局；自由拾词随机使用已有词组。
3. 学习入口：教材练习、我的词单；只有存在真实教材进度时显示继续卡，不增加收藏或排行榜。
4. 教材选择：出版社 → 年级 → 教材/册次 → 真实单元；核验范围来自现有目录。未核验历史词表仅显示整册。
5. 核心游玩：返回/进度/暂停顶栏；中文目标和换词；可点选叠放棋盘；答案格、确认与撤回/清空/重排/提示固定在下方。
6. 暂停：继续、换组、分享、主页；音效和帮助/设置为轻入口。原生平台无浏览器全屏操作，H5 在设置提供单一全屏入口。
7. 结算：点亮的小岛、真实本局词单；下一岛/下一批为主操作，复习/同题重玩和返回次要。
8. 自定义词单：保留 2–8 词和总计 80 字符限制、短语及符号支持，页内错误反馈。
9. 帮助：三步规则，说明叠放、重复字母和标点，不占用游玩主画面。
10. 分享：小岛卡和同题链接；原生用宿主分享，H5 使用系统分享/复制链接。
11. 好友同题：创建与加入房间，已有房间/赛况沿用比赛规则，使用同一字体、颜色、厚底按钮和牌面。
12. 设置：音效开关、H5 全屏；从首页或暂停进入，返回原页面，原生平台隐藏 H5 显示卡。

## 画面尺寸

竖屏适合观察字母叠层和单指拾牌，所有页保持一致。设计基准 390 × 844：普通页左右 24 px、顶部 24 px；游玩左右 18 px；顶部控制区 44 px。主按钮 58 px、厚底 5 px、圆角 18 px；普通卡圆角 22 px；二级按钮 52 px；工具不小于 44 px。

游玩基准图：顶栏 y=24 / h=44，词义卡 y=83 / h=122，棋盘 y=220 / h=370，答案 y=634 / h=47，工具 y=722 / h=50。实际棋盘必须使用引擎逻辑尺寸和内容高度，独立滚动；小屏先保留上下控制热区，再缩短棋盘窗口，不能把字母压到 44 px 以下。桌面以窄竖屏栏居中；H5 横屏且高度不足 500 px 时，使用棋盘左侧、词义/答案/工具右侧的两列适配，所有控件保持在视口内。安全区使用宿主实际 safeArea 或 CSS env 参数。

## 交互核验要求

仅触屏走通首页 → 词岛/学习 → 游玩 → 暂停 → 结算 → 返回。页面切换清晰返回，不叠加多层弹窗。按下按钮下沉，字母选中变暖黄；遮挡牌深薄荷色，点击给即时解释；答案格可直接撤销，重排和提示不丢进度。失焦、触摸取消、后台恢复不留下输入状态。长答案换行并在答案区滚动，长词义页内查看完整释义。对照实际截图记录视觉和交互结果，桌面触摸模拟与真机验证明确区分。

## 重新生成效果图

在游戏目录执行 `node docs/design/mobile-2026-10-06/render-design.mjs`。脚本启动临时 HTTP 服务，使用 `/usr/bin/chromium`，等待页面 `.screen .top` 可见、字体就绪且页面无脚本错误再截图。设计画面为静态效果稿；生产实现应读取真实词表、进度和存档，不将样例学习记录当作数据。

实装与设计使用同一小岛素材、色彩、厚底按钮及牌面。H5 使用视口剩余高度配置棋盘窗口，原生额外避让宿主胶囊，动态棋盘、真实学习状态和不同对局的词单会使截图位置和内容不同。原生学习卡采用同款图标和卡片，设置保留音效卡并省略 H5 全屏卡；截图对照统一视觉和操作可达性，平台安全区与真实内容按各运行环境适配。

以上浏览器和 SDK 模拟验证不能替代微信、抖音、B 站、快手官方开发者工具或真机验证。发布配置中保留 `nativeRuntimeVerified: false` 与 `platformLoginVerified: false`，实际宿主登录、分享、音效、震动与网络域名还需平台环境验证。
