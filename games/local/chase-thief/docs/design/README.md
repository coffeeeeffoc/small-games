# 《追贼别撞墙》画面方案

先生成 [概念效果图](concept.png)，再编写对应的场景及界面代码。效果图展示手机比例的主页、核心游玩和选关。场景由原创 Canvas 插画绘制，不把概念图当作运行素材或实际截图。

采用竖屏：三条跑道向前收束，前方小偷和障碍需要足够的纵向观察空间；四向滑动与拇指触控适合该方向。宽屏视口保持完整界面并重新排布菜单和控件，不阻断游玩。尺寸或全屏变化只改变绘图和布局，不重置追捕。

主页 → 开始追捕 / 选择街区；主页 → 如何追捕 / 设置。游玩 → 暂停 → 继续 / 重试 / 设置 / 返回主页；抓捕或失败 → 结算 → 重试 / 下一街区 / 返回。街区按正常通关解锁，开发试玩独立于成绩和进度。

游玩只显示距离、连续成功、剩余时间、失误次数与暂停入口。三次连续成功以暖金色反馈和速度线显示，距离在两秒内连续缩短三米，小偷投影同步变大靠近。碰撞时画面闪动、角色减速、距离增加，连续次数清空。首关前三波通过场景内短提示逐步教跳跃、滑铲、换道；后续不常驻说明文字。

红白矮路障、蓝色低杆、木箱分别具有独立形状和纹样。原创街巷包含瓦檐、青绿百叶窗、砖墙、盆栽和灯笼；蓝衣玩家与橙衣小偷均独立绘制，动作、音效和路线独立制作。没有列车、滑板、涂鸦或引用作品的角色和界面。

概念图提示词：三幅 390×844 手机页面，暖赭石、青绿、深蓝配色，手绘感矢量 2.5D 老城巷子；主页突出“追贼别撞墙 / 开始追捕”，核心画面蓝衣玩家跳过红白矮路障、前方橙衣小偷逃跑，顶部距离与连续成功，底部四向触控，选关显示晨光里、骑楼巷、灯火街三条 60 秒街区。

2026-10-06 的生产构建在 Chromium 151.0.7922.173 验收通过，覆盖 390×844、360×640 与 844×390。使用真实触屏事件模拟四向滑动、按钮及取消，验证暂停、后台、抓捕、三撞/超时、免费重试、三关解锁、存档及存储/全屏拒绝降级。三关正常通关使用浏览器时钟推进实际 RAF，不通过修改规则伪造结果；开发手动时钟局单独验证且不计分。

实际画面：[主页](actual-home.png)、[选关](actual-levels.png)、[跳跃](actual-play.png)、[三连冲刺](actual-boost.png)、[正常抓捕结算](actual-win.png)、[失败](actual-loss.png)。详细结果见 [浏览器报告](report.json)。部分规则演示截图保留开发试玩标签；默认玩家页面不显示开发入口。

最新游戏制品同时通过 Web Shell 生产构建及 Pages 桌面 iframe / 手机触屏操作回归，主页返回导航、游玩沉浸、暂停与返回均通过。手机尺寸触屏模拟不等同于物理手机或原生渠道验证。
