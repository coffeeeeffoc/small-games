# 小贼哪里跑

穿过热闹的老城街巷，追赶小贼，收集沿途掉落的物品！左右闪避、跳跃滑铲，挑战更远的追逐纪录。

从廊柱店招的骑楼街、灰墙晾衣的居民巷，或彩棚果蔬的集市出发。选中街区即可预览环境，沿途仍会经过全部街区；木栏、晾衣框、包裹和果蔬货车呈现各自的生活气息。

左右滑动换道，上滑跳过矮栏和沟壑，下滑钻过低横杆。街道越跑越快，整排矮栏必须跳、整排横杆必须滑，换道与动作要跟上节奏。看清路面断口、箱堆、推车和滚桶，在分岔街口提前选择通道，追回沿路掉落的物品。

没有倒计时，也没有终点抓捕。跑得更远、动作更稳，就是下一次追逐的目标。三次碰撞或未跳过沟壑会结束本局；随时可以免费重试。支持声音、震动、减弱镜头动态和辅助触控按钮设置，本地保存最远纪录。
