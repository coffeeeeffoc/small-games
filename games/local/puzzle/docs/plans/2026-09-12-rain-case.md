# 雨停之前 Implementation Plan

**Goal:** React + TypeScript + Vite 实现一个竖屏优先、可调查并完整结案的原创推理案件。

**Architecture:** case.ts 存案件数据；game.ts 保存纯状态转移与评分。App.tsx 负责五个页面、场景和审问；Puzzles.tsx 负责手机与三种可触控取证。无路由库、状态库、动画库。localStorage 版本化自动存档。

**Tech Stack:** React, TypeScript, Vite, CSS, SVG, Web Audio, Pointer Events；Node assert 自检与 Playwright 浏览器回归。

## 执行步骤

1. 先完成 docs/case-design.md 和 docs/evidence-graph.md，逐一代入四名嫌疑人审查唯一性。
2. 新建 package.json / index.html / tsconfig.json / vite.config.ts，npm install，建立最少工具链。
3. 编写 src/case.ts 数据与 src/game.ts 状态、评分、存档验证；scripts/check.ts 用 Node assert 覆盖主路径、低分路径、缺支线路径和错误输入。
4. src/App.tsx / src/styles.css 实现暗色档案视觉：案卷开场、可点击现场、嫌疑人问询、证物板、时间线、结案。
5. src/Puzzles.tsx 实现监控滑动抓拍、照片双指缩放与找细节、拖动碎片恢复，均有原生按钮替代操作。
6. 本地原创场景素材放 public/assets；添加静音、首次交互启动音效、轻量动画和刷新续玩。
7. npm run check && npm run build；修复全部类型和逻辑错误。
8. scripts/playtest.mjs 用真实 Chromium 完成三条路径，保存截图与结果；检查375/390/430/768宽度、触控与键盘操作、无溢出或浏览器错误。
9. README.md 记录启动、玩法、测试、素材与边界；docs/playtest-report.md 记录实际证据。打开本地预览交付。
