# 雨停之前

**第 07 号档案 · 望潮档案馆**

原创、竖屏优先的 H5 嫌疑人推理游戏。一个完整案件，四名嫌疑人，设计游玩时长约 10—20 分钟。使用 React、TypeScript、Vite，运行时没有后端或外部服务依赖。

## 运行

需要 Node.js **22.18+ 或 24+**（`check` 使用 Node 原生 TypeScript 支持）。

```sh
npm install
npm run dev
```

打开终端给出的地址。开发服务监听 `0.0.0.0`，手机与电脑在同一局域网时可以用终端显示的 Network 地址访问；是否能访问还取决于本机防火墙。推荐手机竖屏，支持 375 / 390 / 430 / 768px，也适配桌面。

```sh
npm run check      # 纯逻辑、评分、存档和三条路线自检
npm run build      # TypeScript 严格检查 + 生产构建
npm run preview    # 预览 dist 中的生产版本
```

## 不剧透的操作说明

- **现场**：点击编号检查物品，主动点“收集证据”。“调查清单”提供同样完整的文字入口。阅档室与一楼控制台可以随时切换。
- **嫌疑人**：先选择人物和话题，听到证词后再质疑。使用能够直接反驳该句话的记录；部分话题需要先找到相关证据。
- **手机**：从现场相框找密码线索。解锁后分别浏览聊天、相册、通话、备忘、转账和已删除内容。查看记录不会自动代替取证。
- **小游戏**：双指缩放照片并检查细节；拖动删除回执碎片恢复记录；拖动监控时间轴截取有意义的画面。放大按钮、上下移动按钮、监控逐分钟按钮与键盘均可替代手势。
- **证据板**：点“建立关联”，选择两条证据后“验证关联”。有效组合生成推理，无效组合不会凭空产生事实。证词矛盾需回到问询当面质疑。
- **时间线**：由已取得的原始记录逐步补全。尚未调查的事件不会提前泄露。
- **推理**：提交六项完整解释。S 完整破案；A 找到真凶但细节或调查评分有不足；B 证据链不足；C 指认错误。错误报告后可以继续调查并重新提交。

不同的错误质疑首次扣 5 分，相同错误不反复扣分，最低 40 分。错误密码、碎片、抓拍和证据板尝试不扣分，也不消耗证据。提示不扣分。判断机会不会耗尽，不会出现不可恢复的死局。

进度自动保存在当前浏览器的 `localStorage`，刷新可续玩。设置中可以静音和“重新开始案件”；重开会明确确认清空。雨声、取证提示音在首次交互后启动，后台暂停，支持减少动态效果偏好。手机震动取决于浏览器能力。

## 可重复的浏览器试玩

先在一个终端运行生产预览（或使用对应的开发地址）：

```sh
npm run build
npm run preview -- --port 5186 --strictPort
```

另一个 PowerShell 终端执行：

```powershell
$env:PLAYTEST_URL = 'http://127.0.0.1:5186'
npm run test:play
```

macOS / Linux：

```sh
npx playwright install chromium
PLAYTEST_URL=http://127.0.0.1:5186 npm run test:play
```

脚本优先使用本机 Chrome / Edge，也支持设置 `PLAYTEST_BROWSER` 为浏览器可执行文件路径。没有本机浏览器时用 `npx playwright install chromium` 安装测试浏览器。脚本默认目标地址是 `http://127.0.0.1:4176`，建议显式传入运行中的地址；它会验证页面标题，避免测到其他项目。

所有操作通过真实浏览器界面进行，**不向存档注入通关状态**。触控测试通过 Chromium CDP 发送多指及拖动事件。结果写入 `test-results/playtest-report.json`，截图也在 `test-results/`。三条路线分别覆盖高效破案、大量错误怀疑、遗漏非关键线索。

## 文件与设计

| 文件 | 用途 |
| --- | --- |
| `docs/case-design.md` | 完整真相、分钟时间线、四人秘密与唯一性检验，**含剧透** |
| `docs/evidence-graph.md` | 证据依赖、组合规则、渐进提示与防死局设计，**含剧透** |
| `docs/playtest-report.md` | 实际验证结果与测试边界 |
| `docs/assets.md` | 场景与人物生成提示词、字体与素材来源 |
| `src/case.ts` | 23 条证据、16 个问询话题、15 条时间线、5 项关联与6项结案数据 |
| `src/game.ts` | 纯状态转移、解锁、质疑、评分与存档校验 |
| `src/scene.ts` | 场景热点、普通环境描述与开案简报 |
| `src/App.tsx` | 五个页面、案卷、证物检视、问询与结案 UI |
| `src/Puzzles.tsx` | 照片、手机、恢复回执、监控取证 |
| `src/audio.ts` | 本地合成雨声与提示音 |
| `scripts/check.ts` | 数据引用、逻辑、分级和损坏存档自检 |
| `scripts/playtest.mjs` | 三条完整浏览器操作路线及触屏/尺寸回归 |

派生状态（解锁问题、时间线）由已保存的事实重建，避免两份状态不一致。存档带版本与字段校验；无效或不完整字段会安全归一化，孤立的谜题完成标记会清除以便重新取证。存档失败时页面会显示提示，当前局仍可继续。

这是单机客户端案件，存档可以被用户修改，没有线上排名或反作弊设计。案件判断是游戏设定中的逻辑，不是现实刑侦工具。没有加入账户、后台管理、付费、广告或远程发布。

## 素材

场景和四人肖像为本项目生成的原创素材，保存在 `public/assets/scene.png`、`public/assets/portraits.png`。照片与监控是可交互 SVG；开场和现场共用本地场景图。背景钟面由原生 SVG 覆盖以对齐案内时间，所有精确证据以检视页为准。

标题字体为 Noto Serif SC 的本地子集（约 204 KB），采用 SIL Open Font License，见 `public/assets/OFL.txt`。无外链字体、音频或运行时 API。生产 `dist/` 可以放在任意静态服务器根目录或子路径下，Vite 使用相对资源基址。
