# 子弹花园 · Bullet Garden

Canvas 2D 战术射击 Game，支持独立运行与 Web Shell iframe。保留失落庭院并新增十关，共十一关；第4、8关为首领关，第11关为最终BOSS。各关以庭院布景、天气和敌人组合区分，开局战场没有石墙、泥地、阶坡或增益植物。

## 运行与验证

无需安装运行依赖，Node.js 20+：

```sh
node server.mjs
# http://127.0.0.1:4410
npm test
npm run test:balance
npm run test:campaign-balance
node build.mjs
node server.mjs --root dist --port 4411
```

浏览器和绘制验收需要 Playwright 与 Chromium；可用仓库依赖或指定 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`。通过 `GAME_URL` 指向开发服务或构建制品，`QA_OUTPUT` 指定证据目录。

```sh
npm run test:browser
npm run test:campaign-browser
npm run test:rendering
npm run test:screens
```

## 战斗与成长

普通枪械自动攻击附近怪物，击杀积累**局内经验**，升级时选择三项之一（局内等级5起四项）。每局开始不拥有自动植物；只有选中对应祝福后才会自动生长。现有灌木、沟渠、霜花、毒花以及新寒冰柱、爆炸蘑菇、暖阳花、引雷芦、花瓣炮共用自动生长流程。暖阳花、引雷芦、花瓣炮分别要求**永久玩家等级2、4、6**，解锁后仍须在局内选到对应祝福。

准备页配置两个不同的能量技能。能量来自战斗时间与击杀，每槽最多储存3次（300能量）；每次释放消耗100能量，保留其余储存与下一次的充能进度。选中技能并瞄准施放，若还有储存则保持瞄准，可连续释放，释放间隔0.3秒。技能卡显示储存次数及下一次充能进度，底部操作区位于战场Canvas之外。五种现有技能、武器多发/连发/反弹/元素弹/分裂与1/2/3/5倍速均保留。触屏使用左下摇杆移动，右侧技能卡准备技能，在场地瞄准、松手施放；取消触点不消耗能量。键盘WASD移动，1/2选技能，E或右键确认，空格冲刺，Escape取消瞄准或暂停。

通关获得金币、**永久经验**并解锁下一关；在营地消费金币升级攻击力、攻速、生命、护甲、种植精通、宠物及枪械伤害/连发/穿透。玩家等级5自动解锁金蜂助手，金币用于提升助手。永久成长跨关、重试和刷新保留；局内祝福每局重置。

首次通关发放完整地图奖励和击杀金币；重玩奖励按35%，失败保留25%击杀金币及按存活比例计算的部分经验。挑战编号使同一次结算只到账一次。存档位于 `bullet-garden.profile.v1`；保存不可用时显示提示，仍可在内存中继续玩。

主页、选关、营地、玩法指南、强化选择与结算概览均独占画面，各自滚动，战场不会显示在页面背后。结束后立即显示本局概览，唯一操作是返回主页；从主页再进入选关或营地。主页的“上一局概览”保留当前页面会话内上一局数据，重复查看不重复发奖。

## 开发者模式

URL 加 `?dev=1`（已有查询参数时用 `&dev=1`）即可选择全部关卡。也可在同源浏览器控制台设置 `localStorage.setItem('bullet-garden.dev', 'true')` 后刷新。`?dev=0` 优先关闭模式；移除 `bullet-garden.dev` 后刷新可关闭本地开关。

开发者模式仅开放关卡选择，不提升玩家属性。主页和选关页显示模式提示，试玩不发放金币、永久经验、正式通关记录或最佳成绩；普通存档的关卡锁不受影响。

| 10  | 冰雹花台 | 冰雹＋风 | 冰雹预警与落冰伤害           |
| 11  | 雷鸣心圃 | 阴＋雷暴 | 三阶段花园之心BOSS、雷击预警 |

首关保持300秒/10波；新增关卡为120～180秒/6波。所有关卡在计时结束后停止普通刷怪，进入清场，HUD显示剩余敌人数；必须清空所有存活敌人才能获胜，首领与BOSS关也必须击败指定目标。清场期间仍可移动、攻击、充能、选择强化、暂停和死亡，时间与动画继续运行。

战斗地形仅在选中对应局内增益后生成。灌木、沟渠、霜花与毒花不阻挡角色或子弹；寒冰柱保留阻挡双方移动与子弹的掩体作用，怪物可绕行或击碎，卡片明确提示该代价。花叶灌木卡片使用带花的灌木图标。地图目录保留原有地形定义和校验供内容工具使用，当前战斗不自动加载这些障碍。天气影响植物伤害/治疗/耐久、自动生长、敌人移速/攻击和有效射程；大风与雷暴可叠加。冰雹和雷击先画地面预警再产生伤害。钻地与升空具有可见阶段，地面植物和枪械/对空电击按攻击层级判断。

## 扩展结构

| 模块                                   | 职责                                                    |
| -------------------------------------- | ------------------------------------------------------- |
| `config.mjs`、`catalog.mjs`            | 地图、怪物、植物、天气、祝福、技能和数值定义            |
| `content-schema.mjs`                   | Dynamic Content的版本、引用、数值、处理器和地图连通校验 |
| `progression.mjs`                      | 永久成长、经验、解锁、原子购买、幂等奖励和存档净化      |
| `loadout.mjs`                          | 双槽配置、局内经验、祝福所有权与升级候选                |
| `combat.mjs`、`world.mjs`              | 攻击层级、伤害修饰、地形移动与天气倍率                  |
| `simulation.mjs`                       | 确定性模拟、技能、怪物能力、植物生命周期与遭遇流程      |
| `renderer.mjs`、`ecology-renderer.mjs` | 相同几何数据的Canvas绘制与特效                          |
| `main.mjs`                             | 触屏/键鼠、战役/商店、保存适配与界面                    |

`registerContentPack({version:1, levels, enemies, plants, weather, buffs})` 接受纯JSON数据：整包成功才追加，失败不改变已加载目录；稳定ID、关卡序号不得重复，未知技能处理器被拒绝，地图检查安全出生点与连通性。定义不可变，目录引用稳定。可在启动Game前载入数百关，模拟、解锁、结算与关卡列表不依赖十一关硬编码。

`registerGrowthDefinitions(definitions)` 可追加现有数值处理器支持的成长项，商店、费用、保存与属性聚合自动读取同一注册表。全新行为需要添加处理器并完成测试，内容包不执行任意代码。动态内容schema由本Game拥有，遵循仓库ADR-0007。

新内容遵循**设计机制→生成效果图→实现→验收**。本次六类成长、三项枪械升级、植物/增益、所有怪物外形以及十一张独立地图参考图已归档，生成时间与SHA-256见 [效果图清单](docs/design/concepts/manifest.json)。概念图用于视觉设计，运行时使用Canvas绘制，不加载大图。

详细规则：[架构设计](docs/design/architecture.md)、[关卡生态设计](docs/design/encounters.md)、[模块契约](docs/CONTRACT.md)。自动验收证据与限制见 [验收报告](docs/qa/campaign/verification-report.md)。

126项规则案例全部通过；正常资源、实际消费金币成长的三个种子完成33/33关。未购买永久成长的对照中，种子7在第8关失败。源码真实首关通关、奖励、购买、下一关与刷新流程，以及构建产物横竖屏双触点和三场首领/BOSS实战已验证；后期浏览器场景使用明确标注的合法存档fixture。触屏验收使用桌面Chromium模拟，Android/iOS真机性能和安装尚未验证。
