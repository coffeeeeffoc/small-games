# 子弹花园 · Bullet Garden

在失落庭院守住十波敌人、五分钟。普通射击自动护身；玩家选择地形增益构筑战场，再积蓄能量，手动决定主动技能的落点和释放时机。

## 运行与验证

无需运行依赖，使用 Node.js 20 或更新版本：

```sh
cd games/local/bullet-garden
node server.mjs
# http://127.0.0.1:4410/

npm test
npm run test:balance
npm run build
node server.mjs --root dist --port 4411
```

浏览器测试复用仓库 Playwright 开发依赖。在启动开发服务后运行：

```sh
CHROMIUM_PATH=/usr/bin/chromium npm run test:browser
CHROMIUM_PATH=/usr/bin/chromium npm run test:rendering
```

也可通过 `PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs` 指定已有 Playwright。`GAME_URL` 指定服务地址，`QA_OUTPUT` 指定截图和报告目录。构建保留相对资源路径，可由 Web Shell 的 `bullet-garden` iframe 承载。

## 选择地形增益

开局默认没有地形，也不选择地形增益；准备界面只搭配两项不同的主动技能。击杀敌人积累经验，升级时暂停并提供强化选项：初期三选一，达到 5 级后四选一。只有在这里选中某项地形增益后，才开始自动生成对应地形；只选择武器或生存强化时，场上仍不会生成地形。普通子弹落空也不会生成地形。经验溢出保留，波次只调整敌人压力，重新开局会清除已解锁地形。

| 地形增益 | 作用                                         |
| -------- | -------------------------------------------- |
| 花叶灌木 | 圆润叶丛和小花，拖慢敌人并造成持续伤害       |
| 缓行沟渠 | 浅沟大幅拖慢踏入的敌人，角色可以自由通过     |
| 霜冻花圃 | 短暂冻结敌人，同一敌人有再次冻结的间隔       |
| 毒雾花丛 | 敌人中毒后持续受伤，离开区域仍会残留一段时间 |

选中的增益按各自间隔在来敌前方生成地形。地形会过期，最多保留 18 处；满额替换较老的地形。具体间隔、范围和伤害集中在 `src/config.mjs`。

## 经验与枪械构筑

保留攻击力、攻速、多重弹、连射、边界反弹、冰弹、火弹、爆弹、子弹分裂和分裂爆炸等强化。升级按权重、等级上限与前置条件抽取；分裂弹仅产生一代，灼烧刷新持续时间，避免派生效果无限递归。击杀只结算一次经验。地形解锁与枪械强化共用经验选择，主动技能能量独立显示。

## 蓄能主动技能

两项技能分别蓄能，随战斗时间和击杀增长，最多 100。蓄满后保留，只有玩家选中技能、确认目标才会消耗；暂停和升级期间不充能。取消瞄准不扣能量。

| 技能     | 释放方式与作用                         |
| -------- | -------------------------------------- |
| 花火爆破 | 指定区域，短暂预告后爆炸并眩晕         |
| 回旋大风 | 指定区域，持续伤害、向外推开并减速     |
| 冲锋花车 | 指定方向，冲击沿途敌人并眩晕           |
| 踏风战马 | 指定方向，践踏并使沿途敌人恐惧后退     |
| 日光射线 | 指定方向，穿透伤害并使命中敌人短暂易伤 |

准备界面可更换搭配。战斗中先点击充满的技能槽进入瞄准，再点击或拖动画面确认落点；线性技能显示从角色出发的方向和作用宽度。所有效果和敌人异常状态都有时间上限。

## 操作

| 动作           | 触屏                             | 键鼠                          |
| -------------- | -------------------------------- | ----------------------------- |
| 移动           | 左下摇杆                         | WASD / 方向键                 |
| 普通射击       | 默认自动射击                     | 默认自动射击 / 按住左键       |
| 选择已蓄满技能 | 点击两个技能槽                   | 1 / 2                         |
| 瞄准与释放     | 进入瞄准后点击场地，或拖动后松手 | 瞄准后点击场地、右键或 E 确认 |
| 取消技能瞄准   | 再点已选技能槽或取消控件         | Escape                        |
| 冲刺           | 冲刺按钮                         | 空格                          |
| 暂停           | 暂停按钮                         | 非瞄准状态按 Escape           |

战斗可选择 `1× / 2× / 3× / 5×` 倍速。移动、弹道、敌人、充能、状态持续时间和五分钟倒计时按相同倍率推进；暂停与经验升级期间全部冻结，画面仍每个浏览器动画帧绘制一次。

支持摇杆与技能瞄准同时触控。触点取消、切后台、失焦及画布丢失会清除持续输入；画布恢复前不推进战斗。

## 性能与扩展

- 怪物动画和子弹发光采用固定大小图集，缓存不随波次和敌人 ID 增长；屏幕外对象跳过绘制，模拟仍正常推进。
- 主画布限制到 400 万像素，碰撞先快速排除无关对象，再执行精确计算。
- 密集爆弹和分裂弹最多保留 24 个爆炸画面、40 个地面提示；实际伤害和击杀仍完整结算，出怪提示优先保留。
- Canvas 恢复后重建背景和图集，背景缓存单独丢失时保留可读地面。该处理覆盖恢复路径，不能等同于已复现所有设备上的黑屏根因。
- 模拟与 DOM 分离。`window.__bulletGarden.snapshot()` 只返回状态副本，无改血量、跳关或改能量接口。
- 新增机制从 `BOONS` / `SKILLS` 定义开始，同时实现模拟、范围预览、图标、效果和回归。场景仍由本地 Canvas 绘制，无外部图片、字体或音频请求。

模块接口见 [CONTRACT.md](docs/CONTRACT.md)。浏览器回归使用桌面 Chromium 触屏模拟，不代替 Android/iOS 真机验证；渲染压力脚本的同步像素回读耗时也不等同真机帧率。

## 本次回归

56 项机制测试、12 局正常生命五分钟回放通过，全部从无地形开局，只经经验升级解锁地形。浏览器回归覆盖首次选择非地形强化后仍无地形、后续选中地形卡才生成、重新开局清空解锁，以及五分钟自然通关。390×844 与 844×390 双指操作、取消瞄准、四档倍速、暂停及升级冻结均通过。保留的渲染压力报告覆盖四档屏幕各 540 帧满载绘制：48 敌人、18 地形、120 属性弹、40 地面提示和 12 技能效果，缓存保持固定大小。

证据：[浏览器报告](docs/qa/browser-report.json)、[渲染压力报告](docs/qa/rendering-report.json)、[平衡回放](docs/qa/balance-report.json)、[手机战斗](docs/qa/mobile-390x844.png)。渲染恢复测试使用合成事件，未声称复现真实 GPU 丢失；尚未进行手机真机验证。
