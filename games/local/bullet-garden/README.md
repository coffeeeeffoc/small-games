# 子弹花园 · Bullet Garden

可独立运行、也可由 Web Shell 的 iframe 承载的 Canvas 2D 生存射击游戏。首章为失落庭院：十波敌人、五分钟挑战。玩家专注移动、躲避和选择成长方向，射击与地形释放自动完成。

## 运行

无需安装运行依赖，使用 Node.js 20 或更新版本：

```sh
cd games/local/bullet-garden
node server.mjs
# http://127.0.0.1:4410/
node --test tests/simulation.test.mjs
node tests/balance.mjs
node build.mjs
node server.mjs --root dist --port 4411
```

可使用工作区中的 `pnpm --filter @coffeeeeffoc/bullet-garden dev`、`test`、`build`。服务接受 `--host`、`--port`、`--root`；`dist/` 保留相对资源地址，支持静态站点子目录与 Shell iframe，Game ID 为 `bullet-garden`。

浏览器回归复用 Playwright：先启动开发服务，再运行 `pnpm --filter @coffeeeeffoc/bullet-garden test:browser`。可通过 `PLAYWRIGHT_MODULE=/path/to/playwright/index.mjs` 和 `CHROMIUM_PATH=/usr/bin/chromium` 使用已有工具，通过 `GAME_URL` 验收构建制品，`QA_OUTPUT` 指定证据目录。

## 两条独立成长线

### 打空 → 自动临时地形

普通主弹没有命中敌人并结束飞行时，增加一次打空计数。发生过反弹的子弹、分裂子弹、爆炸与持续伤害不贡献打空计数。命中过敌人的弹道不能在结束时再领取打空收益。

初始每 6 次有效打空触发一块地形，沿触发时最后一发打空子弹的原始方向，在玩家前方扇区随机取安全落点。无需选择位置、种子或释放时机；无目标时仍沿最后朝向自动射击。计数不是可囤积的技能能量，也不按时间自动充能。

三种基础地形采用打乱袋轮换，每轮各出现一次，避免长时间抽不到某一种。地形有持续时间和场上数量上限；自动寒冰只阻挡敌人，玩家可以穿过，避免随机封路。

| 地形     | 基础作用               | 强化方向                 |
| -------- | ---------------------- | ------------------------ |
| 荆棘藤蔓 | 范围减速与持续伤害     | 伤害、范围、持续时间     |
| 寒冰柱   | 阻挡敌人并提供寒霜减速 | 耐久、持续时间、寒霜作用 |
| 爆炸蘑菇 | 延迟范围爆炸           | 爆炸伤害、半径           |

生成最短间隔为 1.25 秒，冷却中最多暂存一次待生成触发，额外整段累计不排成长队，保留计数余数；场地边缘没有安全落点时延后，不能把地形放到场外或贴住玩家。满额替换旧地形不会触发额外蘑菇爆炸。打空提供战术补偿，升级仍依靠消灭敌人。

### 击杀 → 经验升级选择

普通芽怪、疾行芽、岩壳巨芽分别给予 2 / 3 / 8 经验，枪械、地形和持续伤害击杀均按每敌一次结算。起始为 1 级，首个升级门槛 12 经验，以后每级增加 10；溢出经验保留，连升逐次选择。

升级选择期间整个战场暂停。初期随机 3 选 1，达到 5 级后随机 4 选 1；选择后获得短暂无敌保护。每轮无重复，在有可用项时保证枪械与地形各至少一项；满级项和缺少前置的项不进入抽取池。波次仍控制敌人压力和小额恢复，不再固定弹出升级。

## 强化池与组合边界

| 分类         | 已实现方向                                           |
| ------------ | ---------------------------------------------------- |
| 基础枪械     | 攻击力、攻击速度、多重弹、额外连射、边界反弹         |
| 属性与派生弹 | 冰弹减速、火弹灼烧、爆弹、子弹分裂、分裂爆炸         |
| 地形         | 藤蔓强化、寒冰强化、蘑菇强化、地形持续、打空生成效率 |
| 生存         | 生命上限、恢复与冲刺冷却                             |

每项配置抽取权重、最大等级和可选前置条件。分裂爆炸需要先取得子弹分裂；分裂只产生一代子弹，爆炸、灼烧不能继续递归生成子弹。攻速、弹量、地形数均有边界，防止组合失控。冰与火可以同时生效，不要求额外切换武器。

多重弹与连射能带来更多主弹，也可能增加地形频率；反弹提升弹道覆盖，但已反弹弹丸不会再贡献打空。这是构筑取舍。连射增加一轮射击内的连续发数，攻击速度缩短两轮之间的间隔。

## 操作

| 动作         | 触屏                             | 键盘与鼠标                 |
| ------------ | -------------------------------- | -------------------------- |
| 移动         | 拖动左下摇杆                     | WASD / 方向键              |
| 射击与地形   | 默认自动完成                     | 默认自动完成               |
| 临时定向射击 | 按住或拖动场地，松开恢复自动瞄准 | 按住左键，松开恢复自动瞄准 |
| 冲刺         | 点击冲刺按钮                     | 空格                       |
| 暂停与继续   | 点击暂停与继续按钮               | Escape                     |
| 升级         | 点击一张强化卡                   | 点击强化卡                 |

支持移动与瞄准的双指操作。手势取消、失焦和暂停会释放持续输入。底部显示打空进度、下一种地形与基础地形图例；经验等级单独显示。没有种子库存、播种按钮或手动释放技能。

## 结构与后续关卡

| 文件                        | 责任                                             |
| --------------------------- | ------------------------------------------------ |
| `src/config.mjs`            | 地形、敌人、强化及关卡规则                       |
| `src/simulation.mjs`        | 确定性战斗、子弹来源、双成长线、生命周期与流程   |
| `src/renderer.mjs`          | 庭院、角色、地形、属性弹和特效绘制               |
| `src/main.mjs`              | 触控、界面、暂停、升级与结算                     |
| `tests/simulation.test.mjs` | 计数来源、碰撞、成长、组合边界与流程回归         |
| `tests/balance.mjs`         | 四类构筑、三个固定随机种子的正常血量自动战斗回放 |
| `tests/browser.mjs`         | 桌面与双尺寸触屏、自然战斗、升级、暂停及手势取消 |
| `docs/CONTRACT.md`          | 模块接口和扩展约定                               |

新关卡在 `LEVELS` 中定义时长、波次、场地、敌人组合、打空生成规则、经验曲线和可用强化池，再通过 `createGame(levelId, seed)` 选择。敌人的 `xp` 独立于金币；强化的分类、权重、等级和前置统一控制抽取，不需要复制升级流程。

新增伤害机制需要同时补充配置、模拟行为、视觉反馈和规则回归；仅添加名称不会自动实现行为。可在后续章节加入毒沼、雷击或友方召唤物，但本次先完成三种基础地形与枪械组合，不增加未经验证的关卡。

`window.__bulletGarden.snapshot()` 仅返回深拷贝，没有改血量、跳关或伪造结果的入口。源码与构建制品都无需图片、字体、音频或其他外部运行请求。

## 验证范围

43 项模拟机制回归与独立构建通过。浏览器验收记录在 `docs/qa/browser-report.json`，12 局固定种子回放记录在 [平衡报告](docs/qa/balance-report.json)。平衡脚本输出首次生长/升级时间、各构筑胜负、伤害和对象峰值；它用于复现与调参，不等同于真人难度评估。不同构筑会消耗不同随机序列，因此不能把同一个种子的结果当作严格配对实验。

手机验收使用桌面 Chromium 的触屏模拟，不等同于 Android/iOS 真机。未运行整个仓库的 Pages、APK 或 iOS 构建。

首轮调参保留了四种偏好：枪械和混合构筑各 3/3 局通关；先取得一级多重弹再优先地形的构筑 2/3 局通关，另一局坚持 291 秒，地形伤害为 3715～5402；只优先地形的基准 0/3 局通关（211～240 秒）。因此现阶段地形适合与多重弹搭配，尚不能把纯地形路线描述成同等强度。没有通过赋予命中弹或计时充能来补足地形资源。首次自动生长约 1.7 秒，首次升级 14～15 秒；完整存活回放获得 12～13 次升级，后续真人试玩应继续评估选择频率与难度。

仓库依赖边界检查通过。全仓游戏配置审计发现 12 个由四个未初始化 Git 子模块引起的问题，未报出本游戏配置问题；没有为本次修改初始化无关子模块。

源码与独立制品的浏览器检查使用 Chromium 151：390×844 竖屏和 844×390 横屏均通过双指移动/定向射击、取消恢复自动、冲刺、暂停冻结与恢复；只移动即可自然生长并获得经验升级。后期四项强化在两种尺寸内均完整显示。暂停图标已核对为两根等高等宽的实心竖条。
