# 子弹花园

在被芽怪侵扰的庭院里，成为守园人，守住属于你的花园。

用手指或鼠标按住、拖动摇杆移动，武器会在附近出现有效敌人时自动瞄准射击，无目标时停火；抓住时机冲刺，避开包围。击退小兵、积累经验，在战斗间隙选择枪械强化或植物祝福，让这一局的花园逐渐长出不同的战斗方式。

探索十四个花园关卡，面对新的敌人和环境。解锁并手动释放植物技能，最多储存三次蓄力；倒计时结束后清理剩余敌人，才能完成守护。通关获得金币和成长经验，返回营地培养能力，再向下一处庭院出发。

支持手机触屏，电脑也可使用 WASD / 方向键移动、空格冲刺。无需注册，本机保存进度；清除浏览器存储会丢失本机进度。正常开始、成长和通关均不依赖广告。
