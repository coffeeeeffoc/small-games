# 清场、技能储存与独占页面验收

日期：2026-10-04。环境：Windows，Node.js 24.21.0，Playwright 1.55.1，Chromium 140.0.7339.186；浏览器验证使用 `dist` 构建制品和本地端口 4413。

## 已通过

- 131 项 Node 单元测试。新增覆盖：所有关卡与重试均无初始地形；到时停止普通刷怪、仍有敌人不能胜利；清场期间暂停、强化与死亡；首领死亡后仍须清理普通敌人；3 次技能储存、逐次扣除、剩余充能和容量上限。
- `controls/browser-report.json`：桌面与 320×568、390×844、844×390 手机尺寸；原生键鼠、触屏及 CDP 双触点。验证摇杆与瞄准同时操作、松手释放、触点取消、暂停、重试、倍速。实测战术面板、摇杆和冲刺均在 Canvas 外，且不覆盖技能卡。
- `charges/browser-report.json`：390×844 与 844×390，正常血量、正常经验升级与战斗充能，储存满 3 次后只选一次技能槽，用三次原生战场触屏连续释放。
- `screens/screens-report.json`：320×568、390×844、844×390、1680×900。主页、选关、营地与结算概览都占满屏幕，仅当前页面可见；页面独立滚动，无横向溢出。实际敌人伤害触发失败结算，返回主页可重看上一局，奖励未重复结算。
- 同一页面测试覆盖 `?dev=1`、localStorage `bullet-garden.dev=true` 和 `?dev=0` 覆盖本地开关。开发者模式下 11 关可选，正常模式仅首关可选；直接进入最终关，实际伤害导致结束，开发者概览显示试玩，金币、永久经验及通关记录未变。
- `challenge/browser-report.json`：正常血量、无存档 fixture，原生键鼠完成首关；在 307.5 秒清空全部敌人后获胜，击退 296 只，释放技能 102 次。此前普通非植物强化没有生成地形；植物只在选中对应增益后出现。
- `balance.txt`：12 次正常资源模拟回放全部通关，覆盖 4 种植物路线、3 个随机种子和 5 种主动技能；清场耗时正常超过 300 秒。
- `campaign-balance/balance-report.json`：种子 7，无购买与用正常奖励购买成长的两条策略均通过 11 关。属于模拟调参证据，不是人类试玩。
- `campaign-ui/browser-report.json`：横竖屏营地购买、存档写入失败、全部 11 关选择；该组使用已解锁存档 fixture，只用于覆盖后续 UI。
- `campaign-natural/browser-report.json`：无存档 fixture，正常血量实际通关后返回主页，再进入营地消费正常奖励、选择下一关、刷新恢复。金币、经验和成长均按实际结算保存，无重复领奖。
- `shrub-icon.png`：使用运行中的图标绘制模块单独放大检查，花叶灌木为圆簇绿叶与小花，没有蛇形藤蔓；这是绘制检查，不是额外玩法证据。
- 独立构建、格式检查和 `git diff --check` 通过。

## 范围

战术面板采用独立底部操作区。保留已解锁寒冰柱的掩体代价，并在说明中标明阻挡双方移动和子弹；其它现有植物与区域增益不形成硬障碍。花叶灌木选项使用带花的灌木图标。

浏览器虚拟时钟仅加速等待，不修改游戏状态；公开接口只读。桌面触屏模拟不替代 Android/iOS 真机、原生小游戏平台或手机性能验收。本次未完成真机验证。上一局概览保留在当前页面会话，刷新后不会恢复。
