# 子弹花园扩展验收设计

目标是保留失落庭院的核心体验，新增 10 个可游玩关卡，并证明成长、怪物、天气和地图规则可以继续由数据扩展。验收不以修改血量、跳关或伪造胜利代替正常战斗。

## 实现前的交付顺序

1. 在机制设计中明确成长数值、解锁条件、金币消耗、地图规则与敌人技能。
2. 保存成长机制效果图、各关卡地图效果图、各新增怪物样式图，并在设计文档中建立对应关系。
3. 效果图完成后才实现对应规则和外观。最终验收对照图与实际渲染检查轮廓、颜色、地图标识和技能反馈。

此顺序属于本次用户要求。设计与效果图可以按互不依赖的领域并行完成；模拟、渲染、界面的接口应先统一，避免同时修改同一文件。

## 现有基线与需要保留的覆盖

2026-10-04 起始检出的旧版本曾通过模拟及种子 7、42、81 的手动播种平衡回归；这只能说明该旧检出状态，不能作为当前 `origin/dev` 验收基线。同步最新 `dev` 后，以远端自动地形、经验升级、双技能槽、能量、枪械 build 与倍速版本为必须保留的基线。

远端模拟覆盖经验加成、地形祝福取得前不生成植物、自动地形与状态效果、两个独立技能槽的能量与手动施放、枪械组合、暂停、勝负冻结、移动边界、容量与确定性重放。恢复 `tests/simulation.test.mjs`、`tests/balance.mjs`、`tests/browser.mjs` 和 `tests/rendering.mjs`，扩展测试单独增加。首关继续 300 秒 / 10 波；强化次数由击杀经验控制，不再按固定波次发三次强化。

远端浏览器脚本使用真实键鼠和 CDP 多触点，只读取 `window.__bulletGarden.snapshot()`，验证技能充能、双触点移动与瞄准施放、取消、倍速与完整五分钟挑战。新增回归覆盖营地、战役和保存，已解锁存档 fixture 只用来覆盖后续内容；首次通关 → 奖励 → 升级 → 下一关的证据必须来自正常游戏。

## 模拟与内容验收

| 领域         | 必须证明的行为                                                                                                                                                                               |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 关卡目录     | 总计 11 个独立关卡，ID 唯一，顺序稳定；每关引用的怪物、植物、天气、地图和奖励定义存在。新增数据项不需要复制战斗循环。                                                                        |
| 地图         | 相邻关卡至少有一个实际地图元素变化；出生点合法；阻挡区不与出生点冲突；地面敌人能够追击或拆除障碍；飞行与钻地遵循各自通行规则。                                                               |
| 关卡胜负     | 第 4、8 关出现首领，第 11 关出现 BOSS；首领或 BOSS 存活时不能仅因计时结束获得胜利；普通关卡按其目标结束。失败和胜利后不得继续伤害、刷怪或记奖励。                                            |
| 通关经济     | 通关增加明确的金币或经验；一次结算重复执行、重新渲染、刷新页面或再次读取存档不能重复发奖；失败按照设计保留或丢失奖励；重试不会凭空增加金币。                                                 |
| 成长与购买   | 每次购买正确扣款和改变属性；余额不足、达到上限、未解锁和未知 ID 都不扣款；连点只产生实际成功的购买次数；攻击、攻速、生命、护甲分别产生可观测战斗差异。                                       |
| 等级解锁     | 等级阈值前一刻拒绝使用，达到阈值后解锁；宠物在阈值前不生成和攻击，阈值后实际参与战斗；怪物解锁与关卡推进条件一致。                                                                           |
| 枪械         | 伤害、攻速、散射、穿透或其他已设计特性按枪械定义生效；切换与升级不错误重置永久成长，不导致子弹数量无界增长。                                                                                 |
| 怪物技能     | 防控减弱指定控制；加速有明确触发与持续时间；受伤召唤有冷却和数量限制；护甲减少伤害；盾牌有方向或容量规则；钻地与升空有可攻击窗口；远程攻击先预警后命中。                                     |
| 植物与增益   | 新植物先满足永久等级，再通过实际经验祝福选择获得，随后自动生长；解锁前和只达到永久等级时都不生成地形。攻击型、支援型、治疗型等按设计作用，临时增益正确开始、到期及叠加，暂停期间不消耗时间。 |
| 地形         | 固定阻挡同时约束需要阻挡的单位；减速与植物、天气倍率按约定合成；爬坡概率跌落使用确定性随机数，不能使单位永久卡住；冲刺不能穿过约定不可穿越区。                                               |
| 天气         | 晴、阴、雨、雾、冰雹及实际启用的风、雷暴产生配置的伤害/攻速/移速/植物效果；不同天气能在固定场景下比较数值差异；雨雾不会生成 NaN，雷击有预警和边界。                                          |
| 存档         | 旧版只有最高击杀/音效偏好的玩家能正常进入；缺字段、未知内容 ID、损坏 JSON、负值、非有限数、过大等级都归一化；刷新保留进度，未完成战斗不会被视为通关。                                        |
| 确定性与容量 | 相同内容版本、存档、输入、种子产生相同结果；状态 JSON 可序列化；敌人、植物、子弹、召唤物、预警和粒子受明确上限约束。                                                                         |

单位规则测试可建立隔离场景以检查具体效果；平衡证据必须保留正常生命、资源、敌人和奖励，记录策略、随机种子、购入成长、结果与最后存活时间。不要把隔离规则测试的通关结果当作可玩性证据。

## 浏览器与触屏验收

运行源码和构建产物，分别覆盖 1440×900、390×844、844×390。使用原生点击/触屏完成：选择关卡、搭配技能、开始、双触点移动与瞄准施放、技能选择、冲刺、暂停/恢复、帮助返回、倍速、购买成长、自然失败、重试、通关奖励和下一关。

战役流程至少验证从首关真实通关后进入第 2 关、金币购买可见改变并刷新保留。首领关和最终 BOSS 应保存实战截图与只读状态记录；长程自然战役模拟负责覆盖全部 11 关，浏览器选择有新机制的代表关卡进行真实操作。

检查场景中央可直接触控、HUD 不挡玩家与敌人、列表可滚动且热区适合触屏；技能卡、关卡面板、升级面板在横屏也必须完整可达。取消手势、打开面板、窗口失焦后不得继续移动或重复施放。暂停图标继续为两根等高等宽的分离实心竖条，具备“暂停”无障碍名称。

同时收集 JavaScript 异常、console error、请求失败和 HTTP 4xx/5xx。构建产物要验证实际素材 HTTP 200 与 MIME，不仅检查文件存在。当前 `build.mjs` 仅复制 `index.html`、`style.css`、`src/` 与图标，`server.mjs` 只允许这些运行路径；新增素材置于 `src/assets/`，或同步修改并验证复制与允许路径规则。

桌面 Chromium 触屏模拟不能等同于 Android/iOS 真机；无头环境无法稳定重现后台可见性切换时，应记录实际使用的失焦验证，不能称为已验证真机切后台。

## 执行与证据

1. 先运行旧有模拟及平衡回归，新增内容与经济规则测试。
2. 跑全部关卡的正常资源重放，记录通过率、地图卡住情况及容量峰值。对失败关卡定位规则、路线或数值原因，避免修改测试阈值消除失败。
3. 构建并启动 `dist/`，运行浏览器触屏与战役验收，保存报告、代表地图、首领/BOSS、奖励和成长页面截图。
4. 执行仓库游戏配置、依赖边界与涉及的 Shell 独立游戏检查；未更改的整仓 APK/iOS 编译不作为本次必要检查。
5. 最终报告列出实际命令、结果和材料路径，明确尚未进行的真机测试。推送 `dev` 前检查只包含本次游戏与必要元数据变更。

## 优先缺陷风险

- 通关在每帧渲染中结算，或保存后重试导致奖励重复。
- `startGame` 重建状态时清空永久金币、经验、购买和解锁。
- 怪物选择只看波次，绕过玩家等级解锁；首领被普通生成器重复刷出。
- 新怪物复制旧路径或碰撞逻辑，钻地/升空仍被冰柱永久卡住。
- 分裂怪物在敌人数组遍历时添加单位，无限递归召唤或突破上限。
- 天气倍率多次累乘到基础属性，换天气或重试后不能还原。
- 新关卡展示图变了，但实际地图碰撞和战斗配置仍是首关。
- 地形祝福越过永久等级锁，或开始关卡时直接赠送未通过经验选择获得的植物。
- 关卡数量增加后横屏/竖屏面板溢出，下一关或升级入口无法触达。
- 本地源码可加载素材，构建目录或 Shell 子路径中丢失素材。
