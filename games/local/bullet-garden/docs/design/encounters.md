# 子弹花园：关卡与生态机制设计

本设计将已有 `ruins` 保留为第 1 关，并新增 10 关。关卡是同一座花园逐步深入后的轻微地形演变，而不是 11 套独立战斗代码。设计顺序为机制规则 → 地图/怪物效果图 → 数据与模拟 → 实机画面核对。规则先完成，11张独立地图图、怪物图鉴、成长/枪械/植物图随后生成归档，再进入实现；时间与哈希见 `visual-manifest.json`。玩法继承最新 dev 的自动地形祝福、局内击杀经验升级与双槽主动技能。

## 架构边界

- 内容目录负责关卡、敌人、植物、地形、天气、奖励与解锁要求，定义只包含可序列化数据。
- 行为注册表负责有限的通用动作：追击、冲刺、抗控、护甲、盾牌、受伤召唤、钻地、升空、远程射击与阶段切换。同一动作可被普通怪、首领和 BOSS 复用。
- 模拟只处理状态、确定性随机数、碰撞、伤害与事件。画面、音效、界面不能修改怪物能力状态。
- 渲染读取怪物 `visual`、`rank`、`abilityState` 和地图 `terrain`；地形的碰撞与渲染读取同一几何数据，避免出现“看起来能走却走不过去”。
- 永久成长与本局增益分开计算。永久攻击力、攻速、生命、护甲、枪械与宠物来自成长档案；本局强化仅保存到当前挑战。两者都通过带来源的属性修饰项叠加，天气无需知道升级菜单如何实现。
- 新增第 12～数百关时，添加关卡数据或章节生成规则即可。关卡使用稳定 ID 与显式 `order`，不按对象键排序推导进度；最高关与 Boss 规则从章节配置读取。

建议配置接口（实现可细化字段名称，但需保持职责）：

怪物解锁的“等级”在初始章节中采用到达关卡序号；玩家成长等级另有独立 `playerLevel` 条件，供后续章节组合要求。敌人池在加载关卡时验证解锁，不允许用未到达章节的怪物随机替代。普通小兵使用独立 `minion` 标识，并不能递归生小兵。

状态新增建议：`terrain`、`weather`、`enemyProjectiles`、`encounter:{spawned, defeated, entityId}`、`rewardReceipt`。实体能力状态保存 `cooldowns`、`mode`、`timer`、`shield`、`summoned` 等原始值；禁止把函数和 DOM 对象放入游戏状态。现有 `createGame/startGame/step/pauseGame` 接口保留；可用 `createGame(levelId, seed, profile)` 提供永久成长，而旧两参数调用仍有效。

### 地形天气模块对模拟的精确接口

`src/world.mjs` 不导入模拟、DOM 或渲染器，只读取配置与可序列化状态。初版墙体使用圆形石块组合，现有碰撞器可直接读取 `radius`；以后增加矩形时由世界几何模块统一处理，而不是每个关卡写碰撞逻辑。

```js
// 所有永久地面障碍，支持与寒冰柱数组合并。
terrainSolids(state);
// => [{ id, kind:'wall', x, y, radius, permanent:true, blocksProjectiles:true }]

// 点位是否与永久障碍相交。movement='air'|'underground' 忽略墙体，但不能出界。
terrainPointBlocked(state, x, y, (radius = 0), (movement = 'ground'));
// => boolean

// 读取脚下地形，更新 body.terrainContacts / terrainSlipCooldown / terrainLastX/Y。
// body.layer = 'ground'|'air'|'underground'，缺省 ground。
// 每次进入坡地最多掷一次确定性随机数；随机数写回 state.randomState。
terrainMovement(state, body, dt);
// => { speedMultiplier: number, slip: null | { dx, dy, terrainId } }
// slip 是相对位移，模拟通过原 moveBody 碰撞器执行，不直接改变 body.x/y。

// 全部系数缺省1；不改变永久档案和任何实体。
weatherStats(state);
// => {
//   plantDamage, plantDuration, plantHealth, seedRegen, enemySpeed,
//   enemyFireRate, gunRange, iceHealth, healPower, electricDamage,
//   airSpeed, projectileSpeed, slopeChance
// }
```

`weatherStats` 中 `enemyFireRate` 是频率倍率，远程冷却需除以它；`gunRange` 作用于有效射程；`plantDamage` 仅作用于带 `flower` 标签的花瓣炮，`healPower` 仅暖阳花，`electricDamage` 仅引雷芦。阴天生命/持续作用于所有植物，雨天自动生长频率作用于所有已激活祝福。怪物基础速度乘 `enemySpeed`，飞行额外乘 `airSpeed`。雨天荆棘减速幅度 ×1.1 在植物效果处理中计算，不能把减速因子直接乘1.1而让雨天控制更弱。

冰雹与雷暴的攻击时间表由模拟创建地面危险区并先发预警；世界模块只提供天气规则与倍率。危险区使用统一 `telegraphs` 数据，与怪物冲刺/出土一致，暂停时不推进倒计时。

## 植物规则

## 地形与天气

地形 `kind` 和效果独立：同种地图美术可以带不同参数，地形不需要复制敌人移动代码。阻挡圆形与矩形统一为碰撞障碍；玩家、地面怪、冲刺都使用扫掠短步与贴边滑行。飞行与地下怪通过移动层过滤地形。

| 地形             | 规则                                                                                                                           | 画面反馈                               |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------- |
| `wall` 石块/残墙 | 永久阻挡地面移动；可选 `blocksProjectiles`；避免封死通道，最窄可行走间隙至少 96                                                | 有高度与投影的石块；轮廓和碰撞边界一致 |
| `mud` 潮湿苔地   | 玩家速度 ×0.80，普通地面怪 ×0.72；飞行/地下忽略；冲刺受影响但至少保留 ×0.8                                                     | 深色湿土、涟漪；进入后脚边泥粒         |
| `slope` 苔阶坡   | 进入后速度 ×0.9；每进入一次由 seeded RNG 判定 22% 概率滑落到进入点后方 35 单位，冷却 1.8 秒；雨天 ×1.4 概率；滑落不能出界/穿墙 | 台阶方向线、坡顶边缘、滑落脚尘和提示   |

滑落概率按进入坡地的事件触发，不能每帧掷骰；角色留在坡上不会连续抽奖。出生点半径 120 内无墙，初始附近无坡；每关地图至少一条可连通的环路。永久障碍只占可玩面积约 4%～8%，减速/坡合计不超过 22%，保证每过一关只是局部演变。

天气是基础天气加独立风/雷暴修饰，每关准备界面显示直接效果，战场仅保留天气图标和短文字。天气加成来自统一 `Modifier` 数据，不直接改永久属性。

## 11 关章节配置

世界保持 1440×900、可玩边界 x=100～1340、y=150～750、玩家从中央 (720,470) 出生。第 1 关继续 300秒/10波；新增关卡 120～180 秒，每波 20～30 秒，每关 6 波。这既保留原关卡兼容，也让“通关→奖励→消费金币→新地形”的循环及时发生。各关继续通过击杀经验触发局内强化：初次升级12经验，后续阈值每级+10；本局5级起提供4选1。首领/BOSS 于最后波开始出现，必须击败才能通关，计时到终点后停止普通刷新但不直接赐予胜利。

普通刷新共同基线：初始间隔 1.8秒、每波减少0.13秒、下限0.68秒；怪物最多32只，第11关40只。首领出现时最多24只；召唤计入总上限。每关新增一个主要机制，保留前关至少80%的障碍位置。第1关原有世界装饰转成明确可见的轻量石块，不改变原测试依赖的出生和简单行走区。

通关奖励与击杀奖励分离。表中奖励只在正常胜利结算时支付一次，每次挑战使用 `runId`；结束界面重复打开、重载或重复按下一关不能重复领取。首次通关发全额奖金，重玩通关奖金为35%；失败保存25%的本次击杀金币，并按生存比例给25%的关卡经验。金币结算加入成长档案后才允许购物，规则在结果页说明。玩家等级由成长 agent 的经验阈值表决定，怪物关卡解锁不能暗自改该阈值。

章节进度连续解锁下一关，已通关关卡可以重玩。最后一关 Boss 列为章节数据，不能把所有未来关卡都写死为 `order===11`。每 4 关首领的默认模板可由生成器填充，但本章第 4/8 手工定义；第 11 为最后关 Boss。

### 后续数百关的扩充约束

后续章节声明 `chapterId`、`startOrder`、`levelCount`、`theme`、`enemyUnlocks`、`weatherPool`、`terrainMutationBudget`、`bossId`，生成器把声明展开成与手工关卡同形的 `LevelDefinition`。关键首领与首次机制教学可以显式覆盖生成结果。已发布关卡的稳定 ID 与世界随机种子不能因在数组前插入一关而改变；存档按 ID 保存通关记录，迁移映射由独立版本表处理。

每关最多改变两片地形或将已有障碍移动40单位。生成后检查出生安全区、边缘刷新点合法、主要环路连通；尝试上限后使用已验证的章节模板，禁止无限重掷。敌人池必须引用已注册能力和已解锁 ID，权重均非负且总和大于0；首领遭遇不得同时进入普通随机刷新池。关卡规模增长不会增加单场实体上限。

新增机制需补充“触发条件、持续/冷却、叠加规则、反制方式、命中层、上限、可视预警”七项定义，并先画效果图再实现。外观与能力可组合：新增耐火怪只需抗性修饰与新视觉，复用 chase/armor 行为，无需写新的整套敌人更新函数。

怪物图必须先于怪物代码。已生成 `concepts/monsters.png`：13种主怪各有面板，minion在brood面板展示，合计覆盖14个怪物ID。每种画全身、地面影子及对应技能动作，图例以稳定 ID 对应表格，保持当前植物精灵与荒废花园的可读风格。怪物配色和体积不能只靠名字区分。能力预警也要在图中画出：charger 的冲刺方向、brood 的裂荚与小兵、burrower 的土丘、glider 的地面与飞行、shield 的完整/碎裂护罩、spitter 的蓄力弹。

## 验收关注点

1. 11关均可选择/解锁/进入，关卡 ID 与序号唯一；地图与敌人引用完整，天气/奖励/解锁数据可验证。
2. 第4/8关出现必杀首领、第11关出现必杀BOSS；时间到而首领未死仍战斗，击杀后结算；无敌人的普通关按生存计时结束。
3. 防控仍有最低可察觉减速；护甲/盾正确吸伤；母株最多4小兵且不递归；钻地/升空可观察、有合法命中规则；敌方远程弹不种植物。
4. 永久阻挡、植物阻挡、冲刺、弹道读取同一障碍；泥地影响双方；坡滑落每次进入最多判一次且使用可重放随机数。
5. 天气影响在准备页可见、暂停时冻结；雾不遮攻击预警；冰雹/雷击提前警示且可躲；天气视觉不改变重放随机序列。
6. 通关奖励单次领取、重玩可再赚但不能重复结算；扩展数据不依赖11关硬编码；存档未知版本/未知内容容错。
7. 390×844/844×390触屏实际运行，移动+主动技能双触点，双槽选择、冲刺、暂停/取消、进入下一关/消费金币；检查首领血条、天气文字与警示不被控件遮挡。

## 实现与独立检查

`src/config.mjs` 已实现11关、14种怪物、6种植物元数据、5天气与风/雷修饰，重导出 `catalog.mjs` 的原有祝福、双槽技能与枪械构筑池。`src/world.mjs` 提供同源地形碰撞、移速、坡滑落和天气倍率。新关的生成只改变最多两处地形，稳定地形ID跨关保留。

实际入口 `registerContentPack({version:1,levels,enemies,plants,weather,buffs})` 先校验整包，再追加不可变定义。内容目录容器可扩充；失败时全部目录不变。新植物同时派生自动BOON及boon-ID经验强化，确保不只是定义可加载而是玩家可以获得；新weapon类别buff同步武器发现目录。新植物可给 `autoInterval` 覆盖生长频率，缺省沿用 `regenSeconds`，等级条件沿用 `unlockLevel`。

独立执行的 Node 断言通过：11地图边界/120像素出生安全区/32像素网格全场连通；14怪、6植物和天气引用与处理器完整；无效内容包不改变任何目录，合法第12关可追加并深冻结；坡地持续停留120步只消费首次入坡的一次随机数，空中忽略坡地。战斗、经济、浏览器回归由专项验收记录。
