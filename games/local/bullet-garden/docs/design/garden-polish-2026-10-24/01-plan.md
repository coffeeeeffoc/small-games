# 子弹花园：操作、成长节奏与花园界面

保留 Cocos 3.8.8、十四关稳定 ID、旧存档、三蓄力技能和清场胜利规则。用户本次授权继续优化，不提交或发布。

## 本次范围

- 移动：复现正式构建中的摇杆输入；支持按住固定摇杆的方向、连续拖动、松手/取消归零，补齐桌面 WASD/方向键与空格冲刺。暂停、失焦、切页清空输入。
- 节奏：基础射击放慢，保留攻速强化空间；三选一主要来自击杀经验，首个收益需要一段清兵，不用开局连续弹窗。用固定种子模拟衡量首次强化、后续间隔和首关通过率。
- 呈现：当轮目标采用深绿、羊皮纸、古金边框；后续新样式按最新认可图更新场景与控件。首页主次按钮、图形菜单；选关徽章和紧凑任务卡；战斗 HUD、摇杆、技能图标；三选一图文卡、暂停/结算/营地等复用一致控件。
- 交付：补齐 publishing 八类资料，截图/录像来自本次真实 Creator 构建；效果图单独标注。

## 选择与影响

使用 Graphics/Label/Sprite 实现共享控件；新视觉目标要求更换背景、皮肤或控件时同步实现，不以现有实现限制样式。规则只改共享模拟/成长配置，旧网页参考入口自然复用；正式输入和 UI 只改 Creator 两个脚本。保留现有广告和持久化契约，不修改公共平台模块。

验收覆盖 320/330/390/430 手机视口及横屏；触屏无冲刺移动、方向按住、反向拖动、多指、取消、键盘、失焦；首关自然通关与强化卡、存档重载；纯规则/平衡/类型检查。仅桌面 Chromium 触屏模拟，不声称手机或原生 SDK 验收。
