# 子弹花园扩展：视觉与实现顺序

设计冻结日期：2026-10-04（Asia/Shanghai）。保留失落庭院，新增十关，共十一关。先完成本设计与机制文档，再生成效果图；效果图归档后才能编写对应游戏实现。效果图是美术目标，实际游戏以同一套 Canvas 2D 形状、色彩与特效实现，保持无需外部运行资产。

## 成长与枪械

永久成长六类：攻击力（粉色花瓣枪）、攻击速度（双弹轨迹）、生命值（红心萌芽）、护甲（青铜叶盾）、种植精通（翠绿根系）、宠物助手（发光蜜蜂，第5玩家等级解锁）。金币逐级购买，经验提高玩家等级并解锁。武器三个独立升级轴：伤害、连发频率、穿透（玩家等级4解锁）。界面为深绿/黄铜卡片、清楚的当前值/下一档/金币成本、锁定等级；局内随机增益与永久成长分开。

## 植物与场景

保留荆棘、寒冰柱、爆炸蘑菇；新增金黄色治疗向日葵（玩家等级2）、蓝紫色雷鸣芦苇（等级4，对空）、粉色花瓣炮台（等级6）。静态地形分石块阻挡、泥地减速、阶地攀爬及概率滑落；概率用模拟随机种子，不用绘制随机数。天气晴/阴/雨/雾/冰雹，叠加大风/雷暴；明确粒子、色调与地面范围预警，避免遮住控制区。雷击和冰雹先警示后伤害。

## 关卡效果图要求

每一关独立效果图，使用相同俯视略等距战术庭院风格、1440×900逻辑比例与开放中心出生点，避免结构完全跳变。图只展示地图，美术不绘制功能UI。中心可环绕，障碍不封死出口。

1. ruins 失落庭院：暖沙色菱形地砖、苔藓石墙、粉色花。
2. meadow 晨露草甸：同庭院，边缘生草、少量矮石与青草慢速区域，晴。
3. wetland 雨后湿地：同庭院新增泥洼、浅水反光、小石块，雨。
4. quarry 岩壳采石场：庭院边缘扩大灰石堆、首领空地，阴。
5. windpass 长风隘口：保留石堆，增加风吹草与开阔通道，晴+大风。
6. hollow 地下根穴：同布局，地砖根系裂缝、橙色孢子窝，阴+雷暴。
7. terraces 青苔阶地：同庭院，外围低矮阶台和缓坡、攀爬/滑落提示，雨。
8. bastion 叶盾堡垒：同阶地加蓝铜盾门和石台，首领空地，阴+大风。
9. mistwood 迷雾林庭：同庭院边界茂密树根、薄雾和可读地面，雾。
10. hailfield 冰雹荒原：同庭院覆霜、冰雹浅坑、蓝色预警地圈，冰雹+大风。
11. heartgarden 核心花园：原庭院中央旧徽章演变为红紫花核、四周根触手、BOSS空地，雨+雷暴。
