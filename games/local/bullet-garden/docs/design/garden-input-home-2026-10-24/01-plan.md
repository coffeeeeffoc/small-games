# 鼠标/手机输入、有目标射击、战斗首页

沿用固定战场、八方向角色、现有成长节奏和存档。用户反馈 Web 鼠标摇杆无反应，并要求手机手动操作可靠、无敌人不射击、首页表达花园战斗与敌人。

- 输入：分别复现纯鼠标、触摸设备上的鼠标、触摸后切鼠标、摇杆中心拖出、移出画布/松手/取消/失焦。手机继续使用单指移动、第二指冲刺/技能，不能用键盘验证替代。用真实生产构建和只读快照观察；手机真机证据另列。
- 射击：自动瞄准只认存活、可命中、射程内敌人，无有效目标时不发新弹；排队连射也不得在空场继续盲射。保留显式手动瞄准接口用于规则测试与旧参考入口。
- 首页：制作独立透明度不变的竖屏战斗插画，保留原场景光照、白发雏菊叶帽守园人与种子炮。中部清楚画出朝敌人开火、逼近的紫色芽怪与苔石怪；顶部留标题、底部留按钮。原图归档保留，用新资源名接入首页，其他菜单不必更换。

先检查并生成首页图，再接入运行画面。用单元回归、真实鼠标/触摸、多指/生命周期以及生产首页/通关录制验收，更新受影响的上架材料。无提交或发布授权。
