# 鼠标、手机操作与战斗首页验收

日期：2026-10-24。引擎为真实 Cocos Creator 3.8.8 web-mobile，源码指纹 `f8d7e3d9611d6e646c8246d714abe3bfa703b676b35e820a7e9cb99872235e46`。未提交、推送或发布。

## 修复与范围

- Web 鼠标和触摸使用同一套 Pointer Events，按下后捕获该指针，按画布实际尺寸换算坐标。摇杆中心向外拖、直接按边缘、鼠标移出画布松手、触摸取消都走已有的手势状态；原生小游戏保留 Cocos Touch 输入。没有增加依赖。
- 复现了内嵌页面的首次输入丢失：`pointerdown → focus → clearInput → pointerup`，新按下的输入被焦点恢复误清空。清理仍由失焦/隐藏/切屏负责，恢复焦点不再清掉新手势。回归覆盖首次鼠标点击及首次触摸进入内嵌游戏。
- 独立页面的基线鼠标按住、拖动能够移动，未据此把用户原问题归结为唯一原因；现在也覆盖触摸后立即切鼠标、失焦、移出画布等差异路径。
- 自动射击只选射程内存活、可命中的敌人；空场、射程外、已死亡和潜地目标均不发新弹。自动排队连射在每次发射前重新找目标，目标消失就取消该发。已发出的子弹继续飞行。显式手动瞄准接口保留供规则测试和旧参考入口使用。
- 首页接入独立 `home-battle.png`：守园人在花园中向紫色芽怪开火，另有叶怪、苔石怪与南瓜敌人。由内置 imagegen 参考原首页和角色图集生成；提示词见 `home-prompt.txt`。原图保留，其他菜单仍使用原素材。

## 当前证据

- `node scripts/typecheck.mjs`：通过。
- `node --test tests/*.test.mjs`：173/173 通过；空场停火、目标无效、队列取消有直接回归。
- `node tests/balance.mjs`：12 组正常生命构筑通过，验证自动射击修改后仍可完成战斗。
- [鼠标/内嵌输入报告](actual/pointer-report.json)：纯桌面及触摸设备浏览器的鼠标按住均移动约 67 个世界单位，中心拖动、反向、画布外松手、触摸后立即切鼠标、失焦清理通过；内嵌页面第一次点击/触摸即进入战斗。
- [布局及真实通关报告](actual/polish-report.json)：320×480、640×360、320×568、330×717、390×844、430×932、844×390 七种视口通过；首次强化在 26.72 秒/8 次击杀后出现；正常速度首关 60.00 秒、19 次击杀通关，保存后重载一致。页面错误为零。
- [多指/生命周期回归](actual/regression/browser-report.json)：四种视口的移动加冲刺、触摸取消、旋屏、暂停/恢复通过；另覆盖真实技能释放/取消、碰撞失败、重试和内嵌消息。
- [移动回归](actual/regression/movement-report.json)：330×717、320×568、844×390 的触摸方向、键盘、失焦和暂停退出通过。补测曾遇到宿主浏览器启动超时与渲染延迟；移动断言改为先检查即时输入，再等待真实游戏时间推进，避免用固定墙钟等待误判。未改动游戏时钟或跳过操作断言。
- [音效生命周期回归](actual/regression/audio-lifecycle.json)：通过，使用真实 WebAudio 验证首次手势、静音、隐藏/恢复、组件销毁及延迟加载取消。资源就绪等待与公共浏览器夹具统一为60秒，未放宽音效断言。

首页与战斗截图均来自该生产构建。完整首关录像为浏览器真实输入录制，117.08秒，含加载、菜单、暂停和选择过程；19秒宣传片使用实际首页截图3秒与录像7–13秒、72–80秒、101–103秒拼接，不用宣传片代替完整玩法录像。两者均为390×844且无音轨，已核对ffprobe与解码画面。八类资料见 [publishing/STATUS.md](../../../publishing/STATUS.md)。

## 边界

移动端已实现单指移动、第二指冲刺/技能及取消/失焦处理；桌面 Chromium 的触摸与多指模拟不能代替 Android/iOS 真机验收。本机局域网预览地址已响应当前构建，同一 Wi-Fi 手机仍需实际确认网络可达和操作手感。没有改动防火墙。未执行原生渠道打包、广告真库存或发布审核。
