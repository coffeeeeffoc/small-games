# 回合布阵改造

已批准：按三张效果图实现并推送 dev；残字不能出战，凑齐自动成卡，完整卡拖入空地或拖到同名个体相加升级，共用 6 个上阵名额。

1. 共享规则改为整备、自动战斗、回合结算；阵容持久，战斗单位每回合重新生成。残字自动消耗，完整卡不自动合并；AI 使用相同资源、命令与上限。
2. 复用 Creator、现有角色、特效和关卡。接入批准风格的空战场、水晶；卡牌只显示实际持有内容，拖放含取消/无效落点，战斗收起操作区，暂停冻结一切模拟。
3. 迁移对局存档版本，保留关卡进度和旧对局备份；同步引导、图鉴、奖励、宿主冒烟和实际浏览器用例。
4. 验证规则、确定性、非法输入、升级/分兵、AI公平性、30关可达性；真实 Creator Web 构建，手机触屏、横竖屏、暂停/恢复、刷新验收。补齐实际发布截图和视频及资料状态。
5. 独立分支提交；正常合并远端 dev，验证准确候选，再非强制推送并核对 CI/Pages。

范围：assets/scripts/core、MergeFront/MergeView、运行素材、tests、README/设计/发布资料，以及 Shell 中 merge-front 的实际交互调用。无需新依赖、新引擎或联机模式。

临时平衡参数：水晶 20，战斗 30 秒，获胜每回合伤害 2 + 存活单位数（最高 8），整备补给 90；12 回合未击破则按剩余水晶判定，平血为平局。双方同规则；均可在上/中/下自由布阵，不设置固定路线。
