# 神机合阵 · 云上工坊

中文、可触屏操作的神话机关策略游戏。征集姓名残字，拖放觉醒神将，合成升星、装配机关，通过自动战斗守核或攻城。

## 运行

从仓库根目录执行：

```powershell
pnpm --filter @small-games/merge-front dev
```

打开 `http://localhost:4197`。选择防守或进攻、标准或险境，布阵后开始。开发服务使用固定端口，端口占用时会明确退出。

```powershell
pnpm --filter @small-games/merge-front test
pnpm --filter @small-games/merge-front build
pnpm --filter @small-games/merge-front test:browser
```

`test:browser` 需要已启动的服务，默认检查 4197；也可以通过 `GAME_URL` 指向构建后的 preview。输出为 `dist/`，相对资源路径支持目录及 iframe 运行，已登记 Shell 的 Game Catalog。

## 玩法

- 初始：180 灵石，部署台上有「哪」，候补席有「吒」、离火铳和「孙」。先把「吒」拖到「哪」上，再装上离火铳。
- 残字：哪＋吒、孙＋悟＋空、杨＋戬。顺序不限，重复残字不能合并；姓名未齐时沉睡，不攻击、不生产。
- 升星：同名同星完整武将合成，最高三星；同类同星机关也可升级。已有装备会按规则保留或合并；不兼容组合会拒绝，物品不丢失。
- 联动：哪吒＋离火铳＝莲焰机甲；孙悟空＋震雷炮＝齐天重炮；杨戬＋巡天机＝天眼蜂群。可直接装备，或在部署台四邻相接。一件邻接机关只联动一位神将，被占用后不再独立作战/生产。
- 操作：拖放；或点击单位选中，再点击目标格。再次点击已选单位可取消。无效落点、触摸取消、失焦不会吞物品。
- 支援：神机超频在 6 秒内提升攻速与生产速度 55%，并为现存神将补充能量，冷却 36 秒。45 灵石修复核心 280 耐久。回收返还累计成本的 60%。

### 防守：云关守御

十二格对应三路四列，敌军从右侧入场，普通攻击限本路。右侧格先接敌，近战在前、远程靠后；联动范围伤害和大招能覆盖邻路。八波全部清理且核心尚存即胜利。武将阵亡后经过恢复时间再入场，期间有防线空缺。波间获得补给，战斗中可以继续采购、升星和调位。

### 进攻：神机远征

部署格变为生产配方，循环造兵攻城。完整神将基础周期 12.5 秒，孙悟空 15 秒，机关 12 秒；升星每级加长基础周期 22%，合体再乘 1.5。合体出厂具有更高生命、攻击和对应强化技能。调整位置或联动关系会重置相关进度，不能在即将出厂时免费装配。敌晶 6000 耐久，己方核心 1600；敌军持续增援并增强，击破敌晶获胜，己方核心归零失败。

## 表现与首版边界

三位神将和三种机关均使用原创 Canvas 二维关节模型，带沉睡、入场、呼吸待机、行军、普攻、蓄力、大招、升星合体和退场动作；火焰、重炮、巡天光束有不同攻击表现。音效由 Web Audio 合成，需用户操作开启。

暂停和切后台会冻结战斗与生产，回到页面后显式继续。仅本地保存声音偏好和胜场，当前对局不会在刷新后恢复。无需登录或远程素材；未接入微信原生小游戏 SDK。

| ----------------------- | -------------------------------------------- |
| `src/content.mjs`       | 神将、姓名、机关、售价与文案                 |
| `src/engine.mjs`        | 无 DOM 的合成、经济、生产、战斗与胜负规则    |
| `src/render.mjs`        | 浮岛战场、角色关节动画、机关与战斗特效       |

| `tests/engine.test.mjs` | 合成事务、生产联动、时间、生命保留、策略模拟 |
| `tests/browser.mjs`     | 实际鼠标/触摸输入与生命周期回归              |

## 验证记录

规则测试、生产构建、工作区依赖边界及 Shell 目录集成测试通过；规则模拟覆盖空阵失败、单个合体神将失败和合理三路阵容获胜。构建不含运行时第三方资源请求。

生产预览的 8 组 Chromium 回归通过，无页面或资源错误：鼠标/真实触摸拖拽、取消、两字/三字觉醒、装备升星、暂停与后台恢复、联动减速生产、失败重开、完整双模式胜利及切换模式。实际 UI 参考策略进攻约 69 秒、防守约 353 秒通关；手机模拟覆盖 390×844、320×740 与 844×390。

浏览器回归报告生成于 `artifacts/browser-report.json`，截图同目录。报告以实际运行输出为准。移动浏览器模拟不代表物理手机、微信客户端或长期数值平衡验证。
