# 素材与授权

- 队员、感染体、盾牌、Boss、车辆、建筑、树木、锁具、补给柜、吊架：`src/client/scene.ts` 原创程序化几何与材质，没有外部模型文件。
- 招牌与路牌：Canvas 绘制，虚构榕树街、长乐面馆等街景文字；不包含真实店铺商标。
- 弹体、枪口、弹壳、命中火花、倾倒消散、爆炸扩散波、奖励与预警：实例化程序化几何，没有复制外部贴图。
- 背景节奏、步枪 / 霰弹 / 榴弹、材质命中、死亡、领奖、警报与胜负：`src/client/audio.ts` 使用 Web Audio 振荡器、原创噪声缓冲和音序合成，没有第三方录音或引用歌曲。
- 字体：使用操作系统已有字体回退，未将商业字体文件打包进制品。
- Three.js / React / React DOM：使用仓库已有对应版本，授权随依赖包保留。没有引入未核验发行授权的外部美术或音频资产。
- 用户提供的两张图只作为颜色、题材和互动方向参考，不嵌入游戏、不作为战场背景、不冒充实机。
- `docs/evidence/*.png` 来自 Playwright 打开的真实运行版本。不是 imagegen 效果图。
- 《街区突围》/ Urban Breakout 均为工作名，尚未进行正式名称权利检索。
