# 决策记录

1. 沿用父仓库 pnpm workspace / Vite / TypeScript / React，Three.js 与类型版本均固定 0.180.0；React 19.2.8、Vite 8.2.2、TypeScript 7.0.2 与仓库已有依赖一致。未升级其他游戏依赖。核对实际类型和 [Three.js 文档](https://threejs.org/docs/)、[Vite 文档](https://vite.dev/guide/)。Vite 8 使用函数形式的 manualChunks。
2. 游戏归属 `games/local/urban-breakout`，遵循仓库 Game/Shell 边界。当前在游戏包内划分 `core / content / client`，不为尚未实现的服务端生成空 packages；P2 可直接 import 核心纯 TS 模块，抽包不改变规则。
3. 本轮先完成 P1。全体 24 关、权威联机和 PostgreSQL 尚未实现；不把 UI 菜单或本地存档冒充这些功能。没有创建生产身份、云资源或执行公开部署。
4. 样板是综合实战验证，暂不等同最终 24 关中的正式第 01 关。它同时包含三个武器、救援、阶梯箱、Boss，未来须拆为前六关渐进教学。
5. 30 tick/s；补给确认 5 tick（约 0.167 秒），进入阈值 |x|>=2.9，保持阈值 >=2.55；横向速度最多 6m/s。普通步枪单队员 10 DPS，初始 6 人合计 60 DPS。击破 360 点需要约 6 秒，8 秒不保证 660 档。
6. 每人独立生命与射击冷却；武器奖励装备指定数量的存活队员，优先选择尚未持有该武器的人。切换目标、装备和离开瞄准带不重置冷却。人数上限 12，超额救援每人转 15 护盾，护盾总上限 120。
7. 90 秒结束且 Boss 已击败才胜利；战斗失败立即结算。P1 Boss 冲撞与震地有固定前摇，吊架造成 240 伤害并产生 12 秒破甲窗口。固定波次有限，不召唤无限计分怪。
8. B 平衡夹具第一轮在 z=-5 生成 10 名冲刺者，固定谨慎策略也来不及回防。改为 z=-9，为横移回防留出可操作时间；所有策略统一使用修改后的同一场景，不按策略更改敌人。完整老街时间线未因这个夹具调整而改变。
9. 不新增美术依赖，采用原创程序化几何 / 材质 / 招牌 / 音效。轻量透视镜头而非背景海报。附图只用于橙白 / 紫色 / 金色和城市气氛参考。
10. 只有离线练习可暂停，切后台自动暂停并清空输入；已加载的战斗无需网络。不是离线安装 PWA，首次加载和刷新仍需要静态服务。P2 必须换成服务端时钟，暂停面板不得暂停在线世界。
11. 当前没有障碍碰撞玩法：奖励位于道路内侧，建筑及停放车辆位于道路外，不用纯装饰假冒遮挡物。P4 加入路障时必须同时实现命中阻挡和可校验的地图几何。
12. 本机记录最多保留最近 20 次练习，只是 UI 便利，不是可信成绩。未来计榜必须来自独立权威会话及数据库事务。没有把输入约束单测称为联网防作弊完成。
13. 视觉反馈修订：普通射击继续使用逻辑射线判定，视觉改为沿射线移动的短弹体与尖头；霰弹使用扇形弹粒，榴弹使用现有权威投射物轨迹的插值与翻转弹体。视觉飞行不额外生成伤害、刚体或改变射速。感染体外观由独立的 `事件 ID:appearance` 派生，服装、体型和步态不消耗战斗随机流。沿用四类实例化几何，无新增美术依赖。
14. 奖励卡片以装置投影为锚点，竖屏放在装置上方、矮横屏放在下方；奖励描述与伤害进度分行。小屏省略重复装置名称，保留奖励效果、伤害门槛、时间和已领取档位。暂停图标使用两个独立 SVG 矩形，保留“暂停”无障碍名称。
15. 声画强化沿用原创合成资源：116 BPM 低音 / 鼓点 / 合成旋律，战况控制编曲密度；警报、受伤和领奖时压低背景音乐。音效与音乐分总线调节，统一压缩限幅，最多 48 个发声源；只有 Runtime 驱动音序，不另建计时器。暂停 / 退出清理发声源，重开不叠加音乐循环，Web Audio 不可用时仍可玩。
16. 命中与死亡元数据由实际伤害事件产生，补给、护甲、感染体有不同反馈；短弹道飞行只延迟表现，不延迟权威结算。死亡模型倾倒 / 缩小后散去，不留可攻击尸体，不改变击杀和计分。每帧最多 280 个特效部件、12 个消散模型；新增一种复用环形几何，实例缓冲只上传实际使用范围。连续击退提示不增加伤害或得分。
