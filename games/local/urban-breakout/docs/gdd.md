# P1 简明玩法与状态机

目标：用有限火力在前方威胁与街边奖励之间做选择。第一次点击就进入战斗，没有基地、货币、广告复活或永久伤害加成。

初始 6 名橙白救援队员，生命各 20，上限 12。小队只能横向移动。每个存活队员提供真实射击；同一队可混用三类武器。队员阵型在样板第 46 秒解锁：2 列收拢 / 3 列展开，改变实际站位和射击覆盖，不修改伤害系数。

| 武器 |          单次伤害 | 冷却 tick | 范围 | 特征                                |
| ---- | ----------------: | --------: | ---: | ----------------------------------- |
| 步枪 |                 5 |        15 |  23m | 逻辑单体射线                        |
| 霰弹 | 10 / 有效覆盖敌人 |        25 |  11m | 近距离锥形清群；打箱只结算一次      |
| 榴弹 | 22 / 有效覆盖目标 |        48 |  23m | 有飞行时间，半径 2.5m，爆破绕过盾牌 |

主动震荡弹：以小队前方 z=1 为中心，半径 9m，对敌造成 90 爆破伤害，冷却 24 秒。不自动领取奖励。它给“先清场再投入火力”提供手段。

## 奖励状态机

`waiting → active → claimed / expired / excluded`，终态不能重新触发。每个事件有稳定 ID，每档 grantId 是 `事件ID:档位索引`。窗口来自关卡的绝对模拟 tick，移出、重入和状态序列化不重置它。

每 tick 顺序：移动和输入约束 → 生成事件 → 选目标与冷却攻击 → 投射物命中 → 跨档结算 → 截止过期 → 敌人移动 / 攻击 → 胜负。截止 tick 本身的合法攻击可以领奖，晚到的榴弹不可以。

转火状态：无有效目标时前射；进入同侧带保持 5 tick 确认；确认后整队普通攻击转移。部分队员射程不足时停火，不补算正面输出。爆炸的实际半径可以覆盖不同目标，但不凭空复制一发伤害。离带、领完、过期、目标出射程会解除锁定，冷却保持。

计分：固定波次击杀分 + 已领取档位每档 80 + 通关 500 + 存活生命 + 成功通关时实际救援每人 80（救援项上限 600）。当前是有限脚本的本地练习分，P3 前必须实现分项预算、规则版本隔离及数据库权威结算。
