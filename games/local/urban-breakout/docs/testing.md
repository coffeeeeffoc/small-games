## 复现 Shell 检查

正常集成使用父仓库 `pnpm --filter @coffeeeeffoc/shell-web dev`，它会准备全部游戏。只验证此改动时，本轮先构建本游戏，将其 `dist/*` 复制到生成目录 `apps/shell-web/public/games/urban-breakout/`，然后执行：

```sh
pnpm --filter @coffeeeeffoc/shell-web exec vite --host 127.0.0.1 --port 4333 --strictPort --mode pages
pnpm --filter @coffeeeeffoc/urban-breakout test:shell
```

`SHELL_URL` 可以覆盖 Shell 地址。浏览器检查请串行运行。无需、也没有生产数据库或平台密钥。
