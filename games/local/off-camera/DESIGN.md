## 1. 这款游戏让玩家做什么

看见包裹被送进监控盲区，又被送出来。把“贴封条”“盖章”“交换包裹”等**有动作图解的事件卡**拖进时间槽，立即播放自己的重演；用包裹位置、印章落在哪个物体上、墨迹压住还是被封条遮住，验证顺序。

第一版是一局五件小案，约 2～4 分钟；单案约 15～45 秒。不写长剧情、不审讯、不判定人物动机。希望玩家产生的瞬间是：“章在封条上面，所以封条一定更早贴上去。”

**唯一合理的范围必须说清楚：**游戏公开本案可用动作、次数与物理规则，在这个有限模型内要求证据唯一确定答案；不声称两段录像可以排除现实中的一切可能。没有展示过的擦除、换壳、伪造或第二枚印章，不可突然作为谜底。

首轮优先验证两件事：不读长文字也能靠图操作；错误重演会留下肉眼可比较的错误痕迹。美术精度与故事量不能替这两件事过关。

## 2. 三个候选方向与取舍

| 候选 | 实际操作与决策 | 优点 | 最危险的问题 | 本轮结论 |
| --- | --- | --- | --- | --- |
| A：盲区重演台 | 将图解动作排进时间槽，播放手部动作和物体变化，擦动对照自己的结果与实拍 | 选择会改变具体可见结果；可穷举检查证据；两三个动作即可成局 | 容易退化成读文字排序；固定题库会被记住 | **推荐**，用大画面、动作动画与视觉矛盾承担玩法 |
| B：脚印路线还原 | 在俯视场景拖动人物路径，解释湿脚印、门和掉落物 | 操作空间强，人物行为更接近监控故事 | 接近无穷多条等价路径；会变成找唯一像素路线；连续碰撞、脚印采样成本大 | 舍弃首版；需要更大的可视范围和路线等价规则才值得做 |
| C：倒放找异常 | 擦动录像，点出变动，再选事件 | 15 秒展示容易理解，触屏操作简单 | 玩家主要在找不同，因果决策很薄；点对物体不等于推断事件 | 不作为主玩法；只借用擦动和局部放大作为观察工具 |

推荐 A 不代表已经证明好玩。若目标观众在第三关仍只看事件文字、随机换槽，应该停下改核心交互，而不是继续加案子。

## 3. 场景与证据约定

### 一个能看清的监控盲区

场景是夜班快递收件台。一辆两格包裹托盘从入口进入不透明隔板后，在出口再次出现在同一摄像机画面里。玩家看到“之前”和“之后”两段约 0.8 秒的画面。盲区里的操作没有实拍画面；游戏切入的俯视重演永远标注“你的推演”。

两格是托盘自身的“左格 / 右格”，用固定边框和刻度标识，入口与出口保持相同朝向。搬入搬出是固定过场，不算玩家要推断的动作，不会改变包裹位置和痕迹。避免透视翻转制造伪难度。

两只纸盒分别用**珊瑚色三角标**和**青绿色方块标**识别；颜色之外必须有形状。盖章区位于盒盖中央，身份标位于角落，不会被章或封条遮住。

### 首版只有四种动作

| 图解动作 | 精确作用 | 玩家怎样事先知道 |
| --- | --- | --- |
| 盖章 | 固定章机在**托盘左格**压下一个粗圆环；压到当时最上层的表面 | 卡片显示固定左格章机和上下箭头；点击卡片可看独立小演示 |
| 贴封条 | 给卡面标出的**三角盒**贴一条不透明奶黄色封条，横穿盖章区；跟随物体身份，不跟随格子 | 卡片画三角标、纸带与落点；拖入槽位时目标轮廓短暂高亮 |
| 交换 | 左右两只盒子交换位置，盒子及其封条、墨迹一起移动 | 两只形状标和交叉箭头直接表示动作 |
| 揭封条 | 揭下三角盒现有封条，放入托盘上的废纸夹；封条上的墨迹随封条离开 | 动画保留揭下来的纸带，不让关键证据凭空消失 |

封条遮住旧墨迹；章盖在封条上会留下纸带墨迹；揭下封条不擦掉盒盖已有墨迹。墨迹即时干燥，不渗透、不抹花。首关用演示公开这些简化，不考现实胶带材料差异。

“揭封条”要求当时有封条；“贴封条”要求当时没有封条。无效动作会停在那一步，给出具体物体反馈，不悄悄跳过。每张卡本案最多用一次，槽位数直接显示本案动作数；这是公开的谜题限制，不假装由画面推知。

## 4. 直接交互与一段 30 秒实操

竖屏从上到下是：实拍观察窗、两/三个时间槽、动作卡、重演按钮。准备说明只在首关出现一句：“拖动动作，重演镜头外的几秒。”不做大厅、章节地图或多步表单。

- 实拍窗有“之前 / 之后”大切换键，时间带可擦动。盲区段只显示隔板，不插入猜测画面。
- 点盒盖或废纸夹可打开约 2.5 倍局部放大；大按钮返回。关键证据都有对应放大入口，既可点也可键盘聚焦。
- 拖事件卡到槽里；拖已有卡可换槽，拖回卡区移除。也支持“点卡 → 点槽”的替代操作。
- 卡片不只有字：固定物体形状、手势、落点和动作方向组成图解。短中文名负责补充，不承担全部推理。
- 补满槽位后自动播放一次约 1.8 秒的“你的推演”，立即看见本次操作导致的痕迹；还可点“重演”。不自动宣判。
- 点“对照”后，在同尺度场景中左右擦动“实拍 / 你的推演”。提交“这样发生”才显示矛盾或确认。
- 正确结果播放完整重演约 2 秒，显示“证据吻合”，随后可点“下一件”。不加漫长奖励动画。

**首关目标：实拍之后，三角盒的奶黄封条上有连续的圆环墨迹。**

| 时间 | 玩家做什么 | 游戏发生什么 |
| --- | --- | --- |
| 0～4 秒 | 看三角盒入盲区、带着封条和章出来 | 之前无封条无章，之后的环形墨迹清晰可见 |
| 4～8 秒 | 点盒盖放大，切换前后 | 可以看清圆环跨过纸带，不依靠文字解释 |
| 8～13 秒 | 把“盖章”放第一格，“贴封条”放第二格 | 自动重演：先压章，再贴纸带；纸带遮掉圆环中段 |
| 13～18 秒 | 点“这样发生” | 实拍与推演停在相同角度；高亮纸带中段：“这段墨迹对不上。” |
| 18～24 秒 | 把两张卡交换 | 手先贴纸带再压章；纸带上出现完整的环形墨迹 |
| 24～30 秒 | 对照并提交 | 实拍和推演吻合，完成第一件，进入换位题 |

这只是待验证的目标用时，不是已有试玩记录。熟练玩家可一次通过；不强迫先答错。

## 5. 真正能反复作出的决策

1. **选哪条证据来约束动作：**盒子最后在哪格，章属于哪个盒子，章在封条上还是下面，揭下的纸带有没有墨迹。后两关必须合并两种线索。
2. **动作针对位置还是针对物体：**章机始终针对左格，封条针对三角盒。交换之后，两个动作可能影响不同对象。
3. **选择和排序：**早期只排两张；后期从四张选三张，再决定相邻次序。卡槽不按正确答案自动吸附。
4. **有限的反事实试验：**交换两张卡会立即改变可见结果；玩家可观察哪个变化解释了线索，再决定是否提交。

首轮不承诺无限重玩。五关是完整的短体验；看过固定答案再刷不算新的推理。首、二关可切换两种实质不同的证据，第三和第五关构成初始站位不同、正确顺序不同的一对。卡片排列和颜色变化只是表现扰动，不计为内容。

“再来一局”只能从已验证的有限变体中抽题，并标注“练习”；不做每天自动编案，不通过随机故事文本制造伪新鲜感。若用户测试认为五关玩完即结束，这仍是可接受的短原型，不用奖励或排行榜掩盖内容上限。

## 6. 五关完整短局

以下是首轮纸面推导，尚未经过程序穷举。记号只供实现和评审：S=盖章，T=贴封条，X=交换，R=揭封条；正式 UI 只显示中文和动作图。

### 01｜谁压着谁（教学，约 20～30 秒）

- 之前：三角盒在左、方块盒在右；均无封条、无章。
- 之后：位置不变；三角盒有封条，圆环墨迹连续跨过封条；方块盒不变。
- 卡组与槽位：T、S；两格。
- 解：**T → S**。先有封条，章才可能压到它上面。
- 典型错误 S → T：推演的纸带没有墨迹，旧章中段被遮住。反馈只放大此处，不直接给出下一张卡。
- 有效变体：之后改成封条遮住章中段，则答案翻转为 S → T。首关默认不随机，练习才出现变体。

### 02｜章跟着谁走（换位教学，约 15～25 秒）

- 之前：三角左、方块右；均无章。
- 之后：方块左、三角右；只有方块盒有章。
- 卡组与槽位：X、S；两格。
- 解：**X → S**。只有先把方块盒送到左格，固定章机才会盖到它。
- 典型错误 S → X：章随三角盒移到了右边；反馈并列放大两只盒盖：“章落在了另一个盒子上。”
- 有效变体：之后改为右侧三角盒有章，解为 S → X。不是只换卡片摆放。

### 03｜两条线索一起用（组合，约 30～40 秒）

- 之前：三角左、方块右；无封条、无章。
- 之后：三角右、方块左；三角盒有封条，圆环连续印在封条上；方块盒无章。
- 卡组与槽位：T、S、X；三格。
- 解：**T → S → X**。
- 唯一性理由：章属于三角盒，要求 S 在 X 前；墨迹在封条上，要求 T 在 S 前；两条线索合成完整顺序。
- 典型错误 S → T → X：位置与盖章对象都对，但纸带中段墨迹不对。反馈定位纸带。
- 典型错误 X → T → S：封条对象对，章却落到方块盒上。反馈定位两只盒盖。

### 04｜消失的封条（选事件，约 35～45 秒）

- 之前：三角左、方块右；无封条、无章；废纸夹空。
- 之后：位置不变；三角盒没有封条，盒盖只留下圆环的上下弧，中部缺墨；废纸夹有一条带圆环中段墨迹的封条。
- 卡组与槽位：T、S、R、X；选四张中的三张。
- 解：**T → S → R**。章被两种表面分别接住，揭下纸带后它们分开留下证据。
- 典型错误 S → T → R：盒盖保留完整章，废纸带没有墨迹，两个位置都可看出矛盾；先标盒盖，玩家点“另一处”再看废纸夹。
- 典型错误 T → R → S：同样会得到完整盒盖章、无墨纸带。
- 先 R：在揭封条那一步停住，高亮光秃盒盖：“这里还没有封条。”可直接改槽继续。
- 选 X：只交换一次会使最终两盒位置与实拍不符，不靠隐藏的“禁用卡”规则判错。

### 05｜这次从右边来（反记忆短局，约 30～40 秒）

- 之前：**三角右、方块左**；无封条、无章。
- 之后：三角左、方块右；三角盒有封条，封条上无墨，盖住圆环中段；方块盒无章，废纸夹空。
- 卡组与槽位：T、S、X、R；选三张。
- 解：**X → S → T**。
- 唯一性理由：三角盒必须先换到左格才能被章机盖到；纸带遮住章，说明最后贴封条。
- 套用第三关的 T → S → X：会把章盖到原来在左边的方块盒上；错误重演应真实显示这一点。
- 通关结尾：把第三与第五关结果做一次可切换的回顾，强调“先看证据”，不用文字长评、星级或刷分。

五关预计 130～180 秒，加切换和自行观察仍以 4 分钟内为目标。没有强制倒计时或扣命；愿意慢慢看也可以完成。

## 7. 错误反馈与判定的边界

判定比较**玩家能看到的最终证据**，不比较玩家顺序是否等于预存答案字符串。

- 缺卡：空槽提示“还差一个动作”，不消耗任何资源。
- 动作不成立：停在发生矛盾的那一帧，展示具体缺失对象；允许原地换卡。
- 合法但证据不符：完整播放推演，再给同尺度、同角度的实拍对照。按“物体位置 → 封条有无 → 章的对象及遮挡 → 废纸带”的稳定顺序提示一处区别。
- 已吻合的证据不标红；用位置和描边纹理补充颜色。反馈不说“你错了”“差一点”，不只弹红叉。
- 连续失败两次可主动点“提示”：只指出应看的部位，例如“看看废纸夹里的纸带”。不自动代排。
- 如果多个合法顺序真的产生完全相同的可见结果，运行时全部接受。这是判定正确性，不应硬编码唯一答案。
- **关卡发布门槛更严格：**本轮教学/挑战关要求穷举后恰好一个合法顺序符合公开证据；出现歧义就修改证据或移出题库，不能拿“都能过”掩盖设计问题。

必须有一个反例回归：初始三角在左，最后三角在右，封条遮住章。S → T → X 和 S → X → T 都会符合证据；它不能作为唯一顺序题发布，但判定器必须同时接受二者。此例用于检查设计工具有没有把作者写的顺序误当成事实。

## 8. 差异化美术与声音

### 推荐：夜班纸盒剧场

不是写实刑侦，也不是黑底终端。温暖米白纸盒、暗蓝柜台、奶黄胶带，搭配珊瑚三角和青绿方块；监控外壳是深蓝灰，带极轻的时间码。物体像有厚度的剪纸，手是简化的白手套剪影。盲区隔板提供真实空间遮挡，重演时隔板变成浅色线框并带“你的推演”标识。

证据层使用清晰、近乎无纹理的 SVG；纸纤维、扫描线、投影只放在背景。禁止在墨迹缺口上叠噪点或用动态灯光改变证据可见性。两盒的身份标至少有形状、颜色两套编码。

关键动作必须动画化：贴带从一端压到另一端、章机下压与回弹、双手交换整盒、纸带揭起后停进废纸夹。动画由规则产生的状态变化驱动，不能只是播一个与玩家选择无关的通关视频。

### 备选：酸绿色旧录像

黑白偏绿监控画面，物件用粗轮廓、三角/方块与条纹区分，印章用深色墨。更符合悬疑题名，但小屏识别不如推荐方向；作为效果图对照，不在首版做双主题。

### 必须保留的声音

首次主动触控后启用 Web Audio：压章短促闷响、贴/揭胶带撕拉声、换盒轻滑动声、矛盾双击音、完成两音提示。右上角随时静音，静音不影响任何证据。首版不依赖下载音频，不要求背景音乐，不做必须听声的谜题。系统减少动态效果时保留能说明顺序的短状态切换。

## 9. 最小独立实现边界（后续方案，尚未执行）

零新增依赖：原生 HTML/CSS、ES modules、内联 SVG、Pointer Events、Web Audio，加自己目录的 Node 静态 server。拟议文件为 `index.html`、`game.mjs`、`logic.mjs`、`server.mjs`、`check.mjs`；样式可先放 HTML，关卡数据可先放 logic 模块，不为五关先搭框架。

- `logic.mjs`：关卡数据、纯动作状态转移、可见证据提取。对象位置、盒盖墨迹、封条有无/墨迹、废纸带状态足够，不做液体、碰撞或通用物理引擎。
- `game.mjs`：SVG 渲染、触控/键盘操作、动画、声音。动画消费规则产生的状态帧；换卡后旧重演必须取消，避免旧结果覆盖新选择。
- 参考画面与玩家推演共用动作规则和绘制逻辑，但检验脚本还要写独立的预期证据断言，避免两边一起错也被判对。
- 判定提取可见位置、当前表面图案与废纸夹内容，忽略被不透明纸带遮住的盒盖墨迹；不能比较玩家看不到的底层状态来拒绝合理推断。
- 事件卡不采用 HTML 原生拖放 API，避免手机支持问题；拖动使用 Pointer Events、pointer capture，正确处理 `pointercancel`。取消拖动恢复原槽位，不能丢卡或复制卡。
- 场景用 SVG viewBox，自适应比例与点击坐标一致。关键墨迹在普通视图可辨，并支持局部放大。触控目标至少 44×44 CSS px，场景内的小证据借用更大的透明点击区域。
- 不依赖兄弟目录或根目录脚本、素材、node_modules；不读取 games1-8 的代码作为运行前提。
- 存档最多记已看教学和静音设置；存储不可用时继续可玩。首版不做账户、排行榜、云存档、广告、支付或平台 SDK。
- 后续默认端口 **4403**。静态 server 只提供本项目目录内的文件，路径穿越应拒绝，缺文件返回 404。

## 13. 真实第二轮挑战 → 第三轮收敛（2026-09-27）

本节替代前文五件包装台关卡和三次确认流程。挑战来自用户本轮消息，无其他参与者、试玩或评审结论。

| 用户挑战 | 最终取舍 |

### 最终三案（每案约 30～70 秒）

1. **消失的椅子**，两步。之前：老板站在一把空椅旁，店员在右，屏风遮挡储物角；之后：老板坐在地板上，椅子不见，只在屏风边露出椅脚，店员在屏风旁。卡：搬椅子、坐下。搬→坐：老板坐空；坐→搬：已坐的人连椅子一起搬到屏风后。以老板的位置/姿态为矛盾，不要求从文字知道答案。
2. **奶油面具**，三步。之前：脸干净、纸盘干净、蛋糕在托盘；之后：老板脸中央干净、头发周围一圈奶油，手里的纸盘沾着奶油。卡：挡住脸、蛋糕飞来、拿开纸盘。挡→飞→拿开留下奶油边框与带奶油纸盘；先飞或先拿开则整张脸沾奶油、纸盘干净。未挡脸就拿开是有可见原因的无效动作。蛋糕的飞行/碰撞和揭盘必须动画展示。
3. **偷错午餐**，三步。之前：左盘香肠、右盘西兰花，小狗盯着午餐，餐罩在旁；之后：左盘空且罩住、右盘香肠完好，小狗嘴里是西兰花。卡：交换餐盘、小狗偷吃、盖左餐罩。换→偷→盖符合三处证据；偷→换→盖会吃掉香肠；盖→换→偷使罩子留在右盘。餐罩跟随盘子，狗只能够到左盘，规则由桌面距离与图解卡公开。

自动演示不公布正确性，提交才高亮实际可见的差异。次序少，允许试错，不伪装成无限重玩；三案通关后可以重新调查。用奶油模型的两个等价错误过程作为判定器回归：如果把该结果设为目标，两者必须都可通过。

美术收敛：深蓝监控台 + 暖奶油色小店 + 珊瑚色老板/青绿色店员/土黄色小狗，圆润剪纸、厚轮廓、喜剧动作。无文字案情弹窗；短句只提示操作和点出矛盾。效果图仅作方向参考，实际证据由确定性 SVG 绘制。后续真实证据写 README，不继续扩设计稿。
