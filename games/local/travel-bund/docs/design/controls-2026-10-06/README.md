# 游览操作与天空局部调整

`controls-concept.png` 为实现前生成的手机核心游览效果图，沿用奶油色圆角控件与青绿图标。场景建筑、人物及江边布局继续使用实际游戏资产；效果图里的云朵用来指导柔和白色积云的形状与边缘。

主页与设置页关系沿用现有流程，本次局部修改核心游览操作。右下“跳跃”用跃起人物图标并配文字，位于“拍照”“手记”上方；拍照采用相机形状，手记采用展开书本形状。左下只保留移动摇杆，默认快速移动，无速度切换入口。控件不依赖悬停理解操作，中文短标签一直可见。

竖屏沿用全屏游览，两列动作按钮避开移动摇杆；横屏保持相同关系并将按钮缩至 56 CSS px，仍高于 44 px 热区要求。所有底部和侧边控件叠加设备安全区，避免刘海和系统手势区域。桌面保留键盘补充操作与恢复鼠标环顾入口。

`HudActions.tsx` 为实际实现组件，运行对照截图和验证记录由本次浏览器验收补充；生成效果图不视为真机测试。

## 操作规则

- 默认移动速度 18 m/s（约 65 km/h），键盘和摇杆使用同一速度；保留摇杆幅度控制、1/60 秒固定物理步长与胶囊扫掠。
- Esc 释放鼠标后保持游览，点击场景或“鼠标环顾”重新锁定；锁定失败时支持按住画面拖动。
- 触摸拖动画面跟手；摇杆触点不参与缩放。两根场景触点负责变焦，张开放大、捏合缩小，变焦中不转头，剩余单指需重新接触后才能转头。交互标记也支持双指，并禁止浏览器接管手势。
- 滚轮只在活动游览画面变焦；首页、工具栏和设置滚动不会修改镜头。变焦范围为 0.75～2.5 倍，修改真实透视镜头的 FOV，保留人物位置和碰撞。
- 云朵使用 512×256 程序化柔边积云 atlas 与 12 个 billboard 实例，共一次绘制、24 个三角形，纹理约 0.5 MiB；有浅蓝灰下沿，保留夜色和生活动画开关。

## 验证记录

Node 24.21.0、pnpm 12.6.0 下生产构建与 31 项规则/资产/物理测试通过，含高速路沿、桥坡、汽车、行人、5 cm 薄墙及真实外滩栏杆防落水。统一开发者模式检查及 5 项规则检查通过。

Chromium 的真实 App 控件专项覆盖 390×844 / 844×390 的拖动方向、摇杆与双指并行、互动标记双指、取消、丢失指针捕获及暂停恢复。设置专项覆盖独立页面与 iframe 的原生 Pointer Lock、Esc 后场景点击与按钮恢复、滚轮方向及上下限、非场景区域滚动、320×568 手机设置滚动。路线专项通过。这些专项隔离 3D renderer，以避免软件 GPU 的帧率影响输入所有权验证，报告在 `.scratch/travel-bund-controls/`、`.scratch/travel-bund-settings/`、`.scratch/travel-bund-routes/`。

独立 WebGL 云材质验证确认实际渲染为 1 draw / 24 triangles、纹理有透明/半透明/实心区域，退出时 mesh、geometry、material、texture 均释放，无 shader 错误。新增 `test:sky` 可重复云材质与完整场景投影检查。

实际截图使用 Linux Chromium ANGLE SwiftShader 与桌面触屏模拟；不代表真机帧率、Safari 或实体手机验收。效果图为设计参考，运行截图使用实际资产。

完整 `test:browser` 在 SwiftShader 桌面场景通过进入游览阶段后，停在跳跃阶段，后续失败诊断截图也超过 30 秒；页面/控制台错误记录为空，未获得完整后续流程通过结论。本次没有继续重复这条时间敏感的全场景脚本；脚本已修正旧速度、按钮与触摸方向断言，并给操作和失败诊断加上有限超时，避免无限等待或用截图错误覆盖原始异常。完整 life 流程未重复执行，只同步修正其瞄准手势方向。

完整生产场景的 844×390 横屏云与镜头专项通过，浏览器错误为 0：双指放大将真实 FOV 从 68° 降至约 43.283°，投影矩阵同时变化；暂停与生活动画关闭都固定云计时；夜色使用蓝灰色与 0.55 透明度。390×844 已检查实际游玩、抬头、镜头缩放和暂停；其完整动效/夜景步骤未继续跑完。
