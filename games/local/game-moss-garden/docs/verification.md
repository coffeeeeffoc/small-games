# 苔光花园验证记录

浏览器回归使用生产构建和系统 Chromium，测试文件为 [tests/browser.mjs](../tests/browser.mjs)，机器可读结果为 [browser-report.json](./design/browser-report.json)。从游戏目录运行：

```sh
pnpm build
pnpm test:browser
```

脚本自动启动 `vite preview` 的 `4426` 端口；也可通过 `GAME_URL` 指向已有生产预览。默认浏览器可执行文件是 `/usr/bin/chromium`，可用 `PLAYWRIGHT_EXECUTABLE_PATH` 覆盖。

2026-10-06 的最终生产回归通过全部 9 组检查，浏览器版本 `151.0.7922.173`，未发现 console 错误、未捕获异常、请求失败或资源 HTTP 错误。普通玩家提示通关正确结算，开发试玩没有记录通关或解锁玩家关卡。

验证环境为 Linux 上的无头 Chromium 浏览器模拟：手机 `390 × 844`、DPR 2、触屏输入；小屏 `320 × 568`；物理横屏视口 `844 × 390`；桌面 `1280 × 900`。截图为真实生产页面的运行截图，不是效果图，也不是手机真机测试。

| 检查范围               | 验证方式                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------- |
| 主页、选关、帮助及返回 | 普通模式启动；第 1 关可选，其余关锁定；帮助返回保留棋盘                            |
| 播种和错误反馈         | 触屏放置、取回；同行冲突拒绝，状态区提示原因并累计失误                             |
| 标记和撤回             | 格内标记与取消；撤回恢复上一步；CDP 原生触屏事件拖动连续标记                       |
| 手势取消               | 触屏拖动后 `touchCancel`，存档和棋盘不提交排除标记                                 |
| 暂停、恢复和刷新       | 暂停期间计时冻结；恢复后继续计时；刷新后从主页继续原棋盘和标记                     |
| 普通通关和进度         | 仅使用玩家提示按钮完成第 1 关；保存用时、提示次数和失误；解锁第 2 关并在刷新后保留 |
| 屏幕适配               | 小屏和横屏切换不重置对局；横屏维持居中竖屏布局，格内点击映射正确                   |
| H5 全屏和设置          | 浏览器真实全屏进入与退出；设置保存后刷新仍生效                                     |
| 开发模式               | URL 开启、存储开启、URL 显式关闭优先；调试完成仅试玩、不写通关或解锁               |
| 存储降级               | 禁用 `localStorage` 后正常启动，仍可触屏播种                                       |
| 运行错误               | 收集未捕获异常、console 错误、请求失败和资源 HTTP 错误，作为失败条件               |
