# 苔光花园 · 移动端设计

先行效果图：[mobile-concept.png](./mobile-concept.png)。效果图在实现前生成，覆盖主页、选关和核心游玩三屏；仅作为原创视觉基准，图中的系统状态栏不由游戏绘制。

- **主题**：纸张、植物、微光种子。游戏名称、图案、棋盘配色、文字和布局均独立创作；不使用参考游戏的猫角色、品牌、美术或关卡。
- **配色**：奶油纸色 `#f5f3e8`，苔绿 `#264a3d`，柔和植物色区域，金色种子。手绘枝叶、花瓣和种子由 Canvas 路径绘制，无运行时外部美术依赖。
- **方向**：采用竖屏。方形推理棋盘和底部拇指工具适合单手小游戏；逻辑视口 `390 × 844`，缩放并居中适配容器，页面保持相同坐标换算。
- **页面关系**：主页 → 选关 / 继续播种；游玩 → 暂停 / 手册；暂停 → 继续 / 重开 / 主页；完成 → 下一关 / 重试 / 主页。设置提供音效、震动，Web 提供全屏，原生平台隐藏全屏按钮。
- **选关落地调整**：效果图探索了三章节、每章十关的排布；正式内容为五章节、每章六关，因此实际界面采用五行章节、每行六个 48 像素编号按钮，保留效果图的进度条、植物装饰、完成与锁定状态。
- **主操作**：点击棋盘播种或标记，底部工具切换种子与标记、撤回和提示。棋盘外侧显示已满足的行列，区域边界与颜色共同区分花圃，冲突使用明显红色描边反馈。
- **触控与安全区**：主页主按钮、辅助按钮、选关编号及工具均具有至少 44 个逻辑像素的热区；游玩顶栏从逻辑 `y = 84` 开始避让宿主胶囊，暂停图标以两根实心矩形绘制。
