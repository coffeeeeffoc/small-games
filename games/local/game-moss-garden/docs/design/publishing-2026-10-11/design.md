# 苔光花园 发布前局部设计

目标平台：移动触屏 H5/小游戏，竖屏优先；沿用现有画风和主页。2026-10-11 在代码改动前保存 [历史记录：result-concept.svg](https://github.com/coffeeeeffoc/small-games/blob/57f0f85a9c69231108b1a2e172cb38993206985b/games/local/game-moss-garden/docs/design/publishing-2026-10-11/result-concept.svg)，390×844 手机比例，描述新增结算操作的层级和位置，装饰仅为布局示意。

- 结算保留原主要操作，加入可复现挑战和分享；不在游玩画面增加外围说明。
- 分享链接只包含公开挑战参数，不携带开发开关或在线凭据。分享失败或取消不影响对局。
- 广告仅自然结算后离开时调用公共频控模拟插屏，保留立即关闭；三块选两块沿用现有失败续局入口接入可选模拟激励。
- 三块选两块保持在线积分和服务端结算；本地同种子挑战不宣称在线榜单成绩。
- 弹指擂台分享摆位和机器人随机种子；相同玩家操作可复现，不宣称实时联机。
- 苔光花园通过关卡 ID 发起异步比拼，以提示/失误/用时描述成绩；收到的锁定关为独立挑战，不解锁普通关卡或覆盖存档。

验收：实际手机尺寸截图与触屏点击/取消；固定 seed 或同关复现；分享参数隔离；自然转场广告频控；生产构建和现有规则检查。

目标比较补充：分享链接携带有上限的目标成绩，邀请主页标记“好友自报”，结算在既有一句反馈位置显示达成/差距；不当成服务端校验成绩。
