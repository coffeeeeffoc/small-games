# 象五子棋原生入口

严格复用子模块 bcaddf603c28b416a856d51d01c8b7d386c71a3e 的真实规则、电脑与历史回放存档，不改子模块。

竖屏主页提供继续、电脑对弈、同屏双人、棋盘选择、好友赛和帮助。对局页只保留回合、可拖动棋盘、抽子和暂停；暂停页提供继续、回首页、帮助与声音设置。结算提供再战和首页。象棋盘9×10与五子棋盘15×15均使用44逻辑像素格子，小屏拖动棋盘，只有完整可见格子可以落子。安全区、胶囊保留，旋转仅改布局不重置存档。

电脑沿用 practice/standard/hard 规则与搜索，默认练习，搜索预算限制至200ms以防阻塞宿主。旧 local-game 存档结构与 SAVE_KEY 保留；存储失败可继续。好友赛委托既有 competition 宿主，无联网配置时不得伪装真人。TouchStart/Move/End/Cancel 判别点击与拖动；多指、取消、后台和resize清理输入，后台进入暂停。原生没有浏览器全屏按钮。

实施前效果图为 concept-home.png 与 concept-play.png；验证截图与契约记录随后保存。官方开发工具与真机验证单独列待验。

战术练习沿用8题固定局面、一步防守与两步真实黑方回复；练习题页参照 concept-training.svg。练习局与普通对局存档隔离，保留原 challenge progress 格式与提示星级。帮助给出当前题的提示或已完成解法，不另堆叠弹窗。
