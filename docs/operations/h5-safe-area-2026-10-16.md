# 三款游戏顶部安全区修复

范围：围捕小队、象五子棋、街区追捕的独立 H5、Shell 内置及 iframe 页面。当轮修复未重做美术与玩法，针对顶部灵动岛、宿主开发提示及右上胶囊调整布局，返回、声音、设置等左右图标与中间状态整体进入安全区。这一历史范围记录不限制后续按认可效果图改版。

## 布局与实现

- `platforms/h5/safe-area.js` 是公共源，三个静态游戏入口加载字节一致的打包副本；专项测试校验副本和独立构建入口。
- 合并 CSS 系统安全区、宿主窗口安全矩形、状态栏和胶囊底界，额外保留 8 CSS px 间距。SDK 方法保留 receiver，异常或无效矩形降级，不按 DPR 放大坐标。
- 已识别的小游戏宿主未提供完整窗口/胶囊数据时，竖屏顶部至少预留 92 px、横屏 64 px，再加 8 px 间距。普通浏览器只使用系统安全区和间距；仅加载微信网页 JS SDK 不触发宿主预留。
- 宿主窗口尺寸与嵌入文档不一致时，不直接采用全窗口几何数据。页面恢复、尺寸/方向/全屏变化时刷新，保留当前游戏和存档。
- 围捕的棋盘高度、左右边界和对话框随安全区调整。短横屏使用紧凑的地图/控制区，首页菜单可在自身区域滚动；小竖屏隐藏重复的角色快捷头像，避免遮住标题。
- 街区追捕将完整应用区域缩至四边安全矩形，Canvas 根据实际 DOM 尺寸调整地图与触控坐标，子控件不重复预留系统安全区。
- 象五子棋在子模块中更新页面留白、棋盘预算和独立构建复制白名单；主仓库更新对应 gitlink。

## 验证

环境：Linux、Node 24.21.0、pnpm 12.6.0、Chromium，使用实际静态生产构建与真实浏览器触屏输入。宿主 SDK/顶部覆盖层由测试提供，不代表官方宿主或真机。

专项命令：

```sh
node --test platforms/h5/tests/safe-area.test.mjs
pnpm --filter cops-robbers --filter cops-robbers-realtime --filter @coffeeeeffoc/xiangqi-five build
PLAYWRIGHT_EXECUTABLE_PATH=/usr/bin/chromium node platforms/h5/tests/safe-area.browser.mjs
```

专项覆盖普通浏览器、完整宿主 SDK、仅宿主 UA、宿主方法抛错/缺失、延迟出现、非法安全矩形、窗口尺寸不匹配和旋转后重新获取安全区。实际页面检查 320×568、390×844、844×390、568×320，以及 390×844 iframe；检查主页、准备/选关、游玩和暂停/设置/返回，顶部左右按钮、棋盘和底部操作必须位于四边安全边界内。

截图和专项报告保存在本目录旁的 `h5-safe-area-2026-10-16/`。完整专项原始截图和日志由命令生成至 `outputs/safe-area/`；增量发布检查会在准确候选提交的隔离快照内再次执行相关规则、构建和浏览器检查。

尚未完成手机真机及各平台官方工具验收；本次交付不声称已上传小游戏平台、广告验收通过或线上部署成功。
