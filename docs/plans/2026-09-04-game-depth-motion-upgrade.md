# Game Depth and Motion Upgrade

**Goal:** Turn all three short demos into replayable level-based MVPs with stronger moment-to-moment animation feedback.

**Approach:** Preserve the shared shell, persistence, and ad adapter. Extend each game's existing state machine with campaign progression and add CSS-driven transitions that remain performant in a Bilibili mini-game WebView.

## Deliverables

1. Cultivation: 18 events across three chapters, chapter gates, event transitions, floating stat changes, and a visible journey map.
2. Office: five workdays, escalating surveillance patterns, daily objectives, inter-day settlement, unlock persistence, and feedback animations.
3. Arena: five-rank league, escalating opponents, between-match mutations, multi-match season flow, hit effects, particles, and rank persistence.
4. Shared: lobby campaign progress, updated tests, responsive visual validation, production build.
