# 六款游戏 TapTap H5 与手机体验

范围：carding-car、vibeJam-myself-history-guess、wulong-city、night-overwatch、travel-bund、letters-words2。保留现有游戏、引擎、美术和正常存档；沿用统一 build:games 生成带 dist/index.html 的 ZIP。不修改已有本地构建配置中的用户选择。

## 实施选择

扩展现有打包器，按游戏选择实际构建入口。独立脚本复制整套发布流程容易产生配置分叉；把所有游戏迁入一个引擎会扩大风险，因此都不采用。六款默认离线，不接入未实现的竞赛后端。保留此前三款的服务矩阵。

广告采用公共 TapTap provider，提供可用性、请求及取消端口；开启开关且配置有效广告位 ID 才显示可选奖励入口。关闭、加载失败、页面退出和陈旧回调不发奖；完整观看回调至多发一次奖。广告打开后结束加载超时，不因长视频或 visibilitychange 丢失奖励。不自动模拟真实广告。AppID 与广告位 ID 分开说明。

## 画面与操作

- 卡丁车横屏：保留低多边形赛道、青蓝与明黄色；主页突出开跑及选赛道。暂停为紧凑卡片，仅保留暂停、名次/用时和继续、重开、主页；移除排行榜、键盘说明和重复鼓励文案。触屏 HUD 保留必要状态和拇指区。
- 此时此地竖屏：保留历史场景及纸张/朱红风格，主页以场景与开始/选关为主。游玩将观察与答题分步组织，观察时扩大场景，答题时呈现地图、年代和提交；规则进入帮助。离线包隐藏 PK/排行榜入口。奖励提供本幕可用的提示。
- 乌龙城、夜航守望、漫游外滩、词屿：按既有方向检查 320/390 宽及横屏手机、安全区、按钮热区、暂停/返回与手势取消；优先局部修正，保留已实现的玩法。

效果图先于界面实现，存入对应 docs/design/taptap-h5-2026-10-20。实际截图和检查记录随后保存，明确与真机、真实广告验收区分。

## 验证

串行构建，避免同时运行 Creator 或多个浏览器。覆盖六款 ZIP 清单/哈希/相对资源路径；广告关闭、缺失 ID、配置 ID 的三个分支；长广告、取消和重复回调；手机实际触屏主页、选关、游玩、暂停、结算及存档。执行相关规则、类型、dev-mode 和打包契约检查，不将本地通过描述为 TapTap 审核通过。
