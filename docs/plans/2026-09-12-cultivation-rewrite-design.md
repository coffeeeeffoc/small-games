# 三分钟修仙：修炼、探索与渡劫重设计

日期：2026-09-12。

状态：用户已确认「修炼＋探索＋渡劫，动静交替，重视场景互动和成长变化」的体验方向。下文为玩法设计提案；操作细节与节奏需要后续试玩验证，尚未实施。

## 体验目标

玩家亲手引气，入山寻找机缘，以御剑和身法解决危险，最后用自己的准备与操作完成一次突破。

保留《三分钟修仙》的名称。首局目标是筑基，让一次突破有完整的准备、考验和结果；金丹及更高境界作为后续挑战，不在三分钟里跳完全部境界。

原有十八次文字选择、属性加权定境界的流程退出核心玩法。文字用于短提示、场景叙事和结算回顾。动作必须先发生，再由命中、资源、位置与时机决定结果。

## 单局结构

目标为 180 秒有效游戏时间：120 秒修炼与探索，最多 60 秒渡劫。首次教学提示、暂停、场景切换和结算不消耗时间。下列分配是调试起点，不是已验证的最优节奏。

| 阶段     | 建议时段   | 玩家任务                     | 节奏                           |
| -------- | ---------- | ---------------------------- | ------------------------------ |
| 洞府出关 | 0–20 秒    | 吐纳、御起断剑、走出洞府     | 安静，快速建立操作与反馈的联系 |
| 雾竹寻缘 | 20–90 秒   | 战斗、寻找灵脉、选择支路     | 探索与短暂冲突交替             |
| 最后准备 | 90–120 秒  | 再取机缘，或恢复真气迎劫     | 有取舍，但保留安静的调息机会   |
| 云顶渡劫 | 120–180 秒 | 躲雷、护体、抓住间隙击破劫眼 | 压力逐步增加，以主动突破结束   |

前两分钟是连贯的准备期，不在第 20 秒或第 90 秒强制切换玩家动作。香将燃尽时，钟声、云色和地面阵纹共同提醒；准备期结束后，试炼法阵接引角色到渡劫台，避免把跑图迟到变成失败条件。

胜利：气血尚存，并在渡劫限时内击破全部劫眼。失败：气血耗尽，或渡劫时间结束仍未突破。提前完成则直接结束，不等待倒计时归零。

## 场景与互动

采用手机竖屏、略俯视的二维场景，以前景遮挡、远景云雾和人物动作建立层次。地形、敌人和互动物拥有明确的空间位置与碰撞。场景占据主要画面，状态和操作区保持紧凑。

### 山腰洞府

主要物件：蒲团、断剑、灵脉、风铃、出山石阶。

玩家靠近灵脉主动吐纳，再向练剑石出剑，完成开场的基本操作。教学随操作出现，一次只提示一件事；重复游玩时可以直接行动。

按住吐纳，灵气向身体汇集，衣袖和尘土随气流移动；收气成功，灵气入体，断剑随之升起并发出剑鸣。吐纳中断时气流散开，不能仍播放完整成功动画。

风铃和滴水构成安静背景。洞府内少量可触碰物件用于回应玩家，例如碰动风铃，但不为所有摆设增加任务或收集系统。

### 雾竹秘境

主要地形：浅溪、竹林、残柱、安全灵脉、危险支路。

首版设计两种普通妖兽：

- 竹影妖：竹叶先抖动，再显出扑击前摇，扑空后有短暂恢复时间，教会玩家观察与闪避。
- 石甲兽：正面护甲强，冲撞前有明显蓄势；诱导它撞上残柱可以使其失衡，形成蓄力破甲机会。

主路提供基本恢复机会；支路提供更强机缘和额外危险。击败敌人、打开灵脉和取得遗物均由场景行为完成，不弹出文字选择代替操作。

例子：石甲兽守住一处灵泉。玩家站在残柱前引它冲撞，侧闪后趁其失衡出剑。灵泉开放，玩家获得一次恢复真气的机会。柱子、敌招、站位和出手时机共同影响结果。

### 残阵小院：秘境中的可选支路

玩家用已有的御剑操作击破阵眼，封印逐步松动，取得一件遗物。阵眼与危险区域在同一场景中，不另开连线或节奏小游戏。

另一处机缘是救出被困的小狐狸。玩家需要花时间破开封印或清除威胁，随后狐狸走出封印并跟随，在遇敌前示警。渡劫时，它可以挡下一次普通落雷，之后虚弱地退到石台边；不会代替玩家击破劫眼。此段互动固定可发现，先验证它是否能让玩家记住这次经历。

### 云顶渡劫台

主要物件：中央石台、镇雷柱、劫眼、远处云海。

雷劫由三个逐步加强的轮次组成，每轮遵循「预警与落雷 → 劫眼暴露 → 玩家反击」。先学会躲开单点雷，再处理连续落雷，最后组合使用走位、真气和机缘。

落雷前出现地面纹路与形状变化，碎石悬起，雷声蓄积。劫眼开放时提供清晰的视觉与声音提示。玩家必须主动出剑才能完成突破；躲避或站着等待不能自动获胜。

镇雷柱受击会损坏；护盾有清晰裂痕和破裂反馈。突破后风雨骤停、云层打开，声音由密集回到安静。镜头特写放在已经决出结果之后。

## 操作与资源

移动端采用左侧拖动移动，右侧御剑与闪避。御剑支持短按快击、按住蓄势、拖动瞄准、松开出剑。附近可交互对象有明确轮廓，并出现对应的独立交互提示，不能静默把攻击手势改成采集。

桌面端提供同等能力：键盘移动与闪避，鼠标瞄准、按住及松开御剑，交互键对应当前明确提示。两端共用规则，不把原生 Canvas 端简化成点选结算。

| 动作   | 作用                               | 判断与代价                                                                                   |
| ------ | ---------------------------------- | -------------------------------------------------------------------------------------------- |
| 快剑   | 短前摇出剑，对可打断的敌招制造空当 | 伤害和破甲能力有限；敌招是否可打断需有明确表现                                               |
| 蓄力剑 | 增强穿透或破甲，方向由玩家控制     | 蓄势时移动变慢；超过上限不继续变强；闪避可以取消蓄势                                         |
| 闪避   | 短距离移形，躲开明确攻击           | 有恢复间隔，不能无限连续使用；无方向输入时沿最近移动方向                                     |
| 吐纳   | 在灵脉范围内主动恢复真气           | 持续吸气使气环逐渐不稳；及时收气保住本轮所得，失稳则失去本轮尚未收稳的真气；可以主动中断离开 |

状态以气血、真气和剩余时间为主，另显示当前机缘与渡劫目标。气血反映生存，真气支持蓄力剑和部分法术；基础快剑保持可用，避免真气耗尽后完全失去反击能力。闪避恢复独立显示，不额外增加体力属性。

吐纳没有不可退出的长动画。它的压力来自环境：安全时可以稳稳吸气，敌人靠近时则要决定再吸一口还是立刻躲开。安全灵脉也消耗准备时间，因此不能无限刷取。

飞剑按照实际轨迹与目标碰撞：挥空、撞石、命中和回程各有结果。辅助瞄准可以帮助触屏定位，但不自动出剑，也不保证命中。

## 成长与重玩

首版设计三件改变行为的机缘，每局最多携带两件。超过容量时明确提示交换，暂停选择期间不消耗游戏时间。

| 机缘     | 改变的玩法                                                 | 渡劫用途                                   |
| -------- | ---------------------------------------------------------- | ------------------------------------------ |
| 回澜剑诀 | 飞剑回程可以再次命中，玩家需要调整回程路线                 | 在站位合适时提高劫眼开放窗口内的伤害       |
| 护心灵玉 | 解锁消耗真气的主动护盾，激活时有明确按钮；持续期间不能蓄剑 | 来不及躲避时补救，但会消耗之后出剑的资源   |
| 避雷木种 | 获得一次定点种下引雷木的机会                               | 引走一轮可被吸引的落雷，创造恢复或进攻空间 |

三种机缘先作为可选方案验证，不把更多装备、词条与合成树带入首版。每次机缘生效都需要能在场景中看见，不能只提高结算分。

重复游玩的价值首先来自操作熟练、支路选择和机缘搭配。首版仅在已有存档能力中记录最佳表现与突破结果，不引入必须刷永久战力才能通关的养成要求。后续境界可以扩展场景和敌招，但不预先建设完整境界树。

结算回顾使用本局真实行为，例如「引石兽撞柱」「灵狐挡下一击」「最后一剑破开劫眼」。失败说明最后的可观察原因，不编造玩家未做过的经历；免费重试保持直接可达。

## 声画与沉浸

| 行为或状态 | 视觉反馈                                 | 声音反馈                                       |
| ---------- | ---------------------------------------- | ---------------------------------------------- |
| 行走与入水 | 步态、衣摆、脚下涟漪                     | 石阶、泥地、浅水分别使用对应脚步声             |
| 吸气与收气 | 气流弯向角色，气环由稳定变为颤动         | 气流随吸气增强，失稳前有颤音，收稳有短促确认音 |
| 飞剑出手   | 蓄势、指向、出剑、碰撞、回身形成连续动作 | 出鞘、破空、撞石和命中有所区别                 |
| 妖兽攻击   | 准备、扑击、扑空、失衡清楚可辨           | 竹叶、爪地等先兆与攻击动作同步                 |
| 受击       | 身形失衡、短暂顿挫；关键重击才震屏       | 命中声由材质和力度决定                         |
| 雷劫与突破 | 雷纹、护盾裂痕、石柱损坏、云开           | 雷声逐步密集，突破后回归风声与剑鸣             |

环境声分洞府、秘境、云顶三个层次；音乐随阶段变化，并为敌招、失稳和落雷提示让出音量。剧情通过场景变化、跟随者行为和短句表达，避免战斗中弹长对话。

命中反馈仅由实际命中触发，不提前播放成功动画。背景粒子与镜头运动不能遮挡危险提示。声音关闭后，危险仍可通过形状、动作和地面纹路辨认；提供静音、震屏关闭和减少动态效果选项，按钮适合触屏点击。

## 首版范围与项目边界

首版包含三个主场景、一个秘境支路、两种普通妖兽、一场三轮雷劫、三件机缘和一次灵狐互动。形成完整的进入、游玩、胜负、结算和重试流程。

暂不加入炼丹小游戏、宗门经营、大地图、多人、装备词条树或每日任务。未来添加的条件是核心单局已经通过试玩验证，并且新内容能带来新的实际操作或取舍。

重写发生在 `apps/game-cultivation`，保持 Game ID `cultivation`。复用已有 Game Host、装载和存档边界；Web 与 B 站原生 Canvas 使用同一套实时玩法规则。新内容结构由 Game 自己拥有，遵循现有 Dynamic Content Envelope 和版本迁移约定，不沿用十八次事件选择作为玩法驱动。

已有存档不能被新规则直接误读或静默覆盖。实施前检查旧字段、内容版本与迁移路径；本设计不预设已完成兼容。声音在玩家首次操作后启用；暂停、切后台和退出时停止游戏时钟、取消按住动作并清理声音，恢复时不补算后台经过的时间。

## 后续验证顺序与通过标准

先验证洞府外的一小块可玩场景：一处灵泉、一只妖兽、一组可碰撞地形，以及移动、吐纳、御剑、闪避、受击和恢复的完整反馈。此样板是实现后的第一道检查点，不代替完整首版交付。

样板通过后接通三分钟流程，再加入三件机缘、灵狐事件和完整声画表现。数值集中调节，根据真实操作调整预警、耗气、恢复与出手机会。

需要验证：

1. 开局十秒内，玩家能亲手改变场景中的对象，而非只完成菜单操作。
2. 同一只妖兽，站着乱按与观察后出手的结果不同；敌人前摇确实提供反应机会。
3. 挥空、碰撞、受击、取消蓄力与收气失败均有真实后果；没有预先结算后补动画的路径。
4. 准备期机缘实际改变渡劫方式；基础能力也有可完成的通关路径，不能依赖抽到特定物品。
5. 不操作无法自动击破劫眼；失败后玩家能解释最近一次失误，并直接重试。
6. 静音、减少动态效果和窄屏触控下，关键提示仍然可读可操作。
7. 暂停、失焦、触摸取消、退出与再次进入不产生误出剑、计时跳跃或重复结算。
8. 手动试玩关注「愿不愿再玩一次」与「能否说出下一局想改的操作」；自动检查覆盖真实命中、资源、胜负和生命周期规则，不能仅以通关脚本成功代替好玩性判断。
