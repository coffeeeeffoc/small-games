## 2. 几何审查公式

### 边界与折叠

- 右向左折 `c`：移动矩形必须满足 `x+w≤2c`，否则反射到 x<0；左向右折：移动矩形必须满足 `x≥2c-1200`，否则越过右边界。最终仍逐实体验证四条纸面边界。
- 平台跨折痕后要用各片段检查支撑，不能把原平台的宽度都当成“固定”。同一位置在 A 下固定，在 B 下可能移动。
- 操作平台有效站位区间为 `[平台左边界, 平台右边界-22]`，再与折痕安全区取交集，再扣除目标态障碍。只报平台中心点不足以证明站得下。
- 角色、钥匙和门有宽度；触碰门会提前结束。必须检查“第二把钥匙在跳跃中被拿到后直接擦门通关”，不能把后续展开强算进最短解。
- 变换不改变 y。所谓“折到高层”只能是把已有高台接成可达阶梯，不能把低台直接折高。

### 跳跃

连续理想抛物线给出最大抬升 `480²/(2×1600)=72px`，同高飞行时间 `0.6s`，满速水平位移 `102px`。正式实现每步先加重力再更新位置，实际峰值略低；还存在加速、22px 身宽、0.085s 土狼时间、碰顶、下降落台。

因此：

- 72px 不能作为稳定可达高度；主路线建议台阶抬升 40–60px，并预留头顶空间。
- 不能把平台边缘相距 103px 当成必定不可跨越。身宽和土狼时间会扩大跨沟范围；下落到低台时范围还更大。
- 现有测试只证明特定同高条件下 200px 关键沟跳不过，不能外推至落差跳跃、所有起跳位置或多跳。
- 无解判断要检查整条抛物线是否先撞侧壁/底面；只看起落点与落差会漏掉头顶封路。
- 难关应增加需要推断的空间依赖，不能把落点收窄到 22px 附近来凑难度。

## 3. 真难度与去重标准

把每关先抽象为“折叠状态 × 可站立连通区 × 已收集钥匙集合”。合法边只有实际移动、收集、满足固定支撑的展开或折叠。说明书上的动作顺序本身不是约束。

每关至少回答：

1. 当前最短**已知**路线需要几次不可省略的状态切换、几个不同的站位选择？没有最短性证明时不得称“最少”。
2. 删去关键钥匙/障碍，或先取第二把钥匙，会出现什么具体捷径？若没有变化，该要素可能只是装饰。
3. 候选错误折法为何看似合理、具体在哪里失败、能否安全恢复？“按错重新来”不是新的推理结构。
4. 与前一关及原 16 关相比，必要状态图的区别是什么？换左右、平移、改颜色/标题、扩大沟宽、加相同路径上的钥匙、重复 A→展开→B 均不能单独算新谜题。

原 16 关可用作比对家族：1/2 单折接桥及镜像；3 选正确折痕；4 台阶；5 移动尖刺；6 取钥匙返程；7 固定岛展开去遮挡；8 钥匙保留与门前遮挡；9 A/B 换折登高；10/12 换侧与阳台；11 双钥匙与门遮挡；13 三层接力；14 重用首段返程；15 三钥匙归途；16 双向三钥匙归途。复习关可以重复技能，但必须明确标为复习，不能报告为 100 个互不相同的谜题。

## 4. 概念方向通过与几何验收分开

| 项目 | 通过证据 | 不足时结论 |
| --- | --- | --- |
| 几何 G | 设计核对关键空间关系与高风险锚点；完整坐标、正式物理路线在实现后验收 | 未校准保持待证；硬冲突退回，不能写“已证明可解” |
| 真难度 D | 所声称的关键操作有明确空间理由，并指出防止直接跳跃/先拿后钥匙/提前碰门的构造 | 缺失关键隔离则退回改结构；仅待调间距可留实现校准 |
| 独立性 U | 与原 16 关及本批关卡的必要状态图存在可解释差异 | 合并为复习或替换 |
| 可验证性 V | 每项结论可被正式物理路线与针对性反例检查，不依赖未实现机制 | 退回补证据定义 |

G 未经足够几何核对时记为“待证”，不为冻结方向而抬高，也不以缺少完整数据为由机械判失败。D/U/V 可按0–10分评估概念证据，8表示该项足够进入实现；不把待证G纳入平均分。已证几何硬冲突直接退回。分数只是设计审查，不是真人趣味评分。

逐关结论采用三种状态：**方向通过／几何待证**（现有机制可表达、核心构造齐备、有实质差异）、**退回设计**（硬冲突、缺少必要隔离、实质重复或未获批机制）、**需补概念说明**（缺少足以判断的空间关系）。完整100关几何验收只能在实现验证后另行宣布。

实现阶段的路线是**存在性证据**。`tests/routes.ts:10` 已明确不是 solver；`runAction` 只追踪 x，没有验证指定 y 或指定平台，所以不能仅以到达同一个 x 推断预期楼层成立。现有测试不证明最短解、所有错误路线均失败、或普通玩家需要多少次尝试。

## 5. 设计阶段交付与实现后证据边界

设计阶段提交关键空间关系、状态切换理由、隔离构造、错误选择与恢复方式即可；必要处用草图或局部锚点说明。方向冻结要求可由现有机制表达、关键构造齐备、已识别硬冲突消除、与已有题目有实质差异，不要求把100份完整实体数据先在Markdown中执行证明。坐标、跳跃余量和安全站位可在实现阶段校准，G持续待证；后续正式物理若推翻核心结构，退回设计修订，不能修改规则暗中迁就。

例如“要先拿甲才能到乙”却没有封路、换侧或固定支撑依赖，属于设计缺构造；不能靠校准钥匙坐标补成虚构顺序。已有明确隔离墙与换折通路、仅墙边距和平台宽度待调，则可以方向通过并留下几何待证项。局部锚点一旦发现越界或不满足支撑，也要在设计阶段指出并改正，但不因此要求其它99关先交完整可执行数据。

下一轮先扫描全部100关的规则可表达性与结构差异，再按每批25关挑选3–5个最高风险条目核算关键锚点，优先选：混合方向换侧、固定支撑身份变化、钥匙顺序/门前隔离、反射边界和多层跳跃。所有发现的硬冲突均逐项记录，不受抽查数量限制。每项写清“已核实事实／硬冲突或风险／最小改法／实现待证项”，不将抽查结果外推为100关全量几何通过。

实现后再验收：100/100 正式输入路径完成、0 死亡参考解、关键阶段省略反例、实体/出生/视口完整性；并对窄屏实际输入、误操作恢复与真人思考时间另行采样。自动路线的秒数只算操作执行时间，不能用于声称“玩家平均思考三分钟”。

## 6. 超过三道折痕与自由方向：范围审查

### 已核实的输入事实

- `main.ts:40` 的 `options()` 会展平每道折痕的允许方向，`main.ts:43-50` 为每个“折痕+方向”生成按钮，没有硬编码三个按钮的上限。`main.ts:145` 的 C 键也能轮换所有选项。因此不能断言第四折痕在程序上完全选不到。
- 但数字直选明确只有 `Digit[1-3]`（`main.ts:144`），帮助页也只承诺 1/2/3（`main.ts:88`、`strings.ts:10`）。四道单向折痕或两道双向折痕都会产生第四选项；现有教学与直选已经不完整。三道双向则是六选项，并非“三选项”。
- 点击折痕按数组顺序取第一个命中的折痕，而非最近折痕（`main.ts:154`）。命中半径至少 22 CSS px；折痕间距小于44 CSS px 时区域可重叠。例如画面缩为原宽的0.3倍时，100世界像素只剩30 CSS px。增加密集折痕会放大误选，不能以“几何上不同”忽略触控。
- 滑动只在关卡预先声明的方向中选择，并优先已选折痕（`gestures.ts:13-16`）；不是玩家随意创造折痕。只支持竖直折痕的左右180°反射。

### 分类结论

| 提案 | 实际影响 | 本轮决定 |
| --- | --- | --- |
| ≤3道预设单向折痕，含左右混合 | 当前16关已有三折痕及左右混合；可沿用规则与输入 | 允许进入关卡设计，仍逐关验几何 |

### 只有以下证据齐备才重新考虑批准

1. 给出一关精确空间结构和必要状态图，指出第四折痕或第二方向带来的**不可替代选择/依赖**，而非仅增加一个高度层或一段跑腿。
2. 至少给出一个保留原谜题核心、收敛至≤3操作选项的替代设计，并说明它为何在具体约束下不能成立。不能用“100关需要更多花样”代替比较。
3. 对所有新增允许折法验证实体范围、站位、恢复及捷径；不能只验作者希望玩家使用的一种方向。
4. 列出最小输入/提示改动与窄屏验证范围，说明成本确实由谜题收益支撑。未获明确产品批准前不得修改机制或输入UI。

目前没有上述必要性证据，因此不批准范围扩张。100关数量目标不豁免独立性、几何可行性或操作公平性。
