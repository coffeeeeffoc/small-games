# 折叠世界：100 关产品设计与验收

状态：2026-09-27 产品方向冻结。100/100 关已通过独立 D 评审（均分至少8、单项至少7），R1–R4退回与修订记录保留；从此开始代码实现和正式物理 G 校准。

逐关方案：[01–25](2026-09-27-fold-world-01-25-design.md)、[26–50](2026-09-27-fold-world-26-50-design.md)、[51–75](2026-09-27-fold-world-51-75-design.md)、[76–100](2026-09-27-fold-world-76-100-design.md)。独立记录：[产品评审](2026-09-27-fold-world-review.md)、[几何及后段评审](2026-09-27-fold-world-feasibility-review.md)。各稿保留历史退回证据，以文末有效版本说明和最新正文为准，不能把旧稿与替换稿混合实现。

## 目标

总计 100 关。开场允许几秒完成以建立折纸因果关系，后续依靠观察、推理和可恢复的尝试推进；不靠等待、极限跳跃、重复跑腿或坐标微调制造难度。保留单次有效折叠、固定落脚点、钥匙跨展开保留的核心玩法。

时间和尝试次数属于设计目标，不能由自动路线执行时间推算为真实玩家数据。独立 agent 的评分属于设计审查，不能代替真人试玩或宣称完美。

## 已核实的基线

- 原版 16 关；40 个现有测试全部通过。
- 正式物理下已知解的执行时间约为 2.0–18.3 秒，不包含玩家观察与思考；第 1–8 关均不满 5 秒。
- 纸面 1200×600，可视区域 y=180–560；角色 22×28。
- 跳跃速度 480、重力 1600、水平速度 170；理想最大抬升 72，同高中心位移约 102。正式碰撞、角色宽度和土狼时间决定实际可达性，不能只算中心距离。
- 折叠、展开都要求角色站稳且完整由固定平台支撑，距折痕有 12 像素安全带。角色不随纸移动；钥匙保留，重来清空。
- 现有两章选关写死为 1–10 / 11–16，扩容必须改为适合 100 关的分章选择。
- 现有数字关卡存档必须保持含义；若修改旧关内容，旧成绩不得冒充新谜题的最佳成绩。

## 方案比较

1. 现有机制下设计不同空间依赖：规则负担小，可以通过固定地面、移动出口、遮挡与换侧构成谜题。采用此方向。
2. 给模板随机换坐标、镜像和加钥匙：数量快，但很容易让玩家复用同一答案。拒绝作为扩容方式。
3. 新增自由折痕、重力或多层嵌套：会改变产品和触控操作，验证范围显著扩大。本轮没有证明必要性，不采用。

## 多 agent 流程

四位设计师分别负责 1–25、26–50、51–75、76–100 关；两位独立评审检查递进、几何与趣味。主 agent 负责产品取舍、跨段衔接和实现验收。

1. 首轮：每关写明空间结构、折痕、关键洞察、候选路线、错误尝试与恢复、区别于相邻关之处。
2. 独立评审：逐关评分并点名问题，尤其审查看似强制但可以绕过的折叠与取钥匙步骤。
3. 修订：设计师逐项修改；独立复审再次打分。未通过的关卡继续迭代，不直接交付代码。
4. 产品冻结：记录最终取舍、100 关目录、各轮意见及剩余的实测边界后开始实现。
5. 实现验证：正式物理逐关走通、中文分层提示、存档及 UI 回归；发现不可行结构时回到设计修订并记录。

## 评分与否决条件

最终逐关结果见[100关冻结评分表](2026-09-27-fold-world-scores.md)，每行保留独立复评来源。

推理、趣味、公平、可读、梯度各 10 分，等权平均；最终目标每关平均至少 8，单项至少 7。分数必须有对应的设计证据，不能为了达标统一加分。

以下问题直接拒收：无解或折法越界；出生即碰撞；无需核心折叠即可直达；声称有先后约束却无空间理由；照搬相邻答案而仅改坐标；用狭窄落点/重复跑腿作为主要难点；错误一步后没有清晰的恢复或重来方式。

冻结的是产品方向、关卡命题和可实现的依赖结构，不要求在 Markdown 中先实现整套物理。具体坐标、运动容差和各状态可达性仍须在实现阶段通过正式物理校准；已识别的硬冲突和没有构造支撑的关键依赖必须在设计期解决。评分按关卡所处学习阶段判断质量，不能把教程复杂度与终章复杂度直接比较。

## 内容组织与提示原则

- 四段各 25 关，段内按 5 关组织技能变化与综合；选关用原生折叠章节浏览，默认展开当前段，展示已完成数量。只在菜单中展示这些内容，游戏进行时保持核心操作与状态。
- 最多三个预设折法选项，包括折痕与允许方向的组合；不因为关卡总数变多就增加按钮数量。
- 已知参考路线是帮助，不是唯一正确答案。合法换序或探索其他路径不得文案判错；提示应区分参考路线与实际失败，保留玩家收集成果。必要时提供回到参考路线的明确选择。
- 不限制玩家必须思考多久、不能用更短解或必须失败几次。设计目标是让空间关系值得思考，认可合理捷径和一次想通。

## 明确的实现条件

- 对压住角色的非法折叠，显示导致拒绝的目标投影轮廓，提示玩家先让出空间。不能仅报“不可折叠”让玩家盲试。
- 折入纸面覆盖固定平台后，仍能读出原固定承托顶边。标记表示支撑来源，不替代安全带和目标碰撞判断。
- 被实体挡住的钥匙和出口保持位置可见，并显示受阻状态，不能像物品凭空消失。
- 合法替代解不显示“你做错了”或强迫重开。线性提示只是一条参考路线，偏离后仍可继续保留收集成果探索。

## 旧进度迁移

新存档使用 `fold-the-world-v2`，旧 `fold-the-world-v1` 永不覆盖。旧记录只按 16 关校验；新记录才按 100 关校验。有效 v2 存在时不重复迁移。

最佳成绩仅允许旧→新 `1→1、3→4、4→2、6→3、7→6、8→7、9→11`，并在实现中核实出生点、实体与折法完全一致；迁入完成状态后开放新编号下一关。其他改版关只保留访问权限：`10→16、11→13、12→18、13→21、14→14、15→25、16→23`，不凭旧成绩生成新关最佳折数。旧16明确通关额外开放新26，继续保留合法的旧解锁范围与静音偏好；旧2不直接开放新20。
