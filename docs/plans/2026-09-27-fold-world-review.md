## 1. 实际规则：设计不可暗改的边界

以下均为 S 证据，主要来自 `src/geometry.ts:11–47`、`src/physics.ts:3–35`、`src/game.ts:16–87`。

1. 纸面 1200×600；当前镜头只显示 y=180–560。关键落脚点、钥匙、门和必需观察线索不能靠屏幕外内容成立。角色为 22×28，x/y 为左上角。
2. 只有预设竖直折痕及各自允许方向。**同时只允许一次有效折叠**；必须先展开再换折法。每次从原图重建，不会把 A 后的坐标继续绕 B 反射。
3. 反射矩形使用 `x' = 2c - (x+w)`，不能把矩形左边缘当点反射。y、宽、高保持不变；折叠不会直接把平台抬高。
4. 跨任一预设折痕的平台会被拆分。钥匙、出口、尖刺不可跨任一折痕。每一个允许折法的全部实体都要留在纸内，即使候选解根本不用该折法也一样。
5. 折叠与展开时，角色均需落地、水平速度绝对值≤8、竖直速度约为0；完整在固定侧且避开12像素安全带。向左折时角色左边缘 `x≤c−34`；向右折时 `x≥c+12`。
6. 脚下完整22像素必须由原图中属于本次固定侧的同高平台连续支撑。可以由多个相邻固定片段共同支撑；站在折入的平台上即使看起来稳，也不能直接展开。**固定性相对于本次操作，不是某个平台永久固定的标签。**
7. 角色不随纸移动，不被传送；目标平台或尖刺若与身体重叠，操作会被拒绝。不能设计“折纸把角色搬过去”“折入板把人顶高”“边下落边展开救命”。
8. 平台按实体碰撞并集处理；叠在一起不会切出洞或隐去下面的实体。尖刺不被纸层遮蔽免伤。开关墙必须是真正离开通路的几何变化。
9. 钥匙只有“按 ID 收集、全部集齐后可触门完成”的作用。收集后跨展开/重折保留，不消费，不打开单独平台或彩色门，也不改变折法权限。若声称某把钥匙必须先拿，必须有真实空间理由。
10. 死亡约0.35秒后调用整关重启：出生点、折法、钥匙、折叠次数和关内计时全部复位。**快速复活不等于低重试成本。** 没有中途存档、撤销、检查点或保留钥匙的死亡恢复。
11. 预览与折叠动画冻结运动；普通折叠/展开动画0.56秒。提示暂停游戏，提供三层线索，不送钥匙或移动角色。
12. 当前提示是手工阶段路线。操作顺序改变、漏拿指定钥匙后会进入恢复提示，可能建议重开；当前逻辑不会自动重新求解合法替代路线。不能用这条恢复文案证明玩家走错了。

物理的必要约束：速度170、起跳480、重力1600；理想跳高72，同高满速水平位移约102。它们只是连续模型估算，角色宽度、土狼时间、加速度、碰头、平台侧壁和实际离散步长都会影响可达性。现有测试证明其特定场景的200像素关键缺口不可越过，**没有证明任意高差的200像素缺口都不可越过**。

## 2. 什么算有深度、有趣、允许试错

### 2.1 三个量分开记

- **解法执行量**：玩家已经知道答案后需要的折叠/展开/跳跃及走路。`routes.ts` 的多个 x 路点只是控制器航点，不能当作多次决策。
- **推理量**：玩家必须从可见证据推出的因果关系，例如先留住返程支撑、借一个折法到达另一折法的固定侧、先观察出口落点再决定最后状态。
- **试错信息量**：一次合法尝试后排除了什么候选，下一步为什么更明确，多久能回到可以改变计划的位置。

短路线可以是好谜题：两三次操作也可能要求先理解相互冲突的空间条件。长路线也可能很浅：按唯一通路拿三把钥匙再原路跑回，只增加执行量。**不给折叠次数、钥匙数、路线长度或死亡次数直接加难度分。**

“后面每关需要思考或几次尝试”面向熟悉此前规则但首次见到该关的玩家。理解答案后快速完成、玩家一次推理成功，都不应被惩罚；不能要求每个人强制死两次或增加等待来达标。

### 2.2 每关必须回答的六件事

1. 玩家在这一关究竟要发现哪条因果关系？用一句话写，不能只是“先A后B再C”。
2. 哪两个看似合理的计划有实质区别？无需每关强行放错路；若只有一个候选，说明为什么判断其可行仍有价值。
3. 为什么不能直接跳过、少拿一步、换钥匙顺序、从别的高度下降，或在另一个固定点使用同一折法？
4. 玩家能在尝试前看见哪些判别线索？尝试后获得哪些新信息？
5. 错误尝试如何恢复？给出实际支撑点与动作，不能只写“重来即可”。
6. 与邻近关、所属结构家族相比，哪条依赖边变了？删掉这个变化后是否退化为另一关？

### 2.3 往返与重复的判定

合理往返：第二次经过同一区域时目的、可达性、出口状态或落脚点功能发生了因果变化，玩家需要重新判断；或第一次出去时就必须为返程安排位置。收集钥匙使门可用，可以是早期的一次教学洞察，但不能支撑几十关重复。

无效往返：答案已明确、道路和操作完全相同，只因钥匙放得更远而多跑一次。删去无决策路程后谜题不变，就优先压缩该路程。走路时长增长不是梯度。

纯坐标、镜像、改名、配色、等比例伸缩、交换钥匙 ID 均不能单独构成新关。做去坐标对照：仅保留“固定区域—折法—落脚区域—钥匙集合—出口状态”的依赖图，再看关键洞察和错误计划是否变化。**相同折法序列不自动判重复；不同折法序列也不自动判创新。**

开场左右折教学可以承担不同操作教学职责，但须明确教学目的与掌握检查，不得把此例扩展为后期批量镜像豁免。

- 阻断问题独立于算术分。分数高也不能带着已知无解、越界、软锁或核心机制旁路冻结。

## 4. 难度梯度：暂定目标，不冒充实测

以每10关为观察窗口，不要求相邻关严格线性变难。章节开始可给短过渡，但26–100的过渡关仍需独立判断，不能再投放“折一下直走”的新手教程。25→26、50→51、75→76必须联合审查。

以下均为 **A，需首次接触玩家验证后调整**。时间为未看路线的首次解出墙钟时间，包含观察和尝试，另记读提示/暂停时间；不是 `game.elapsed`。

| 区间   | 期望认知变化                               | 初见时长设计目标     | 不能当达标依据       |
| ------ | ------------------------------------------ | -------------------- | -------------------- |
| 1–3    | 直接看到折纸与通路的因果，学会一个简单选择 | 约5–20秒，开场可更快 | 人为拖长入门         |
| 4–10   | 从“按按钮”过渡到判断支撑、遮挡或钥匙保留   | 约15–45秒            | 增加跳跃次数         |
| 11–25  | 两个关联条件；第一次尝试能形成改进计划     | 约30–90秒            | 重复走原路           |
| 26–50  | 先安排中转点/返程，再取得局部收益          | 约45–150秒           | 多摆钥匙、更多折痕   |
| 51–75  | 更远一步的状态预判；局部正确不必然全局可行 | 约60–210秒           | 隐藏规则、漏看像素缝 |

不是要求后期每人花足时长或必定重试。若玩家瞬间洞察仍属成功；若代表性初见玩家普遍在10秒内套前关解法通过后期关，则回查推理/趣味/梯度，不加走路距离“修时长”。

建议实现后的小规模校准：每个后期关至少取得3条独立初见记录，尽可能5条，测试者未读解答且掌握前置规则；按人分配连续小段，避免一个人连玩100关产生疲劳。记录首次有效假设、放弃假设原因、合法折法尝试、思考停顿、操作死亡、提示层级、解决时间与一句“难在哪里”。样本小只支持定性返工，不能宣称统计上完美。可由熟悉玩家补做熟练执行，不能混为初见样本。

良性试错的优先目标（A）：错误折法尽量可在当前安全区预览/取消或展开恢复；关键错误恢复到新的决策点尽量在约10秒内完成。超过此值应解释新信息价值并缩短重跑，不把10秒当引擎已保证的能力。禁止晚期将长流程后的极限跳跃作为主要难点。

### 9.4 对“先后顺序”的严格审查

现有规则下，拿到一把可接触的钥匙本身不会使任何平台消失、关上通路或改变折痕；钥匙集合只会增加直到死亡/重开。**“先拿甲会导致乙拿不到”不能只靠钥匙命名或手工路线规定，必须是去拿甲所经过的空间动作改变了位置/返回能力。** 若同一状态下甲乙都可安全取到并回到同一换折点，则先甲后乙通常不是新谜题依赖。

每条“必须先A后B”论断都用以下反事实检查，书面可以先做D推导，随后才做正式物理R验证：

- 在最早可站稳的位置直接做B，会因固定侧、支撑、目标碰撞还是可达性失败？指出具体区域，不写“设计如此”。
- 不拿当前钥匙，先前往下一安全点，是否仍能回收它？若可以，钥匙顺序是建议路线，不是强制推理。
- 角色从高处直接下降，能否跳过一个换折阶段？下降距离不能套用同高跳距上限。
- 保持当前折法，能否直接接触全钥匙后的门？如果可以，尾部“回固定点展开”并非必需。
- 折前、折后看起来相同的安全点，是否实际相对另一折痕属于移动侧？如果是，这是可用的新依赖，但必须可见并有恢复空间。

只要发现不破坏核心洞察的短解，应允许它，更新路线与提示；不以强迫执行作者最长路线为目标。如果短解消灭本关唯一新判断，应调整几何或重新定位该关，而非声称玩家“不按预期玩”。

### 9.5 信息收益与惩罚成本的独立账本

后续每关分别记录“规划尝试”和“操作失败”：前者是试验一个折法或落脚顺序并更新判断；后者是已经知道去哪但跳漏/刹不住/被刺碰到。同一次失败可以两者兼有，必须说明哪一部分产生了信息，不能把所有死亡都算推理。

具体反例：走完三段已知楼梯、拿两把钥匙后，在窄阳台失足回出生点，约0.35秒重新出现只是复活动画很短；重拿钥匙和重走楼梯仍是惩罚。若没有新空间判断，这一轮不能支撑“需要好几次尝试才通”的目标。可执行的优先修正是加宽决策平台、移除尾部重复越刺、缩短已知通勤段，或把需要验证的选择提前暴露。不要在设计稿里默认新增检查点来掩盖现规则的成本。

在现有机制内，优先寻找这些不同的推理来源（是设计方向，不是已通过的关卡）：同一平台对两道折痕的固定性不同；去程有利的折法不适合最后触门；收集虽保留但目标所在平台会移动；眼前可达的落脚点不具备下一次换折所需支撑；正确展开不仅撤桥，也解除另一处遮挡。各方向必须落到真实几何和反例，不可用换名称批量扩为100关。
