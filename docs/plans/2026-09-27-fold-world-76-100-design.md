## 1. 已核对的真实规则与设计边界

先尝试了仓库 CodeGraph；其结果没有包含本游戏，随后直接阅读 `games/local/fold-the-world/src/levels.ts`、`geometry.ts`、`game.ts`、`physics.ts`、`hints.ts` 和 `tests/routes.ts`。仓库当前有 16 关。以下约束来自这些源码与本轮共同约束，未运行游戏或新增验证代码。

| 项目           | 真实行为及本方案的使用方式                                                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 纸面与可视范围 | 世界宽 1200、高 600；本批玩家需要辨认和使用的内容限制在 y=180–560，平台顶面尽量在 240–540，出口顶部不越过 180。                                                     |
| 折叠模型       | 只允许一个活动折法。不同折法之间必须先展开，再折；没有累积折叠、旋转、横折、穿层、角色随纸传送。                                                                    |
| 镜像           | 矩形绕竖直折痕 c 镜像后，左边为 `2c−x−w`，y、宽、高不变。平台、刺、钥匙和出口都遵守同一规则。                                                                       |
| 平台           | 跨折痕的平台在定义时被切分；移动部分和固定部分可能重叠，碰撞按实体并集处理。不能用“纸在后面”解释可穿透。                                                            |
| 安全操作       | 身体 22×28，完全站稳且水平速度绝对值不超过 8；整个身体要处于固定侧、离折痕 12 以外，脚下全宽都有原始固定平台支撑，目标世界不能把平台或刺压进身体。                  |
| 固定的含义     | 相对于本次操作的折痕和方向固定，不是某个平台拥有永久固定属性。本文每处“站”都必须对当次展开、下一次折叠分别检查。                                                    |
| 跳跃           | 理想最高 72，同高满速理论跨度约 102；土狼时间和身体边界会增加真实可达范围。关键上升优先 40–60，水平净缝优先不超过 35；60 高度同时遇大横向位移的组合不直接视为可达。 |
| 强制隔断       | 不能把 103 的缺口当作“跳不过”。需要隔断时优先明显的大断口、超过跳高的高差或实体墙；后续仍要查土狼跳、擦边落地及借柱顶捷径。                                         |
| 钥匙           | 全部钥匙只控制唯一出口；不打开中途门、不消耗、不要求颜色顺序。折叠和展开不会丢钥匙；死亡和重开会清空。                                                              |
| 失败与恢复     | 没有检查点、撤回到上一步或局部复活。正常错误应能走回安全站后展开；“恢复”不代表回滚已走路线。无刺宽台优先，避免长谜题反复全关重来。                                  |
| 预览           | 预览用于观察候选变化，不是时间停止后可移动的第二世界。预览、折叠动画期间不安排角色跑动。                                                                            |
| 提示           | 现有 `HintGuide` 依赖线性操作序列；偏离或漏拿钥匙后可能进入建议重开的恢复提示。多条合法路线不能直接冒充它已经支持的能力。                                           |
| 现有路线证据   | `tests/routes.ts` 是手写路线执行器，不是最短路或无捷径证明。共同信息中的现有 16 关已知解执行约 2–18 秒，不等于新玩家首解耗时。                                      |

本批不新增游戏机制。长因果链来自站位、同一折法的多处影响、收集分支、路线重访和出口位置，而不是等待、精细操作、故意藏信息或新增规则堆叠。

### 坐标与路线记法

- `P名=[左端,右端]@顶面y` 表示真实平台矩形；默认厚 20。立柱单列 x 区间及 y 区间。不能在实现时把本文的站点名当成无实体的传送节点。
- `K名=(x,y)` 是 16×22 钥匙的左上角；`E=(x,y)` 是 26×38 出口左上角。钥匙通常放在平台顶面减 32，出口放在顶面减 38。出生点的 y 是脚下顶面减 28。
- `A←600` 表示折痕 A 在 x=600，右向左折；`B→500` 表示 x=500，左向右折；`U@P` 表示在 P 上展开。路线中每次从 A 换 B 都明确经过 U。
- K1/K2/K3/K4 是文档中的目标编号，不代表新增彩色锁或编号机关。仅出口校验全部收集。没有物理强制的顺序均标为“推荐”或“可交换”。
- 下文坐标是人工规划的关键实体与镜像锚点，**不是完整实体表或已经跑通的路线**。未列细部须沿既定拓扑补齐并复核，不能靠凭空平台、改跳跃参数或隐形规则填坑。平台清单不满足安全条件时，该候选必须退回设计修改。
- “最低有意义折叠数”是要守住的**设计下界目标**，只计成功折入，不计展开、无效输入、预览、重复白折。所列主路线达到该目标只是候选见证，不是数学最优证明；独立复核发现更短合法解时，应接纳好捷径或重做空间，不能为了数字加隐藏限制。

### 几何可实施性的共同约束

三种折痕组合会反复使用，但不据此生成关卡：

| 组合 | 可用折法            | 所有原始实体的横向边界要求                                                      | 关键安全站位示例                                                               |
| ---- | ------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| R    | A←600、B←700、C←800 | 实体均在 [0,1200]；这三个右折不会把原本在纸内的移动实体反射到负数。             | A 操作时角色左边 x≤566；B 为 x≤666；C 为 x≤766。                               |
| M    | A←600、B→500、C←750 | 实体均在 [0,1200]，三种变换后仍必须逐个检查；本组合的移动半边反射边界在纸内。   | A 需身体右边≤588；B 需身体左边≥512；C 需身体右边≤738。                         |
| D    | A←560、B→640、C←760 | **所有实体整体限制在 [80,1120]**，否则 A 可能反射到左界外，B 可能反射到右界外。 | A 需身体右边≤548；B 需身体左边≥652；两者没有共同安全站位，必须经平展道路换边。 |

后文第 89 关另用 A 的双方向与 B←750；都是现有 `directions` 可表达的规则。坐标跨折痕的平台必须按切分后的每一段审核。钥匙、刺、出口不能跨任何预设折痕。平台来源即使“不在主路线使用”，也要在所有允许折法下保持纸内、无意外通路。

跳跃复核不只看平台净缝：必须同时检查起跳站位、加速距离、头顶、落点、上下行方向与折叠后的所有其他实体。终章也不以极限跳跃抬难度。

## 3. 梯度与可读性目标

76 关入场前，玩家应已在 51–75 掌握：固定支撑、换折必须展开、钥匙保留、左右两方向、折走/折来遮挡、收集后返程。缺哪项，应由前段补教学，不能靠本批提示承担首次教学。

| 组                   | 范围   | 新的推理重点                               | 每关有效决策目标 | 成功折入下界目标    | 首解目标带 |
| -------------------- | ------ | ------------------------------------------ | ---------------- | ------------------- | ---------- |
| 一：先想落在哪里     | 76–80  | 先规划下次操作站，再选择这次到达路线       | 4–6              | 4–5                 | 1–3 分钟   |
| 二：一张图上的几件事 | 81–85  | 多目标分支、共享道路、避免漏项和无价值往返 | 5–7              | 4–5                 | 1.5–4 分钟 |
| 三：换边之后再折     | 86–90  | 固定性随方向变化，展开态也是路线的一部分   | 6–8              | 4–6                 | 2–4.5 分钟 |
| 四：返程重写来路     | 91–95  | 同一折法在不同高度/目标状态下的相反价值    | 7–9              | 5–6                 | 2.5–5 分钟 |
| 五：完整世界         | 96–100 | 多条可读子目标组成长因果链，综合前四组     | 8–10             | 3–5，依赖复杂度优先 | 3–8 分钟   |

这些都是**设计目标，不是实测**。首解时间含观察、思考、正常回退；“尝试”指一次有明确假设的路线尝试，可能只是预览后否定或安全走回，并非必须死亡重开。单关目标死亡通常 0–1 次。已知解的纯执行不追求越来越久，优先控制在约 25–60 秒，末两关可讨论到 75 秒；若熟练执行仍超过 90 秒，应先减路程和重复搬运。上述执行数同样未测。

有效决策需能回答“如果先做另一件事，会在哪个可见条件上行不通/多走一段”。单纯按提示再点一次折叠、同一路走很远、记住五个密码，不计有效决策。每五关的第五关复合前四关的两到三个要点；下一组首关可以少一步操作，以改变思考类型作缓冲，不要求逐关钟表时间单调递增。

每幅图最多突出三个当前候选目的地；使用现有固定/移动平台纹理、清楚的空隙、可见钥匙和出口。需要新加的临时读图标号只出现在设计图中，不假定游戏已具备新的地图 UI。

## 4. 逐关设计

### 第 76 关：带着落脚点出发

- **结构/坐标**：组合 R。起点 H=[80,220]@520，中央 N=[440,580]@520，小台 S=[520,580]@460，换折台 T=[500,580]@350。右纸道路 R0=[760,980]@520，A 后为 [220,440]；中层 R1=[870,1080]@410，B 后为 [320,530]；高层 R2=[1070,1170]@290，C 后为 [430,530]。K1=(1000,378)，K2=(1100,258)，出口 E=(100,482)。T 到 R1 的返程端与到 R2 的起跳端都要有完整宽容落区。
- **预设折法/必要路线**：A←600 接入 N，U@N；B←700，经 S、R1 取 K1，必须继续到 T，U@T；C←800 取 K2，回 T、U@T；A←600，从 T 沿固定落点下到 N，经起初道路回出口。四次折入。K1 在主线经过处，K2 在高层；两把钥匙没有编号锁。
- **主要洞察/反事实**：拿到 K1 不等于本段结束；留在 R1 上无法展开。若提前退到 S 再换 C，会发现上层接点仍太高，需重新借 B 到 T。
- **错误/恢复**：在移动台上要求展开会被拒绝，不扣资源；走回 R1 右端、登上 T 即恢复。提前换 C 可在 S 安全展开，再用 B，不需死亡。
- **最低有意义折入目标**：4；分别承担入场、上中层、上顶层、返乡。需独立确认平展下落不能跳过最后 A。
- **首解/尝试目标，非实测**：60–120 秒；2–3 个假设尝试。
- **相邻差异**：作为 75 后的专家过渡，以“下一站在哪里”提高难度；77 不再重复爬三层，而改为终点附近的遮挡与收尾。

### 第 77 关：门前最后一张纸

- **结构/坐标**：组合 R，整体形成环而非直塔。H=[80,220]@520，N=[440,580]@520，S=[520,580]@460，T=[500,580]@350；R0=[760,980]@520，R1=[870,1080]@410，R2=[1070,1170]@290。K1=(1000,378)、K2=(1100,258)。E=(94,482)，门罩 X=[1070,1130]×[430,520]，A 后落在 [70,130]，与 E 同处。H 上 x=160–200 为可站稳的展开区，不能让罩占满 H。
- **预设折法/必要路线**：A 入场、U@N；B 经中层取 K1、到 T、U；C 取 K2、回 T、U；A 回 H 的右侧，**U@H 才能进入门**。推荐 K1→K2，路线依赖高度，不设置钥匙锁。
- **主要洞察/反事实**：最后 A 同时带来桥和挡门的罩。看见出口并集齐钥匙，不代表在折态能结束；要把自己送回原纸后交还桥。
- **错误/恢复**：误判门罩是可跳障碍，只会停在可见高柱前；从 H 右侧安全展开即可。罩高 90，不以 72 极限跳来解，且要查从其他高台落入罩顶的捷径。
- **最低有意义折入目标**：4，另需末次展开；若末次 A 能直接把钥匙或出口凑到角色身边，应调整实体位置。
- **首解/尝试目标，非实测**：75–135 秒；2–4 次。
- **相邻差异**：76 的困难在中途选择站点，本关在完成条件前的一折两效；78 把同一矛盾移到中途交接，不再以家门罩收尾。

### 第 78 关：两座候车台

- **结构/坐标**：组合 R。H=[80,220]@540、N=[440,580]@540、S=[520,580]@480；R1=[870,1080]@420，B 后 [320,530]。低换折台 TL=[400,480]@360，高换折台 TH=[550,650]@240，中继 R2=[1070,1170]@300，C 后 [430,530]；出口台 F=[180,300]@240，E=(220,202)。K1=(1000,388)，K2=(1110,268)，入口来源 R0=[760,980]@540。末段桥 R3=[850,1100]@240，B 后 [300,550]，C 后 [500,750]。
- **预设折法/必要路线**：A 入 N、U；B 经 S 与 R1 到 TL、U；C 经 R2 到 TH，收 K2，U@TH；B 再折，经 R3 水平向左到 F。TL 与 TH 高差 120，第一 B 不能直接登 TH；C 的高桥左端 500 距 F 右端 300 有 200 断口，C 中继左端 430 与 F 也相隔 130 且还要上升 60。K1 主线先取，K2 后取，不需要新锁。
- **主要洞察/反事实**：TL 能展开，却不等于能完成所有后续折法。C 的价值是把人送到 TH，最终 B 的同名折法承担不同高度的道路。
- **错误/恢复**：在 TL 提前折最终 B 时，上接板高出 120，当前跳不到；U@TL 后恢复 C。若在 C 的 R2 上停下，走到 TH 才能展开。
- **最低有意义折入目标**：4，即 A→B→C→B；120 高差使第一轮 B 的高桥不可直接上，C 高桥又无法横穿 200 断口。
- **首解/尝试目标，非实测**：90–150 秒；2–4 次。
- **相邻差异**：77 处理消失的道路，本关处理同折法不同高度的两次用途；79 的重用发生在回程，且不以更高出口为目标。

### 第 79 关：桥下还有一封信

- **结构/坐标**：组合 R，双层路线。H=[80,220]@480、N=[440,580]@480、S=[520,580]@420、T=[500,580]@300；两段入口来源 [760,850]@480、[920,980]@480，A 后为 [350,440]、[220,280]，中间有 70 宽落口。中层 [870,1080]@360、高层 [1070,1170]@240。上钥匙 K1=(1100,208)，低袋台 L=[270,410]@540，K2=(310,508)，E=(100,442)。落口下面可站稳，桥下净高 40；从袋台可在 70 宽口内向两侧跳回高 60 的桥。
- **预设折法/必要路线**：A 入场、U；B 上 T、U；C 取 K1、回 T、U；A 回到低层，并从折入道路靠左的落口到 L 取 K2，再回 H。K2 可以早拿则接受，不虚构“必须先 K1”；首选布置让低袋口进入后自然回 H，早取会多一趟进场。
- **主要洞察/反事实**：同一桥上行时是通路，返程时是低目标的上方落脚板；应先看清出口与低袋口的连接，避免取完高钥匙直接回家漏项。
- **错误/恢复**：到家才发现漏 K2，在 H 保持 A 或重折 A 去取。袋台能从落口跳回桥，不能用死亡代替返程；袋口跳的宽容需独立复核，必要时扩大开口及两侧接台。
