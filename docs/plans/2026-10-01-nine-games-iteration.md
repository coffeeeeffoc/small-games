## 平台状态的含义

Web 与 H5 是现有浏览器入口；原生小游戏使用经过编译的 Canvas 或 Cocos 工程。五款现有 Canvas 入口是**好友竞赛玩法**，不是完整浏览器单机界面的自动移植。代码、制品检查通过不代表官方工具、平台账号、真机、广告库存或审核通过。

本轮将围捕两款、词屿、此时·此地、象五子棋的 Canvas 好友赛构建扩至微信/B站/抖音/快手，生成 20 份实际制品，并在没有 DOM/window/fetch 的 VM 中逐份执行真实规则动作、后台锁定、存档异常、缩放与清理。音频故障和可选邀请能力另有回归。

卡丁新增 Creator `bytedance-mini-game` 抖音目标；夜航新增微信/B站/抖音工程配置。配置检查通过，真实打包仍需要 Creator 3.8.8。两款快手的 Creator 适配插件尚未验证；外滩与乌龙城原生入口仍待实现。各渠道细目见 `docs/deployment/nine-games-platform-status.md`。

## 持续迭代的下一步

1. **好友竞赛登录**：微信/B站已有服务端交换实现，仍需每个真实应用的账号配置；抖音/快手目前明确拒绝未实现的服务端交换，返回 `PLATFORM_LOGIN_UNAVAILABLE`，不回退游客或借用其他渠道身份。两家的官方登录文档读取被当前网络策略拒绝，先取得官方协议依据，再实现交换与故障回归，最后用真实应用确认。AppSecret 只进入服务端安全配置，不写前端、不在聊天中传值。所需 `developer.open-douyin.com` 与 `open.kuaishou.com` 已加到云配置草稿；保存草稿不会应用当前机器网络，需要通过环境设置应用后再重试。
2. **Cocos 制品**：配置 Creator 3.8.8 或来源可信且源哈希匹配的产物。按微信/B站/抖音真实目标构建、检查分包体积与 AppID，然后在官方工具和设备验证触控首操作、音频、前后台、存档和好友邀请；快手先验证适配插件。
3. **完整原生单机**：优先评估乌龙城的独立 Canvas/Game Host 入口；其余游戏逐款复用规则、迁移菜单、媒体与存档。外滩的 R3F/Three/物理资产应在目标 WebGL/内存环境单独验证。保持比赛模式与单机模式的规则及存档分离。
4. **体验与性能**：按真实错误或实玩证据继续迭代，先保证重试/存档、指针取消、失焦暂停与手机布局，再调整难度、反馈和教程。外滩优化后在软件 WebGL 的真实场景仅约 1 FPS，完整浏览器实玩本轮未通过，不能作为手机帧率验收；必须补物理手机测量。另需单独处理既有 Water 反射 render target 在切换画质时的释放问题。
5. **发行**：每款每渠道填写 AppID、可用广告位、域名、隐私和审核材料，逐项记录官方工具/真机结果。快手广告未取得可靠验证，本轮不支持并明确拒绝配置广告位。发布、上传和提交审核另按实际授权执行。

## 可重复检查

在仓库根目录激活 `source /workspace/.cloud-setup/activate.sh` 后，使用各游戏 README 的 `test`、`test:input`、`test:browser`、`test:lifecycle`、`test:controls` 命令及浏览器执行路径 `/usr/bin/chromium`。不要默认运行包含所有 Cocos 与服务的根 `build/dev`。

```bash
pnpm check:dependencies
pnpm test:boundaries
node scripts/sync-h5-fullscreen.mjs --check
node --import /workspace/.cloud-setup/system-chromium.mjs scripts/test-h5-fullscreen.mjs
node --test scripts/kart-sharing.test.mjs
node --test scripts/competition-sharing.test.mjs
pnpm --filter @coffeeeeffoc/shell-web test:sharing
pnpm --filter @coffeeeeffoc/runtime-api exec vitest run tests/competition-platforms.test.ts
pnpm --filter @coffeeeeffoc/platform-kuaishou test
pnpm competition:native
node scripts/competition-native-smoke.mjs
```

竞争制品测试需要先生成当前源码的制品；SDK 替身与测试身份仅验证本地契约，不作为平台登录验收。保留 passed/failed/unrun 的区别。全仓构建和 Cocos 真实浏览器制品仍未验证；不能据单元测试声称引擎制品已可发行。
