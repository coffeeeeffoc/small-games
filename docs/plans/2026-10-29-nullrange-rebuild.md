# 零域 · NULL RANGE 全面重构实施计划

**目标：**将可玩性验证原型重构为手机优先、真实 Cocos 3D 渲染、有独立单机任务与真实玩家对战入口的完整空战游戏；分批实现、验证、记录进度并推送 dev。

**架构：**Cocos Creator 3.8.8 + TypeScript 负责场景、摄像机、输入、UI、声音及生命周期。确定性飞行与战斗规则独立于引擎；任务、敌机与机体配置独立；联网通过现有通用服务契约与夜航守望相同后端接入，游戏专属规则由 adapter 承载。

**工具：**Creator 3.8.8、Blender 5.2.1、Hyper3D MCP、Node / pnpm、既有浏览器检查工具。遵守 [开发规范](../game-development.md)、[素材规范](../game-publishing.md)、[增量发布](../operations/incremental-publication.md)。当前任务已获分批实现、子智能体及推送 dev 授权，不在批次之间重复征求许可。

## 依据与范围

- 起点：`8c4c821addb627e4196ccdc0b9437475e4b60f47`；游戏目录 `games/local/vibeJam-myself-nullrange`，稳定 game ID、包名及入口 URL 保留。
- 原型只证明低空飞行、追击、射击、导弹和残骸回收有趣。废弃其渲染、DOM 界面与交互布局，不把历史代码结构作为约束。旧源码可按该提交找回，不复制完整原型归档。
- 用户追加要求：单机与玩家对战必须明确区分；后端是一套跨游戏、跨平台的通用接口，复用夜航守望模式；逐页精确对照效果图，不允许用旧交互或灰盒代替。
- 存档仅迁移可信旧最高分和静音偏好，不伪造旧进度；新进度使用版本化数据，校验损坏/非法数值，存储不可用仍可玩。
- 主工作区有夜航守望及后端的其他未提交改动，保持原样；本重构在独立 worktree 中进行。后端依赖必须区分已提交实现与在途工作，不能把未提交能力宣称已发布。
- 不扩展商城、付费、社交聊天或全新后端架构。真实玩家对战不得由机器人、同屏假对手或本地成绩冒充。

## 联机契约

复用现有通用身份、游戏目录、房间/匹配、重连、输入序号、服务端状态和结算通路；跨平台身份使用既有 platform/provider 映射，不把 TapTap ID 当作唯一玩家身份。游戏ID隔离房间/规则/成绩。单机不依赖后端；未配置、断网、满房、版本不符、对手离开需给出可恢复状态。

首个完整对战范围：两名真实玩家同一空域的对战，创建/加入房间、准备、倒计时、服务端开始、同步飞行与武器、伤害和胜负、重连/退出、重开。后端接口继续通用，新增 Null Range 规则适配器；在审查现有服务契约后落实精确接线，禁止私自复制一套 Night 后端。

## 批次与验收门槛

每批顺序：实现 → 定向规则/类型/构建/真实入口验证 → 只读复核 → 修复 → 记录证据 → 中文提交 → fetch/正常合并最新dev → 必要受影响复测 → 非强制推送 → 记录远端SHA。上一批推送成功后启动下一批 implementer；默认同时只有一个写入者。

路径：本计划、游戏 `docs/design/`、README 计划入口。

路径：游戏 `assets/scripts/core/`、`assets/scripts/`、`assets/scenes/`、`settings/`、`scripts/`、`package.json`、`tsconfig.json`、`tests/`；必要构建注册/CI文件由主会话整合。

### B3 手机交互、完整UI与视觉收敛

路径：游戏 Cocos HUD/触控/流程/音频组件、页面资源、浏览器测试及 `docs/design/`。

1. 全新首页、单机/对战选择、任务卡片、准备/机库、HUD、暂停、设置/帮助、结算。

3. 逐页对照目标图修正到可接受一致程度；手机尺寸与桌面辅助输入走通所有路径。

### B4 内容、节奏与成长

路径：游戏内容配置、核心规则、进度、表现与测试。

1. 六个不同任务、三类敌机/精英目标、三种有差异的机体配置；复用规则而不复制关卡逻辑。
2. 提升锁定/命中/破盾/爆炸/回收、预警、近地/加速反馈；所有视觉效果不改变规则时钟。
3. 正常可达性、奖励幂等、解锁、失败原因、旧存档迁移与损坏存储检查；根据实际游玩调整节奏。

### B5 通用后端玩家对战

路径：既有 `platforms/competition/`、`services/runtime-api/` 的游戏适配与必要注册，以及游戏在线适配组件/双端测试；具体边界取决于已提交Night接口排查结果。

1. 接入通用身份/房间/同步；新增游戏专属权威规则，不另起后端服务。
2. 两个独立客户端完成建房/加入/准备/战斗/胜负/退出/再战；单机与对战成绩和暂停语义分离。
3. 验证跨游戏隔离、跨平台身份适配、非法/过期/重复输入、断线重连和旧房间回调。
4. 本地双客户端与服务端成功只证明本地；真实远端部署/平台登录/手机网络尚未验证时明确记录，不伪称线上PVP成熟。

### B6 完整验收、素材与发布接线

路径：游戏 `publishing/`、`reports/`、`README.md`、测试；Cocos CI生产者、Shell/独立构建消费者与增量范围的必要接线。

1. 检查真实生产入口、路径前缀、加载失败重试、自有加载画面与资源完整性。
2. 录制实际手机视口玩法，交付简介/推荐语/开发者说明/图标/宣传图/宣传片/实机截图/实录八类资料；视频来源环境如实标注。

4. 独立只读审查，修复可行动问题；最终代码/素材/证据同步推dev，并核查CI/Pages状态。
