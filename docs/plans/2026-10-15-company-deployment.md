# 官网独立发布方案

目标：先将最新 dev 快进合入 main，再准备 `nenggongzhiren.cn`、`www.nenggongzhiren.cn` 的官网发布。备案号为 `沪ICP备2026053115号-1`。

选择独立静态 Nginx 容器：官网无需数据库、COS 或游戏后端。相比切换现有游戏公网模式，它无需重建游戏或改变游戏入口；相比修改宿主系统 Nginx，它复用现有 Docker 运维方式。Compose 项目为 `company-web`，公开 80/443；现有游戏继续只在回环 8080 访问。

实现 `pnpm deploy:company`，包含只读检查、本地准备、部署及回退。默认使用已配置的证书，缺少 DNS/TLS 时停止并给出具体原因。构建与浏览器回归通过后打包，文件摘要绑定准确源码 SHA，上传后校验，Nginx 配置测试通过再切换。失败恢复上一版。部署后分别核对服务器本机与公开域名的版本。
