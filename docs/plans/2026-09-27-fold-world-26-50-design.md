## 1. 设计依据与硬边界

已先尝试 CodeGraph；索引未命中该游戏，随后直接阅读 `games/local/fold-the-world/src/levels.ts`、`geometry.ts`、`game.ts`、`physics.ts`、`hints.ts`、`tests/routes.ts`。当前有 16 关。现有路线文件是作者编写的操作路线，不是求解器，也不能证明最少折叠次数。

以下是本提案实际依赖的规则：

| 已有规则 | 对设计的约束 |
| --- | --- |
| 纸面 1200 × 600，当前可视 y=180–560，折痕都是竖直线 | 所有关键内容放在可视范围；只改变横坐标，不允许把折叠描述成升降机、旋转平台或水平折纸 |
| 矩形绕 `x=c` 反射后，左边界为 `2c-(x+w)` | 坐标按整个矩形反射；钥匙、门、尖刺也反射，不能只移动平台 |
| 同时至多一道折叠 | `A → B` 实际必须是 `A → 展开 → B`，不存在叠折或保留上一座桥 |
| 角色不会跟着纸移动 | 每次操作必须原地站稳；不能靠折纸把角色运到另一岸 |
| 操作要求角色完全处在固定侧，离折痕安全带 12；固定原始平台须覆盖整个脚底 | 临时桥上不能展开；跨折痕的平台会分段，宽平台不等于处处都能操作 |
| 角色宽 22、高 28；速度 170，起跳速度 480，重力 1600 | 连续近似最高跳升约 72、同高飞行距离约 102；这不是实测可达包络。设计优先采用 45–55 的台阶高差，避免同时逼近高度和距离极限 |
| 平台是完整实体矩形，重叠实体形成碰撞并集 | 没有穿透平台、单向平台、背景墙；“桥下通道”必须有真实净空，“遮挡”必须挡路而非只挡画面 |
| 合拢后的平台或尖刺若侵入角色，操作会被拒绝 | 拒绝操作可以给出无损反馈，但不能把反复碰拒绝提示当成主要谜题 |
| 钥匙按 ID 永久收集至本次生命结束；所有钥匙齐了出口才通过 | 没有钥匙开局部门、分色锁或钥匙消耗。所谓先后关系必须来自路线，不能凭空规定钥匙一开机关二 |
| 死亡会重置本关、钥匙及折叠状态 | 恢复优先设计为退回原路或落到固定回收台；不能声称掉落后保留钥匙或有检查点 |
| 当前提示跟随一条操作序列，偏离后可能进入恢复提示 | 合法多解关不能因为换顺序就被产品文案判错；提示兼容性是整合项，不在本轮改代码 |

### 坐标与路线读法

- `P[a,b]@y`：平台水平范围 `[a,b]`、顶面高度 `y`，厚度默认 20；较厚实体另写。`S(x,y)` 是角色左上角；`K(x,y)` 为 16 × 22 钥匙；`E(x,y)` 为 26 × 38 出口。
- `A=600←` 表示折痕 x=600、右向左折；`B=500→` 表示 x=500、左向右折。`U@R` 表示必须回到固定落脚点 R 后展开。每关折痕 ID 独立。
- 写成“原 `P[900,1080]@390 → B 下 P[320,500]@390`”的是同一个平台，不是两块同时存在的平台。未特别写明的坐标均为原始平面坐标。
- `R` 是用于讨论的落脚点名称，不是新实体种类。必须用已有 platform 表达；纹理沿用固定/移动平台的区分，不增加按钮或交互规则。
- 下列坐标是**构图锚点和反射关系建议，并非完整 Level 数据**。R2把被退回的关键连接、罩体和回升段落实为实体；实现时仍需校准碰顶、起跳余量和完整支撑边界，不能临时添加新机关来维持作者路线。禁止直接批量转成代码并宣布可玩。
- 操作落脚面原则上留至少 60 宽的完整固定区域；桥下净空目标 ≥48；必经跨越不采用像素级落点。默认无尖刺；需要尖刺的关卡只用于显示已有路线的风险，不承担掩盖漏洞的职责。
- 每关的 `F` 是**设计目标：最低有意义的成功合拢次数**，重复合拢只有改变可达区域或完成必要返程才计入；`U` 是对应推荐路线的展开次数。预览、被拒绝操作不计入。尚未证明全局最优，独立评审若找到更短有效路线，应接受合理捷径或重新设计，不能把文案步骤当作下界证明。
- “必要顺序”区分：**地形依赖**（候选布局必须形成的阶段先后）、**推荐顺序**（减少折返，允许别解）、**自由顺序**（有意保留多解）。钥匙编号只供设计沟通，不能在画面上冒充钥匙等级。
- 时间与尝试数均为设计目标，面向已完成前 25 关、第一次见本关、暂不看路线提示的玩家；时间包括观察和试错。一次尝试指形成并执行一种路线/折法假设，不等于死亡或重新开局；一次生命可以完成多次尝试。

## 2. 产品方向备选与取舍

| 方案 | 实际玩法 | 价值与代价 | 结论 |
| --- | --- | --- | --- |
| A：停靠点驱动的空间路线谜题 | 用现有单次反射、固定侧操作、钥匙持有，改变去路、返程和换折位置 | 规则统一；推理发生在地图上；难点是防止合法捷径把阶段吞掉、避免固定/移动重叠难读 | **推荐，本稿采用** |
| B：加入分色钥匙、机关门或一次性桥 | 用新增状态直接强制钥匙顺序 | 更容易制造长依赖链，但会让钥匙顺序取代空间推理，还需要新规则、新教学和状态可视化 | 26–50 不采用；不能因布局难做就加锁 |
| C：保持现有布局，增加尖刺、缩小落点、限制折叠次数 | 更多手速压力和失败次数 | 实现快，但思考量未必增加，手机误触会被当成难度，重复外形依旧明显 | 不作为扩关方向；最少折叠数只作分析，不作通关硬限制 |

本段没有不可替代的新机制需求。建议的“分支”“遮挡”“回收台”“单向落差”全部用已有实体和重力表达。若后续证明某个设计必须靠移动角色、保存多折状态或钥匙开门才能成立，应撤换该设计，不能悄悄扩展本轮方向。

## 4. 第 26–30 关：先选停靠点

### 26. 桥头不是岸

- **结构**：A=600←、B=500→。入口 `[80,220]@490`；A原桥 `[720,980]@490` 接到 `[220,480]`。两座原始固定岸 L=`[350,430]@440`、R=`[520,590]@440` 都可展开A。另有原 `[600,700]@440`，A下成为 `[500,600]` 的接近面；平展后通向B高台：原 `[140,260]@385 → [740,860]`，钥匙 `(200,353)`，终台 `[660,760]@330`、门 `(690,292)`。
- **依赖/新判断**：A可到L或R；两处U都合法，但B要求身体左缘≥512，只有R可直接切换。推荐 `A→R→U→B→右台取钥匙→左上门`。A下门台在 `[440,540]@330`，与左385台隔180，不能借左高台直接结束。
- **恢复**：在L展开后发现B方向不符，可再A借接近面去R；也接受熟练玩家跨同高缺口到R。失败只增加一次局部调整。
- **目标/差异**：70–110秒、2–4次；F=2/U=1。新增的是“两座都能展开，只有一座能接下一方向”，不再把不存在的假岸当选择；27改为比较同折法对两层路的收益。

### 27. 从桥下面回来

- **结构**：A=600←、B=700←。上岸 `[100,250]@350`、出生 `(140,322)`；门厅 `[100,250]@490`、门 `(125,452)`，左墙 `[80,100]×[180,490]`、顶盖 `[100,470]×[410,430]`。原上桥 `[760,950]@350`、钥匙 `(772,318)`；R扩为 `[470,660]@490`。原下桥 `[930,1150]@490` 在A下为 `[50,270]`、B下为 `[250,470]`。固定回升台 `[500,580]@435`，底面455，R上角色顶面462；B态及平展的R在回升台右侧留 `[580,660]` 的80宽外露起跳面。
- **依赖/短解**：B先折，落顶盖后跳上B上桥 `[450,640]@350` 取钥匙，再退回顶盖，经435台到R，从B下桥进门，F=1/U=0。A先取钥匙、R处U再B也是合法两折解。原“A必需”撤销，洞察改为找到同时接通上下两层的折法。
- **恢复**：没拿钥匙先掉R，B态可从x610附近向左上跳435台，再接410顶盖与350上路；平展同样有此回升线。若处于A态，R切分后的并集只有470–600，先在原固定段x520展开，恢复右侧80宽起跳面后再回升，不要求在20宽残段起跳。保持顶盖右缘470、左墙下缘490和门厅60净空；A下下桥与R仍隔200，扩岸未打开门厅旁路。
- **目标/差异**：70–115秒、2–4次。26选择下一方向的停靠岸，27比较同一变换在上下两层的作用；28改用实体柱顶，不复用移动门。
### 28. 登上障碍的顶面

- **结构**：A=600←、B=700←。起点/回收底台 `[500,600]@465`，固定高岸 `[500,600]@355`，固定门台 `[340,420]@245`、门 `(365,207)`。B原踏台 `[900,1020]@410 → [380,500]`；实体柱原 `[720,780]×[300,465]`，B下在 `[620,680]`，A下在 `[420,480]`。钥匙原 `(960,378)` 位于B踏台。
- **依赖/洞察**：`B→踏台取钥匙→高岸U→A→柱顶300→门台245`。柱子挡住低处横穿，却在高处成为55级差的踏面；同一实体的侧面和顶面产生相反用途。A先折时柱顶比起点高165，不能直接登顶；B柱则在高岸右侧，离左门台至少200。
- **恢复**：初始误A可原地U；高处的恢复只指右侧绕过高岸外缘、控制落点回到 `[500,600]@465` 底台的路线，落台后U、B可重新上高岸，钥匙保留。A态柱左侧没有接收台，不再声称两侧落下都能恢复。
- **目标/差异**：85–135秒、2–4次；F=2/U=1。原移动门和最后重折A的回访链已全部删除；29转为同高连续顶面的真实支撑归属。

### 29. 半张长凳

### 30. 门旁留个位置

- **结构**：只用B=800←。入口 `[80,280]@500`，固定阶 `[200,280]@445`、`[280,380]@390`，通左岸 L=`[400,520]@335`；右岸 R=`[720,800]@335`。B原桥 `[880,1080]@335 → [520,720]`；高台原 `[1000,1100]@280 → [500,600]`、钥匙 `(1034,248)`。门 `(410,297)` 被B原罩 `[1160,1200]×[245,335] → [400,440]` 完整包住，L未遮口 `[440,520]` 宽80。

## 5. 第 31–35 关：安排钥匙路线

### 31. 先从屋檐下经过

- **结构**：起点在 `P[100,220]@500` 的低屋内，左墙封边，顶盖 `[100,480]×[440,460]`；A=600←，桥原 `[720,980]@500 → [220,480]`。桥钥匙原 `(844,468) → (340,468)`，屋内净空40，无法跳过钥匙。右岸 `[480,580]@500` 可跳上屋顶。B=700←，原高台 `[880,1020]@385 → [380,520]`，第二钥匙原 `(944,353)`；终台 `[530,600]@330`。
- **依赖**：A 下穿屋取 K1，出右岸上屋顶，展开、折 B 取 K2并上终台。K1 必须先经过：起点不能翻过顶盖，左墙也无绕口；K2没有开路效果。
- **错误恢复**：先 B 只会发现屋外缺桥，原地展开；出屋后提前在 A 下取 K2也接受，再换 B登终台。
- **目标与差异**：90–135秒、2–4次；F=2/U=1。洞察是先后来自空间通路；区别于30的门前停靠，32将故意允许反顺序。

### 32. 先远后近

- **结构**：起点固定台 `[480,580]@410`，脚下近钥匙在 `[480,580]@520`；远钥匙在 B=700← 的原台 `[900,1060]@355 → [340,500]`。A=600← 的原桥 `[730,980]@520 → [220,470]` 通左端门。固定回升台 `[280,350]@465`、`[370,440]@410` 位于左侧；下岸到第一回升台横隔130，不能直接向上抄回。
- **依赖**：推荐 `B取远钥匙→回上岸U→A→下落取近钥匙→沿桥进门`。这是省折返顺序，不是强制顺序。先下楼者可借 A 绕左侧回升，再换 B，最后重折 A。
- **错误恢复**：先拿近钥匙仍可通关，付出有因果关系的一次额外架桥；不死亡、不清钥匙。
