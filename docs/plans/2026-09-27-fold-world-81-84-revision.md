# Fold the World：81 / 84 的 R3 替换候选

2026-09-27。回应独立复评中81、84的退回意见；本次身份为修订设计者，**不自行打分、不宣布通过或冻结**，交主agent独立复评。仅新增本文，不修改76–100设计稿、既有评审或代码。

两关均只用现有规则：一次一个折态，换折先展开，角色不随纸移动，钥匙只控制最终出口且展开后保留。下表为全部原始实体，矩形写作`(x,y,w,h)`；柱、挡块也都是普通实心平台，不另加机关、刺或隐形地面。`A←600`表示右向左折，`U`表示展开。路线与隔离为纸面候选，尚未运行正式物理。

## 81 R3：取完这一支，留在另一岸

第一支在左上方，第二支在右侧低路。取完第一支后，同一阶板既可送人回P，也可送人继续到Q；P、Q都能换B，但B的高墙把它们分在不同区域。**第一支的离开方向决定第二支能否立即接上。**

折法仅两种：**A←600、B←700**。出生`(210,452)`，身体22×28，脚底在P@480。

### 决定依赖的折后区间

P、T、Q、Z、K1、E在两折下都固定；移动实体均不跨折痕。

| 实体          | A←600                  | B←700                         |
| ------------- | ---------------------- | ----------------------------- |

| R@480         | [20,300]               | [220,500]                     |
| X，y=200–480  | [120,180]              | [320,380]                     |
| K2，y=448–470 | [260,276]，完全被Z挡住 | [460,476]，位于墙右、低路之上 |

**候选主线，两次折入：**P折A，从P右端跳上S@420，再从S左段跳上T@360拿K1。回到S后，选择向右走：由S右端480下跳到Q左缘500（横缝20、下降60），在Q约x=530站稳，`U→B`。沿B低路向左走到x约450–470拿K2，再向右回Q的门。B阶板底440、低路顶480，40高净空容得下28高身体，可从下面正常走过，不要求跳入狭缝。

**实际改变的选择：**取K1之后，往S左端下到P与往S右端下到Q都能成功落地、展开和折B；只有Q与B态K2同在高墙右侧。留在T直接换B也合法，但仍处墙左。这里第二支直接使用B从Q出发，无须复述旧77的B→A→B回路；第一支的阶板还承担两支之间的转场。

**可恢复错误：**

- 拿K1后回P再B：墙挡住第二支。`U→A`，沿S转到Q，再`U→B`即可，K1保留。留T误换B，也可在T原地`U→A`，下S后转Q。
- 首先在P选B：只能看到墙左的断点；在P展开换A，没有落井或死亡要求。
- 没拿K1就先沿S到Q，甚至先用B拿了K2：在Q`U→A`，由Q向左跳回S（缝20、升60），再上T补K1；沿S回Q后可直接进门。**接受这条B后再A补第一支的三折候选，不宣称钥匙编号强制顺序。**

**必要结构与安全站位：**P在A下避开柱后的完整站位为身体左边`x=180–238`，Q可取`x=500–566`，T可取`x=180–238`；上述区间可分别完成展开和下一折，且目标实体不压身体。S上的移动部分不能当换折站。平展P经Z只能到顶445，T顶360仍高85；T上的钥匙位于其实体顶面上方，不能从台底穿过收取。B墙顶200，较T高160、较Z高245，排除“从T或挡块跳上柱顶再下右岸”。B阶板左缘460与T右缘260隔200，不能用它跨过分区。A态K2明确是受阻目标，绝不描述为可以钻进去拿的槽口；其位置与受阻显示沿用已承诺的呈现条件。

## 84 R3：门在低处，先留在高处

门在左下方，与出生岸同高。取件之后可回下岸L，也可继续上到U；两处都能合法完成同一个末折A。**A接通的是高处横桥：留在U可以从上路越过缺口再落向门，回L则站在新桥下方，接不上它。**

折法仅两种：**A←600、B←700**。出生`(520,492)`，脚底在L@520。

### 决定依赖的折后区间

L、U、F、E均固定；H在B折痕右边界起始，不需要跨线切分。

| 实体         | A←600                     | B←700                |
| ------------ | ------------------------- | -------------------- |
| H@400        | [240,500]，与U接合        | [440,700]，远离F     |
| S@460        | [180,300]，承接高桥到门岸 | [380,500]，接L与上层 |
| K，y=428–450 | [200,216]                 | [400,416]            |

**候选主线，两次折入：**在L折B，从L的x约520处向左跳上S@460，向左到x约400取K。此时不回L，从S左部未被高桥盖住的`[380,440)`起跳，上B高桥@400，再走到原始固定U的x约520处。`U→A`，沿A高桥向左，到其左端外侧落上A阶板@460，再从阶板左端落到F@520进门。上行两跳各升60；下行借已有阶板分两段落60，不要求从高桥精确一跳直落门。

**上下选择的实际后果：**拿K后从B阶板右端回落L，是一条真实、宽裕的返回路线；L和U都可在身体左边x=520完成`U→A`。但L到A高桥高差120；L左缘440到A阶板右缘300横缝140且还要上升60，不能靠这条低路接近门。留U则与A高桥同高直接相连。门虽在低处，先降回同高岸反而失去通路，区别来自连接高度，不来自操作被拒绝。

**可恢复错误与替代路线：**

- 取K后回L并选A：在L原地`U→B`，重新上S与U，再`U→A`即可；不清空钥匙，不添一把钥匙要求重跑。
- 出生直接选A：出现的高桥高120、左阶又隔140且高60；在L展开换B，仍可继续。
- 先经B上U、漏拿K：允许A后在左阶板取得同一钥匙，再落F结束。已经落F也可沿A阶板回升60补取。**不宣称B独占钥匙，也不因这条合法两折路线判错；它仍要求从上停点接通末折。**

**必要结构与安全站位：**上U原始固定支撑允许身体左边`x=500–558`，下L允许`x=440–558`，均满足A/B安全带；两处站立身体都不与折入实体相交。B高桥左缘440到F右缘200，横缝240、下降120；B阶板左缘380到F右缘200，横缝180、下降60。两条下降候选都明显超过现有身体宽度与土狼时间下的对应跳跃量级，不能据“门低就能跳到”删掉A。B阶板左侧留60宽无顶盖区，A阶板左侧也留60宽无顶盖区，供上行与补取使用；不要求穿板或悬边起跳。

## 交独立复评的边界

81提交的是“第一支有两种离开方向，只有一岸能直接接第二支”的构造；84提交的是“同一末折在上下合法停点产生不同结果”的构造。不以折数或新增钥匙数证明趣味，也不对两关给D分。两折仅为参考路线目标，非最优性实测。

复评请重点反证81的T/Z借高绕墙、A态K2阻挡与两岸回接，以及84保持B直接下降到F、L在A下攀回高桥的可能性。实体已全部列出，不能靠未列出的墙替方案辩护。具体60高跳跃的输入余量、台边回落和受阻目标呈现留正式G校准；若发现必要结构本身失效，应退回本文修订，而非直接宣布产品通过。
