# 五款服务端验证战绩与排行榜方案

用户已明确要求：本轮五款完整服务端校验；公开榜仅收录服务端验证成绩。

## 玩家流程

主页/结算进入战绩页；同页“我的战绩 / 排行榜”两项切换，返回原页面。卡丁车、夜航、乌龙保持横屏；历史猜测、词屿竖屏。44px触控、正常加载/失败重试/空榜，真实姓名使用统一匿名资料，不能展示令牌或开发细节。同步不阻塞本地继续玩。

## 计分与信任边界

复用现有比赛/重放、匿名身份、PostgreSQL明细和最佳纪录。客户端只发经校验输入，服务端固定步进或按时间规则重算结果，拒绝客户端分数、非法步骤、跨身份、跨游戏、重复冲突、超前模拟和过期对局。记录幂等、可重试；服务器未确认不得显示已入榜。开发、离线、试玩与奖励辅助成绩不进入公开榜。

- 卡丁车复用纯竞速模拟，线上多人保留既有权威结算；当前单机模式追加同源规则重放。
- 词屿复用棋盘/字母遮挡和拼写规则；标准内容版本由服务端提供，自定义词库保持本地。
- 此时此地保留日榜、周榜、五幕答题和战书协议，迁入统一身份与PostgreSQL，按服务端期限计分。
- 乌龙城拆分共享世界状态/物理/热点输入，网页与服务器使用同一关卡规则。
- 夜航守望复用Simulation/Flight的实际60Hz规则，明确检查点序列化，覆盖任务及训练。

## 交付覆盖面

游戏调用、版本号、共享服务客户端/历史查询、榜单发现、后端校验与存储、控制注册兼容、部署制品依赖、增量范围分类及回归都需一起更新。必要的数据库变更走独立可回滚部署；不重置现有数据。

## 验收

真实输入可完成结算并查询本人历史/排名；作弊输入、提前结算、重复提交、辅助局不能入榜。持久化重启恢复。五款手机尺寸/触屏验证，横屏旋转回退；真实生产HTTPS接口、源码准确提交、dev推送与线上发布分别记录。
