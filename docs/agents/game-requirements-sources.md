- 根 `AGENTS.md` 改为必须读取的触发入口，原移动／页面／关卡／图标要求迁入规范；dev 和发布操作不再重复抄写。
- 早期八款只例外于默认整体重构；当前任务的测试、可靠性及新上架资料要求仍适用。“整体验证”在本次确认问题中指整体重构的整套验收，不是免测试。
- 旧“所有 Web/H5 都增加全屏按钮”与 Bullet Garden 的明确要求按交付形态拆分；既有 H5 全屏和旋转兜底保留，原生无浏览器按钮，Cocos预览不额外堆控件。
- 广告成功统一为 `completed`，与 `kind: 'rewarded'` 的广告种类分开。H5 的 `show` 与 Game Host 的 `offer` 请求结构不同；旧归途站设计里的“rewarded结果”不能作为公共类型定义。
- 现有 Creator 桥可选择四种 SDK，但当前自动构建注入只核实归途站 TapTap 目标；H5 批量配置仍只接受 TapTap H5。多渠道方向、适配代码、单游戏打包和真机验收分别陈述。
- H5 的打开超时和长视频修复不能宣称覆盖原生 provider；原生当前仍有总等待边界，见公共广告指南。未在本次文档整理中修改运行实现。
- 单次历史配置、账号、广告位、包体与验收记录保留日期和来源，不复制为所有游戏的默认值；状态或文档声明不是实际线上验证。

后续用户确认新的可复用要求时，只更新其唯一维护入口；单游戏设计保留本游戏差异和证据。本次没有重新制作全仓上架素材，也没有将模板当成任何游戏的完成状态。
