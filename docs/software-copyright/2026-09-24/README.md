## 行数为什么与旧稿不同

此次重新读取了当前九款源码，并生成独立交存排版副本。两款围捕游戏的功能和源码已更新；部分项目原本一行包含多条语句，统一正常缩进后行数增加；围捕小队的大型数据声明经规范排版反而减少行数。不是按截图数量、PDF页数或固定3000行倒推。

“源程序量”按交存副本的全部物理行填写，包含注释、空行及源码内数据；PDF软折行、行号、页眉页脚不计入。原件物理行与非空行作为核对数据保留；不混用旧版快照、原件行数和排版副本行数。若最终更换源码、名称、版本或格式，应同步重新统计和出PDF。

统计范围包括卡丁车专有服务和象五子棋休闲好友房服务，其余按各自独立本体；第三方依赖、外部素材、构建产物、测试与工具不计，共用平台服务未在每个游戏中重复计数。源码内关卡数据计入，外部教材和图像文件不计入。逐文件边界以manifest.json为准。
