# 第五版官网 Logo 本地验收

2026-10-16，Windows、Node 24.21.0，使用已安装 Chrome 的显式路径。此记录为桌面浏览器及触屏模拟，不是真机验收或线上发布证明。

全部 PNG/ICO 变体从 Library 生产包下载并核对 SHA256、尺寸、透明通道及 ICO 六帧。独立下载的两个 1024 PNG 与 ZIP 对应文件逐字节一致。实际查看批准原图、透明主 PNG、390px 官网运行截图和本地浏览器 SVG 渲染；网站继续使用 PNG。

`pnpm --filter @coffeeeeffoc/company-web test` 通过：1440/1024/768/390/320 宽度、无横向溢出、图片加载、六帧 favicon、Logo 固定区域内等比显示、键盘跳转、导航、详情、触屏、动态偏好、暂停恢复及无 JavaScript。页面布局、正文和首屏场景保持原内容。实际本地页面截图为 `actual-local-390.png` 和 `actual-local-1440.png`。

两个归档 SVG 在 Chrome 155.0.8059.82 中均按 960×490 正常加载，无页面/请求错误，见 `svg-browser/`。XML 检查确认无图片嵌入、字体、脚本、事件或外部引用；N/星主体闭合，渐变高光描线保持源包原样。两份 SVG 字节未改变；渐变简化效果不等于 PNG 的玻璃折射。

构建只复制当前 `public/` 资源，完整 raster/vector 归档及预览均未进入 `dist`；没有向任何小游戏登记这些素材。生产 TLS、公开资源 SHA256、条件请求缓存和发布 SHA 在实际上线后另记。
