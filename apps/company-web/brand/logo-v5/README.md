# 能工智人 Logo 素材包（批准第五版）

## 使用

- 官网无字标：png/logo-symbol-512.png（512×261，透明背景）；较大展示用 1024 或 2048 版本。
- 带字标：png/logo-lockup-1024.png（1024×725，透明背景），中文为「能工智人」。
- favicon：icons/favicon.ico，内含 16、32、48、64、128、256 方形帧。
- 独立方形图标：icons/icon-\*.png（透明留白，保持原图宽高比）。
- Apple touch：icons/apple-touch-icon.png，180×180，白色背景。
- PNG 文件名数字表示宽度；icons 目录数字为方形边长。不要用 CSS 拉伸，请保持宽高比。
- masters 是统一源母版；所有尺寸均由这两份母版等比派生。
- qa/contact-sheet.png 展示白底、深底与带字版；qa/favicon-contact-sheet.png 每行从左到右为 16、32、48、64、128 实际像素图标。

## 保真与限制

本包从用户批准的第五版展示图直接裁切主标与中文字标并建立透明蒙版，没有采用生成式重绘结果。N 与右侧星的原始相对位置、比例和主体颜色保持；保留区域的完全不透明 RGB 像素已与原图逐点比较一致。蒙版去除了展示背景和地面阴影，边缘作小范围抗锯齿清理。

无字母版为 960×490；带字母版为 960×680。1024/2048 版本是由该母版高质量放大，并非原生高分辨率绘制。素材为栅格 PNG/ICO，不是矢量。玻璃内部高光来自白色展示环境，背景已透明但不模拟随背景变化的实时透射。

16px favicon 中星为少量橙色像素，无法完整表现四角和玻璃细节；32px以上更易辨认，64px以上更适合展示星形。未为小图改动或夸大星号，以免改变已批准图形。将来若需要极小图标的专用简化版，应另行确认。

文件尺寸、字节数及 SHA-256 见 manifest.json。未涉及商标查重或字标字体授权结论。
